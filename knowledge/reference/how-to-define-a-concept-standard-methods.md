# 概念を定義するときの標準的な作法（類と種差・定義の種類・概念分析・項目の型・四原因）

**事実**: 一つの概念を公開文で定義するとき、標準的な作法は五つに集約でき、それぞれが文書の別の部分を担う。一文定義は「上位概念＋区別する特性」、定義の身分は記述的／規定的／解明的／直示的のどれかを決め、本文は定義属性・モデル事例・先行要件と帰結・類似と反対の事例で肉付けし、章立ては百科事典の項目の型（定義→語源・来歴→特徴→種類・例→関連概念との比較→関連項目）に沿わせ、「視点ごとの記述」は四原因（質料・形相・作用・目的）を下敷きにできる。

**確認日**: 2026-11-04（pd#144「Love駆動開発とは」第四稿の骨格を組むときに調べた）。

## 作法の一覧

| 作法 | 中身 | 文書のどこを担うか |
|---|---|---|
| **用語学の規格 ISO 704**（Terminology work — principles and methods・2009/2022） | 概念は特性の束。定義は**上位概念＋区別する特性**（内包的定義）が基本。本質的特性と区別特性を分ける。概念どうしの関係（上位・下位／部分／連想）で体系に置く | 冒頭の一文定義（類＋種差）。関連概念との位置関係（上位・部品） |
| **哲学の定義論**（SEP「Definitions」） | 定義の種類＝記述的（既存の用法に合う。反例がないことが妥当性）／規定的（新しい意味を与える）／解明的（中心の用法は保ち周辺は規定）／直示的（例を指さす）。実在的（本質）と名目的（語の意味） | 定義の身分を決める。造語や既存語の転用は多くが**解明的**。例を指す直示も併用できる |
| **概念分析**（Walker & Avant・8 段階） | 概念の選択／目的／用法の洗い出し／**定義属性**／**モデル事例**／境界・類似・反対事例／**先行要件と帰結**／経験的指標 | 本文の肉付け。定義属性の箇条書き・モデル事例・先行要件と帰結・類似と反対の事例（対比の章） |
| **百科事典の項目の型**（Wikipedia MoS 導入部） | 第一文は簡潔な定義。導入部は本文の要約。本文＝語源・来歴／特徴／種類／例／関連概念との比較／批判／関連項目 | 章立ての骨。来歴の章・比較の章・関連項目 |
| **四原因**（アリストテレス『自然学』。何でできているか・どんな形か・何が動かすか・何のためか） | 一つの物事を複数の「なぜ」で記述する古典の型。質料・形相＝内在、作用・目的＝外在 | 「構造・プロセス・原理・視点」のように視点ごとに書くときの下敷き（構造＝形相・プロセス＝作用・原理＝目的・視点＝観測の構え） |

## 使い方（pd・cs・ks・as の READER で）

1. 一文定義を「〜のうち（類）、〜である局面・もの（種差）」の形で書けるか確かめる。書けなければ類が決まっていない。
2. 定義の身分を決める。既存語の転用（Love駆動開発・欠損駆動思考など）は解明的＝中心の用法は保ち、周辺を規定する。
3. 来歴の章は、発見の過程そのものを流れとして要約する（pjdhiro「駆動源の発見までの過程…この流れは大事」）。
4. 定義属性は本人の記録に出所がある特性だけを並べる。モデル事例は本人の体験の一文。
5. 対比の章は「代わり」「対立」で書かず、類似と反対の事例として並べる（二元論にしない。`.claude/rules/writing-stage.md`）。
