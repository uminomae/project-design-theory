## 1. 光円錐 — 見えている空間は、過去の光

**何か（第一段）**: 一点（今ここ）から出る光・届く光の面。上が未来光円錐（行ける先の全部）、下が過去光円錐（見えているものの全部）、水平の面が「現在」（届かない・理屈で引く面）、円錐の外が空間的に隔たった「今あそこ」。ミンコフスキー 1908。

**一文の候補**（【私】＝pjdhiro の言葉）:
- 【私】私が空間と思っているものは過去の光（§20）
- 【私】現在という空間はゼロに等しいサイズ（§19）
- 【私】今、ここ、の空間は光が追いつかないから認知不可能（§19）
- 【私】今の空間は理屈でしかない（§20）
- 【私】時間とは素朴に感じる空間の正体である（§19）
- それで駆動するとは、過去の光に駆動されること（§20・本人「キャッチー」）

## 2. 虚軸 — 感じていない方に i を付ける

**何か（第一段）**: ミンコフスキー／ポアンカレの x₄ = ict。時間は「i を掛けた空間の座標」で、四次元のピタゴラスが成り立つ。時間と空間のどちらにマイナス（i）を付けるかは約束で、物理は両方の流儀を使う（符号 (−,+,+,+) と (+,−,−,−)）。不変なのは「二つは 90° で隔たる」ことだけ。現代の一般相対論は ict を捨てて符号で書くが、場の量子論は t → −iτ（Wick 回転）を日常的に使う。

**一文の候補**:
- 【私】現在という空間はゼロに等しいサイズ。まるで虚軸です（§19）
- 【私】質量は時間で虚軸で Love かもしれない（§19・本人が取った軸）
- 時間とは、進むのを止められない方向。空間とは、行くか行かないかを選べる方向（§16）

**たとえ話の候補**:
| たとえ | 中身 | 印 |
|---|---|---|
| 符号は約束 | 感じている方（時間）を実軸に、感じていない方（現在の空間）を虚軸に置く流儀と、物理の ict は、i をどちらに付けるかの違い。「90 度ずれた認識」（§7）はこの差 | 第一段 |
| 虚軸の性質 | 実在し、構造を持ち、直接は見えず、体験上のサイズはゼロ、差（位相のずれ）としてだけ効く | 第三段 |
| ブラックホール | 地平面の内側では r が時間の役（必ず減る）・t が空間の役＝虚軸の値が半径という空間のような概念になる。虚時間が周期的でないと幾何がなめらかにならず、その周期が温度（Gibbons–Hawking 1977） | 第一段／第二段 |
| 届かない・避けられない | 外から見れば地平面に届かない（無限の時間）。内から見れば中心は避けられない（有限の固有時） | 第一段 |

## 3. 回転の掛け算 — i を掛ける＝90° 回す

**何か（第一段）**: 複素数に i を掛けると 90° 回る。ローレンツ変換は (x, ict) の面の回転（双曲回転）で、空間の向きを普通の回転で時間の向きには回せない（光の線には届かない）。四元速度の大きさは誰でも c で、時間と空間への配分は速度で変わる。質量は、その向きを回すのに要る押しの大きさ（傾けにくさ）。

**一文の候補**:
- 【私】非二元性という言葉が指し示すものはゼロ回転のイメージでほぼ結論づいてる。☯️のような（§19）
- 【私】光が時間がとまり空間が止まれない。質量が大きいと空間が止まり、時間が止まれない（§19・精度＝質量があれば）
- 回っていると中心は空になり、回っていないと中心は満ちる（§16）
- 弱いのに最後に勝つのは、符号が無いから（§16）

**たとえ話の候補**:
| たとえ | 中身 | 印 |
|---|---|---|
| ゼロ回転＝止まっていること | (x, ict) 面の回転角ゼロ＝四元速度が時間軸に全部向いている＝being に全振り（§2）。☯️の二つの半分が一つの円 | 第一段＋第三段 |
| 質量＝傾けにくさ | m → ∞ はどう押しても回らない（時間軸に固定）。m = 0 は止まれない（光の線に固定）。質量＝向きがゼロ回転にどれだけ留められているか | 第一段 |
| 光の対 | 空間ゼロ・時間無限の候補＝止まっている質量（有限）／ペンローズ図の i⁺（質量の世界線は一点に、光は面 ℐ⁺ に終わる）／定常状態（ΔE = 0 ⇒ Δt = ∞） | 第一段 |
| 1s と励起 | 回っていない 1s は中心で密度最大（無でなく無方向）。回る p・d は偏り＝励起（§2） | 第一段 |

## 4. 入口に据える順（候補）

光円錐（天体の図 → レイトレーシング → ラグ）で「見えている空間は過去の光」を入れる → 現在の面が虚軸のように見えることから虚軸へ → 面の傾きを回すのがローレンツ変換、傾けにくさが質量、で回転の掛け算へ。三つは一つの図の上で順に出る。
