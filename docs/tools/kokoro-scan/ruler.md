## 物差し（要点）
1. 物事が生まれるときは、場→波→縁→渦→束 の形を通る。波と縁は、差が分かれ、異なるものがぶつかる段。渦は、二つが見分けられるのに一つのようにまとまること。包むには、先に分ける段が要る（☯️ であって ⭕️ ではない）。分ける段のない包み方は曖昧さになり、「ぎりぎり嘘は言っていない」ことが起きる。
2. 人の心は、思ったほど立派にできていない。信頼・愛・共感の感じには、本人に見えない発生源（転移・投影・理想化）と、心を守る働き（防衛機制：否認・合理化・理想化など）が入り込む。
3. 同じ言葉が、受け取る人・使う人の発達の段階で、前へ進める言葉にも、手前へ引き戻す言葉にもなる。引き戻している側も「理想どおりにしている」と言えてしまう（合理化）。
4. Love と呼びたいものは、良い側だけに限らない。善悪の判断を持ち込まない。良い面だけを選び、逆の面を切り離して固定するのは理想化。
5. 規範が成り立つには条件がある（長く勤める雇用・人が重なって働く職場・時代など）。条件が書かれないと、条件の無い所でも同じ言葉が使われる。
6. 人は環境をコントロールしきれず、将来は予想しきれない。それを前提にしない言葉は、思いどおりにならない側を論の外に置く。
7. 不安を煽る言葉や期待を煽る言葉（バズワード）は、他者が心に入り込む入口になりやすい。
8. 近い心の働きが、一つの言葉や一つの施策の中で取り違えられ、すり替えられると、論の芯がずれる。語の数には出ない脆弱性で、診断の中心に置く。語として書かれていなくても、文章が人に求めている心の働きが何かで見る。見る型は、下の「よくある誤解（台帳）」に溜めてある。台帳に無い取り違えも、同じ形なら拾う。

## よくある誤解（台帳）
文章の中でこの形を見つけたら、取り違えとして拾う。各項は「誤解 → 区別」の順。★は pjdhiro の言葉から来たもの。出典は repo の中の場所（読み物・規約）。この台帳は、セッションの終わりに足していく。

### メタ認知・視点・共感
- ★ メタ認知を、他者の視点を取ることだと思う → メタ認知は自己の対象化（自分の考え・感情・価値観を対象として見る）。他者視点取得（相手の立場から見る・相手から自分がどう見えるかを見る）は別の働きで、ある発達段階には成長、その段階に到達している人には停滞になる。文章では、他者視点取得は「〜と思われる不安」「周囲を気にする」「相手の立場に立つ」「相手の発言を要約して返す」「読んだ人はどう思うか」の形で、自己の対象化は「自分の考えや感じていることに気づく・観る」の形で出る。くわしくは読み物の独立ページ「メタ認知とは」（https://uminomae.github.io/project-design-theory/reader/metacognition.html）（読み物 Love駆動開発・発達段階とは・メタ認知とは／stance 2026-11-22）
- 相手の視点に立って推し量ること（視点取得）を共感だと思う → 視点取得は、自分が感情の状態にない点で共感と分けられてきた（共感とは）
- ★ 共感を、境が消えて一つになることだと思う → 融合・投影・逆転移・鏡転移・情動伝染も「共感した」に見える。同じ語が、自分と相手の境の持ち方の違う人のあいだで違うものを指す。共感は、侵入される不快を伴うフェーズを経て使いこなせるようになるスキルかもしれない（共感とは／stance 1-1）

### 信頼・安心・理想化
- ★ 信頼と、信仰・期待・理想化を分けずに書く → どれも本人には「信頼」と感じられる。分けられるかは感情をどこまでメタ認知できるかによる。逆らえない上司への「信頼しています」は、従えば守られることを指すことがある（Love駆動開発の第四部／stance 1-3）
- 良い面だけを見て預けることを信頼と呼ぶ → 良い面だけを選び逆の面を切り離すのは理想化（Love駆動開発「理想化と信頼は、どう違うのか」）
- 安心と信頼を同じものと書く → 仕組みに頼る安心と、人柄を見込む信頼は、根拠の違う二つの期待（山岸。安心とは）。「安心はいつも良いもの」も誤解（安心とは）
- ★ 同じ「安心」でも、防衛を下ろすための安心と、保身・日和見のための安心を区別しない → 後者は心理防衛による依存のような状態で、知らせから守られ続ける条件として求められると、防衛を保つ側に働く（Love駆動開発・安心とは）

### 心理的安全性
- ★ 心理的安全性を、一人の内側の能力・資質・状態として扱う（育てる・測る・引き出す） → 原典はチームで共有された信念。集団の信念が個人の水準の概念にすり替わりやすい（Love駆動開発「事業の言葉は、どこで誤解されるか」・心理的安全性とは／stance 4）
- ★ 心理的安全性を「自分自身の安心・安全」のことと読む → 利己的に振る舞うための都合のよい解釈になりうる（心理的安全性とは）
- ★ 安全を身の安全・罰されないことと読む → 「心理的に安全であって、生物的に安全ではない」。重きは弱さや惨めさへの防衛にある（心理的安全性とは）
- ★ 罰を恐れずに済むこと（低次の欲求のケア）だけを残し、信頼され尊重されることを落とす → 原典は両方を包む。現場では確かめやすい前者だけが使われやすい（Love駆動開発・心理的安全性とは）
- 心理的安全性を、優しさ・厳しさの無さ・居心地のよさと思う → 気の緩んだ放任でも居心地のよい場でもない。課題や異論や恥に向き合えることと、不安が無いことは別（心理的安全性とは）
- 「何でも言ってください」と宣言すれば作れると思う → この信念はふつう暗黙のもので、尊重と信頼から生まれる（心理的安全性とは）
- ★ 高いほど良く、どこでも要ると思う → 条件付きで効く。軍隊型の組織では低いほうが機能するかもしれない（心理的安全性とは）
- 脅威を取り除けば安全だと思う → 脅威が無いことと、安全の合図があることは同じではない（心理的安全性とは）

### 不安・防衛・葛藤
- ★ 不安を、安心の反対・弱さや病気の印・消すもの・鎮めるもの・無いほうが良いものとして書く → 不安は大事な感情で、安心の逆でもない。不安を「ポジティブ思考」などで消す話と、不安を対象として見る話は別（不安とは／stance 1-3）
- 不安と恐怖を一つの軸に並べる → 別の感情（stance 1-3）
- 防衛は弱い人や病気の人だけが使うと思う → 成熟した水準の防衛も防衛で、防衛の無い状態は描かれていない（心理的防衛機制とは）
- ★ 葛藤を、善悪の二分や悪いものとして扱う → 葛藤に善悪は無い。二つのことの対立を心理的な印象で善悪判断するので誤解が多い。創造の直前の衝突でもある（Love駆動開発）

### 粘り・立ち直り・動機
- ★ GRIT を我慢や根性と読む → 忍耐は分解されていない。侘びに近い、諦念と受容の柔らかい忍耐もある（Love駆動開発）
- ★ レジリエンスを、折れない個人の強さとして書く → 研究は本人の力と周りの支えで起きる立ち直りの流れとして書く。pjdhiro の見方では、立ち直りは防衛を外す自己受容による自己刷新（Love駆動開発）
- ネガティブ・ケイパビリティを、我慢の力や決めない態度と読む → 原典には耐えることや努力の語は無い。不確かさの中にいられること（Love駆動開発）
- ★ 内発的動機を、理想状態の一面（良い側）だけで書く・性格や資質として見る・内発か外発かの二択で見る → 保身の嘘を楽しむ動きも内発的動機に入る。誤解の理由は善悪判断が入ること。打ち込む姿は防衛からののめり込みと同じに見える。理論は、人と活動の間にもあると書く（内発的動機とは）

### 組織・プロジェクトの言葉
- 心に関わる経営の言葉が、関係や場のことなのに、人の内側の能力・資質として受け取られる（総論） → 誤解は見ている視点の違いのところで生まれる（Love駆動開発「事業の言葉は、どこで誤解されるか」）
- ★ 「グループと一つになる」を、専門を手放さずに大きな目的で働く向きでなく、集団への所属として使う → 使う人の段階が手前だと、専門に深まった人を引き戻す言葉になり、引き戻す側は理想どおりと言えてしまう（野中の読み物）
- 包むことを、混ぜること・曖昧にすることと同じに書く → 包摂には先に分けることが要る。曖昧と包摂は違い、融合と包摂も違う（stance 1-2）
- ★ 手順を決めればコントロールできると書く → 手順というのは支配欲で、支配できないものへの対処には構造とプロセスを当てる（stance 1-3）
- プロジェクトを率いる人を、先の像と構想と計画を持ち、不確実性を予測と信念で貫く力強い人として描く → 現場に行って判断し適応する、を再帰的にくり返す単純な過程かもしれない（stance 1-3）
- 構想や計画はいつも要ると書く → 意味がない・逆効果・不要・必要のどれもある（stance 1-3）
- 意思決定を、決定ツリーの全探索（予測できる未来から選ぶ）だけで書く → 起業家は入れ子の深さ優先探索のように、目的を変えながら進む（stance 1-3）
- ★ 構想を叡智としてだけ書く → ただの心理防衛として働くこともある（Love駆動開発）
- 価値は商品に埋め込むもの、クリエイターが生むものと書く → 価値は受け取る人の意識で生まれる。込めることと感じることは一続き（Love駆動開発）
- 善とされたものを、いつでも善いものとして書く → 善とされたものは条件付き（stance 1-2）

## 見る問い（当てはまるものだけを選ぶ）
- 取り違えていないか：近い心の働き（上の 8）が、一つの言葉や施策の中で取り違えられ、すり替えられていないか。文章が「何をせよ」と求めているときに、それがどの働きを求めているかを確かめる
- 歯止めがあるか：その言葉を手前の段階の読み（融合・おせっかい・理想化や期待・派閥の価値観）に置き換えても、筋が通ってしまわないか
- 分ける段があるか：包む側・良い側だけが残っていないか。落ちているのは、心が思いどおりにならない側ではないか
- 誰の段階で読まれるか：言葉の向きと使う人の段階が合わないとき、引き戻しに使われても理想どおりだと言えてしまわないか
- 条件が書かれているか：その規範が成り立つ条件が、規範と一緒に書かれているか
- 仕組みで答えているか：問題への答えが、過去の例と望む姿だけになっていないか
- 分けることに値打ちがあるか：集団に馴染まない・専門に深まる動きに、値打ちが置かれているか
- 誰に心地よいか：変わらずにいられる人に心地よいことが、支持の理由になっていないか
- 煽っていないか：不安や期待を煽って、読む人の判断の前に入り込んでいないか

## 手本
野中郁次郎の知識創造の論文をこの物差しで読んだときの芯：駆動するものを人の内側に置く点で、Love駆動開発と同じ所を見ている。ただ、共感・愛・ケア・信頼・共通善の五つの言葉は良い側だけで書かれ、ぶつかりと心の守りの話が抜けている。そのため同じ言葉が、読む人の守り方と段階しだいで逆の向きにも働く。向きは「悪いのではなく、言葉足らず」。
