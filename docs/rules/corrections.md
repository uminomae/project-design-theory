# Claude が繰り返す誤りの型

対話や執筆の前に一巡する。自分の案がどの型に当たるかを見る。今までの repo の「指摘の台帳」（2025〜2026-11 の事例 90 件ほど）から、型だけを取り出した。型ごとの代表例（事例と pjdhiro の言葉）は `corrections-examples.md` に、型 K の作業の種類ごとの確認は `corrections-k.md` に、型 R・G の確認のうち決まった作業のときだけ要る文は `corrections-rg.md` に、繰り返しの記録は `corrections-repeats.md` に分けてある。分けた四つは毎回は読まない。その作業のときに、当たる行や節だけを読む（この文書は毎回読む）。新しい指摘を受けたら、同じセッションで型を足すか、型の確認を直す。足すときは、まず既にある行に溶かせるかを見る。

| G 読み違い | 本人の言葉を条件文・断定・一般論に言い換える、条件を落とす、焦点をずらす、例の一つを規則にする、たとえの芯を取り違える | 趣旨を保つ。「など」の一例を規則にしない | 趣旨は本人の言葉と一致するか。読みは本人に確かめたか。指示の言葉（「作ってしまう」など）を、自分のなじんだ作業の型に読み替えていないか。「再検討して」「考えて」を、書き換えの指示と読んでいないか。案を示してから直す（2026-11-09・Love駆動開発の三章の趣旨を考えてと言われて先に書き換え、見出しの仮の言葉まで本文に入れた）。定義は、正本の文と一字ずつ照らしたか。本人の見立てや例を一つ取り出して、問いや結論の芯に置いていないか。本人の文に「少なくとも」「一つは」の印が無くても、周り（「どの面も一面」など）を見て、本人が多種類を探している前提で候補を複数の形で書いたか（2026-11-09・ks の調査の問いで、臍の緒の安定を欠けの基準として一つだけ置き「それは一つです。他の可能性もあるし、多種類あると思って探してます」）。本人が借りた古典の語（指月 など）は、一般の意味で読む前に本人の記録での使い方を確かめたか。本人の指摘から決まりを作るとき、その指摘が困っていたこと（どのページで、何が起きたか）を添え、別の場面へ当てる前に、同じ困りごとがそこで起きているかを見たか（難しさの話を、判定を厳しくする規則に変えない）。問いを立て直すとき、本文の言い換え（「問いは、構想の手前で働いている駆動源」など）でなく、本人の問いそのもの（「私は何に駆られてプロジェクトを行うのか」）に戻ったか（2026-11-09・言い換えから第四部「最初の問いに戻る／構想」を立て、「そこに問いは置いてないよ」）。見た目の依頼の「抽象的」「意味深」を、物理の対象をそのまま描いた図（ブラックホール・銀河の絵）に読み替えていないか（2026-11-10・Love駆動開発の背景の見本に「かっこ悪い」）。物理の語と時間の尺度の語を書くときの確認は `corrections-rg.md` の G3 |

## 繰り返し

同じ型の誤りを、前に指摘されたあとでまたしたときに、ここに日付を足す（pjdhiro 2026-11-09・セッションの終わりの振り返りを問われて）。確認の文を足すだけでは、表の欄が長くなって一巡で読めなくなり、同じ誤りが続く。だから次のように決める。

- 1 回目の指摘：その型の「書く前の確認」を直す（今までどおり）。
- 2 回目から：確認の文をさらに足さない。次の二つのどちらかをする。
  - 機械で止められるものは、仕組みに移す（`scripts/check.sh` の検査・`.githooks/`・`scripts/` の補助など）。移したら、確認の文はその仕組みの名前だけにする。
  - 機械で止められないもの（読み違い・範囲の狭め など）は、確認の文を書き直す。足すのでなく、なぜ前の文で止まらなかったかを見て、置き換える。
- 数え始めは 2026-11-09。それより前の繰り返しは、表の文に「にも繰り返した」とあるものだけを入れた。

繰り返しの行は `corrections-repeats.md` の表に足す（型 K は `corrections-k.md` の「繰り返し」）。毎回は読まない。繰り返しを足すとき（セッションの終わり）と、ある型の確認の文を直すときに、その型の行を読む。2026-11-10 に、表をここから移した（毎回読む分を小さくするため）。回数（2026-11-10 まで）：B 1・C 1・G 5・R 6・K 16。

型 K の確認は 30 項目を超えて一巡では読めなくなったので、2026-11-10 に作業の種類（K0 どの作業でも・K1 git とサンドボックス・K2 生成・検査と数え直し・K3 画面・K4 調べと記録）で分け、`corrections-k.md` に置いた。
