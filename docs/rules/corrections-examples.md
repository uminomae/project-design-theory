# 誤りの型ごとの代表例

`corrections.md` の型ごとに、事例と誤りの起きた形を残す。2026-11-08 に `corrections.md` から分けた（毎回読む分を小さくするため）。公開文を書く・直すとき、当たりそうな型の行を読む。毎回は読まない。代表例は型ごとに一、二件に保ち、足すなら入れ替える。2026-11-08 に 45 件から 26 件へ戻した（外した事例は git の履歴に残る。学びは `corrections.md` の「書く前の確認」に溶かした）。

型だけでは伝わりにくいニュアンスを、事例の誤りの起きた形（何が起き、どこがずれていたか）で残す。今までの project-design の台帳（`develop`・2026-11-07 時点、事例 90 件ほど）から、型ごとに一、二件を Claude が選んだ。Issue の番号・ページの細部・非公開の repo に触れる事例は外した。pjdhiro の発言の原文と、それが出た場面は写さない（2026-11-28。前は言葉の列に原文を置いていた）。選び方は pjdhiro が確かめる。
