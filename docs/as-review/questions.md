## 回答が満たす条件

一つの論点の回答は、次の全部を満たしたら「満たした」とする。満たさない所は、次の周の調べの対象になる。

1. 既存の知見がどう言っているかを、立場ごとに並べている。支える立場と、反対・批判の立場の両方がある（`sources.md` §1-5）。一つの立場に絞って答えにしない（群盲象・stance 1-1）。
2. 根拠にする研究は、原典の本文を読めたもの（本文照合済）。要旨・二次資料・書籍で読めていないものは、回答の根拠に数えず、そう書く（`sources.md` §3-3・判断 2 の答え）。
3. 分かっていることと、分かっていないことを分けて書く。探したのに当たらなかったことは、探した語と場所を添えて「当たらなかった」と書く。
4. 体験の記述（as の公開ページの pjdhiro の言葉）と、構造が似ているところ・食い違うところを、Claude の読みとして書く。体験を研究の語で言い換えない。研究で体験を説明したことにしない（型 A）。
5. 用語の違いを書く。脳のモデルの「予測」「予測誤差」（prediction・prediction error。意識し得ないレベルの過程の語）と、欠損駆動思考の「予想と現実の誤差」（それを意識が「欠け」として捉えた主観的経験。ks の公開ページの欠損の定義）は、厳密に分ける。脳のモデルの話では「予想」「誤差」だけの言い方をせず「予測誤差」と書き、二つを結ぶときは、同じものと読める書き方をせず、別のもののあいだの関係として書く（pjdhiro 2026-11-10「予想と誤差は欠損駆動でも使う言葉なので、そこは厳密に分けて」）。同じ語が研究ごとに違うものを指すとき（awareness・consciousness・meta-awareness など）、原典の語のまま並べる。
6. pjdhiro が判定すること（しっくりくるか・採るか）を、判定を仰ぐ形で残す。Claude が答えを決めない（型 L）。
7. 文は `writing.md` に従う。as は神経現象学の研究を材料として調べるが、as そのものが神経現象学として成り立つわけではない（README「中心の問い」）。

## ループの回し方

一周は、**レビューする → 足りないところを調べる → 書く → レビューする**（stance 2-5 のループの言い方）。

1. 論点ごとに、今ある記録（A01〜A03）と資料から回答を書いてみる。書けないところは見出しだけ入れて工事中にする。
2. 回答を、上の条件と README「記録の品質の点検」の人の目の項目でレビューする。レビューは、書いたのとは別のエージェント（コンテキストを分ける）にも頼む。
3. 満たさない所を並べ、調べる。足りない領域（A04〜A07）は、計画の領域の手順（`prompts.md`）で一つずつ回す。論点に要る論文だけを狙って探すときも、照合の決まりは同じ。
4. 回答を書き直す。2 に戻る。
5. 論点ごとに、条件を全部満たしたら「満たした」とし、pjdhiro の判定を待つ形にする。

止めどころ：条件を全部満たした、または、探せる経路を全部試して当たらなかったことを書いた。周を重ねても進まない論点は、何が足りないかを書いて pjdhiro に見せる。
