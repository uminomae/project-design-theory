## なぜするか

as の公開ページは、神経現象学を「調べ始めたところ」と書いている。Love駆動開発の骨格では、神経現象学と心理学が、Love と呼びたいものを指す群盲の一つとして並ぶ。ただし「意識とは」は神経現象学などを参考に組み立てたもので、論そのものは神経現象学から見たと言えるほど精査していない（pjdhiro 2026-11-09・stance 2-4）。このレビューは、その精査に当たる。

2026-11-09 に一読して分かった今の状態（この計画の出発点。記録は本体の `.cache/session/log-20261109-as-research-review.md`）：

1. 神経現象学の読み（`as/evidence/review/layer0-interoception-reading.md`・`layer1-prediction-error-reading.md`・`first-person-vs-third-person.md`・`neurophenomenology-design.md`）は、読んだ対象が欠損駆動思考の旧資料と ChatGPT のレビューで、神経現象学の論文を読んでいない。
2. 論文の名前と書誌が出てくるのは `band-signal-source-reading.md`（2026-11-03・#16）だけで、照合は Crossref の書誌と要旨まで（要旨照合済）。記憶から挙げた候補であること、頁を取れていないこと、食い違う知見を正直に書いている。この形は使える。
3. 神経現象学の芯の一人称の方法（体験の記述と神経の測定を互いの制約に使う、体験を聞き出す面接、内観の信頼性の議論）の文献が、as に一つも無い。ks のレーン 2 の報告（`ks/docs/issues/survey-216/lane2-neuro.md`・2026-11-02）が候補を挙げ、#36 に渡してある。
4. 心理学の読み（`attachment-safe-base-reading.md`・`trust-and-intersubjectivity-reading.md`）も、対象は as の概念ノートと旧資料。Bowlby などは名前だけ。
5. as から開ける学術版の報告（当時は pjdhiro の repo の `assets/awareness/guides/ja/md/awareness-academic.md`。2026-11-11 に `as/archive/guides/` にしまった・2026-04-09・「意識と間主観性」）は、核心仮説を支える研究を集める向きで組まれている。書誌の誤り（Cole 2007：209 遺伝子・N=14 の論文は Genome Biology 2007 の 10.1186/gb-2007-8-9-r189 で、報告の題と誌は別の論文が混ざっている。Crossref で確かめた）、書誌の取れない文献（van Heijst ら 2025）、確かめようのない反証の条件、別の問いを調べた cs の 30 分野を「反証なし」の根拠にする所がある。

### 中心の問い

as の目標は、意識とは何かを言えること。意識と気づきの違いを定義できるようにすることは、その目標に届いたかを確かめる、内部のテストのような目標（pjdhiro 2026-11-10・「判断が要ること」4 への答え「意識と気づきの違いを定義できるようにすることがas/の目標ですね」と、同じ日の入口の案のページへの答え「内部的な目標だよ。目標は意識とはを言えることだよ。目標達成のテストのような目標だよ。気づきとの違いが言えないと意識という言葉の輪郭が曖昧だよね」）。入口や機械向けの案内で、看板にしない。このレビューは、その材料を原典で確かめて集める。

as は神経現象学の研究を調べるが、as そのものが神経現象学として成り立つわけではない（pjdhiro 2026-11-10「神経現象学の調査をすることと、as/が神経現象学として成立することは全く違うよ。誤解しないように入れておいて」）。記録・公開ページ・計画で、二つを混ぜて書かない。

「**pjdhiro が体験として書いていることについて、神経現象学と心理学は何を確かめ、何を確かめていないか。原典で確かめて並べる**」。

- 研究は、pjdhiro の体験を説明する根拠ではない。体験が先で、研究は共通語として借りる（stance 1-4）。研究を論拠に演繹しない（stance 1-1・`sources.md` §1-3）。並べるのは、体験の記述と構造が似ているところと、食い違うところ。似ているか、しっくりくるかの判定は pjdhiro が行う（stance 2-1・型 L）。
- どの研究も一面（群盲象）。一つの研究で体験を言い当てたことにしない。
- 生存と信頼の二つの値は pjdhiro の見立てで、検証の対象であって前提ではない（`as/PROJECT.md`）。見立てを勝たせるために、支える研究だけを集めない。反対の知見と批判を同じ重さで探して並べる（`sources.md` §1-5「直接示した研究には当たらなかった」と書けることも成果）。
- 一人称の記述（どう経験されているか）と三人称の記述（測ったもの・計算論の語彙）を分けて書く。この区別は as の今の原則（`first-person-vs-third-person.md` §6）にあり、神経現象学の考え方とも合うので引き継ぐ。ただし、二つの重さの置き方は違う。as の原則は一人称を本論、三人称を参照枠と置き、神経現象学は二つに同じ重さを求め、三人称のデータが一人称の記述を直すことも相互制約に含める（A01 の記録の判定 6・2026-11-09）。どう並べるかは「判断が要ること」3。

## 調べ方（一つの領域）

研究論文の文献調査として足りるように、cs の手順（`docs/cs-review/README.md`「調査の手順」）に、次の四つを足す。

1. **探し方を記録する**。どこで（Crossref・OpenAlex・PubMed・Europe PMC・PhilPapers・Semantic Scholar・Google Scholar）、何の語で、いつ探し、何件から何を選んだか。選んだ理由と、外した理由。第三者が同じ探し方をなぞれるように書く。
2. **総説とメタ分析から入る**。その領域の今の到達点（総説・メタ分析・系統的レビュー）を先に読み、個々の研究はそこから辿る。古典は、引かれている形でなく原典で確かめる。
3. **反対の知見と批判を同じ重さで探す**。その論への批判・追試の失敗・論争を、論ごとに一つは探す。見つからなければ「探した語と場所で当たらなかった」と書く。
4. **研究の型と厚みを書く**。論ごとに、研究の型（理論・総説・メタ分析・実験・観察・事例・一人称の報告）、人数（実験なら N）、追試の状況、動物か人か。`sources.md` §1-3 の実証の厚み（経験則・実証済み・見送り・仮説）を添える。

そのうえで、cs と同じに：

5. 論ごとに、URL があるかダウンロードできる一次情報を探して読む（`sources.md` §2-5・§5）。`bash scripts/find-source.sh` を使う。確かめ先（URL・DOI）と読んだ頁を残す。
6. 照合の状態は `sources.md` §3 の四つ（本文照合済・要旨照合済・二次資料のみ・未照合）。写しの性格（著者稿・授業の写し・個人が上げた写し）は cs のレビューの「規約で決めたこと」に従う。
7. 既存の as の資料と学術版の主張を、原典で確かめて判定する。判定の語は cs と同じ（一致・言い過ぎ・取り違え・帰属違い・付け足し・抜け・未判定）。
8. 兄弟の記録（cs の `cs/evidence/evidence-Dxx-*.md`）で本文照合済の文献は、読み直さずに参照する。

一つの論の中で深く照合するのは、(a) 体験の記述と並べるところ（何を測り、何を記述したか）、(b) 人名・年・数・書誌、(c) as の公開ページ・学術版・Love駆動開発が引いている文。それ以外は照合の状態を付けて残す（stance 2-6「網羅しようとしない」）。

## 記録の形

- 領域ごとの記録（公開する md）：`as/evidence/evidence-Axx-<slug>.md`。as のディレクトリごと公開される。文は `writing.md` に従い（教科書のような普通の文・断定しない・文末は「です・ます」）、冒頭に文責が Claude であることを書く。並び：
  1. 冒頭：この領域で分かったことと、分からなかったことを数文で。文責。
  2. 探し方：探した場所・語・日付・件数・選んだ理由と外した理由。
  3. 一面の表：論ごとに一行。列は 論・何を見たか（一人称／三人称、測ったもの）・研究の型と厚み・批判や反対の知見・似ている体験（番号）・食い違う体験（番号）・照合の状態。似ている・食い違うは Claude の読みで、そう書く。空でよい。 表に置くのは、本文を読めた文献が一本はある論だけ。本文を読めなかった論は、表の下の一覧と、論ごとの節の最後の「本文を読めなかった論」に分ける（2026-11-10）。
  4. 論ごとの節：要旨、確かめ先と読んだ頁、照合の状態、鍵の文（原文のまま短く・頁つき）、批判と追試、既存の as の資料と学術版から直したこと。
  5. 分からなかったこと・取れなかった原典。
- 原典の台帳：`as/knowledge/raw/manifest.md`（公開する。stance 2-7）。PDF は手元の `as/knowledge/raw/` に置き、git に入れない（`.gitignore`）。置き場は `sources.md` §8-2 とスキル `find-source`「取る」にも書いてある（2026-11-10）。台帳に足すのは司令塔。
- 保存を頼む PDF（自動で取れないもの）：#95 のコメントの表に、ダウンロード先と保存名を残す（stance 2-8）。
- UI：記録を as の画面から読めるようにする（「判断が要ること」1 の答え。2026-11-09）。
- セッションの記録：本体の checkout の `.cache/session/`。

## 記録の品質の点検

機械で見る（`scripts/check-as-evidence.mjs`。`scripts/check.sh` で回る。6 は `NODE_USE_ENV_PROXY=1 node scripts/check-as-evidence.mjs --crossref` で手で回す。2026-11-10）：

1. frontmatter（`file_id`・`area_id`・`title`・`last_updated`・`status`）。
2. 冒頭に文責が Claude であること。「## 探し方」「## 一面の表」があること。
3. 一面の表の照合の状態が `sources.md` §3 の四つのどれか。各行の照合の状態に「本文照合済」がある（本文を読めなかった論は表に置かない。「規約で決めたこと」の本文を読めなかった論の行。2026-11-10）。判定の列が決まった語で始まる。
4. 本文照合済・要旨照合済と書く節に、確かめ先（DOI・URL・台帳の行）がある。
5. 台帳の「使う記録」にその領域がある行ごとに、第一著者・年・題の頭・DOI が記録の本文にある（記録は台帳の番号を書かないので、番号では突き合わせない）。台帳の行の形（番号・照合の状態・取得の状況）。手元の絶対パスが無い。地の文の文末が「です・ます」。本文に領域・原典・分野の記号やパス・ファイル名が無い。
6. DOI を Crossref で引いて、題と年が記録と合う。

人の目で見る（司令塔が領域ごとに。エージェントの報告をうのみにしない）：

- 要の点を三つほど確かめ直したか（DOI を Crossref で、鍵の文を原典の本文で）。
- 反対の知見と批判を、論ごとに探したか。支える研究だけになっていないか。
- 似ている・食い違う体験の列が、体験の中身を研究の語で言い換えていないか。研究で体験を説明したことにしていないか（型 A）。
- 一人称の記述と三人称の記述が混ざっていないか。
- 「示した」「明らかにした」のような言い切りが、研究の型と厚みに見合っているか（型 E）。動物の研究を人に、相関を因果に、状態を段階に読み替えていないか。
- pjdhiro の見方を、公開の記録の本文に引いていないか（writing §7-5）。

## 判断が要ること

予想は stance.md から立てた、聞く前の予想。

1. 記録を as の画面から読めるようにするか。予想：する（cs と同じく。「これまでの記録」の畳みか、「調べてきたこと」の節から）。試しの一領域の記録を見せるときに聞く。**答え（pjdhiro 2026-11-09・確かめ用のページのコメント）：「する」**（予想どおり）。どこから開くか（畳みか節か）は、作る別セッションが cs の仕組み（`cs/evidence/reviewed.json`）に倣って案を出す。
   - 1-2. 一覧をどこに置くか（2026-11-10・確かめ用のページに二つの見本を並べた）。案 A：「調べてきたこと」の節に置き、畳まずに見せる。案 B：「これまでの記録」の畳みを開いた先頭に置く。予想：案 A（`writing.md` §5-6「最新の結論を分かりやすい位置に置く。古い結果は畳む」。畳みは「今の筋と合わない記述も残っている」と断って置いた場所で、照らし直した記録を入れると古いものと同じに見える）。 **答え（pjdhiro 2026-11-10・ページのコメント）：「はい。a」**（案 A。予想どおり）。
2. 学術版の三本（pjdhiro の repo）をどうするか。予想：照合が済むまで今のまま「これまでの記録」に置き、済んだら、本文を読めた研究だけで直すか、取り下げる。今の規約（`sources.md` §3-3）では、本文を読めていない出典は公開文に載せない。**答え（pjdhiro 2026-11-09・確かめ用のページのコメント）：「本文が読めたものだけ採用する。」** 学術版の出典は、領域の照合で本文を読めたものだけを残し、読めなかったものは外す。直すのは段 4「返す」で（予想どおり）。A01 では、学術版の題の「神経現象学…からの状況証拠」が言い過ぎと出た（§2 に神経現象学の方法を使った研究が無い。A01 の記録の判定 14・2026-11-09）。
3. as の原則「一人称が本論、三人称は参照枠」（`first-person-vs-third-person.md` §6・§8）と、神経現象学の「二つに同じ重さを求め、互いに制約する」（Varela 1996）を、どう並べるか（2026-11-09・A01 の判定 6）。予想：as の原則は保つ（体験が先・stance 1-4）。そのうえで、as の資料と公開ページに、神経現象学とこの点で違うことを書く（stance 2-6）。書き入れは段 4「返す」で。記録の形を見せるときに聞く。 **答え（pjdhiro 2026-11-10・ページのコメント）：「神経現象学の調査をすることと、as/が神経現象学として成立することは全く違うよ。誤解しないように入れておいて」**。as は神経現象学の研究を材料として調べるが、as そのものが神経現象学の方法（訓練した一人称の記述と測定の相互制約）で成り立っているわけではない。だから as の原則が神経現象学と違うことは、直すべき欠けではなく、as の立ち位置として書く。書く所：この文書の「中心の問い」、as の公開ページの「調べてきたこと」（記録の入口の段）、A01 の記録の判定 6 の中身。
