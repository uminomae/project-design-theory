## 5. evidence の退避（pjdhiro に聞かれて調べた）

- 意図的。手違いでも、git から外したのでもない。2026-04-07 の cs#207「原典アクセス再監査」の計画（`cs/evidence/investigation/original-access-rerun-plan.md`）の手順 1・2 どおり。

- 理由：原典を読まないまま、[P] の主張が強く見えている恐れ。LLM の補完が混じったまま verified / accepted を保つと、30 領域全体の信頼が崩れる（計画の「背景」）。退避した本文は「今の verified / accepted を正当化するためには使わない」（`pre-rerun-20260407/README.md`）。
- その後：pjdhiro の判断で、wiki をもとに evidence を作り直すことになった（cs#217 → #48）。2026-05-01 に作り直しの形式が決まった（cs#223）。D01 の試しの作り直しは 2026-08-17 時点で未着手のまま、方針は source-note をもとにする方向へ進んでいた（#48 のコメント）。stub のまま止まっている。
