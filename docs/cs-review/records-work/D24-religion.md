## 手順について分かったこと

- 古典の原文は、CBETA の API（cbdata.dila.edu.tw の juans）で JSON を取り、行の番号（頁・段・行）つきの翻刻として読めました。一つの巻を一度に取れるので、段を控えやすい。CBETA の作品ごとの句読点の性格（「AI」か「CBETA」か）が JSON に入っているので、記録に添えました。SAT は頁の本文を後から読み込む作りで、自動では取れませんでした。
- Internet Archive の図書館の走査（トロント大学・グラスゴー大学・ブリガム・ヤング大学）は、`_djvu.txt` で語を探し、`_page_numbers.json` で誌面の頁と走査の葉の番号を対応させ、`/page/n<葉>_w700.jpg` で頁の画像を取って確かめられました。対応は走査ごとに一つずれることがあり（Underhill・Waite）、画像の頁の頭の番号で確かめました。手元の文字認識の道具は使っていません。外へ送る文字認識のサービスも使っていません。
- 手元の PDF の表紙を見ると、Suzuki の走査に二つの版の十牛図が入っていて、精読ノートが読んだ「第 7〜10 図」は普明の頌の版でした（下の直しの表）。Otto は第 2 版の 1952 年の刷でした。
- 報告の論の芯にある原典（スーフィズムの訳・十牛図の頌・十地の経）は、どれも衝突と途切れる形を本文に書いていて、報告の §6 は調べた跡の題をそのまま写していました。人文系の古典の分野でも、本文に当たれる経路（パブリックドメインの訳と翻刻）は多くありました。
