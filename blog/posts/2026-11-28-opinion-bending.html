「どっちがいい？」を直角に曲げる

種 2026-11-28
  • #妄想
  • #感情
  • #信頼
  • #四元数

この記事は、プロジェクトの対人のスキル（建設的な対話など）を考えていた pjdhiro の思いつきに、Claude が付き合って書いた妄想です。

狩野英孝さんの「意見直角曲げ法」を感情処理の技法として見て、何が起きているかを見立て、支持できそうな心理現象を当ててみました。そこから置いた仮説は、当てた心理現象を、直交する二つの単位円のたとえで矛盾なくまとめて扱えるのではないか、というものです。

直角曲げは、二択を比べる線から降ろす

意見直角曲げ法は、狩野英孝さんがテレビ番組で紹介した会話のこつです。「どっちがいい？」と聞かれたら、一方を全力で褒め、すぐに向きを変えて、もう一方も肯定します。

「どっちがいい？」は、A と B を一本の線の上に並べて、どちらが上かを決める問いです。直角曲げは、A を横、B を縦に置き直します。直交する二つの向きは、互いの長さを削り合いません。

直角に曲げると、実軸では 0 になる

pjdhiro は、名前の由来を「実軸で +1 か −1 かという選択肢のようなものを、虚軸のコサイン 90 度に持っていくから、というのが命名理由なのだろう」と想像しています。単位円の上で 90 度回った点は、実軸の成分が cos 90° = 0 で、+1 にも −1 にも寄りませんが、長さは 1 のままです。

分断の痛みの時間を 0 にする

pjdhiro は、二択の片方を選ぶことには、分断の悲しみという小さな痛みがあると見ています。直角曲げは、その痛みの時間を 0 にしているのかもしれません。

pjdhiro の見立て

分断の痛みを予測する緊張と恐怖を、一方の選択肢の能動的全肯定でプラマイゼロにしつつ、瞬時にもう片方も全肯定に切り替えることで、分断の悲しみの時間をゼロにする。

pjdhiro のほかの見立て
  • 「片方を選択するというのは、分離と包摂の分離です。それは喪失の悲しみ、分断の悲しみ、そういった小さな痛みがある。それが葛藤や曖昧さを生んでいるかもしれない。その分断の痛みの時間を 0 にすることなのかもしれない。☯️」
  • 「意見直角曲げ法の最初の全肯定は、予測以上の全力の全肯定で信号を出させ、瞬時に切り替え予測を裏切ることで信号を出す。どちらも喜びの信号で、客観的な現実に影響させないまま、心理の喜び信号だけを出す。リアルは変化量ゼロのまま、意識だけ信号が MAX 出てる状態にする、ってことかもだね」
  • 「分断の悲しみの予測に対し、全肯定で痛みは無いという予測に切り替えさせ、その逆側も全肯定なので全く痛みがない。分離の痛みも包摂の時間もゼロ。」
  • 受容的な態度にも近い。「投影・取り入れなどの精神力動が瞬間的に行われている可能性がある。赤ちゃんをあやすような技法の上手な切り取りかもしれない」
  • 「共感と解釈に近い気がするな。相手の葛藤を一緒に抱え、受け取れる状態にして分離して咀嚼した☯️のようなものを、解釈として渡す。それを瞬間的にやってるのかも」
  • 「コサイン 90 度というと類推で、欠損駆動思考を考えちゃいますね」（欠損駆動思考）

二つの単位円なら、矛盾なく扱えるのではないか

四元数を使うと、直交する二枚の平面を一緒に扱えます。片方の平面を 90 度曲げると、もう片方の平面も同じだけ回り、全体の大きさは 1 のまま変わりません。片方にはオイラーの等式で知られる単位円を、もう片方には禅で描かれる円（円相）を置いてみます。

pjdhiro の見立て

複素平面的な言い方では、直角に曲げたかのように見えますが、同時にもう一つの平面も回転してしまう。その結果生まれるものが、信頼、緊張からの緩和、笑い、喜び、などの何かで、その値は単位球面のような安定した 1 なのではないか。うまく単位円の上で回転させる技法かもしれません。まだわからない。

pjdhiro の仮説

当ててみた心理現象は、直交する二つの単位円のたとえで、矛盾なくまとめて扱えるのではないか。意見直角曲げ法は、その最も近い応用事例ではないか。

この記事の解説

本文で触れた数学を、少しだけ書きます。

四元数は q = x + iy + jz + kw の形の数です。前の二つ（1 と i の平面）をオイラーの平面、後ろの二つ（j と k の平面）を禅の円の平面に当てました。どの成分に何を当てるかは、この記事の妄想です。

大きさ 1 の四元数を片側から掛けると、二枚の平面が同じ角だけ一緒に回ります。片方の平面だけを回したいときは、両側から半分ずつ掛けて、もう片方の回りを打ち消す必要があります。どちらの掛け方でも、大きさは変わりません。

0 から 1、1 から無限大、無限大から −1、−1 から 0 へと進む回転は、球の上では 90 度ずつの回転です。これを四元数で書くと j の入った形になり、二回分（0 と無限大を入れ替える半周）は j そのものになります。1 と i の平面で回すだけでは、0 と無限大は動きません。
