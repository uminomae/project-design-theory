# DESIGN-RULES-LDD — Love駆動開発のページだけの見た目の決まり

対象は `reader/love-driven-dev.html`（テンプレート `scripts/reader-love-driven-dev-template.html`）だけ。ほかの読み物は `DESIGN-RULES.md` のまま。

きっかけ：pjdhiro 2026-11-10「デザインルールを別にしたいね。LDD 特有の。白いすりガラスはおかしい。ダークな感じは ks、cs レポがいいと思う」（膜の渦の背景の上に、白いすりガラスの読書欄が乗っている画面を見て）。

## 1. 雰囲気

- **ダーク。** 暗い地の上で、背景（膜の渦）の光が見え、読書欄は暗いすりガラス、文字は明るい色。手本は cs の読み物（`cs/reader/wave-vortex.html`）と ks。
- **背景は膜の渦。** `src/backgrounds/love-membrane.js`（創造とはの `cs/src/scene-intent.js` の作り方を移したもの・WebGL）。body の `data-background="love-membrane"` で選ぶ。読み始めは 1:30 の位置から、中央の円の中心へ落ちていく。分析と経緯は `docs/gemini-prompt-love-background.md`。
- **開いたときは、まず背景を全画面で見せる。** 読書欄は最初の画面（100svh）の下から始まる。最初の画面に置くのは、下の端の真ん中の下へ促す印（押すと読書欄の上端 `#ldd-read` へ）と、左下の小さな題だけ（pjdhiro 2026-11-10「次はページ開始位置を少しずらして、背景を全画面で見れるようにしたい」。見本 A 何も置かない・B 題だけ・C 印だけ・D 題と印・E 8 割だけずらして読書欄の頭を覗かせる、を並べて C を選んだ。そのあと「左下に小さく Love駆動開発と呼びたいもの β を入れて。scroll と似た雰囲気で。テキストサイズは少し大きい方がいいと思う。でも、目立たないように。背景 Three を見せたいので」）。
  - 形は html の `data-intro`（空白区切り：`blank`・`title`・`cue`・`peek`）で決める。今は `data-intro="title cue"`。css は `reader-ldd-dark.css` の「最初の画面」、js は `src/ldd-intro.js`（head で同期に読む）。見本のページは `src/backgrounds/intro-samples.html`（`?intro=…&ih=…` で上書き）。
  - 印は創造とはのトップ（`cs/?graphic=i`）の `#scroll-hint` に倣う：「scroll」の小さな字（Georgia・0.85rem・字間 0.1em）と ▾、淡い青白（180, 200, 230）、3 秒でゆっくり 4px 沈む。濃さだけは cs（0.3・矢印 0.25）より上げた（0.62・0.55・字の後ろに地の色のにじみ）。cs の濃さでは膜の渦の明るい縞の上で見えなかったため（pjdhiro 2026-11-10「下へ促す矢印は、cs/?graphic=i を参考にして」）。
  - 題は印と同じ雰囲気にそろえる（Georgia・字間 0.1em・淡い青白・地の色のにじみ）。字は印より少しだけ大きく（1.05rem）、濃さは印より薄く（0.5）。狭い画面（640px 以下）では二行にして、真ん中の印に掛からないようにする。
  - 題と印は画面に留め（fixed）、スクロールを始めた直後（24px）に 0.6 秒で消す（pjdhiro 2026-11-10「目次が登場するタイミングで、スクロールと矢印を消す。ページタイトルも消す」のあと「コンテンツが画面に出るタイミングがいいので、スクロール開始した直後くらいのところで消して良いです」）。目次は今までどおり、読書欄の上端が画面の半分より上に来たときに出る。
  - 最初の画面にいるあいだは、目次（左の常設・右下のボタン）を出さない。Menu と右端の dev ボタンは出したまま。
  - 背景の読み進めた量（落ちる速さが変わる割合）は、最初の画面のぶんを数えない。読書欄の上端に着いたところが 0（`love-membrane.js` の readScroll）。
- **背景は 60fps で動かす。描く画素に上限を置き、画面の大きさで細かさを変える。** 重さは描く画素の数にほぼ比例する。上限は約 52 万画素（1440×900 の画面で、cs と同じ細かさの 0.5 倍＝907×567）。広い画面ほど小さく描いて引き伸ばし、狭い画面（スマートフォン）は上限に届かないので cs と同じ細かさのまま描く（`love-membrane.js` の `PIXEL_BUDGET`・`pixelRatioFor`）。M4 の Mac で、上限ちょうどのとき一枚 10ms（歩数 52）・8ms（歩数 34）。cs と同じ細かさのままでは 1440×900 で一枚 27〜29ms（約 35fps）で、カクカクして見えた（pjdhiro 2026-11-10「three がカクカクしているのをなんとかしたい」のあと、細かさ 1・0.7・0.5 を見比べて「0.5 でも問題ないね。レスポンシブのように画面サイズで変えることはできないの？」）。
  - 歩数（光を進める回数）は減らさない。輪の線の間隔は歩数から生まれているので、見た目が変わる。
  - 見比べには `?fps`（左上に描いた枚数と描く画素）・`?rs=0.5`（上限を使わず cs と同じ細かさに掛ける）・`?px=800000`（上限の上書き）を使う。
- **背景の色は、創造とはと同じにしない。** 今の値は cs に近いので、pjdhiro が調整の板で決める（2026-11-10「創造とはと似てる色であることが、ちょっと嫌なんだ」）。決まったら `love-membrane.js` の既定に写す。

## 2. 色の付け方

- html に `class="ldd-dark"` を付け、`src/styles/reader-ldd-dark.css` を `reader-flow.css` のあとに読む。
- **トークンを差し替える。** pd の読み物は色をトークン（`tokens.css` の `--ink`・`--mid`・`--mute`・`--gold`・`--navy`・`--coral`・`--white`・`--glass-*`・`--glow-*`）経由で塗っているので、`html.ldd-dark` でトークンの値だけをダーク用にする。部品ごとの直しは最小にする。
- 差し替えは html に掛ける。図を描くスクリプト（`reader-gravity-love.js` など）は html 要素からトークンを読むので、body に掛けると図だけ明るい地の色のまま残る。
- 差し色の色相は tokens の gold・navy・coral のまま、暗い地で読める明るさに上げる（新しい色相を作らない。`DESIGN-RULES.md` §0a の考え方は継ぐ）。

| トークン | 既定（明るい地） | LDD（ダーク） | 役 |
|---|---|---|---|
| `--ink` | #0f172a | #e6ebf5 | 本文の強い文字 |
| `--mid` | #334155 | #c3cbdc | 本文 |
| `--mute` | #94a3b8 | #8e98b2 | 補助 |
| `--gold` | #8a7040 | #d2b47c | 小見出し・線 |
| `--navy` | #2e3a6e | #aebcff | 見出し・強調・押したボタンの面 |
| `--coral` | #b04050 | #e58a97 | 注意 |

| `--glass-bg-medium` | 白 75% | 紺黒 64% | 読書欄 |
| `--glow-*` | 白 | 地の色 | 文字の後ろのにじみ |

## 3. 部品ごとの直し（トークンだけでは済まないもの）

- リンク：ブラウザの既定の青は暗い地で沈むので、明るい青（#9db4ff）。
- 明るい紺（`--navy`）の面に乗る文字（押したボタンなど）は、白でなく地の色（#0b1020）。
- 白い面を直に書いている部品（Menu・メニュー・言語の切り替え）は、暗いすりガラスに。
- 白い地のための白いにじみ（`.glow-card` の text-shadow）は外す。

部品を足すときは、まず cs・ks に同じ役の部品があるかを見て、あれば形と動きをそれに倣う（作り直さない）。濃さなど背景に合わせて変えたところは、ここに理由と一緒に書く（2026-11-10・下へ促す印を Claude が細い線で作り、pjdhiro「cs/?graphic=i を参考にして」）。

部品を足したときは、その部品が色を直に書いていないかを見る。直に書いていたら、このファイルの 3 に足す。
