# 抱持

> **高校生向けのやさしい解説**
>
> 何かに「あれ？」と引っかかったとき、すぐに答えを決めてしまわずに、その引っかかりを問いのまま持っておくことがあります。それが抱持です。二つの見方を両方とも同時に見ておくことも、まだよく分からないものを分からないまま包んでおくことも含みます。自分の説にこだわって離れないのは、問いでなく結論を持っているので、抱持とは違います。

抱持は、[[欠損駆動思考]]を組み立てる三つの要素（欠損・抱持・駆動）の一つ。正本は、欠損駆動思考の中核定義である。そこでの定義は仮説的な定義、つまり足場として置かれていて、検証とともに直していくものとされている。

## 定義

> **抱持**：違和感を、反射的に処理せず、問いとして抱え保つこと。二軸のまま同時に見ること、または、識別できないまま包容すること（非二元。区別は消えない）。

この定義は 2026-11 に言い直されたもので、それまでの定義は「反射的に処理せず、誤差を問いとして保持する機能」だった。

**pjdhiro の見方：** 同時に見ることでしょうね。抱持や包容は。非二元という意味でもあります。

**pjdhiro の見方：** 非二元的なものを、曖昧なまま、識別できないまま、それでも包容することも含まれます。忍耐力やわからなさへの迷いの時間など（安易に正解という二元に陥らない）などを表します。

ここでいう非二元は「二つでない」であり、「一つになる」ではない。実軸と虚軸の区別は保たれたまま、切り離されていない。区別を消してしまえば、それは抱持ではない。

## 二つの場合

正本は抱持に二つの場合を挙げ、それ以外もあるだろうと書いている。

| 場合 | 中身 | 要るもの |
|---|---|---|
| 識別できないまま包容する | 虚軸があることは見えていても、値はまだ識別できない | 忍耐力、わからなさへの迷いの時間 |
| 二軸のまま同時に見る | 値が少しずつ識別されてきた | — |

二つの分かれ目を「値の識別」に置くのは、草案の推論である。どちらが先かという順序は決めていない。

## 抱持が終わる道

草案の推論として、抱持が終わる道が二つ挙げられている。

- **決める**：軸を一つに潰して閉じる。正解を一つにしたがることと、ゼロはゼロと決めることは、同じ動きとされる（この見方には pjdhiro も同意している）。
- **忘れる**：保っていた違和感そのものが消える。記憶が、保つ力の候補に入るのはこのためである。

## 抱持でないもの

**pjdhiro の見方：** 執着や信仰のように囚われることは悪い。自説にこだわるような。

この保ち方は、問いを保っているのではなく、閉じた結論を保っている。いったん決めたことを変えたくないという心の傾き（need for closure の permanence）も、こちらに入る。

| 概念 | はたらき |
|---|---|
| 反応抑制 | 行動を止める |
| 抱持 | 行動の準備を保ちながら、評価し直す |
| need for closure の permanence | 閉じた結論を保つ（抱持ではない） |

## 保つために何が要るか

正本は、この問いを答えで埋めずに置いている。

**pjdhiro の問い：** 保つために、何が必要なのかわかりません。一般的には脳みそでの記憶力とされると思いますが、心理的な興味関心、性格的なものなど、他にもありそうです。

候補は、記憶・興味や関心・性格・関係の四つの方向に挙げられている。

そのうちの関係について、pjdhiro は、抱持には支えになる環境や関係が要ると見ている。たとえば、安心できる場、問いを分け合える相手、立ち返れる記録が、その足場になるのかもしれない。支えは、外の環境や関係だけではない。

**pjdhiro の見方：** 支えるのは精神性もあります。そのために不安症のような状態や、発達段階の低次では難しくなると思います。

「一人では待てない」「安定した心理が必要」という見方も、pjdhiro の仮説・持論として正本に置かれている。

<details>
<summary>詳しく：抱持を支える条件の、候補の一つ</summary>

中核定義には、2026-02 に整理された「抱持の成立条件」が、候補の一つとして残されている。抱持は個人の意志力ではなく、いくつもの条件が重なって支えることで成り立つ、という整理である。正本は、これが答えではないと断っている。

| 支え | 具体例 | 根拠として挙げられているもの |
|---|---|---|
| 生理的な余裕 | 睡眠、栄養、身体的な安全、ワーキングメモリの容量 | 神経科学 |
| 自律神経の調整 | 安全な関係、身体の修練（瞑想・武道・呼吸法）、環境の設計 | Porges、Bowlby（[[愛着理論]]）。禅、ヨーガとの対応 |
| 外の構造・制度 | 公案、茶道の作法、分析の設定、アンドン、学問のディシプリン | Bion の後期の論。世阿弥、茶道との対応 |
| 認知の枠組み | 判断保留（エポケー）、覚悟（葉隠）、[[ネガティブケイパビリティ]] | ストア派、Keats から Bion へ、ハイデガーとの対応 |

安定した関係は、この中で発達のうえでもっとも根っこにある支えとされるが、唯一の道ではないとされている。

</details>

## 似た向きの概念

正本は、群盲象を評すように、抱持と似た向きを持つ概念を並べている。これらは同じものとしてではなく、別の面から同じあたりを指すものとして置かれている。

- Bion の Container（β要素を保つこと）
- Klein の、PS（妄想分裂ポジション）に留まる耐性
- 世阿弥の「秘すれば花」
- 『葉隠』の「忍ぶ恋」
- 『中庸』の「未発の中」
- Keats の negative capability（不確かさや疑いのなかに留まれること）
- 成人発達理論の「包容」（Cook-Greuter の Embrace）：同じ語である。抱持の範囲が広がることと、ゼロと測るものが減ることは、同じ動きの二つの面ではないか、と草案は推論している。発達の段階を評価の物差しにはしない。

## アウェアネスモデルとの関係

[[アウェアネスモデル]]の記述（v3）では、抱持は検証待ちの仮説として、優先度を低く置かれている。Bion（1962）の containment の概念が、意識のプロセスの「何か」に関係するという洞察で、その「何か」の中身はまだ決まっていない。抱持は欠損駆動思考の側の概念として扱われる。

同じ記述には、検証待ちの仮説のつながりとして、次の三つが並べられている。間主観性は信頼感情と関係する。信頼感情の体験は身体に記録される。それが抱持する能力へつながる。これは、実証の土台が固まった後に、対話を通じて掘り下げる対象とされている。

## 定義の間の関係

中核定義は、四つの定義の関係を次のように並べている。

```
欠損駆動思考 = 態度
    |
    | この態度で扱う対象が
    v
欠損 = 五つの面で言う（虚軸のたとえ／構図／体験／ゼロの場所で湧く信号／引き寄せられる方向）
    |
    | 違和感を評価するのが
    v
情動の構成 = 生存-信頼評価（据え置き）
    |
    | 評価後に即時反応せず、ゼロのまま確定させないのが
    v
抱持 = 二軸のまま同時に見る／識別できないまま包容する
    |
    | 気になって探索へ向かうのが
    v
駆動 = 好奇心のようなもの
```

[[欠損]]と[[情動の構成]]は、それぞれのページで扱う。

## 保持論点

プロジェクトデザイン論の調査から欠損駆動思考への接続を見たときに、抱持に関わる問いが、急いで解かない論点として残されている（[[PDブリッジ保持論点]]）。

- 信頼のない場での抱持は可能か。
- 欠損駆動思考（態度）から、抱持を経て、frame creation（操作）へ向かう流れを、一つの形として書けるか。抱持がその間をつなぐ可能性は、まだ確かめられていない。
