# 欠損駆動思考のサイトと knowledge の概観

> **高校生向けのやさしい解説**
>
> このページは、「欠損駆動思考」という探究が、公開しているサイトと、資料の置き場（knowledge）に、今なにを置いているかを並べた案内図です。欠損駆動思考は、何かが欠けているという感じや違和感を、すぐに片づけずに問いとして持ち、そこから考え始める構えを指す名前です。サイトは読み物としての入口で、knowledge には定義・概念ノート・短い表現・本文の下書きが置かれています。

## 概要

[[欠損駆動思考]]は、Love駆動開発の読み物が呼び出す探究の一つとして、サイトのトップに置かれている。サイトのトップ（`ks/index.html`）が本筋の読み物を持ち、knowledge（`ks/knowledge/`）が定義・概念ノート・表現・本文テキストを持つ。サイトと knowledge とでは、定義の言い方が違うところがある（下の「サイトと knowledge の言い方の違い」）。

---

## サイトのトップが置いているもの

トップの問いは、「記号の上では 0 と出るところで、人は何を感じているのか」。考えや心と、体で湧く信号とが離れるとき、人は何かが欠けていると感じるのかもしれない、と置く。その欠けている感じや違和感などを駆動源にする思考や精神の構えを、欠損駆動思考と呼んでいる。

本文は次の章で組まれている。各章に「詳しく」の畳みがある。

| 章 | 中身 |
|----|------|
| この探究の問い | 構想や設計や計画のいちばん最初には、何かが欠けているという感じがある、という pjdhiro の見方から始める。畳みに、指月のたとえと、波間に巻く渦のたとえを置く。「意識とは」が人が何で世界を切り取っているかを見るのに対し、このページは切り取った渦の輪郭のところを見る |
| 欠けは、受け身で感じてしまう | [[欠損]]を、pjdhiro がこれまで言ってきた五つの言い方を言った順に並べて置き（下に引く）、どれも欠損の一つの面だとする。考えや心と体で湧く信号とが離れるとき、人は欠けを感じやすくなる、Love と呼びたいものが駆動しているから人は受け身で欠けを感じてしまう、という pjdhiro の見方を置き、欠損は予測との誤差で気づかれるものでもある、と添える。畳みで、「意識とは」の生存と信頼の二つの値の見込みと、経験とのずれにつなぎ、予測との誤差には時間の長さの違う二つの話（脳が瞬間ごとに行う、本人が意識できない予測と誤差／期待していたことと起きたこととの違いのような、人が気づける長さの話）がある、と書く |
| 切り取った輪郭のところに、まだ何かある | 前の章の一つ目の言葉（虚軸のたとえ）を、軸の絵で見る。pjdhiro の見方「実存主義的な i や、無意味さは、コサイン 90 度だと思います。実軸では無意味。でも。」と、もう一つのたとえ（質量で歪んだ方向に吸い寄せられるように感じる信号とのギャップ）を置く。畳みに、回転の掛け算から見た虚軸とコサイン 90 度の説明と、Love駆動開発の読み物の重力場のたとえを置く |
| 問いのまま持つ | [[抱持]]を、違和感を、反射的に処理せず、問いとして抱え保つことと書く。支えとして、安心できる場・問いを分け合える相手・立ち返れる記録と、精神性を挙げる |
| 欠けから、構想や設計が始まる | 欠けはやがて解くべき問題になり、その先の問題解決は経営学がこれまで扱ってきた範囲だ、という pjdhiro の見方を置く。欠損駆動思考は、その手前で欠けを問いとして拾う構えとする |
| この見方は、何の役に立つのか | 違和感をすぐに解かずに抱えておくと、一つの面だけに縛られた判断をしにくくなるのかもしれない、と置き、Love駆動開発の読み物の同じ問いの節へつなぐ |
| まだ分からないこと | なぜ 0 のところに何かを感じるのかは、まだ分かっていないと置く。メタ認知の先で感じる臍の緒のような安定感の体験を引き、生存と信頼の信号は「意識とは」で追っていると書く。この安定が何とのつながりなのかを、つながりの安定を扱う論と並べて見たページ（「つながりの安定は、何とつながっているのか」）へつなぐ |
| 調べてきたこと | 調べた論を並べた読み物として「つながりの安定は、何とつながっているのか」（確かめずにつながっている安定を、つながりの先で九つの段に並べた論と照らす）を挙げ、これまでの調査ノートと記事を畳みにまとめる |

「欠けは、受け身で感じてしまう」の章が並べる五つの言い方は、次のとおり。

1. 「欠損駆動思考と呼んでいる私の体感をたとえるなら、虚軸に値があって、しかも、認知上は 0 の直観です。」
2. 「実軸で認知したものの中に、ゼロだからゼロと定義されて、無意味・無価値のように扱われたものが、実は虚軸で意味があった。そんなことが　欠損だと思います」
3. 「違和感や欠けを感じること。その一つとして誤差がある。」
4. 「その信号がゼロの場所で湧いてしまうとしたら何？と思うことが、欠損への気づきだと思う。」
5. 「欠けとは　引き寄せられる　ドリフトしていく　落ちていく　そのような方向を指すものかもしれません」

畳みの中には、調査ノート（デザイン思考）、関連概念（[[プロジェクトデザイン]]・創造とは・意識とは）、記事の一覧が並ぶ。トップの下には、Love駆動開発と呼びたいもの・意識とは・創造とは へのリンクがある。

## コア定義

`schema/core-definitions.md` は、2026-11-03 に定義を仮説的な定義（足場）へ改め、2026-02 の確定版を旧定義として併記している。欠損は、2026-11-10 に、五つの言い方を面として並べる形に言い直した。

| 用語 | 仮説的定義（2026-11-03。欠損は 2026-11-10） |
|------|------|
| 欠損駆動思考 | 実軸ではゼロと定義されて無意味・無価値のように扱われたものに残る違和感を、切り捨てずに問いとして抱え保ち、そこから探索へ向かう態度。出発点にあるのは、虚軸の欠損 |
| 欠損 | 一つの文にしない。pjdhiro の五つの言い方（虚軸のたとえ・実軸でゼロと定義されたものが虚軸で意味があった・違和感や欠けを感じること・ゼロの場所で湧く信号への問い・引き寄せられ落ちていく方向）を、欠損の面として並べる。欠損は、予測との誤差で気づかれるものでもある（補足） |
| 抱持 | 違和感を、反射的に処理せず、問いとして抱え保つこと。二軸のまま同時に見ること、または、識別できないまま包容すること（非二元。区別は消えない） |
| 駆動 | 違和感が気になって、探索したくなること。好奇心のようなもので足りる |
| [[情動の構成]] | 欠損が生存軸（生存）と信頼軸（愛）で評価され、情動として構成されるプロセス（旧定義のまま据え置き） |

「虚軸」は、記号で表現するときにもっともしっくりくる概念として使われ、ただの比喩か本質を言い当てているかは決めていない。「虚軸に値があって、しかも、認知上は 0 の直観」は、定義と同じタイミングで起きることの違う言い方として、定義と並べて置かれている。二つの関係は、まだ言葉にされていない。

## サイトと knowledge の言い方の違い

| 用語 | サイトのトップ | knowledge のコア定義 |

| 欠損 | 五つの言い方を並べ、どれも欠損の一つの面とする。二つ目は仮説的定義の構図の側と、三つ目は体験の側と同じ趣旨。予測との誤差は、欠損が気づかれる道の一つとして添える | サイトのトップと同じ五つの言い方の並べ方。2026-11-03 の仮説的定義（構図の側と体験の側の二つ）と、2026-02 の旧定義（予想と現実の誤差を、意識が「欠け」として捉えた主観的経験）は、前の定義として残している |

## 「意識とは」との関係

サイトのトップは、「意識とは」が人が何で世界を切り取っているかを見て、欠損駆動思考はその切り取った輪郭のところを見る、と書き分けている。knowledge の `reference/as-links.md` は、「意識とは」に関する知見は「意識とは」の側に残し、欠損駆動思考の側は結果をリンクで参照して写さない、という分担を pjdhiro の判断として記している。「意識とは」の概観は [[cross-refs/awareness-space-overview|「意識とは」のサイトと knowledge の概観]]。
