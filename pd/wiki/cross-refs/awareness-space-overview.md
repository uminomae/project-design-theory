# 「意識とは」のサイトと knowledge の概観

> **高校生向けのやさしい解説**
>
> このページは、「意識とは」という探究が、公開しているサイトと、資料の置き場（knowledge）に、今なにを置いているかを並べた案内図です。「意識とは」は、人は何で世界を切り取っているのか、を問います。人は、生き延びられるか（生存）と、つながっていられるか（信頼）の二つの値を見込んで世界を見ているのかもしれない、という見方から考えています。

## 概要

「意識とは」は、Love駆動開発の読み物が呼び出す探究の一つで、受け取る側を見る、とサイトのトップに置かれている。サイトのトップ（`as/index.html`）が本筋の読み物を持ち、knowledge（`as/knowledge/`）が起点のメモ・概念ノート・調査トピックの置き場・原典の台帳を持つ。

---

## サイトのトップが置いているもの

トップの問いは、「人は、何で世界を切り取っているのか」。人は、生存と信頼の二つの値を見込んで、世界を切り取っているのかもしれない、と置く。意識も、そうして切り取られた形に当てた名前の一つかもしれない、とする。

本文は次の章で組まれている。各章に「詳しく」の畳みがある。

| 章 | 中身 |
|----|------|
| この探究の問い | Love と呼びたいものは直接は観えず、人のすぐ近くで動かされているものの一つが、体に湧いて意識に上る信号だ、と置く。このページはその信号を見る。畳みに指月のたとえを置き、「欠損駆動思考」は記号の上では 0 と出るのに体が何かを受け取っているところを見る、と書き分ける |
| 意識も、波間に見えた渦の一つ | 意識も、人が認知しやすい大きさで切り取って名前を当てた渦の一つかもしれない、と置く。畳みで、以前は意識を「主観的経験の総体」と置いていたと書く |
| 切り取り方は、受け取る側で決まる | 何を大事なものとして拾うかの選び方に、生存と信頼の二つの向きがある、という pjdhiro の見方を置く。畳みで、生存の信号は脅威・安全・地位・資源に、信頼の信号は愛着・所属・信頼・[[間主観性]]にかかわる、と書く。同じ畳みで、「生存と信頼の信号」は便宜上の呼び名で、pjdhiro は、厳密には、闘争と逃避の生存の信号と、信頼と嫌悪のような快・不快の精神的な信号ではないか、と見ている、と書く。研究の側には、この二つとちょうど同じ線で分けたものは見当たらず、近いもの（体の自己を守る動機と並べて、人との間での自分を守る系を置く Dickerson と Kemeny 2004 年）があること、数も一つには決まらないこと、二人の脳や体の活動がそろうことがやり取りの経験をなしているのか副産物なのかは決着していないことを並べる |
| 二つに分けて書くが、二つでない | 生存と信頼は切り離されておらず、一つの気持ちの中で取り違えられ、入り込み合っている、と置く。畳みで、以前の「誤適用」という見方を、二つが取り違えられている場面の一つとして読み直している、と書く |
| 一列の記号には、二つの値が乗りきらない | 言葉や数値のような記号は一列に並んでいる。それを受け取ったときに起こることとして、生存についての値は同意でも信頼側の値は未知、などという pjdhiro の見立てを置く。切り取った渦の輪郭はここでぼやけるのかもしれない、とする |
| この見方は、何の役に立つのか | 生存と信頼の二つを取り違えていないかに、気づく手がかりになる、と置く。例に、お金を追っていたつもりが、人との間での自分の位置を気にしていた、という pjdhiro の例を挙げ、Love駆動開発の読み物の同じ題の章へ送る |
| まだ分からないこと | 身体と意識を結ぶ信号がどのようなものか、という pjdhiro の問いを置き、神経現象学や心理学の研究を材料にして調べている、と書く。畳みに、不安を不確かさへの備えとして捉える研究（Grupe と Nitschke 2013 年）を置く |
| 調べてきたこと | 意識や気づきにかかわる神経現象学や心理学の研究を、原典に当たって調べ直している、と書く。領域ごとの記録は文責が Claude。このページは pjdhiro の一人称の体験を本論に置き、研究はそれを考えるための材料として調べている、と書く。神経現象学の研究も材料の一つで、このページが神経現象学として成り立っているわけではない、とも断る。これまでの探索で描いた発散のノートは、畳みにまとめている |

「調べてきたこと」の一覧には、原典に当たって調べ直した領域ごとの記録が十五本並ぶ。神経現象学の方法、予測と気づき、自己と境界、内受容と情動、不確かさと安全、関係と信頼、間主観性の哲学と臨床、意識とメタ意識の区別、信号の分け方、間主観性の信号、安定とつながりの感じ・手放す構え、信頼の定義と長い時間の動機、一列の記号と、そこに乗らない値、受け取る側の選び方、取り違えへの気づき。トップの下の畳み「これまでの記録」に置かれているのは、発散のノートである。Love駆動開発と呼びたいもの・欠損駆動思考・創造とは へのリンクもある。

## 起点メモ

`survival-trust-axis-starting-memo.md` は、生存-信頼軸を確定した理論としてではなく、探索の起点として置いている。最小の形は次のとおり。

- 人間の意識経験は、ズレや欠損を検出するだけでなく、少なくとも二つの方向で評価している。
- 第一の方向は生存軸で、生存・脅威・安全・身体的・社会的な危険回避に関わる。
- 第二の方向は信頼軸で、関係・愛着・所属・信頼・間主観的なつながりに関わる。
- 情動や行動準備は、この二軸での評価を通じて方向づけられる。

メモは、生存-信頼軸を感情の分類表ではなく、意識が何を重要なものとして扱うかを分ける最小の座標系として仮置きする。[[欠損駆動思考]]の側の[[情動の構成]]の定義は、移植せずに出発点として参照する。作業仮説の一つに「人間の苦しさの多くは、信頼軸の問題を生存軸で処理しようとする構造的な誤配から生じる」があり、サイトのトップはこれを、二つが取り違えられている場面の一つとして読み直している。この仮説には、2026-11-11 の照合し直しの注が付いている。向きの近い研究はあるが、苦しみの「多く」がそこから生じることを確かめた研究には当たらなかった、という判定である。

まだ扱わないこととして、二つの軸の最終的な定義、信頼軸を「愛」と呼ぶか「間主観性」と呼ぶか、神経基盤、第三の軸が要るかどうか、などを挙げている。

## 概念ノート

`concepts/index.md` は五件を載せている。

| ID | 題 | 核心の一文（ノートの冒頭から） |
|----|----|------|
| CN-001 | 内在化された関係 | 保持や再評価を支える条件としての「関係」は、外的・物理的な関係だけでなく、心の中に内在化された関係を含む |
| CN-002 | 生存軸の衣が剥がれる体験（「別の絶望」） | 生存軸の条件を完全に遂行しても信頼軸の欠損が解消しないと気づく体験 |
| CN-005 | 信頼の定義仮説インベントリ | 「信頼とは何か」を問うための仮説群で、定義の候補であり、同時にテスト文でもある（探索的）。[[信頼]] |
| CN-006 | 信頼とは何か — 軸による多元的記述 | 信頼の定義を確定せず、現時点の探索結果を暫定的な結論として記録する。「期待」「信頼」のラベルでなく、軸で多元的に記述する |
| CN-007 | 測定設計の原則 | 理論を操作化できることを示すための、概念的な測定設計の原則。実験の手順を決めるものではない。[[測定設計原則]] |

CN-006 の、期待と信頼を時間の向きで分ける軸には、2026-11-11 の注が付いている。「過去〜現在（信頼的）」の極は、Claude とエージェントが作った暫定の整理で、pjdhiro の発言ではないこと、研究の信頼の定義の多くは先を見込む期待や信念として書かれ、同じ「信頼」の語で取り違えが起きうること、が書かれている。

CN-001・CN-002 は、欠損駆動思考の knowledge にも同じ番号・同じ題で置かれている。「意識とは」の側の CN-001 は、核心の一文の「抱持の成立条件」を「保持や再評価を支える条件」と書き換えている。
