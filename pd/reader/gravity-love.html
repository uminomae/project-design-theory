動いていないのに、駆動している

周りの点は回り続けます。内側ほど速く、外側ほどゆっくりです（ケプラーの法則の形）。けれど中心は一度も動きません。それでも、すべての周回は、この動かない場所がつくったくぼみから生まれています。動きの原因が、動きのない場所にある。ふつうの「動いているものが動かしている」という見方とは、逆の向きです。

何もない — 回しているのは、くぼみの形

図の中心には、光る太陽を描いていません。くぼみの底に、空の輪がひとつあるだけです。中心は、周りの点を一つずつ押したり引いたりしていません。周りを回しているのは、中心がつくったくぼみの形です。駆動源は、中心に置かれた「物」より、中心がつくる場の形のほうにあります。

自分からは見えない

井戸の底に立つと、周りのすべてが自分を中心に回って見えます。けれど、どちらを向いても映らない場所がひとつあります。いま見ている、この中心そのものです。見ている点は、自分の視野の中に現れません。

  • 外からは、止まって見える。ブラックホールへ落ちていくものを外から見ていると、事象の地平面に近づくほど時間が遅れて見え、やがて止まったように見えます。外から見ているかぎり、地平面を越える瞬間は見えません。
  • 中心が、エンジンになる。M87 の中心からは、光の速さ近くで噴き出すジェットが、数千光年にわたって伸びています。2026年1月には、EHT の観測から、そのジェットの根元とみられる成分の兆しが、ブラックホールのすぐそば（約0.09光年）にとらえられました。まだ暫定的な検出で、研究者自身がその明るさを上限値として扱っています（Astronomy & Astrophysics 706, A27）。ジェットは、ブラックホールの回転のエネルギーを電磁的に引き出して噴き出す、と考えられています。
  • まわりが回る中心。天の川銀河の中心では、恒星たちが何も光っていない一点のまわりを回っています。その軌道を何十年も追い、中心に超大質量のコンパクトな天体（ブラックホールと考えられている）があることを示した研究に、2020年のノーベル物理学賞が贈られました。

ただし、太陽と違うところもあります。ブラックホールそのものは回転していて、ジェットはその回転から力を得ていると考えられています。完全に「動かない」中心ではありません。また、天の川銀河の中心のブラックホールの重力がまわりを支配しているのは、中心から十光年ほどの範囲だけです。銀河全体の回転を支えているのは、光を出さない暗黒物質を含む、銀河全体の目に見えない質量のほうです。ここでも、回転を支えているのは「見えないもの」でした。

素粒子：大きさのない中心

  • 大きさが見つからない。電子には、どれだけ細かく調べても内部の構造が見つかっていません。大きさの上限は 10−19〜10−20 メートルほどまで押し下げられています。大きさのない一点なのに、質量と電荷を持ち、まわりに電場を広げる中心になっています。
  • 重さの大部分は、中身ではない。陽子の質量のうち、中のクォーク自身の質量はわずか数％です。残りの大部分は、クォークを閉じ込めている力と運動のエネルギーから来ています（量子色力学の計算）。重さの中心にあるのは「物」ではなく、関係と動きです。

ただし、原子は小さな太陽系ではありません。電子は原子核のまわりの軌道を回っているのではなく、雲のように広がって存在します。水素原子のいちばん低いエネルギーの状態では、電子の存在の密度がいちばん高いのは、原子核のある中心そのものです。素粒子の世界では、中心は避けて回る場所ではありませんでした。似ているところと、似ていないところの両方がある、というのが今の見立てです。

橋の先：つながっているが、通れない — 物理の側の解説

ブラックホールには、もう一つ奇妙な性質があります。1935年、アインシュタインとローゼンは、二枚の同じ「シート」をつなぐ「橋」として粒子を描きました。この橋をブラックホールの喉と重ねる読み方は後の解釈ですが、いまでは標準的な呼び方です。シュヴァルツシルトの解を数学的に最後まで延ばすと（クルスカル 1960）、こちら側の外部と鏡に映したような、もう一つの外部時空が現れ、二つは喉でつながります。向こう側は一点ではなく、無限遠まで広がる一つの外部時空そのものです。ただしこれは、永遠に存在する理想化したブラックホールの解での話で、星の崩壊でできる実際のブラックホールには現れません。

そしてこの橋は、通れません。喉は有限の時間でくびれて閉じ、光でさえ渡りきる前に閉じてしまいます（フラー＝ホイーラー 1962）。つながっているのに、行き来はできない。2013年にマルダセナとサスキンドは、量子的にもつれた二つのブラックホールが、この通れない橋でつながっているのではないか、と予想しました（ER＝EPR）。予想の段階ですが、ここで言われている「つながり」は、信号を送れる通路ではなく、相関です。向こうで何が起きているかは届かないのに、切り離されてはいない。

5. 仮説 — 経営者の役割とは：存在そのものが源か

ここからは仮説です。プロジェクトを回すエンジンとしての経営者は、この中心に似ていないでしょうか。そして、愛と経営者は似ていないでしょうか。

  • 動かないのに、動かす。中心は惑星を一つずつ押してはいません。くぼみの形をつくるだけで、周りはそれぞれの速さで回ります。経営者の仕事も、人を一人ずつ動かすことより、人が自然に回り出す場の形をつくることに近いのかもしれません。
  • 何もない。中心が強く押したり引いたりしなくても、場の形が周りを回します。中心が何かを足すほど、場の形は崩れるのかもしれません。
  • 自分からは見えない。中心に立つと、周りのすべてが自分を中心に回って見えます。けれど、自分がどんなくぼみをつくっているかは、中心からはいちばん見えにくい。周りの人には見えている自分の重さが、本人にだけ見えない、ということは起こりそうです。

一つめの点は、経営学にも近い議論があります。エドガー・シャインは『組織文化とリーダーシップ』（1985年）で、リーダーが行う本当に重要な仕事は、文化をつくり、扱うことだけかもしれない、と書きました。一人ずつへの指示より、場の形を通じて働く影響です。

意思決定は、周りの一つひとつに向きを与える「動き」でした。けれど重力の井戸で周りを回していたのは、中心が一つずつ下す判断ではなく、動かない中心がつくるくぼみの形でした。意思決定を分けていって現れた Being の層が、もしこの「動かずにそこに在る中心」なら、未解明だった存在についての役割は、意思決定という言葉の中で動きに隠れて見えにくくなっていた、この層にあるのかもしれません。経営者の、決めることではなく、そこに在ること。その存在そのものが、源である。そういう仮説になります。そしてその中心は、愛と同じ形に描けます。

pjdhiro の見方：「考えて決める」だけの行動の軸と直交するように、存在の虚軸があるかもしれない。コサイン 90 度のような、ゼロの点。

この仮説は、軸の絵でも描けます。「考えて決める」を一本の軸（実軸）とすると、存在は、それと直角に立つもう一本の軸（虚軸）かもしれません。直角に立つ二本の軸は、互いの上に影を落としません。cos 90° ＝ 0 です。井戸の中心の「ゼロ」は、そこに何も無いという意味ではなく、存在の軸が行動の軸と直角に立っていて、行動の軸の上では長さがゼロに測られる、という意味かもしれません。行動の側から測るかぎり、存在はいつもゼロに見える。それでも、回っているものの軌道は、その軸のまわりにできています。虚軸と回転については、別の読み物「なぜ 3 と 7 だけが特別なのか」の 2章が扱っています。

この見方の原型は、pjdhiro の 2025 年 6 月の二つの投稿にあります。「対話：「森の木」Wood Wide Web と陰陽なフラクタルの青山常運歩」は、森の信号のやり取りから、平方根のように真逆の二つが生まれる不思議、虚軸のような人々、罪と恥・神と人の「垂直と水平」という直交する軸へ進みます。「スピノル場の理解のために民話をあててみる」は、オイラーの公式 eiθ と四元数、二つの直交する状態を回す σ3、「スピノルは回転の平方根」までを民話にあてて辿っています。存在を行動と直交する虚軸として置く見方は、このときから育っているものです。

pjdhiro のたとえ：欠損駆動思考と呼んでいる私の体感をたとえるなら、虚軸に値があって、しかも、認知上は 0 の直観です。

ここで、この読み物と欠損駆動思考がつながります。行動の軸の上では 0 に測られるのに、直角の軸には値がある。それを「欠けている」と感じ取る直観が欠損駆動思考で、井戸の中心のゼロは、その直観を一枚の図にしたものです。

認知は射影、体感は絶対値

ここで、4章の「先が見えないのに、安定する」に、一つの仕組みの候補を置けます。cos 90°＝0 は、虚軸の値を行動の軸に射影した長さです。認知は行動の軸しか読まないので、0 と出ます。けれど体は、射影ではなく、値そのものの大きさを受け取っているのかもしれません。2章の橋の像で言えば、緒の先は認知の上では 0 で、安定感は値の大きさです。虚軸を見ているのではなく、虚軸の値を受け取っている。だから「認知上は 0」と「安定を感じている」が、矛盾せずに同時に成り立ちます。これは構造の比喩で、脳や体がこの計算をしているという主張ではありません。

pjdhiro の見方：なぜゼロに虚軸を観れるのか？は、臍の緒の安定感は感じているから、というのは一つだし、全てかもしれない。だから awareness-space で生存と信頼の信号について追っていた。その信号がゼロの場所で湧いてしまうとしたら何？と思うことが、欠損への気づきだと思う。

4章で意識とは — awareness-spaceに預けた二つの信号が、ここで一度だけ戻ってきます。行動の軸の上で 0 なら、そこから信号は湧かないはずです。それでも湧くなら、どこかに値があります。見えないものを直接見るのではなく、見えない所から来る信号で、そこに何かあると知る。2章でブラックホールを周りの光で知ったのと、同じ検出の仕方です。ゼロの場所で湧く信号を「何？」と問うこと。それが欠損への気づきだ、と pjdhiro は言います。ここも、pjdhiro の内省の一人称の報告を資料にした読みで、証拠ではありません。

そして、湧く信号の種類で、同じゼロの場所の扱いが分かれるのかもしれません。湧くのが生存の信号なら、見えない先は脅威になり、不安になり、欠損は埋めるべき欠陥として扱われます。湧くのが信頼の信号なら、見えない先は安定になり、欠損は源として観られます。欠損を源として観る扱いと、欠陥として埋める扱いは、同じゼロの場所でどちらの信号が湧くかの違い、という読みです。これは推測です。信号そのものの論拠は、awareness-space が追っています。

この見方にも先例があります。『老子』第11章は、三十本の輻（や）が一つの轂（こしき）に集まり、その真ん中が空っぽだからこそ車輪として働く、と書きます。第17章は、いちばん良い統治者について、下の者はその存在を知っているだけだ、と書きます。何もない中心が回転を支え、優れた中心ほど目立たない、という読みです。

もし経営者がこの中心に似ていて、この中心が愛に似ているなら、プロジェクトを回しているエンジンは、経営者という人そのものより、その人がそこから見ている場所、つまり愛に近い何かなのかもしれません。プロジェクトデザイン論が「Love 駆動開発」と呼んでいる現象——Love を「つながりを生む引力一般」とし、生存と並ぶ駆動力ではないかと問う構え——は、この中心の働きに名前を与えようとする試みとも読めます。

pjdhiro の背景：場→波→縁→渦 というように、渦を巻くまでのエネルギーとして、重力や愛のような、ゼロで何もしない中心の、無のような駆動エンジンを探している。

ここで、冒頭で触れた問いに戻ります。プロジェクトデザイン論の Being の節は、創造を「場が現れ、波が立ち、縁で衝突が生まれ、渦として統合され、束として成る」という五つの段階で見ています。この読み物の井戸は、その中の「渦を巻くまで」を回している駆動源の候補を、一枚の図で探したものです。答えはまだ探索中です。

場と揺らぎが、渦を生む

その五段階を、ここまでの言葉で読み直してみます。創造とは — creation-spaceのトップページは、五段階をこう置いています。「場は創造が生まれる環境と条件、波は探索と揺らぎの過程、縁は異質な要素が出会う境界、渦は要素が結合し変容する核心的段階、束は新たな形式として統合される完成」（創造の5段階モデル・2026年10月の版。上の Being の節の言い方とは少し違いますが、同じ五段階です）。姉妹読み物「波間の渦」は、物理学者デヴィッド・ボームを引いて、渦とは流れの安定したパターンであって、流れから独立した実体ではない、と書いています。

pjdhiro はこれを「場と揺らぎが渦を生む」と縮めます。pjdhiro の読みでは、場が限りなさで、渦が日常です。渦は場の揺らぎそのものが形になったもので、場から切り離して取り出せません。限りなさと日常は、二つ並んでいるのではなく、二つでない。4章で引いたスクリーナーの帯で言えば、6.0 の形（時間や境界のなさと相対の現実の相互性。資料のたとえは大海と波）に、この読み物の中でいちばん近いのが、この「場と揺らぎが渦を生む」です。2章の橋の像は、その先の 6.5〜7 の推測でした。井戸の中心は、渦を巻くまでを回す駆動源の候補であると同時に、この「二つでない」形を一枚の図で見せる絵でもあります。引用元は creation-space で、創造のモデルはそちらで独立に組み立てられています。

pjdhiro の見方：経営者すらも、愛のような中心の駆動源によって引き寄せられているのかもしれない。

6. 根にある問い — 人と人との間、自らを分けたところ

pjdhiro の問い：人間とは人と人との間に存在し、自分とは自らを分けたところに存在するとしたら。そんな問いが根元にあると思う。自分という言葉が、まさに表している。

この問いが、ここまでの全部の根にあります。中心が「物」ではなく、人と人との「間」や、自らを「分けたところ」にあるなら、それが何もない点であること、動かずに周りを回すこと、自分からは見えないことが、一本につながります。この問いは解かずに、問いのまま置きます。日本で古くから同じ方向を向いてきた考えが、いくつかあります。

日本で古くから同じ方向を向いてきた考え — 和辻・唯識・西田
  • 和辻哲郎：人間は「人の間」にある。和辻は『人間の学としての倫理学』（1934年）で、「人間」という言葉に「世の中」と「人」の両方の意味を読み、倫理は個人の内面ではなく、人と人との間柄に成り立つとしました。
  • 唯識の「四分」：ひとつの認識を、分けて見る。飛鳥・奈良時代に日本へ伝わり、いまも興福寺や薬師寺を本山とする法相宗の唯識は、ひとつの認識を四つの「分」に分けてとらえます。見られる面（相分）、見る面（見分）、見ていることを自ら知る面（自証分）、それをさらに確かめる面（証自証分）です。この「分」は部分・側面の意で、動詞の「分ける」ではありませんが、心が自分を見るはたらきに「分」の字が当てられています。
  • 西田幾多郎：知るとは、自己の中に自己を映すこと。西田は『自覚に於ける直観と反省』（1917年）で、知るということは自己の中に自己を映すことである、という考えに初めて至り、同じ本で「無」が西田哲学の主要概念になりました（板橋勇仁の整理）。自己が自己を分けて映すはたらきと、その中心が無であることが、一冊の中で一緒に出てきます。この読み物の 4 章（分けると層が変わる）と 2 章（ゼロの点）の重なりに、いちばん近い先例です。ただし西田は「映す」と言い、pjdhiro は「分ける」と言います。

なお、「自分」の「分」を「自らを分けたもの」と読むのは、辞書で決まった語源ではありません（国語辞典には語源の記述がなく、語源を扱う Web サイトには、出典を示さずに「本分」の「分」とする説明があります）。これは pjdhiro の読みで、ここでは先例と並べて置くにとどめます。

二つでない、とはどういうことか

ゴムシートの絵について

重いボールでゴムシートをくぼませる絵は、一般相対論の教育でよく使われます。ただしこれ自体が比喩です。ボールがくぼみを転がり落ちるのは、下向きの重力があるからで、重力を説明するのに重力を使っています。

また、一般相対性理論では、惑星の軌道を主に決めているのは、重い物の近くほど時計が遅れることの方だとされています。この図は、くぼみの深さを重力ポテンシャルとして描いています。

よくある誤解：太陽は本当に動いていないのですか？

誤解：太陽は宇宙の中で静止している。

なぜ違うか：太陽も、惑星との共通の重心のまわりで小さく揺れています。銀河の中心のまわりも回っています。

この図での意味：ここでの「動かない」は、太陽系の内側から見て、回転の中心にあるという意味です。系の中の動きを生んでいる場所が、その系の中では動かない点になっている。この関係を描いています。

よくある誤解：太陽の中心には何もないのですか？

誤解：太陽の中心は空っぽである。

なぜ違うか：逆です。太陽の中心は、太陽の中でいちばん物が詰まった場所です（温度は約1,500万度、密度は水の150倍ほど）。核融合もそこで起きています。
