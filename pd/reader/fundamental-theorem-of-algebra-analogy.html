代数学の基本定理は、方程式の答えを数直線の上だけで探すと足りなくなるが、平面まで広げると、答えの数がちょうど次数とそろう、と言います。zn = 1 では、答えが円の上に同じ角度ずつ並びます。このページは、その登場人物を、人の意識や、プロジェクトを動かしているもの（駆動源）に、仮に当ててみるページです。数学そのものの説明は、独立ページ「代数学の基本定理」にあります。

今の仮説は三つです。認知できる側だけで探して「答えが無い」と出る問いは、答えが無いのでなく、探す軸が一本足りないのではないか。自己は一つでなく、いくつかの自己が同じ資格で並んでいて、いま認知できているのはそのうちの一つではないか。今の自分から一段遡ると、真逆の向きの二つが残り、どちらだったかは決まらないのではないか。どれも、これから確かめる仮説です。

式の登場人物を、仮に当てる

このページは、平面の横の軸（実軸）に認知できるもの、縦の軸（虚軸）に認知し得ないものを置きます。置き方の出どころは、読み物「起業家の漸化式と、ジュリア集合」です。

その読み物は、式の z を起業家の脳内の自己と置き、z を二乗することを、自己と自己の掛け合わせと読んでいます。足場にしたのは、自己には一つの中核が無い、とする研究で、それを読んで pjdhiro はこう見ました。

pjdhiro の見方：自己は単一では無い。とするなら、二乗するように、自己と自己が創造的に協働するイメージです。

この見方の上で、代数学の基本定理の登場人物を一つずつ当ててみます。左の列は式で確かなことで、独立ページ「代数学の基本定理」で説明しています。右の列が、このページの仮説です。

式のふるまいを、当てた先で読む

登場人物を当てたうえで、式のふるまいが、当てた先でどう読めるかを見ます。ふるまいは三つです。

一つ目：数直線の上だけで探すと、答えが足りない。x² + 1 = 0 の答えは、数直線の上にありません。数直線の上のどの数も、2 乗すると 0 以上になるからです。平面まで広げると、i と −i の二つが答えになります。i と −i は、正の数でも負の数でもありません。この二つを横の軸で測ると、どちらも 0 です。横の軸に認知できるものを置いたので、認知できる側だけで探すと、この問いには答えが無いと出るのではないか、と読めます。欠損駆動思考のたとえ「虚軸に値があって、しかも、認知上は 0」は、この二つの答えの形と重なって見えます。pjdhiro は、A でないなら B だ、とは見ません。A でも B でもないが、A とも B とも言えるものもありうる、と見ています。正でも負でもない i と −i は、その形の一つの写しに見えます。

二つ目：答えは、同じ資格で並ぶ。zn = 1 の n 個の答えは、どれも 0 からの距離が 1 で、円の上に等しい角度で並びます。どれが本当の答えかを決める順位は、式にはありません。これを自己に当てると、自己は一つでなく、いくつかの自己が同じ大きさで並んでいるのではないか、と読めます。数直線の上に出ている答えは 1 だけ（n が偶数なら、1 と、その反対の −1）で、ほかは数直線の外にあります。いま認知できている自己は、並んでいる自己の一つにすぎず、ほかの自己は認知できる軸の外にいるのかもしれません。

三つ目：一段遡ると、真逆の二つが残る。2 乗して同じ数になる数は、0 を中心に半回転させた二つです。2 乗された数から、どちらを 2 乗したのかを決めることはできません。読み物「起業家の漸化式と、ジュリア集合」は、式の一歩を逆に一段戻すとき、この平方根の二つが出てくることを、今の自分から一つ前の自分を出すことに当てています。前へは二つが一つに寄り、振り返ると二つが残る、という形です。pjdhiro は、陰陽の印（☯）を描いて眺めていた頃に、ブログにこう書いています。

pjdhiro の見方：平方根って、真逆の二つが生まれる不思議。（ブログ「対話：「森の木」 Wood Wide Webと陰陽なフラクタルの青山常運歩」2025-06-12）

詳しく — 数直線でも二つ出る平方根と、平面でだけ出る平方根

平方根が二つあることは、数直線の上でも起きます。2 乗して 4 になる数は、2 と −2 の二つです。この二つも、0 を中心に半回転させた写しです。数直線の上で答えが無くなるのは、負の数の平方根を取るときです。2 乗して −1 になる数は、数直線の上にはありません。平面まで広げて初めて、i と −i の二つが出てきます。だから、二つに分かれることだけなら数直線でも見えますが、二つがどちらも認知できる軸の外にある形は、平面でだけ見えます。

当たらない所

複素数の構造に乗った当てはめは、ほとんど何にでも当てはまってしまいます。似て見えることを当然として閉じず、当たらない所も並べておきます。

  • **答えは止まって並ぶだけで、動かない。**方程式の答えは、平面の上の点として並ぶだけです。読み物 julia-potential の、一つの c で打った z の並びが回りながら一点へ寄って見える形（軌跡の渦）も、創造の五段階の渦（散逸構造。蝋燭の炎のように、エネルギーの出入りで形が保たれるもの）も、この定理は書きません。
  • **答えがあることは言うが、どれにどう着くかは言わない。**定理は、答えがそろっていることを言いますが、答えの求め方は言いません。人がいくつかの自己のどれを生きるのかも、式からは出てきません。
  • **等しく並ぶのは、zn = 1 の形のときだけ。**ほかの方程式では、答えは平面のばらばらな所に、違う大きさで並びます。自己を、いつも同じ大きさで等しく並ぶものとは言えません。
  • **三つ以上の自己が掛け合わさる心の働きが、まだ見つからない。**次数を、自己を掛け合わせた回数と当てても、三つ以上の自己が一度に掛け合わさる、と言える働きは見つかっていません。
駆動源に返すもの

当てはめが立った所を、プロジェクトの駆動源に戻してみます。どれも仮説です。

「私は何に駆られているのか」と問うて、認知できる側だけで答えを探すと、答えが無いと出たり、一つしか見つからなかったりするのかもしれません。そのとき、駆動源が無いのではなく、探す軸が一本足りないのかもしれません。

駆動源を一つの動機に絞って説明しようとすると、残りの答えは、認知できる軸の外に出るのかもしれません。起業家を動かしているものは、一つの自己の一つの動機でなく、いくつかの自己が同じ資格で並んで掛け合わさったもの、と見る方が、見えてくるのかもしれません。

また、何に駆られてここまで来たかを振り返ると、答えは一つに決まらず、真逆の向きの二つが残るのかもしれません。前へ進むときは二つが一つに寄るので、どちらだったかは、振り返っても決まらないのかもしれません。
