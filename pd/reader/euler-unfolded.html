数学では単位円は、半径 1 の円です。複素数の平面では、この円の上の数を掛けることが、平面ごと回すことになります。オイラーの等式 eiπ + 1 = 0 は、eiπ = −1 の −1 を左へ移した形で、この円の上の半周を書いた式です。

式の読み方は、このページでは一つに決めておきます。eiθ を掛けることは、平面の全体に掛けて、平面ごと角度 θ だけ回すことです。i を掛けると 90 度、eiπ を掛けると半周回ります。点 1 が −1 に着くのは、その結果です。

見方どこが似て見えるのかは、このページを通して探していきます。一つ目の手がかりとして、このページは、どちらも、はしの無い一つの輪だ、と見ます。

数学では等式は、その輪の上で 1 を半周させて −1 に着かせ、そこに 1 を足して 0 にします。0・1・i・π・e の五つが、輪の上の一つの動きに収まっています。五つの数の一つずつの説明は、独立ページ「オイラーの式」にあります。

詳しく — 行列で書くと、オイラーの等式は −I + I = O になる

平面全体に i を掛けることは、点 (x, y) を 90 度回す行列 J = [[0, −1], [1, 0]] を掛けることと同じです（[a, b] は行列の一つの行）。J を 2 回掛けると −I になります。I は、何も変えない単位行列です。i² = −1 は、行列では J² = −I です。

eiθ を掛けることは、角度 θ だけ回す行列 cos θ I + sin θ J を掛けることです。θ = π を入れると、cos π = −1、sin π = 0 なので、行列は −I になります。平面のすべての点を、0 をはさんで反対側へ送る行列です。

だから、eiπ + 1 = 0 は、行列では −I + I = O と書けます。O は、どの点も 0 に送る行列です。等式の 1 は「何も変えない」行列 I、0 は「すべてを 0 に送る」行列 O、eiπ は「半周回す」行列 −I にあたります。

その円に、e が出てくる

見方等式を単位円の上で見ると、不思議な所が一つあります。円の式なのに、出てくる数が e です。

e と聞いて思い浮かぶのは、2.718… という数、自然対数の底、指数や対数の計算を足し算で扱えるようにしてくれる便利な数、くらいではないでしょうか。指数の曲がった線を、まっすぐな線にして扱うときに出てくる数、という覚え方もあります。教科書では、利息の計算から出てくる数として習います（下の寄り道）。

けれども、その覚え方からは、e が 2 や 10 より特別な理由は見えてきません。

数学では対数を使えば、底が 2 でも 10 でも、掛け算は足し算になり、指数の曲線は、目盛りを対数にしたグラフでまっすぐな線になります。この働きだけなら、底は e でなくてもかまいません。

単位円の上では、この同じ働きが、回転を重ねることを、角度を足すことに替える形で出てきます。eiα と eiβ を掛けると、ei(α+β) です。eiθ は、半径 1 の円の上を、1 から左回りに速さ 1 で進みます。θ がそのまま、円の上を歩いた道のりになります。底をほかの正の数 c に替えても、ciθ は同じ円の上を進みます。ただし、速さは |ln c| になります。2 ならおよそ 0.69、4 ならおよそ 1.39 です。肩の θ と、円の上を左回りに進んだ道のりがぴったり同じになるのは、底が e のときだけです（1/e なら、速さは 1 でも逆回りです）。足し算になるのはどの底でも同じで、足す角度が、そのまま歩いた道のりになるのは e だけ、ということです。

見方e が 2 や 10 より特別に見えない理由と、単位円で e が大活躍する理由は、ちょうど裏表になっています。底を選ばないのは、掛け算を足し算にする働きで、e だけが持っているのは、その足し算を、円の上の道のりにそろえる働きです。ここに、驚きがあります。

単位円の半周の道のりは π です。だから eiπ は、ちょうど半周の所の −1 に着きます。π と e が一行に並ぶのは、肩に乗せた数を、そのまま円の上の道のりとして読めるのが、底が e のときだけだから、と言えます。

補足：立体の回転と並べると

数学では章「四元数から平面へ：二つの向きを使わないと、複素数を掛ける回転と同じ回転が出てくる」の続きです。四元数で回す式と、二つの向きを使わずに並べた対比の表、その場で動かせる計算、二周で戻る回し手とスピン、行列での書き方を置きます。

立体の回転は、数で挟んで書く

四元数の掛け算は、順番を入れ替えると答えが変わることがあります（i と j を掛けると k、j と i を掛けると −k）。ただし、実の部分の数（ふつうの実数）は、どの四元数と掛けても、順番で答えが変わりません。順番で答えが変わるのは、向きの違う虚の向きどうしを掛けたときだけです。

立体の中の点 v を、軸 u のまわりに角度 θ だけ回すには、点を xi + yj + zk の形に置き、q = euθ/2 という数で前と後ろから挟みます。

v' = q v q−1

q−1 は q の逆数です。挟むと、軸の向きの成分はそのまま残り、軸と直角な成分だけが角度 θ だけ回ります。q は、e の肩（指数）に、軸 u と、回したい角度の半分 θ/2 を乗せた数です。軸と直角な成分は、前から q を掛けて半分、後ろから q−1 を掛けてもう半分回り、合わせて θ になります。

物理では、同じ回転を、パウリ行列という三つの 2 行 2 列の行列で書きます。電子のスピンの向きを回すときの書き方です。四元数の i・j・k を、パウリ行列 σx・σy・σz にそれぞれ −i を掛けたものに置き換えると、掛け算の決まりがそっくり同じになります。だから、物理の U v U†（U† は U の逆にあたる行列）は、四元数の q v q−1 と同じ形をしています。

詳しく — 四元数の掛け算の決まりと、パウリ行列との対応

四元数の掛け算の決まりは、次のとおりです。i² = j² = k² = −1、ij = k、jk = i、ki = j、ji = −k、kj = −i、ik = −j。

パウリ行列は、σx = [[0, 1], [1, 0]]、σy = [[0, −i], [i, 0]]、σz = [[1, 0], [0, −1]] です（[a, b] は行列の一つの行）。四元数の 1 を 2 行 2 列の単位行列 I に、i・j・k を −iσx・−iσy・−iσz に置き換えて計算すると、上の決まりがすべて成り立ちます。このページでは、置き換えたものどうしを掛けて、全部の組で確かめました。

軸 k のまわりを角度 θ 回す q = ekθ/2 は、行列では U = [[e−iθ/2, 0], [0, eiθ/2]] になります。点 σx（四元数の i にあたる）を U σx U† と挟むと、cos θ σx + sin θ σy になり、i が j の向きへ角度 θ だけ回ったことになります。

詳しく — 回す式の前提（実の部分を 0 と置くこと、q と −q）

v' = q v q−1 は、点 v の実の部分を 0 と置いて使う式です。実の部分は、q と順番を入れ替えても同じなので、挟むと q と q−1 が打ち消し合い、動きません。軸の向きの成分も、同じ理由で動きません。

q と −q は、同じ回転を表します。挟むと符号が二回出て、打ち消し合うからです。だから、回し手 q の側は、立体が一周（θ = 2π）しても −1 になるだけで、もとの 1 に戻るのは二周（θ = 4π）したときです。電子のスピンの状態が、二回転（4π）でやっと元の符号に戻ると言われるのは、この性質のことです。向きそのものは一周で戻ります。

この書き方には、平面の回転を eiθ で書いたときには見えなかった部品が出てきます。回す軸 u、角度を半分ずつ前と後ろに分けること、掛ける順番、それに、二周してやっと元に戻る回し手 q（上の畳み）です。続けて、四元数の二つの向きを使わずにオイラーの側と並べ、この四つが等式の中ではどこへ行ったのかを見ます。

二つの向きを使わずに、オイラーの側と並べる

四元数の w・i・j・k の四つの向きのうち、二つを使わない（0 と置く）と、平面が一枚残ります。そこでは、eiθ を掛けるのと同じ回転が書けます。

どの二つを使わないかで、残る平面が変わります。挟む式 q v q−1 は、実の部分を 0 と置いて使う式です。だから、この式でオイラーの等式と並べるには、実の向きを含まない平面を残します。ここでは、実の部分 w と k を 0 と置いて使わずに、i と j の平面を残し、軸を k にします。

両側に同じ項目を並べると、次のようになります。

項目 オイラーの等式の側（複素平面） 四元数の側（i と j の平面）
平面の点 x + iy xi + yj
横の向き 1 i
縦の向き i j
回す軸 式には出てこない（※） k
回す式 eiθ を片側から掛ける ekθ/2 と e−kθ/2 で前と後ろから挟む
回したあとの点 (x cos θ − y sin θ) + i (x sin θ + y cos θ) (x cos θ − y sin θ) i + (x sin θ + y cos θ) j
半周（θ = π） eiπ = −1 を掛ける。1 は −1 に着く ekπ/2 = k で挟む。i は −i に着く

※ オイラーの側の回す軸は、平面に直交する奥行きの向き（z の向き）です。複素数には、その向きを書く場所がありません。

回したあとの点は、横の向きの名前と縦の向きの名前が違うだけで、同じ数が並びます。たとえば x = 0.3、y = 0.9、θ = 0.7 では、どちらも横が −0.3503、縦が 0.8816 になります。

function mul(a, b) {
  const [a0, a1, a2, a3] = a, [b0, b1, b2, b3] = b;
  return [
    a0 * b0 - a1 * b1 - a2 * b2 - a3 * b3,
    a0 * b1 + a1 * b0 + a2 * b3 - a3 * b2,
    a0 * b2 - a1 * b3 + a2 * b0 + a3 * b1,
    a0 * b3 + a1 * b2 - a2 * b1 + a3 * b0,
  ];
}

const x = 0.3, y = 0.9, theta = 0.7;

// オイラーの側：e^{iθ} を x + iy に片側から掛ける

数学では電子のスピンにも、同じ形の数学が出てきます。物理では、電子のスピンの状態に掛かる回転の行列が、この形をしています。上の畳み「四元数の掛け算の決まりと、パウリ行列との対応」にある U = [[e−iθ/2, 0], [0, eiθ/2]] は、θ = 2π で −I になります。スピンの向きは一周で元に戻りますが、状態には −1 が掛かり、4π でやっと I に戻ります。それでも、U と −U は、挟んで回したときに同じ回転になります。立体の回転一つに、回す行列が二つずつ対応しているので、数学では、回す行列の集まり（SU(2)）が、立体の回転（SO(3)）を二重に覆う、と言います。行列の計算は、確かめられる数学の事実です。電子のスピンの回転がこの行列で書けることは、量子力学の教科書の事実です。

見方一周で半分しか回らない、という形が、何の本質を指しているのかは、このページでは問いとして置きます。

詳しく — 実の向きを含む平面で並べると

オイラーの等式と同じ平面（w + iy の平面。j と k を使わない）を四元数の中に残すこともできます。この平面は実の向きを含むので、挟む式 q v q−1 では動きません。q = eiθ/2 で挟むと、点 0.3 + 0.9i は 0.3 + 0.9i のまま残ります。

この平面を回すには、q−1 でなく、同じ q で両側から挟みます。eiθ/2 z eiθ/2 = eiθ z で、オイラーの側と同じ点に着きます（0.3 + 0.9i は、θ = 0.7 で −0.3503 + 0.8816i）。

逆に、同じ q で両側から挟む式は、j と k の平面を動かしません。q で前と後ろから挟む二つの式は、同じ q を使いながら、別々の平面を回しています。

詳しく — 片側から一回掛けると、もう一枚の平面も回る

オイラーの側の「eiθ を片側から掛ける」ことを、四元数の全体に当ててみます。すると、1 と i の平面が角度 θ 回るのと同時に、j と k の平面も同じ角度 θ だけ回ります。たとえば、j に eiθ を前から掛けると、cos θ j + sin θ k になります。j と k を使わない平面の上では、この二枚目の平面の回転は見えません。

片側から一回掛けるという一番素朴な書き方が、四元数の中では、二枚の平面を同時に回す働きになっています。見方オイラーの等式は、その二枚目を見えない所に置いた形だ、と読むこともできそうです。

詳しく — 四元数の側も、行列で書くと −I に着く

章「禅の円と、オイラーの等式は似ていないか」の畳みで、eiπ + 1 = 0 は、行列では −I + I = O でした。

四元数の側も、パウリ行列で 2 行 2 列の行列にすると、同じ所に着きます。ekπ も −I になります。i と j の平面の点 xi + yj は、行列では −i [[0, x − iy], [x + iy, 0]] になり、左下の角にオイラーの側の点 x + iy がそのまま入っています。これを U で挟むと、左下の角が eiθ/2 (x + iy) eiθ/2 = eiθ(x + iy) に変わります。

U = [[e−iθ/2, 0], [0, eiθ/2]] で [[0, a*], [a, 0]] を挟む（a* は a と虚の部分の符号だけ違う数）と、左下の角は eiθ/2 × a × eiθ/2 になります。複素数どうしは順番を入れ替えても同じなので、これは eiθ a です。右上の角は e−iθ a* です。

挟む式 q v q−1 を行列にすると、その中で、オイラーの掛け算が、同じ数を両側から半分ずつ掛ける形で行われています。上の「実の向きを含む平面で並べると」の畳みで見た、同じ q で両側から挟む式が、ここに入っています。

補足：次元という言葉も、一つの意味ではない

見方円の世界を数直線の側で扱う記号の話をしていると、そもそも「次元」とは何かが揺れてきます。このページの構成を考えていたとき、pjdhiro はこう言っています。

pjdhiro の問い：そもそも次元という概念も、だいぶ誤解されてる可能性あるよね。ジュリア集合の次元数とか、違いそうだもんね。

数学では次元という言葉には、少なくとも二つの使われ方があります。一つは、場所を言うのに数がいくつ要るか、です。数直線は 1 つ、平面は 2 つ、立体は 3 つです。もう一つは、細かく見ていったとき、形がどれだけ増えるか、です。線を半分の大きさの升目で数え直すと、升目の数は 2 倍に、面なら 4 倍になります。何倍になるかを 2 の何乗かで書くと、その指数が次元です。

二つの使われ方は、いつも同じ数になるわけではありません。たとえば、線分を三等分して真ん中を山形に折る操作を、限りなくくり返した曲線（コッホ曲線）は、大きさを 1/3 にすると同じ形が 4 つ並びます。4 = 3d から、d はおよそ 1.26 です。線より込み入っていて、面より薄い形です。

ジュリア集合の縁も、同じように測れます。c = 0 のときの縁は、半径 1 の円で、次元は 1 です。c = −1 のときの縁を、このページで細かい升目で数えて見積もると、およそ 1.23 になりました。c = −0.123 + 0.745i でも、1.1 から 1.2 ほどで、どちらも整数になりませんでした。知られている値は、c = −1 でおよそ 1.268、c ≈ −0.1226 + 0.7449i（ドゥアディのウサギと呼ばれる形）でおよそ 1.393 です。升目の見積もりは、整数でないことを見るためのもので、次元の値としては読めません（下のやり方）。

数の個数で数えた次元も、一つの決まりではありません。複素平面に一点 ∞ を足すと、球の表面になります。四元数は四つの数で書きますが、大きさ 1 の四元数を集めると、四つの向きの中の、三次元の球の表面になり、それが立体の回転を書きます。何次元の世界の話をしているのかは、何を数えたかで変わります。

ジュリア集合の縁を、升目で数えたやり方

c = −1 のジュリア集合の縁の点を、逆向きのくり返し（z から ±√(z − c) を選ぶことをくり返す）で 60 万個ほど集めました。平面を、一辺が 4/2k の升目に分け、点が入る升目を数えます。k を 6 から 9 まで細かくしていったとき、升目の数がどれだけ増えるかの傾きを取ると、およそ 1.23 でした。同じやり方で c = 0 を数えると 1.01 で、円の 1 に合います。

この数え方では、逆向きのくり返しで集めた点が縁の一部に偏るので、次元ははっきり低く出ます。ウサギでは、知られた値より 0.2 以上低く出ました。
