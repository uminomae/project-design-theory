立体の回転は、数で挟んで書く

平面の回転は、複素数を一回掛ければ書けます。i を掛けると 90 度、eiθ を掛けると角度 θ だけ回ります（独立ページ「オイラーの式」）。立体の回転を書くには、四元数という数を使います。

四元数は、w + xi + yj + zk の形の数です。w が実の部分で、i・j・k は三つの虚の向きです。三つとも、2 回掛けると −1 になります。i と j を掛けると k になりますが、順番を入れ替えて j と i を掛けると −k になります。掛ける順番で答えが変わることを、非可換と言います。

四元数が四つ目の向きを持つ数としてどう見えるかは、動画で見ると掴みやすいかもしれません。

ただし、実の部分の数（ふつうの実数）は、どの四元数と掛けても、順番で答えが変わりません。順番で答えが変わるのは、向きの違う虚の向きどうしを掛けたときだけです。

立体の中の点 v を、軸 u のまわりに角度 θ だけ回すには、点を xi + yj + zk の形に置き、q = euθ/2 という数で前と後ろから挟みます。

v' = q v q−1

q−1 は q の逆数です。挟むと、軸の向きの成分はそのまま残り、軸と直角な成分だけが角度 θ だけ回ります。q は、e の肩（指数）に、軸 u と、回したい角度の半分 θ/2 を乗せた数です。前から q を掛けて半分、後ろから q−1 を掛けてもう半分回り、合わせて θ になります。

物理では、同じ回転を、パウリ行列という三つの 2 行 2 列の行列で書きます。電子の向き（スピン）を回すときの書き方です。四元数の i・j・k を、パウリ行列 σx・σy・σz にそれぞれ −i を掛けたものに置き換えると、掛け算の決まりがそっくり同じになります。だから、物理の U v U†（U† は U の逆にあたる行列）は、四元数の q v q−1 と同じ形をしています。

詳しく — 四元数の掛け算の決まりと、パウリ行列との対応

四元数の掛け算の決まりは、次のとおりです。i² = j² = k² = −1、ij = k、jk = i、ki = j、ji = −k、kj = −i、ik = −j。

パウリ行列は、σx = [[0, 1], [1, 0]]、σy = [[0, −i], [i, 0]]、σz = [[1, 0], [0, −1]] です（[a, b] は行列の一つの行）。四元数の 1 を 2 行 2 列の単位行列 I に、i・j・k を −iσx・−iσy・−iσz に置き換えて計算すると、上の決まりがすべて成り立ちます。このページでは、置き換えたものどうしを掛けて、全部の組で確かめました。

軸 k のまわりを角度 θ 回す q = ekθ/2 は、行列では U = [[e−iθ/2, 0], [0, eiθ/2]] になります。点 σx（四元数の i にあたる）を U σx U† と挟むと、cos θ σx + sin θ σy になり、i が j の向きへ角度 θ だけ回ったことになります。

詳しく — 回す式が、そもそも省いているもの

v' = q v q−1 は、点 v の実の部分を 0 と置いて使う式です。実の部分は、q と順番を入れ替えても同じなので、挟むと q と q−1 が打ち消し合い、動きません。軸の向きの成分も、同じ理由で動きません。

q と −q は、同じ回転を表します。挟むと符号が二回出て、打ち消し合うからです。だから、回す数 q の側は、立体が一周（θ = 2π）しても −1 になるだけで、もとの 1 に戻るのは二周（θ = 4π）したときです。電子の向きが二回転で元に戻ると言われるのは、この性質のことです。

この書き方には、平面の回転を eiθ で書いたときには見えなかった部品が出てきます。回す軸 u、角度を半分ずつ前と後ろに分けること、掛ける順番、それに、二周してやっと元に戻る回す数 q（上の畳み）です。次の章で、四元数の二つの軸をゼロにしてオイラーの等式と並べ、この四つが等式の中ではどこへ行ったのかを見ます。

二つの軸をゼロにすると、オイラーの等式が出てくる

前の章で出てきた四つの部品が、平面の回転ではどこへ行くのかを見ます。四元数の w・i・j・k の四つのうち、二つをゼロにすると、平面が一枚残ります。そこでは、オイラーの等式と同じ働きの式が書けるはずです。

どの二つをゼロにするかで、残る平面が変わります。挟む式 q v q−1 は、実の部分を 0 と置いて使う式です。だから、この式でオイラーの等式と並べるには、実の向きを含まない平面を残します。ここでは、実の部分 w と k をゼロにして、i と j の平面を残し、軸を k にします。

両側に同じ項目を並べると、次のようになります。

項目 オイラーの等式の側（複素平面） 四元数の側（i と j の平面）
平面の点 x + iy xi + yj
横の向き 1 i
縦の向き i j
回す軸 式には出てこない（※） k
回す式 eiθ を片側から掛ける ekθ/2 と e−kθ/2 で前と後ろから挟む
回したあとの点 (x cos θ − y sin θ) + i (x sin θ + y cos θ) (x cos θ − y sin θ) i + (x sin θ + y cos θ) j
半周（θ = π） eiπ = −1 を掛ける。1 は −1 に着く ekπ/2 = k で挟む。i は −i に着く

※ オイラーの側の回す軸は、平面に直交する奥行きの向き（z の向き）です。複素数には、その向きを書く場所がありません。

回したあとの点は、横の向きの名前と縦の向きの名前が違うだけで、同じ数が並びます。たとえば x = 0.3、y = 0.9、θ = 0.7 では、どちらも横が −0.3503、縦が 0.8816 になります。

詳しく — この計算を、その場で動かして確かめる

下のコードは、両方の計算をその場で動かせるようにしたものです（JavaScript）。数を書き換えて「実行」をクリックすると、ほかの点や角度でも同じ所に着くことが見られます。コピーして、ブラウザの開発者ツールのコンソールや Node.js に貼っても動きます。

// 四元数 w + xi + yj + zk を [w, x, y, z] の並びで書く
function mul(a, b) {
  const [a0, a1, a2, a3] = a, [b0, b1, b2, b3] = b;
  return [
    a0 * b0 - a1 * b1 - a2 * b2 - a3 * b3,
    a0 * b1 + a1 * b0 + a2 * b3 - a3 * b2,
    a0 * b2 - a1 * b3 + a2 * b0 + a3 * b1,
    a0 * b3 + a1 * b2 - a2 * b1 + a3 * b0,
  ];
}

const x = 0.3, y = 0.9, theta = 0.7;

// オイラーの側：e^{iθ} を x + iy に片側から掛ける
const euler = [
  x * Math.cos(theta) - y * Math.sin(theta),
  x * Math.sin(theta) + y * Math.cos(theta),
];

// 四元数の側：e^{kθ/2} と e^{−kθ/2} で xi + yj を前と後ろから挟む
const q    = [Math.cos(theta / 2), 0, 0,  Math.sin(theta / 2)];
const qInv = [Math.cos(theta / 2), 0, 0, -Math.sin(theta / 2)];
const v = [0, x, y, 0];
const r = mul(mul(q, v), qInv);

console.log("オイラーの側：横", euler[0].toFixed(4), "縦", euler[1].toFixed(4));
console.log("四元数の側　：横", r[1].toFixed(4), "縦", r[2].toFixed(4));
console.log("四元数の側の実の部分と k：", r[0].toFixed(4), r[3].toFixed(4));

同じ計算を Python で書くと、次のようになります。エディタに写して、Python 3 で動かせます。

import math

# 四元数 w + xi + yj + zk を (w, x, y, z) の並びで書く
def mul(a, b):
    a0, a1, a2, a3 = a
    b0, b1, b2, b3 = b
    return (
        a0 * b0 - a1 * b1 - a2 * b2 - a3 * b3,
        a0 * b1 + a1 * b0 + a2 * b3 - a3 * b2,
        a0 * b2 - a1 * b3 + a2 * b0 + a3 * b1,
        a0 * b3 + a1 * b2 - a2 * b1 + a3 * b0,
    )

x, y, theta = 0.3, 0.9, 0.7

# オイラーの側：e^{iθ} を x + iy に片側から掛ける
euler = complex(math.cos(theta), math.sin(theta)) * complex(x, y)

# 四元数の側：e^{kθ/2} と e^{−kθ/2} で xi + yj を前と後ろから挟む
q = (math.cos(theta / 2), 0, 0, math.sin(theta / 2))
q_inv = (math.cos(theta / 2), 0, 0, -math.sin(theta / 2))
r = mul(mul(q, (0, x, y, 0)), q_inv)

print("オイラーの側：横", round(euler.real, 4), "縦", round(euler.imag, 4))
print("四元数の側　：横", round(r[1], 4), "縦", round(r[2], 4))
print("四元数の側の実の部分と k：", round(r[0], 4), round(r[3], 4))

二つの式は同じ点に着きます。それでも、四元数の側には、オイラーの側に書かれていない部品があります。前の章で出てきた四つです。このページで並べてみると、オイラーの等式がたたんでいたものは、少なくとも次の四つに見えます。

  1. 回す軸：平面の回転にも、平面と直角な軸があります。オイラーの側では、軸は数の中に置き場がなく、式に出てきません。
  2. 半分ずつ、両側から：四元数の側では、角度の半分を前に、半分を後ろに掛けます。オイラーの側では、全部を片側から掛けます。
  3. 掛ける順番：四元数の側では、k と i を入れ替えると符号が変わります。オイラーの側では、eiθ と点を入れ替えても答えが同じなので、順番が見えません。
  4. 二周で戻る回し手：回す数 ekθ/2 は、平面が一周しても −1 で、二周してやっと 1 に戻ります。eiθ は一周で 1 に戻ります。
詳しく — 実の向きを含む平面で並べると

オイラーの等式と同じ平面（w + iy の平面。j と k をゼロ）を四元数の中に残すこともできます。この平面は実の向きを含むので、挟む式 q v q−1 では動きません。q = eiθ/2 で挟むと、点 0.3 + 0.9i は 0.3 + 0.9i のまま残ります。

この平面を回すには、q−1 でなく、同じ q で両側から挟みます。eiθ/2 z eiθ/2 = eiθ z で、オイラーの側と同じ点に着きます（0.3 + 0.9i は、θ = 0.7 で −0.3503 + 0.8816i）。

逆に、同じ q で両側から挟む式は、j と k の平面を動かしません。q で前と後ろから挟む二つの式は、同じ q を使いながら、別々の平面を回しています。

詳しく — 片側から一回掛けると、もう一枚の平面も回る

オイラーの側の「eiθ を片側から掛ける」ことを、四元数の全体に当ててみます。すると、1 と i の平面が角度 θ 回るのと同時に、j と k の平面も同じ角度 θ だけ回ります。たとえば、j に eiθ を前から掛けると、cos θ j + sin θ k になります。j と k をゼロにした平面の上では、この二枚目の平面の回転は見えません。

片側から一回掛けるという一番素朴な書き方が、四元数の中では、二枚の平面を同時に回す働きになっています。オイラーの等式は、その二枚目を見えない所に置いた形だ、と読むこともできそうです。

詳しく — 行列で書くと、オイラーの等式は −I になる

二つの側を、同じ 2 行 2 列の行列の言葉で書くと、一本につながります。

平面全体に i を掛けることは、点 (x, y) を 90 度回す行列 J = [[0, −1], [1, 0]] を掛けることと同じです。J を 2 回掛けると −I になります。I は、何も変えない単位行列です。i² = −1 は、行列では J² = −I です。

eiθ を掛けることは、角度 θ だけ回す行列 cos θ I + sin θ J を掛けることです。θ = π を入れると、cos π = −1、sin π = 0 なので、行列は −I になります。平面のすべての点を、0 をはさんで反対側へ送る行列です。

だから、eiπ + 1 = 0 は、行列では −I + I = O と書けます。O は、どの点も 0 に送る行列です。等式の 1 は「何も変えない」行列 I、0 は「すべてを 0 に送る」行列 O、eiπ は「半周回す」行列 −I にあたります。

四元数の側も、パウリ行列で 2 行 2 列の行列にすると、同じ所に着きます。ekπ も −I になります。i と j の平面の点 xi + yj は、行列では −i [[0, x − iy], [x + iy, 0]] になり、左下の角にオイラーの側の点 x + iy がそのまま入っています。これを U で挟むと、左下の角が eiθ/2 (x + iy) eiθ/2 = eiθ(x + iy) に変わります。

U = [[e−iθ/2, 0], [0, eiθ/2]] で [[0, a*], [a, 0]] を挟む（a* は a と虚の部分の符号だけ違う数）と、左下の角は eiθ/2 × a × eiθ/2 になります。複素数どうしは順番を入れ替えても同じなので、これは eiθ a です。右上の角は e−iθ a* です。

挟む式 q v q−1 を行列にすると、その中で、オイラーの掛け算が、同じ数を両側から半分ずつ掛ける形で行われています。上の「実の向きを含む平面で並べると」の畳みで見た、同じ q で両側から挟む式が、ここに入っています。

0 と 1 も、次元をたたむ記号かもしれない

四つを開いてみると、たたむ働きをしているのは、eiθ を掛ける一つの式だけではないように見えてきます。オイラーの等式の登場人物も、それぞれが何かを一つにたたむ働きをしているように見えます。pjdhiro は、等式の登場人物を眺めていた対話の初めに、0 と 1 について、こう言っています。

pjdhiro の見方：非二元から発想しようと思ってます。0 と 1 は、数直線のような左右に配置されるものではない。e と π は、数直線に次元を落とす、ステレオ投影のような際に必要になるもの、と逆に発想しようとしてます。つまり e の理解は不要。ルートのような記号になりつつある。

ステレオ投影は、球の上の点を、平面へ写すやり方です。球の北極から、球の上の点を通る線を引き、平面に当たった所へ写します。複素平面に、どこまでも遠い所を表す点 ∞ を一つ足すと、平面は球の表面と同じものとして扱えます（リーマン球面）。そのとき、0 は南極、∞ は北極、半径 1 の円は赤道に来ます。1 は赤道の上の一点です。

この球の上で、大きさ 1 の数を掛けることは、北極と南極を結ぶ軸のまわりに、球を回すことです。回しても動かないのは、0 と ∞ の二点だけです。また、点を「1 ÷ その点」の向きに写す鏡（z → 1/z̄）は、0 と ∞ を入れ替え、半径 1 の円の上の点だけを動かしません。この球の上では、0 の反対は ∞ で、1 は二つの真ん中の輪にあります。

pjdhiro の見方：ゼロの逆が 1 かのような世界観を捨て、ゼロの逆は無限大で、1 は 1/2 かのような。

ほかの登場人物も、何かをたたんでいます。これは数学の事実です。2 乗は角度を 2 倍にするので、z と −z を同じ一点に重ねます。√ はその逆で、角度を半分にし、答えを二つに分けます。π は、半周の道のりで、回転を一本の長さで書きます。ez は、縦にまっすぐ伸びる線（z = iy）を、半径 1 の円に何周も巻きつけます。横にまっすぐ伸びる線（z = x）は、左の果てを 0 に、右の果てを ∞ に縮めます。

pjdhiro の見方：2 乗されてるのが普通の世界で、それを数学にする際に、√ するように π や e を使ってるような道具のイメージです。二次元を一次元にするものとする、という宣言のようなものとしてます。

続けて、pjdhiro は 0 と ∞ も同じ並びに置きました。

pjdhiro の見方：ゼロと無限大は、√ や e や π のように、次元を落とすための道具なのかもしれませんね。

このページは、ここまでを仮説として受け取ります。e・π・√ は、平面の回転を数直線の上で扱えるように折りたたむ記号で、0 と ∞ も、球の上の向きを持たない二点を、数直線の両端に置く記号ではないか、という仮説です。どれも、意味の重い主役というより、√ の記号のような「たたむ操作の名前」に見えてきます。

では、なぜ人は、たたんだ側の数直線から数学を積み上げるのでしょうか。pjdhiro は、その理由を、世界の側より、人の認知と道具の側に見ています。創造とはの見方について、こう話しています。

pjdhiro の見方：創造とは、は、四元数による三次元の回転を言ってます。反対側に回転子がいる。それが本質なのではなく、本質の現れではありますが、同時に、道具と認知がそうだから。数学と三次元の制約により、現象をそう認識してしまう人間の特徴があり、でも、それ以外はどうせ理解に苦しむから実用的でない。

なぜ人の認知がそうなっているのかは、まだ分かっていません。このページでも、問いのまま置きます。

寄り道 — 美しいと感じる所は、赤道なのか

オイラーの等式は、数学者たちが美しいと呼んできた式です（読み物「美とは」の章「数学者が、いちばん美しいと呼んできた式」）。球の上で見ると、等式に出てくる 1 と −1 は、どちらも赤道の上にあります。pjdhiro は、美しさの基準について、こう問いを立てています。

pjdhiro の問い：オイラーの等式は、我々の現実と数学が重なるポイントですね。ステレオ投影で言える。それは美の基準かもしれない。いつも通りの感じというしっくり感かもしれないし、フツーの世界がフツーに赤道に出てるという安心感かもしれない。美の基準が数学的なのか、我々の日常に近いのか、ということは分かってないんじゃ？

美しいと感じる所が、二つの世界が重なる輪にあるのかは、このページでは確かめられません。仮説として置きます。

次元という言葉も、一つの意味ではない

たたむ記号の話をしていると、そもそも「次元」とは何かが揺れてきます。このページの構成を考えていたとき、pjdhiro はこう言っています。

pjdhiro の問い：そもそも次元という概念も、だいぶ誤解されてる可能性あるよね。ジュリア集合の次元数とか、違いそうだもんね。

次元という言葉には、少なくとも二つの使われ方があります。一つは、場所を言うのに数がいくつ要るか、です。数直線は 1 つ、平面は 2 つ、立体は 3 つです。もう一つは、細かく見ていったとき、形がどれだけ増えるか、です。線を半分の大きさの升目で数え直すと、升目の数は 2 倍に、面なら 4 倍になります。何倍になるかを 2 の何乗かで書くと、その指数が次元です。

二つの使われ方は、いつも同じ数になるわけではありません。たとえば、線分を三等分して真ん中を山形に折る操作を、限りなくくり返した曲線（コッホ曲線）は、大きさを 1/3 にすると同じ形が 4 つ並びます。4 = 3d から、d はおよそ 1.26 です。線より込み入っていて、面より薄い形です。

ジュリア集合の縁も、同じように測れます。c = 0 のときの縁は、半径 1 の円で、次元は 1 です。c = −1 のときの縁を、このページで細かい升目で数えて見積もると、およそ 1.2 になりました。c = −0.8 + 0.156i と c = −0.123 + 0.745i でも、1.1 から 1.2 ほどで、どれも整数になりませんでした。

数の個数で数えた次元も、一つの決まりではありません。複素平面に一点 ∞ を足すと、球の表面になります。四元数は四つの数で書きますが、大きさ 1 の四元数を集めると、四つの向きの中の、三次元の球の表面になり、それが立体の回転を書きます。何次元の世界の話をしているのかは、何を数えたかで変わります。

詳しく — ジュリア集合の縁を、升目で数えたやり方

c = −1 のジュリア集合の縁の点を、逆向きのくり返し（z から ±√(z − c) を選ぶことをくり返す）で 60 万個ほど集めました。平面を、一辺が 4/2k の升目に分け、点が入る升目を数えます。k を 6 から 9 まで細かくしていったとき、升目の数がどれだけ増えるかの傾きを取ると、およそ 1.23 でした。同じやり方で c = 0 を数えると 1.01 で、円の 1 に合います。

この数え方は見積もりで、点の集まり方の偏りで少し低めに出ることがあります。

回ることが先にあるのかもしれない

ここまでを並べると、一つの見方が浮かびます。平面の回転が先にあり、それを数直線に折りたたむために、0 と ∞、√・π・e のような記号が便宜上使われているのではないか、という見方です。

pjdhiro は、回転が溢れていることについて、こう話しています。

pjdhiro の見方：世界には回転の性質を持つものが多いのか、世界を回転という性質で認知するからなのか、道具が回転を扱うからなのか、どれなんでしょうね。いずれにせよ、回転は溢れてそうですね。

自然対数（底が e の対数）についても、同じ向きの見方があります。対数は、歴史の上では、大きな数の掛け算を足し算に替えて楽に計算するための道具として作られました（ネイピア）。e は、利息を細かく分けて付けると元の何倍になるかを考えたときに出てきた数です（ヤコブ・ベルヌーイ）。どちらも、円の話から始まったものではありません。

ところが、複素数の対数を考えると、円が出てきます。log z の虚の部分は、z が 0 のまわりで回った角度です。その角度を、半径 1 の円の上の道のりでちょうど測れるのは、底が e のときだけです（独立ページ「オイラーの式」の畳み「e と、「1 + x/n を n 回掛ける」こと」）。pjdhiro は、ここから逆向きに考えています。

pjdhiro の見方：e は単位円のためのツールではない、というのが一般的ですよね？そこが逆だと思うのです。我々が自然対数と呼ぶものが特別なのは、単位円が特別だからで、その上の次元にステレオ投影前のものがあって、それが大切だから、と逆算しています。

歴史の順番は、計算の道具と利息が先でした。このページが置くのは、歴史の言い直しではなく、自然対数が「自然」に見える理由が、円の側にもあるのかもしれない、という揺さぶりです。0 と ∞ が、まだ誤解されているかもしれないのと同じ向きの問いです。

pjdhiro の見方：ゼロはまだ誤解されてるかもしれませんね。無限大も。

禅の円と、円の雲

回転と円の話から、少し寄り道をします。禅には、円を描いて答える話や、円を欠けの無いものとして語る言葉があります。pjdhiro は、禅の円についてこう話しています。

pjdhiro の見方：禅は単位円のようなものを表してると、勝手に思ってた。

たとえば、『信心銘』（伝・僧璨）には「圓同太虛　無欠無餘」（円かなることは大きな空と同じで、欠けも余りも無い）という句があります。同じ銘は、いちばん小さいものといちばん大きいものが同じだ、とも言います（「極小同大」「極大同小」）。『碧巌録』第 33 則では、資福が、訪ねてきた陳操を見るなり、一つの円を描きます。禅の円は、真理を言葉の代わりに指すもののように扱われています。

いちばん小さいものと、いちばん大きいものが同じ所にある、という言い方は、球の上で 0 と ∞ が同じ重さの二つの極になることと、形が似ています。これは、このページの読みです。

出典
  • 『信心銘』（伝・僧璨）。大正蔵 T48 no.2010。「圓同太虛　無欠無餘」は 0376b24、「極小同大　妄絕境界　極大同小　不見邊表」は 0377a05〜a06（CBETA の本文で照合）。
  • 『碧巌録』第 33 則「陳操尚書看資福」。大正蔵 T48 no.2003 巻 4、0172a17〜a19（CBETA の本文で照合）。
  • 禅の円が、単位円のどの性質に近いかを禅籍で調べた記録は、「禅の円は、単位円のようなものを表しているか」にあります。回り続けることと鏡の面では近く、欠けの無さの面では逆を向く、という読みです。

円が真理のように扱われる話は、ジュリア集合の読み物の円の雲につながります。読み物「起業家の漸化式と、ジュリア集合」の章「円の中に雲として残れるのは、縁にあったものだけ」で、円の雲は、いろいろな c のジュリア集合の縁の点が重なって、半径 2 の線の内に作る、横に長い雲のことです。一つの c の図には現れません。その雲が「私」かもしれない、というのが、あちらの仮説です。

0 と ∞ のあいだに立つ 1 の輪と、半径 2 の線の内に残る円の雲は、どちらも、散りも縮みもせずに残る所として並べて見ることができそうです。pjdhiro は、0 と ∞ と 1 の並びを見たとき、こう言っています。

pjdhiro の見方：ゼロと無限大の波間に、渦としての 1 が立つのかもしれませんね。これも創造の構造に見える。

ここでの渦は、創造の五段階の渦（波間に立つ渦）のたとえです。式の値を打って見える軌跡の渦とは別のものです。複素平面の入口としてこのページが置くのは、回る・たたむ・残る、の三つの見方です。ほかの数学のページは、この三つのどれが働いているかを手がかりに読むことができます。
