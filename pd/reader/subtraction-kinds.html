いろんな引き算

一本の数直線の外で差を測るための前提知識

最終更新: 2026-11-12 ／ 状態: 工事中
正本 (GitHub)

ふつうの引き算は、一本の数直線の上で、二つの数の差をとります。答えは一つの数で、0 なら差は無いと読みます。数学には、ほかの形の引き算もあります。このページでは、一本の数直線の上の引き算では 0 と出る差や、そもそも出てこない差を測る引き算を、七つ見ます。初めの四つは、欠損駆動思考の章に関わる引き算です。数学 III の知識は要りません。虚軸や i が初めての人は、先に「回転の掛け算」を読むと分かりやすくなります。

大きさの差と、差の大きさ

数直線の上で、0 から右へ 3 進む矢印と、0 から左へ 3 進む矢印を考えます。数で書くと 3 と −3 です。

二つの矢印の長さ（大きさ）は、どちらも 3 です。大きさの差をとると、3 − 3 = 0 です。

二つの矢印の差をとってから大きさを測ると、3 − (−3) = 6 なので、6 です。

同じ二本の矢印でも、先に大きさにしてから引くと 0、先に引いてから大きさにすると 6 になります。大きさだけを見ると、向きの違いは消えます。

平面でも同じことが起きます。右へ 3 の矢印と、真上へ 3 の矢印は、大きさの差が 0 です。二つの矢印の先どうしの距離は、約 4.24（3 × √2）です。

二乗した姿の差と、根 — 二つの根が重なる 0

2 乗すると 4 になる数は、2 と −2 の二つです。このような数を、4 の根（平方根）と呼びます。

二乗した数どうしの差は、二つの掛け算に分けられます。

a × a − b × b = (a + b) × (a − b)

たとえば、5 × 5 − 3 × 3 = 16 で、(5 + 3) × (5 − 3) = 8 × 2 = 16 です。

3 と −3 は、二乗するとどちらも 9 です。二乗した姿の差は 0 ですが、もとの数は 6 離れています。二乗した姿が同じでも、もとの数は二通りあります。

2 乗すると x になる数（x の根）を、x を変えながら見ます。

  • x が 4 なら、根は 2 と −2 です。どちらも数直線（実軸）の上にあります。
  • x が −4 なら、根は 2i と −2i です。どちらも虚軸の上にあり、実軸の向きの値は 0 です。
  • x が 0 なら、根は 0 だけです。ただし数学では、二つの根が 0 で重なっている、と数えます（二重根）。

x を 4 から 0 を通って −4 へ動かすと、二つの根は実軸の上で近づき、0 で一つに重なり、そこから向きを 90 度変えて、虚軸の上で離れていきます。二つの根が重なるのは、0 のところだけです。

一周しても戻らない — 角度と 720 度

角度の差は、360 度で 0 に戻ります。10 度の向きと 370 度の向きは、同じ向きです。

ところが、一周しても元に戻らないものがあります。前の節の根です。

4 を、0 を中心とした半径 4 の円の上で、ゆっくり一周させます。このとき、2 から出発した根を追いかけると、根は半周（180 度）しか回らず、一周し終えたときには −2 に着きます。もう一方の根になっているのです。もう一周させると、ようやく 2 に戻ります。元に戻るには、二周（720 度）が要ります。

動いて見る — x を二周させると、根は一周する

（この対話図は JavaScript で動きます。動かない環境では: x を 0 のまわりに回すと、2 から出発した根は半分の角度だけ回ります。x が一周すると根は −2 に着き、二周（720 度）で 2 に戻ります。0 を囲まない輪にすると、根は一周で元に戻ります。）

これは、根が元の数の角度の半分だけ回るからです。0 を囲まない小さな輪を一周させるなら、根は元の根に戻ります。違いを決めているのは、輪の内側に、二つの根が重なる 0 があるかどうかです。物理のスピノルと呼ばれる量も、360 度の回転では元に戻らず、720 度で戻るものとして知られています。

値が同じでも、変わり方が違う — 微分

y = x と y = x × x の二つの式を考えます。x が 1 のとき、どちらも y は 1 です。値の差は 0 です。

ところが、x を少しだけ増やしたときの y の増え方は違います。y = x は、x が増えた分だけ増えます。y = x × x は、x = 1 のあたりでは、x が増えた分のおよそ 2 倍増えます。

ある点での増え方（傾き）を求めることを、微分と呼びます。x = 1 での傾きは、y = x が 1、y = x × x が 2 です。値の差は 0 でも、傾きの差は 1 です。

同じ所に戻っても、向きが変わっている — 道

平らな紙の上で、矢印の向きを変えないように気をつけながら、どこかを一周して出発点に戻ると、矢印は出発したときと同じ向きを指しています。

球の表面では違います。北極で、矢印をある向きに向けます。その向きを保ったまま赤道まで下り、赤道に沿って地球の 4 分の 1 周を進み、北極へまっすぐ戻ります。戻ってきた矢印は、出発したときから 90 度回っています。

同じ所に戻ったので、位置の差は 0 です。それでも、向きには差が残ります。この差は、通った道が囲んだところの曲がり方で決まります。このように、一周して戻ったときに残る向きの変化を、ホロノミーと呼びます。

掛ける順番の差 — 交換子

数の掛け算は、順番を変えても答えが同じです。2 × 3 − 3 × 2 = 0 です。

「回転の掛け算」で見たように、立体の回転を計算する四元数では、i × j = k、j × i = −k です。順番を入れ替えて引くと、i × j − j × i = k − (−k) = 2k で、0 になりません。

二つのものを、順番を入れ替えて掛けたものの差（AB − BA）を、交換子と呼びます。交換子は、順番によってどれだけ違うかを測る引き算です。数では、いつも 0 です。

いくつ足りないかと、何が無いか — 集合の差

かごに、りんご・みかん・ぶどうがあるとします。別のかごには、りんご・ぶどうがあります。

数の引き算で比べると、3 − 2 = 1 で、一つ足りません。集合の差で比べると、一つ目のかごにあって二つ目のかごに無いものは、みかんです。

かごの中身が、りんご・みかんと、りんご・ぶどうなら、数の差は 2 − 2 = 0 です。集合の差は、一つ目から見るとみかん、二つ目から見るとぶどうです。数の差では 0 でも、何が違うかは残ります。
