# ミンツバーグの学派を、駆動源と創造の流れで見る

経営学者のヘンリー・ミンツバーグは、戦略がどう形づくられるかについての論を、十の学派（スクール）に分けました。十の学派をまとめた長い論文（1990 年）のほかに、一部の学派に当たる論文も残しています。学派ごとの章を本にする計画もありましたが、多くは書かれないままでした（本人の振り返り、1993 年）。

のちの本『戦略サファリ』（1998 年）は、冒頭にサックスの詩「群盲象を評す」を置いています。目の見えない人たちが、象のそれぞれの部分に触れて、象を言い当てようとする詩です。著者たちは、戦略形成が象で、論じる側が目の見えない人たちだと書いています。

<strong>pjdhiro の見方：</strong>群盲象を評す　それはどこをどうスライスしてるかなんですよね。

十の学派も、それぞれが一つのスライスです。このページでは、そこに [Love駆動開発と呼びたいもの](love-driven-dev.html)の側から、二つのスライスを重ねます。Love駆動開発は、何が人や物事を動かしているかに、駆動源という切り口から近づこうとする試みです。その駆動源を、Love と呼びたい何か、と置いています。

一つめのスライスは駆動源です。その学派が見ている動きを、何が生んでいるかを見ます。まだわからないものは「わからない」と書きます。

二つめのスライスは、[「創造とは」](https://uminomae.github.io/project-design-theory/cs/)の創造の五段階です。「創造とは」は、場を創造が生まれる環境と条件、波を探索と揺らぎ、縁を異質な要素が出会う境界、渦を要素が結合し変容する核心、束を新たな形式として統合される完成、と置いています。表の「波 → 渦」のような矢印は、その学派がどこからどこまでを見ているかを表します。「束の中」は出来上がった形の中だけを、「束 → 次の場」は出来上がった形が次の創造の条件になるところまでを見ている、という意味です。

## 一覧 — 十の学派を、三つの切り口で並べる

<!--OPEN-->

十の学派を、どこから何を見ているか、創造の区間、駆動源の三つで並べます。創造の五段階の順です。

<div class="tablefit cols-4">

| 学派 | どこから、何を見ているか | 創造の区間 | 駆動源 |
|---|---|---|---|
| エンバイロメント | 組織の外から、環境の力を | 場 → 波 | 場の揺らぎという状況 |
| ラーニング | 時間の流れの中から、行動の積み重ねを | 波 → 縁 | 合わないところに感じる違和感 |
| ポリティカル（のちの呼び名はパワー） | 人と人、集団と集団の間から、力関係を | 波に近い縁 | 人の心。Love と呼びたい何か。権力欲や支配欲は、その一つの例 |
| デザイン | 経営の頂点から、外と内の適合を | 波 → 渦 | 揺らぎに押されて渦が立ち上がる |
| アントレプレナー | 一人の頭の中から、ビジョンを | 縁 → 渦 | 起業家の欲や本能やビジョン |
| コグニティブ | 一人の頭の中から、世界の受け取り方を | 渦（輪郭を切り取ること） | わからない（意識の駆動源） |
| プランニング | 計画担当のスタッフから、戦略を形にする手続きを | 渦 → 束 | 先を読み、コントロールしたいという欲求 |
| ポジショニング | 分析者として外から、市場の中の位置を | 束の中（場の構造の上） | 競争の中で生き残ること |
| カルチャー | 集団の内側から、共有された信念を | 束 → 次の場 | 一緒にいたい、信じ合いたいという思い |
| コンフィギュレーション | 時間をまたいで全体から、形と形の移りを | 束 → 渦 → 束 | わからない |

</div>

この並べ方では、十の学派が、場から束まで創造の流れに沿って並びます。最後のコンフィギュレーションは、束がほどけて次の束になるひと回りを見ています。

一方で、ミンツバーグの学派は、名前の付け方がそろっていません。章の副題には、やり方（形式的、分析的）、出どころ（ビジョン）、場所（心の中、集団）、応じ方（環境への反応）、進み方（創発的）、結果（変革）と、違う種類の言葉が並びます。中身も重なっています。たとえば、アントレプレナーとコグニティブは、どちらも一人の頭の中から見ています。ラーニングとエンバイロメントは、どちらも環境に応じる動きを見ています。

<strong>pjdhiro の感想：</strong>違う言い方としては、同じような視点だが、アントレプレナーという現象から見たか、人の認知という現象を見たか、という対象の違いで分類することでさらに切り分けた、ということで消化できる。

<strong>pjdhiro の感想：</strong>ミンツバーグは人が見つけやすい現象から追っていった。初学者にはわかりやすい。でも、出口に近づくにつれて、駆動源が似ているためにベン図で円が重なる部分（AかつB）のようなところが出てしまって綺麗に切り取れてない。

駆動源が「わからない」のは、コグニティブとコンフィギュレーションです。コンフィギュレーションは、全体を一度に見ようとする学派と言えます。

<strong>pjdhiro の感想：</strong>私はコンフィグレーションに近いですよね。時間軸でも空間でも物質も非物質も。広めに全体を見る。非二元で。

<details><summary>詳しく — 三つの分け方と、フラクタル</summary>

<strong>pjdhiro の見方：</strong>物質と非物質、主体の内部と外部、集団と個人という分け方がありそうで、それが構造とプロセスとしてフラクタル。それを「創造とは」で一般化した。ミクロもマクロも内部も外部もフラクタルとして圧縮しちゃってるんだと思います。分離と包摂で。

同じ場から束への流れが、一人の心の中でも、組織の中でも、市場の中でも起きている、という見方です。pjdhiro は、これを「分離と包摂のスパイラル」とも言います。一覧の創造の区間は、この流れのどこを見ているかなので、三つの分け方もその中に含まれている、と Claude は読んでいます。ミンツバーグが 1983 年に置いた三つの力（環境、リーダーシップ、組織）も、当てはめると、主体の外と、個人と集団に当たります。

</details>

|---|---|
| よくある誤解 | 論文からは読み取れない |
| Love駆動開発の視点で見た解釈 | <strong>区間：</strong>波 → 縁。<strong>駆動源：</strong>合わないところに感じる違和感。<strong>pjdhiro の感想：</strong>「組織や個人が　気づきのような概念として取り出せる、輪郭を持った何かを切り分ける渦に至るプロセス」 |
| 効く条件 | 環境が複雑で動きが激しく、組織が既に確立していて、力が分かれているとき（1973 年） |

### ポリティカル

<div class="tablefit cols-2">

| 定義 | （近い論文から）組織の中で影響を及ぼす仕組みは四つある。権限、イデオロギー、専門性、そして政治。政治は、正統かどうかの外にある力で、人や集団をぶつけ合うことが多い（ミンツバーグ、1985 年） |
|---|---|
| よくある誤解 | <strong>誤解：</strong>組織の政治は害でしかない、と思うこと（誤解の言い方は Claude）。<strong>論文では：</strong>著者は政治を好まないと書きつつ、人をいらだたせもするが役にも立つ、逆説的なものだと結んでいる |
| Love駆動開発の視点で見た解釈 | <strong>区間：</strong>波に近い縁。対立や衝突が生み出す。<strong>駆動源：</strong>人の心。Love と呼びたい何か。<strong>pjdhiro の感想：</strong>「ポリティカルもLoveと呼びたい何かなんですけどね。権力や支配欲は一つの事例。わからない。人の心が駆動源ではある。」著者が結ぶ「いらだたせもするが役にも立つ、逆説的なもの」については「これこそがまさに、「創造とは」の波と縁です。悪いと感じることや対立、無意味さも包摂してより良いものが生まれる。」 |
| 効く条件 | 正式な仕組み（権限・イデオロギー・専門性）が、必要な変化を止めていたり、一つの見方しか通さなかったりするとき（1985 年）。<strong>論文では：</strong>政治は、問題のいろいろな面を議論させ、止められていた変化を進める。対立が組織全体を覆う場合も、組織の土台が変わったときなどには役に立つ |

</div>

### デザイン

<div class="tablefit cols-2">

| 定義 | 戦略形成を、外の脅威と機会、内の力との適合を得るための設計と見る。考えるのは最高経営者で、意識的にコントロールされた思考で行う。戦略は、実行の前に完全に形づくられている（ミンツバーグ、1990 年） |
|---|---|

### アントレプレナー

<div class="tablefit cols-2">

| 定義 | 戦略づくりの型の一つ、起業家型。力のある一人が大胆に決める（ミンツバーグ、1973 年）。起業家にとって戦略は、頭の中にある事業の像。それを生み、変える鍵は、事業についての細かな知識（ミンツバーグとウォーターズ、1983 年） |
|---|---|
| よくある誤解 | <strong>誤解：</strong>起業家の戦略は、紙に書かれた詳しい計画だと思うこと。<strong>論文では：</strong>多くは頭の中にある事業の像で、だから変えやすい |
| Love駆動開発の視点で見た解釈 | <strong>区間：</strong>縁 → 渦。<strong>駆動源：</strong>起業家の欲や本能やビジョン。<strong>pjdhiro の感想：</strong>「アントレプレナー学派やエフェクチュエーションは、起業家の心が駆動源でしょうね。欲や本能のような。その背後にあるものを追っているのがLove駆動開発です」 |
| 効く条件 | 組織が若いか小さいか、強いリーダーがいるとき（1973 年）。事業が一人の頭で分かるほど単純なあいだ（1983 年） |

</div>

### コグニティブ

<div class="tablefit cols-2">

| 定義 | （近い論文から）戦略の定義の一つに、知覚としての戦略がある。組織の人たちが、自分たちの世界をどう見ているか（ミンツバーグとウォーターズ、1983 年） |
|---|---|
| よくある誤解 | <strong>誤解：</strong>環境を見張り続けていれば、変化に気づけると思うこと。<strong>論文では：</strong>見張りすぎると、何も変わっていないときに注意を使いすぎて、本当に変わったときに気づかないことがある |
| Love駆動開発の視点で見た解釈 | <strong>区間：</strong>渦。<strong>駆動源：</strong>意識の駆動源で、わからない。<strong>pjdhiro の感想：</strong>「コグニティブは、　人が感じれるサイズで切り取った渦に名前をつけた　と言うのを基本としていると思う。もしくはそれを微細にしているのかもしれない。私でいう「意識とは」のように」 |
| 効く条件 | 環境が本当に変わったとき。<strong>論文では：</strong>そのときは、戦略より先に心の構えが変わる（1983 年） |

</div>

たとえば、1960 年代の終わり、カナダの女性下着メーカー、カナデル社のガードルが、急に売れなくなりました。ミニスカートが流行し、女性たちが自由で楽で自然な装いを求めるようになったからです。売上は毎年 30% ずつ落ちました。

社長は、フランスと米国の会社を訪ねるうちに、女性たちが求めているのは「もっと自然に見えること」だと気づきました。社長はそのときのことを「急に考えが形になる」と話しています。

ミンツバーグ（ウォーターズとの共著、1983 年）は、この話を、戦略が変わる前に、まず社長の心の構えが変わった例として書いています。社長は「どうすればいいか分かる前に、混乱の時期がある」とも話しています。ミンツバーグは、その不確かさと居心地の悪さに耐えることが大事だと書いています。

pjdhiro の「創造とは」の五段階で見ると、一人の心の中で、古い構えという束がほどけ、揺らぎの中で渦が巻き、新しい構えという束にまとまっている、と読めます。社長が混乱に耐えていた時期を、pjdhiro は、分離と包摂の前の段階にあたる「抱持」に近いと見ています。[「欠損駆動思考」](https://uminomae.github.io/project-design-theory/ks/)は、反射的に処理せず、誤差を問いとして保持する機能を、抱持と呼んでいます。

### コンフィギュレーション

<div class="tablefit cols-2">

| Love駆動開発の視点で見た解釈 | <strong>区間：</strong>束 → 渦 → 束。<strong>駆動源：</strong>わからない。<strong>pjdhiro の感想：</strong>「コンフィグレーション　はわからない。ミンツバーグもよくわかってないんじゃないかな。」 |

たとえば、モントリオールのスーパーマーケット、スタインバーグ社は、1917 年に一軒の食料品店から始まりました。創業者のサム・スタインバーグは、株の議決権を一人で持ち、大事なことは全部自分で決めていました。店のことは、商品も値段も客も、創業者がいちばんよく知っていました。組織は単純なまま、会社は大きくなりました。

ミンツバーグ（ウォーターズとの共著、1983 年）は、この会社を、一人が決めるやり方と単純な組織とが、ひとまとまりになっている例として書いています。こうしたまとまりを、ミンツバーグはコンフィギュレーション（形）と呼びます。このまとまりは、会社が多角化を始めるころまで続きました。

pjdhiro の「創造とは」の五段階で見ると、決め方と組織と事業がひとつの束にまとまり、その束が長く保たれている、と読めます。

## ミンツバーグ自身の切り口 — 三つの力と、七つの見る向き

ミンツバーグ自身も、学派とは別のスライスで戦略を見ていました。

1983 年の論文は、戦略形成を、環境・リーダーシップ・組織の三つの力の絡み合いとして追っています。何が動かしているかで見る点で、駆動源のスライスに近いと言えます。

1991 年の論文は、戦略的に考えることを「見る」こととして描きました。前と後ろ、上と下、横と向こうを見ること、そしてそれをやり遂げる「見届ける」の七つです。たとえば、過去が分からなければ未来は見えない。ヘリコプターから見ると、森は絨毯にしか見えない。この論文は、どの向きから見るかでスライスしています。
