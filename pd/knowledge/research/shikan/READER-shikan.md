# 止観とは

<div class="reader-lead glow-card" id="sk-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>止観は、心を静めること（止）と、ありのままに観ること（観）を、二つで一組にした仏教の修行です。古い経典に説かれたこの修行は、今の人が自分でしてみると、どんな作業になるのでしょうか。</p>
<p>pjdhiro は、この止観を自分の実践にしていて、メモリーを 0 で埋めるプログラムの関数にたとえます。このページは、その実践と見方に、Claude が原典を調べて答える形で書いています。</p>
<p>心をいったん静かにそろえると、小さな変化に気づきやすくなる、という見方を、経典と禅の原典と並べて見られます。</p>
</div>

<p class="reader-summary__title">概要</p>

<div class="reader-lead"><span class="reader-lead__label">問い</span>
止観とは、何か。どこから来た言葉で、pjdhiro はそれをどう行っているのか。
</div>

<div class="reader-lead"><span class="reader-lead__label">今の答え</span>
止は心の動きを静めること、観はものごとをありのままに観ることで、経典は二つを車の両輪のように一緒に修めるものとして説いてきました。天台の智顗は、594 年の講義『摩訶止観』で、これを修行の全体を貫く道としてまとめました。禅宗は別の宗ですが、静めることと観ることを分けない、という同じ形の言い方を持っています。pjdhiro の止観は、心を静かな海面のようにそろえ、そこに立つ小さな変化を、心で指さすように見に行く作業です。
</div>

## 経典は、止と観を二つで一組に説いた

<a id="sk-sutta"></a>止観という言葉は、二つの語を合わせたものです。止は、心の動きを止めて静めること、観は、ものごとをありのままに観ることです。

二つを一組にして説く形は、古い経典にすでにあります。パーリ語で伝わる経（上座部の仏教が伝えてきた経典）の『増支部』には、明らかな知に与る二つのものとして、samatha（静まり）と vipassanā（観ること）を並べる短い経があります。静まりを修めると心が育ち、貪りが捨てられる。観ることを修めると智慧が育ち、無明が捨てられる、と説きます。

同じ『増支部』の別の経では、アーナンダが、悟りに至った人はみな四つの道のどれかを通った、と言います。静まりを先にして観ることを修める道、観ることを先にして静まりを修める道、二つを対にして（yuganaddha、くびきでつないで）修める道、そして、教えへの落ち着かなさにとらわれた心が、やがて内に静まる道です。

漢訳の経典では、同じ二つが「止」と「観」の字で説かれています。『雑阿含経』の一つの経で、アーナンダに問われた長老は、静かな所で思惟するときは、止と観の二つの法で思惟する、と答えます。止を修めればついには観が成り、観を修めればまた止が成る、止と観をともに修めて解き放たれる、と言います。

先にどちらかを置く道も、対にして修める道も、どちらか一つだけで終わる形にはなっていません。二つを分けて名前を付けながら、離さずに修める、という形が、止観という語の芯にあります。

## 天台の智顗が、止観を一つの体系にした

<a id="sk-tiantai"></a>経典の中で一組だった止と観を、修行の全体を貫く一つの道としてまとめたのが、中国の隋の時代の僧、智顗です。智顗は天台山に住んだので、天台大師とも呼ばれ、その教えは天台宗として伝わりました。

主著の『摩訶止観』は、智顗が書いた本ではなく、講義を弟子の灌頂が書き留めたものです。冒頭に、灌頂は、594 年（開皇十四年）の夏、荊州の玉泉寺で講じられたこと、講義は「見境」の所まで来て止まり、その後の分は説かれなかったことを記しています。同じ冒頭は、この止観は智顗が自分の心の中で行ってきた法門を説いたものだ、とも書きます。智顗の師は南岳の慧思、その師は慧文で、慧文は龍樹の論に拠った、と系譜を引きます。

灌頂は、天台には師から受けた三つの止観がある、と書きます。浅いところから深いところへ梯子を登るように進む漸次止観、前と後が入れ替わる不定止観、初めと終わりが二つでない円頓止観です。『摩訶止観』が説くのは円頓止観で、その定義の一文は「法性寂然名止，寂而常照名觀」です。ものの本性が静まっているのを止と呼び、静まりながら常に照らしているのを観と呼ぶ。初めと後と言っても、二つではなく別でもない、と続けます。

修行の場面では、止と観は、坐ることの中で一つになっています。『摩訶止観』の常坐三昧の段は、正しく坐って乱れた想いを捨て、ただ心を一つにつなぐことを止、それを一念に観ることを観、と書きます（つなぐのが止で、一念するのが観）。観る心そのものを振り返ると、観る者が見つからない、という段もあり、それは「[ジェームズに辿り着くまで](to-james.html#tj-shikan)」の止観の章の畳みで読めます。

初めて坐る人のための短い手引き『修習止観坐禅法要』（『天台小止観』）も、智顗のものとして伝わります。その冒頭は、涅槃に入る道は多いが、急所は止と観の二つを出ない、と言い、二つを車の両輪、鳥の両翼にたとえ、片方に偏ると誤る、と書きます。止だけに偏ったものを癡定（愚かな定）と呼び、観だけに偏った心を風の中の灯にたとえて、偏りの形も名指しています。この手引きの言葉は、「[不安とは](anxiety.html#守りに戻るか向き合い続けるか)」の章の畳み「智顗の、止と観の言葉」で、原文とともに読めます。

智顗は、597 年（開皇十七年）の十一月に、六十歳で亡くなった、と弟子の灌頂が伝記に記しています。

## 禅も、静めることと観ることを分けない

<a id="sk-zen"></a>止観は天台宗で体系立てられた修行で、禅宗のものではありません。それでも、禅の書物にも、同じ形の言い方があります。

禅の六祖とされる慧能の言葉を伝える『六祖壇経』は、心を定めること（定）と智慧（慧）を、二つに分けてはならない、と言います。定は慧の体で、慧は定のはたらき。慧のときには定が慧の中にあり、定のときには慧が定の中にある。先に定があって慧が出る、先に慧があって定が出る、と分けて言う者は、法に二つの相を見ている、とまで書きます。たとえは灯と光で、灯が体、光がはたらきで、名は二つでも体はもとは一つ、と言います。

同じ書物は、常に坐って動かず、心を起こさないことを修行だと思い込むことを、情の無いものと同じで、道を妨げる、と戒めます。臨済の語録にも、壁にもたれて坐り、静まり返って動かない清浄な境地を仏法と取るのは大きな誤りだ、という戒めがあります。どちらも、静めることだけを目当てにしてしまう偏りを言っていて、『天台小止観』の癡定と同じ所を見ている、と読めます。

## pjdhiro の止観は、0 にそろえて 1 を見に行く

<a id="sk-pjdhiro"></a>pjdhiro にとって、止観は、本で読んで知った修行というより、自分でしている作業です。どんな作業かを、pjdhiro はプログラムの言葉でたとえています。

<strong>pjdhiro のたとえ：</strong>瞑想は C 言語の bzero() 関数、memset(0) のようなものです。変化があるかないかを識別しやすくする。雑念のようなものが立てる 1 をポーリングするような。止観はそんな感じです。

bzero() と memset(0) は、メモリーの領域をすべて 0 で埋める関数です。ポーリングは、状態が変わったかどうかを、繰り返し見に行くやり方です。心をいったん 0 にそろえておくと、どこかに 1 が立ったとき、それが変化として見分けやすくなります。

pjdhiro は、このたとえを海の像でも言い換えています。静かな海面に一か所だけ白波が立てば、小さくてもすぐに気づける。荒れた海では、白波と渦だらけで、どれがどれだか分からなくなる。だから、静かな海面のほうが、微細な変化を見つけられる、という像です。

では、立った 1 を見に行って、何をするのか。pjdhiro は続けてこう話しています。

<strong>pjdhiro の見方：</strong>湧いた思いや感情や思考、認知した音や映像など、キャッチしてはオブジェクトとして対象化していく作業です。認知した音や映像などの感覚的な刺激は対象化というよりは、キャッチした私を眺める感じですね。そのまま感じ、感じてる私がいることを確認する。オブジェクト化するとか難しいことではなく、心で指さしていく。

湧いた思いや感情は、一つずつ心で指さして観ていきます。音や映像の刺激は、それをキャッチした私の方を眺め、感じている私がいることを確かめます。

この作業を続けた先で起きることを、pjdhiro はほかの読み物で書いています。自分の中を指さすように観ていくと、最後に観察する私が残り、それすらも観ようとすると、観る私と観られる私が分けられなくなる、という見方は、Love駆動開発の章「[Love は、重力に似ていないか](love-driven-dev.html#ldd-shikan)」にあります。止観の中で、I だと思っていたものが me に分かれていった体験は、「[ジェームズに辿り着くまで](to-james.html#tj-shikan)」にあります。止観で心のしくみを知ることを、修行の二つの側の一つめに置く見方は、Love駆動開発の章「[どう鍛えるのか、どう修行するのか](love-driven-dev.html#ldd-practice)」にあります。

## 原典と並べると、どこが近いか

<a id="sk-near"></a>pjdhiro の止観を、ここまでの原典と並べてみます。この段は Claude が並べた読みで、pjdhiro に確かめたものではありません。

湧いたものをキャッチして観る所は、『摩訶止観』の覚意三昧の段と同じ形に見えます。智顗は、心のはたらきが起きたときに、振り返って照らし観察する（「心數起時，反照觀察」）と書きます。智顗がこの三昧を、坐るときに限らず、行くことにも一切の事にも通じる、と置いている所も、繰り返し見に行くポーリングの像と重なります。

0 にそろえる所は、止の側に当たりそうです。ただ、pjdhiro の 0 は、静けさそのものを目当てにするのでなく、1 が立てばすぐ気づけるようにするための下地として置かれています。『天台小止観』の癡定、『六祖壇経』の「常坐不動」への戒め、臨済の「湛然不動」への戒めは、どれも、静けさを目当てにしてしまったときの方を言っている、と読めます。0 を下地にして変化を観る、という pjdhiro の形は、これらの戒めとはぶつからず、止と観を両輪にする、という智顗の言い方の側にあるように見えます。

感じている私がいることを確かめる所は、原典の向きが一つではありません。智顗は、観る心を振り返ると観る者が見つからない、と書き、臨済は、聴いている者をありありと指さしながら、名を与えた途端に突き放します。pjdhiro の「確かめる」が、その途中のどこを指しているかは、ここからは決められません。

智顗 説・灌頂 記『摩訶止観』巻第二上、非行非坐三昧（覚意三昧）（大正新脩大蔵経 第 46 巻 No.1911。[CBETA の本文](https://cbetaonline.dila.edu.tw/zh/T1911_002)。本文照合済）：「實通行、坐及一切事」（p.14b27–b28）、「行者心數起時，反照觀察，不見動轉、根原、終末、來處去處，故名『覺意』」（p.14c03–c04）。観る者が見つからない段（巻第二下 p.16c11–c15）と臨済の指さす段（p.497b26–b29・p.496c10–c14）は、「[ジェームズに辿り着くまで](to-james.html#tj-shikan)」の畳みに原文の出典があります。
