- pjdhiro の公開文「森の木」（https://uminomae.github.io/pjdhiro/20250612WoodWideWeb/）を 2026-11-19 に開き、「罪と赦し、恥（弱さ）と救い駆動で開発される、人生というプロジェクトがあるだろう、と。」を確かめた。カードでは末尾の「、と。」を外した。保持論点の「風のように包む受容の器、赦しの癒し」「雷のように鋭いAgility（機敏さ）、英雄の救い。指し示す、光をあてる。」も同じ頁。
