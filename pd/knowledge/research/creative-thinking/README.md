- 冒頭のカードは三つめの発言の前半。「#150の」を外し、何の創造的思考かは前の文脈の文（世界経済フォーラムの一覧）で示した（公開ページに Issue の番号を出さないため。趣旨は変えていない）。
- 「パースの創造的な愛はまず最初に扱うべき」は、パースの論の中で最初に置く、と読んだ。ページの頭は一般の定義にし、第三部（駆動源）の頭にパース 1893 を置いた。別の読み（ページの頭にパースを置く）なら、第三部の一章を第一部の前へ動かす。
- 「同じ論者の最新の論文だろうから」：年を原典の書誌で確かめた。1893 の「進化的な愛」は、仮説の推論を書いた 1878 より新しいが、アブダクションを書き直した 1903 の講義と 1908 の論文より古い。本文には、パースの論を年の順に並べた表を置き、1893 の位置を書いた。
- 「仮説思考」は、このページの使い方として「まだ確かめられていない説明を先に立て、それを手がかりに考え進める思考」と置いた。日本のビジネスの本で広まった語の定義は、無料で読める原典が見つからず、引いていない。
