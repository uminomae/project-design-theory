# ソフトスキル・非認知能力とは：調べの記録

#208 の A4。公開ページは `pd/reader/soft-skills.html`（正本 `READER-soft-skills.md`・工事中・noindex）。2026-11-26。

## 答える問い

テストで測る頭の能力の外にあるものを、研究はどう名づけ、どう測ろうとしてきたか。

- Issue の仮の問いは「研究と仕事の側は」。仕事の側の名付けの原典（下の Whitmore & Fry 1974）は本文が読めず、仕事・教育の側の名前の並びは A1（`emerging-abilities/`）にあるので、研究の側に絞った。
- 出発点：pjdhiro（2026-11-26・#208 の本文）「能力という上位概念の下に思考がありますね。心理や身体なども含む。ソフトスキルのようなものの比重が高いのでしょう。知能テストのようなものはサブセットなのでしょうね」。

## A1 との切り分け

A1（新しく注目されている能力）は、名前を付けた側の原典で「何が、なぜ今」を並べる。ヘックマンとカウツ 2012 の名前の並び（ソフトスキル・性格の特性・非認知のスキル…）と、OECD 2021 の「性格の特性の別の名前」は、A1 の章「昔からあったものに、名前を付け直す」（`#ea-rename`）にある。A4 は写さずにリンクで指し、名前の付き方（残りの側からの名前）と、測り方とその問題で切った。

ほかのモジュールとの境：構え（やり抜く力・成長の構え・自制心の中身）は A3、人と関わる力（社会的スキル）は A5、頭と心と身体が分けきれないところ（暗黙知など）は A2。ページではどれも名前だけで指した。

## 並べ方

- 章：呼び名（残りの側から・それへの疑い）→ 何で測ってきたか → 測るときに起きること → 頭のテストも頭だけを測っていない → 「サブセット」の見方へ。分け方と最後の章の読み（どちらを測っても、もう一方を切り離せない）は Claude のもの。
- 載せなかったもの：Kautz ら（2014）p.13 の、ご褒美で IQ の人種間の差が消えるという段（論争の多い話題で、このページの問いに要らない）。マシュマロの実験と自制心の中身（A3 の範囲）。
