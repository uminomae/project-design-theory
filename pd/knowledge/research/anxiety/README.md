### 結果

- 「不安こそ解離である」は、新田の言葉として本文照合済（著者本人のサイト）。
- 解離＝防衛と正反対の動き・行き来する（「防衛⇔解離」）も本文照合済。
- 「現実直視」の語は、取った頁のどこにも無い。pjdhiro の言葉として扱い、新田の流れ（防衛⇔解離→制御、制御＝現実検討能力の源）との対応は、本文で「Claude の読み」と書いた。
- 書籍『精神分析統合理論』の本文は読んでいない。本文に書いたのは、サイトの頁で読めたことだけ。

## 足した視点と理由（stance.md 2-4：包摂の無い列挙にしない）

| 足した視点 | 理由 |
|---|---|
| 不安と恐怖の違い（新田）＋先の不確かさ（Grupe & Nitschke、畳み） | 定義の「何がはがれるか」を言うのに要る。二つの共通（向ける先・来るものが定まらない）を強調 |
| フロイトの流れ（A. フロイトの三つの不安）とヴァイラント | 当てはまらないもの：古典では不安が守りを呼ぶ（向きが逆）。新田自身が「不安−防衛論」を包むと書くので、同じ境目の両側として包んだ。ヴァイラントは解離を守りの一つに数え、語が衝突するので畳みで分けた |
| シャインの学ぶ不安と心理的安全・エドモンドソンの恥の危険 | 新田の「制御が無ければ守りに戻る」と同じ形。「心理的安全性とは」と恥不安への橋 |
| クック＝グロイターの段階ごとの主な不安 | 何がはがれるのが不安かが人によって違うことを言うのに要る。pjdhiro の二つ目の視点（発達段階） |

外したもの：クラインの理想化と不安（守りの詳細で、定義の輪郭に要らない）、ブロスショットらの安全の感じ（先の不安の神経の話で、本文の一本道から外れる）。
