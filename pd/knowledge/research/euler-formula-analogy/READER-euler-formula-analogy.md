# オイラーの式から、構造の類似を考える

<div class="reader-lead glow-card" id="ea-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>オイラーの式 e<sup>iθ</sup> = cos θ + i sin θ には、掛け続けても大きくならずに回る数と、その点の影がつくる波が出てきます。このページは、その登場人物を、人の意識や、プロジェクトを動かしているもの（駆動源）に、仮に当ててみるページです。数学そのものの説明は、独立ページ「<a href="euler-formula.html">オイラーの式</a>」にあります。</p>
<p>今の仮説は三つです。駆動は、量として増え続けるものでなく、向きを変え続けながら保たれるものではないか。認知できる側から見ると、その働きは行って戻る波に見え、平均すると 0 と出るのではないか。同じ所に戻ってきたように見えても、何周してきたかは、見えない側に溜まっているのではないか。どれも、これから確かめる仮説です。</p>
</div>

<strong>pjdhiro の見方：</strong>人間の認知と数学などのツールの限界で、解釈は似たものとなる、という制約があることは承知でやっています。ならば違うツールで同じものを眺めるだけです。群盲象。プロジェクトの駆動源を追っている、という北極星は忘れずに。

## 式の登場人物を、仮に当てる

<!--OPEN-->

<a id="ea-cast"></a>当てる前に、平面の二つの軸に何を置くかを決めます。このページも、読み物「[起業家の漸化式と、ジュリア集合](julia-potential.html)」と同じく、横の軸（実軸）に認知できるもの、縦の軸（虚軸）に認知し得ないものを置きます。この置き方は、欠損駆動思考の次のたとえとも重なります。

<strong>pjdhiro のたとえ：</strong>欠損駆動思考と呼んでいる私の体感をたとえるなら、虚軸に値があって、しかも、認知上は 0 の直観です。

この置き方の上で、オイラーの式の登場人物を一つずつ当ててみます。左の列は式で確かなことで、独立ページ「[オイラーの式](euler-formula.html)」で説明しています。右の列が、このページの仮説です。

<div class="tablefit">

| 登場人物 | 式で確かなこと | 仮に当てる先 |
|---|---|---|
| 回る向きの指数（iθ） | 0 からの距離が 1 の数を掛けると、大きさは変わらず、角度だけが進む。掛けた角度は指数の中で足される | 一歩ごとに、大きさを変えずに向きだけを変える働き。前へ進む量として増えないが、止まってもいない |
| 円の上の点（e<sup>iθ</sup>） | 半径 1 の円の上を、1 から道のり θ だけ回った点。一周（道のり 2π）すると同じ点に戻る | いまの心の向き。大きさは同じまま、向きだけが変わり続ける |
| 影の波（cos θ と sin θ） | 回る点の、横の軸への影と縦の軸への影。どちらも 1 と −1 のあいだを行って戻り、波を描く。縦の影は横の影より 90 度ぶん遅れる | 横の影は、回っている働きのうち、認知できる分。縦の影は、同じ働きの、認知し得ない分。認知できる側から見ると、回っている働きは、増えたり減ったりして行って戻るものに見える |
| i | 掛けると 90 度回る。2 回掛けると −1 になり、向きが裏返る | 気づき。縦の軸（認知し得ない側）にあった成分が、90 度回って、横の軸（認知できる側）に出てくること |
| 1 + iθ/n を n 回掛ける | 小さな向き替えを細かくくり返すと、行き着く先は、円の上の道のり θ の点に近づく。大きな向き替えを少ない回数でくり返すと、円の外に出る | 一歩ずつの小さな向き替えを、細かくくり返すこと。細かくくり返すほど、大きさを保ったまま回れる |

</div>

<p class="reader-summary__title">五つの数</p>

オイラーの等式 e<sup>iπ</sup> + 1 = 0 の五つの数も、同じように当ててみます。当てる先がまだ置けないものは、そう書きました。

<div class="tablefit">

| 数 | 式の中でしていること | 仮に当てる先 |
|---|---|---|
| e | 回る点を、指数の形で書く。回る角度がちょうど道のりと合うのは、e のときだけ | 小さな向き替えを細かく積み重ねる、くり返しの形そのもの |
| i | 指数の中で、伸びる代わりに回ることを表す | 気づき（認知し得ない側から、認知できる側へ回り込むこと） |
| π | 半周の道のり。半周回ると、1 は −1 になる | もとの見方の、ちょうど反対に出るまでの道のり |
| 1 | 回り始める所 | いま認知できている、一つの見方 |
| 0 | 足して行き着く所。円の中心で、回る点はそこに来ない | まだ置けない。回る働きがその周りを回っている所、とまでは言える |

</div>

## 式のふるまいを、当てた先で読む

<!--OPEN-->

<a id="ea-behave"></a>登場人物を当てたうえで、式のふるまいが、当てた先でどう読めるかを見ます。ふるまいは三つです。

<b>一つ目：掛け続けても、大きくならずに回る。</b>数直線の上では、同じ数を掛け続けると、大きくなるか、0 に近づくか、裏返るかです。平面では、距離 1 の数を掛け続けると、大きさは同じまま回り続けます。これを駆動に当てると、駆動は、何かを増やし続ける力というより、向きを変え続けながら、同じ大きさで保たれている働きなのではないか、と読めます。成果や進んだ距離のように増えていく量を見ていると、この働きは見落とされるのかもしれません。

<b>二つ目：回る点の影は、行って戻る波になる。</b>回る点を横の軸だけで見ると、影は 1 と −1 のあいだを行って戻ります。一周を平均すると 0 です。横の軸に認知できるものを置いたので、認知できる側から見ると、回り続けている働きは、出たり引っ込んだりして、平均すると何もしていないように見えるのではないか、と読めます。欠損駆動思考のたとえの「虚軸に値があって、しかも、認知上は 0」は、この形と重なって見えます。同じ形は、家のコンセントの電気でも、行って戻るだけで平均 0 の電力（無効電力）として出てきます。それは独立ページ「[交流回路のフェーザ](ac-phasor.html)」にあります。

<b>三つ目：一周すると同じ点に戻り、何周したかは点に出ない。</b>円の上の点は、一周すると同じ点に戻ります。点だけを見ると、一周目か二周目かは分かりません。回った道のりは、指数の中の θ にだけ残ります。これを人に当てると、同じ気分や同じ状況に戻ってきたように見えても、何周してきたかが違うのではないか、と読めます。pjdhiro は、自我の同一性を、昨日の自分が今日の自分と同じだと信じるのでなく、さも同じであるかのように感じる、の側で見ています。見た目の点は同じで、来歴は違う、という式の形は、この見方と同じ向きを向いて見えます。来歴は、見えている点でなく、指数の中に溜まります。

<details><summary>詳しく — 何周したかが、どこに残るか</summary>

オイラーの式で、θ に 2π を足しても、点は変わりません。e<sup>i(θ + 2π)</sup> = e<sup>iθ</sup> です。だから、点から θ を逆に求めようとすると、答えは一つに決まらず、2π ずつずれた答えがいくつもあります。この逆向きの計算が、複素数の対数（log）です。数直線の上の対数は、答えが一つに決まります。平面の対数は、一周するごとに答えが一段ずれます。何周したかを区別して並べると、平面を螺旋の階段のように重ねた面（リーマン面）の上で、答えが一つに決まります。リーマン面は、目次「[複素平面で考える](complex-plane.html)」の表の 10 にあります。

</details>

## 三つの物差しで見る

<!--OPEN-->

<a id="ea-measure"></a>探索の記録は、式を人の何かに当てるとき、当てる前に三つの物差しを決めていました。一つ目は、式の登場人物を、一つずつ何かに当てられるか。二つ目は、式のふるまいが、当てた先で、pjdhiro の記録の言葉と同じ向きを向くか。三つ目は、複素数ならではの構造（掛け算・i・複素数として滑らかに続くこと）が働いているか。点や回転だけなら、二つの実数の組でも書けるので、三つ目がいちばん厳しい問いです。

<div class="tablefit">

| 当てはめ | 当てられるか | 同じ向きか | 複素数ならではか |
|---|---|---|---|
| i を掛ける＝気づき | 立つ | 立つ。気づきの二つ（予測と違う違和感・見えていなかったものが突然現れる驚き）は、回り込んで出てきた成分の感じ方の違いと読める | 立つ。i を掛けることは複素数の掛け算そのもの。ただ、回すだけなら二つの実数の組の回転でも書ける、という留保が残る |
| 大きくならずに回る＝向きを変え続ける駆動 | 立つ | 半分。駆動を量で測らないことは記録の言葉と合うが、「大きさが保たれる」に当たる本人の言葉は、まだ見つけていない | 立つ。角度が指数の中で足されることは、複素数の掛け算から出る |
| 影は行って戻る＝認知上は 0 | 立つ | 立つ。欠損駆動思考のたとえと同じ形 | 半分。影の波だけなら、円を回る点の座標で書ける |
| 何周したかは点に出ない＝来歴は見えない側に溜まる | 立つ | 立つ。さも同じであるかのように感じる、の見方と同じ向き | 立つ。答えがいくつもある対数は、平面の上でだけ出る。数直線の対数には無い |
| 細かい向き替えのくり返し＝一歩のくり返し | 半分 | まだ分からない。細かさに当たる本人の言葉は無い | 立つ |

</div>

## 当たらない所

<!--OPEN-->

<a id="ea-miss"></a>複素数の構造に乗った当てはめは、ほとんど何にでも当てはまってしまう、と Claude が指摘したとき、pjdhiro はこう答えています。

<strong>pjdhiro の見方：</strong>人間の認知がそうである以上、そこがボトルネックです。つまり、それを通して得られるものが最も細かい分析となる可能性がある。壁にぶち当たるので停滞する。

似て見えることを当然として閉じず、当たらない所も並べておきます。

- **外からの出入りが無い。**オイラーの式の円は閉じていて、外からエネルギーや物が入ることも、出ていくことも書きません。創造の五段階の渦（散逸構造。蝋燭の炎のように、エネルギーの出入りで形が保たれるもの）は、出入りがあって生まれます。この式の回転は、その渦には当たりません。
- **ちょうど 1 のときだけ回り続ける。**距離が 1 より少しでも大きい数を掛け続けると、点は回りながら外へ広がり、少しでも小さいと 0 へ寄っていきます。人の働きを、大きさを保ったまま回るものと当てても、なぜそう保たれるのかは、式からは出てきません。
- **二つの向き替えを掛け合わせる心の操作が、まだ見つからない。**式では、二つの回る数を掛けると角度が足されます。心の中で、二つの向き替えが掛け合わさる、と言える働きは、まだ見つかっていません。見つからないあいだは、三つ目の物差しは留保つきです。
- **速さが一定。**式の点は同じ速さで回ります。人の歩みは、速くなったり止まったりします。

## 駆動源に返すもの

<!--OPEN-->

<a id="ea-return"></a>当てはめが立った所を、プロジェクトの駆動源に戻してみます。どれも仮説です。

駆動は、売上や成果や進んだ距離のように、認知できる軸の上で量として測れる所には、そのままは出てこないのかもしれません。測れる軸の上で見ると、回り続ける働きは行って戻り、平均すると 0 と出るように見えるからです。

駆動の芯は、何かを増やす力として測るより、向きを変え続けながら、同じ大きさで関わりを保つ働きとして見る方が、見えてくるのかもしれません。読み物「[起業家の漸化式と、ジュリア集合](julia-potential.html)」は、Love と呼びたいものを、一歩ごとに同じだけ引き寄せる働き（`c`）と置いています。オイラーの式からは、その見立てを置き換えずに、もう一つの面を足せるかもしれません。一歩ごとに同じだけ向きを変え、大きくならずに回り続ける働き、という面です。

また、駆動源は、いまの一点だけでは測れないのかもしれません。同じ所に戻ってきたように見えても、何周してきたかは、見えない側に溜まっているように見えるからです。

## 抱えたままの問い

<!--OPEN-->

<a id="ea-open"></a>

- i を 2 回掛けると、向きが裏返ります（i² = −1）。気づきのあと、同じ向きにもう一度回ると、もとの見方の反対に出る、という体験はあるか。
- 人の働きが、大きくも小さくもならずに回り続けられるのは、何によるのか。
- 二つの向き替えが掛け合わさる、と言える心の働きはあるか。
- 何周してきたかは、認知し得ない側の、何に溜まるのか。

数学の説明は独立ページ「[オイラーの式](euler-formula.html)」に、複素数が関わるほかの数学は目次「[複素平面で考える](complex-plane.html)」にあります。
