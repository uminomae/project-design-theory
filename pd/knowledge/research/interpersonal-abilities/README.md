## 並べ方（Claude の整理）

人と関わる力を、①頭の知能の一つとして（社会的知能）、②感情を読んで使う知能として（情動知能）、③身につける技能・性格の特性として（CASEL・OECD の社会情動的スキル）、④集まりの性質として（集合知の c 因子）、と四つの見方に並べたのは Claude。どの見方も一面で、どれかを選ぶためではない。

- 思考・心理・身体知が分けられないところ（A2）・構えと体力（A3）：踏み込まない。

## このページの仮説として書いたこと

人と関わる力は、頭の知能として測ると一般の知能と分けにくく、技能や性格の特性として名付けると一人の性格の側に寄り、集まりで測ると一人の力でなくなる。どの分け方でも、人と関わる力は、一人の中に閉じた量としては掴みきれずに残っているように見える（ページの結び。Claude の読み）。
