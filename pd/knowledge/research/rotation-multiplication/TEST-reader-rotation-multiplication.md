# 回転の掛け算 READER — LLM 読解テスト

**目的**: 数学 III を習っていない読者を想定し、文脈ゼロの LLM がページ *だけ* を読んで、−1 で 180 度・i で 90 度・虚軸・直角の軸の値が実軸の上で 0（cos 90 度 = 0）を取り違えず言い直せるかを確かめる。
あわせて、このページが数学から心やプロジェクトの結論を導いていないこと（共通語としての数学・pjdhiro「演繹してるわけじゃないよ。説明してるだけ」）と、冗長さを見る。

対話図は JavaScript で動くため、文脈ゼロのテキストには各図の代わりの文（mw-fallback）だけが入る。

## 手順（1 ラウンド）

1. `node scripts/reader-llm-comprehension-test.mjs rotation-multiplication` → `.cache/active/reader-llm-test-prompt-rotation-multiplication.md`
2. 文脈ゼロのサブエージェントに、そのファイルだけを読ませて回答させる（絶対パスで渡す）。
3. Main が下のルーブリックで採点し、誤読・詰まり・冗長の指摘を集める。
4. 本文とテストを直し、再生成・static-checks のあと、同じ質問で回帰確認。

## 規定の質問群（ハーネスがこのブロックを読み込む）

<!-- QUESTIONS:START -->
### A. 主旨
- A1. このページは何のためのページで、読み終えた人は何が読めるようになりますか。2 文以内で答えてください。
- A2. このページは、数学から心や人間やプロジェクトについての結論を導き出していますか。導いている文があれば引用してください。無ければ「無し」と書き、ほかの読み物との関係をテキストがどう書いているかを一文で述べてください。

### C. 構成
- C1. 節の並びを順番どおりに列挙し、各節が何をする節かを一言で添えてください。
- C2. 前の節で出たことを次の節がどう受けているか、飛び・重複・逆流があれば具体的に指摘してください。無ければ「無し」。

### E. 平易な再説明（数学 III を習っていない高校生向け）
- E1. 3 に −1 を掛けることを「180 度回す」と見るとは、どういうことですか。
- E2. i とは何ですか。なぜ数直線の上には無いのですか。
- E3. 虚軸と実軸とは何ですか。
- E4. 「直角の軸の値は、もとの軸の上では 0」とはどういうことですか。cos 90 度 = 0 との関係と、地図と山のたとえを使って説明してください。
- E5. 平面の回転と立体（三次元）の回転は、何が違いますか。四元数の i・j・k とは何で、i × j = k と j × i = −k は何を表していますか。本のたとえを使って説明してください。

### E'. 用語の自己完結性
- E6. 「cos（コサイン）」「虚軸」「実軸」「四元数」という語は、本文だけで意味が取れますか。詰まるところがあれば指摘してください。

### G. 文体
- G1. 同じことを言い直している文、なくても意味が変わらない文があれば、引用して挙げてください（最大 5 つ）。
- G2. 説明が足りず、高校生が読んで止まりそうな箇所があれば挙げてください（最大 3 つ）。

### R1（2026-11-05・develop 3c79d22・読者＝Sonnet サブエージェント・文脈ゼロ）

- 合格: A1・A2（「無し」。言葉の意味を補う前提知識と読めた）・C1・E1〜E5（誤りなし。E4 は長さ × cos・90 度で 0・地図と山がつながった）。
- 詰まり（E6・G2）: ① cos が何かの説明が無い（「斜めの矢印の、横への影の長さ」の一言で足りる）。② i × i = −1 が「ふつうの数の例外」として突然に見える。③ 四元数の j・k が何を回すかが薄く、1・2・4・8 の定理の一文が置き去り。
- 飛び（C2）: 「まっすぐ下ろす」と cos の結びつきが本文に無い。§5 は §4 から四元数へ跳ぶ。
- 言い直しの候補（G1）: 「実軸の上で測ると、3i は 0 です」「どれほど長くても実軸の上では 0 です」「どれほど高い山でも、地図の上では 0 と出ます」。
- 直す候補は pjdhiro の採否待ち。
- R1 の修正（pjdhiro 採否「その二つを直して」）: ① cos を「斜めの矢印から実軸へまっすぐ下ろしたとき、実軸の上に残る長さの割合」と一文で足した（下ろすことと cos が結びつく）。② 言い直し三か所を、前の文に畳んで削った。③ 四元数・i × i の詰まりは、冗長との兼ね合いで手を付けない。
- 四元数の節を外した（pjdhiro「四元数はいらないんじゃないかな。三次元の回転についてはこちらを参考みたいな促し方をするとか」）。立体の回転は、最後の節のリンクカードから 3と7 の「回る数」の節へ案内する。E5・E6・C1 を合わせて直した。
- 四元数を「立体を回す — 四元数」の節として戻し、丁寧に書いた（pjdhiro「四元数も丁寧に説明して。やっぱり。三次元の回転ということで」）。平面は順序で変わらない／立体は変わる、を軸にした。E5・E6・C1 を戻した。

### R2（2026-11-06・develop 9467aa7・読者＝Sonnet サブエージェント・文脈ゼロ）

- 合格: A1・A2（「無し」。言葉の意味を貸す立場と読めた）・C1（6 節）・E1〜E5。cos は本文だけで意味が取れた（R1 の詰まりは解消）。数学の誤りは見つからず（(2 + i) × i、cos 90 度、平面の順序、i × j = k と j × i = −k、本の回転）。
- 詰まり: ①「平面の i にあたる数」から、立体でも i を一回掛けると 90 度回ると読まれやすい（数学的には誤解）。② i・j・k と本の回転のどれがどの軸かが書かれていない。③ 地図と山の図の「等高線が増えるだけ」が、等高線は高さを表すのでは、とぶつかる。④ §4 の冒頭で「実軸の上で測る」に切り替わる宣言が無い。
- 言い直しの候補: 「平面の回転は順序を変えても同じで、立体の回転は順序で変わります」（§5 末・節の頭と重なる）・「3i は、0 から真上に 3 離れた点です」。
- 直す候補は pjdhiro の採否待ち。
- R2 の修正（pjdhiro 採否「1 と 2 を直して」）: ① 四元数の節に「立体では、i を一回掛けると 90 度回る、という平面のような単純な対応にはなりません。i・j・k は、掛け算の順序の決まりを、立体の回転と同じ形で持っている数です」を足した。② 地図と山の図から等高線を外し、地図には山の印だけを置いた（表示の文と代わりの文も合わせた）。③ 3〜5 は手を付けない。
