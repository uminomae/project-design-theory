# 円の雲の「私」を詰める：数で確かめることと、仮に当てることを分ける（探索の記録）

2026-11-25・Issue #202・worktree pensive-diffie-a9c424。

読み物 julia-potential の第五部で「私」かもしれないと置いた**円の雲**を、推論が「さも確からしいかもしれない」と感じられるほどに詰めるための記録。アブダクションのまま精度を上げる（`stance.md` 1-4「アブダクションの名乗り」）。論証にはしない。数学の事実と原典だけを言い切り、当てはめはどれも仮。読み物は直していない。

足場：#198（量子論の励起・`EXPLORE-excitation-20261125.md`）・#199（人一般・`EXPLORE-general-self-20261125.md`）・#200（生化学と神経現象学・`EXPLORE-bio-neuro-20261125.md`）と、2026-11-25 に pjdhiro が選んだ新しい仮説 A（`decisions.md`「c は一定の力か、円の雲の「私」までの食い違い」）：一定なのは一歩の働き方で、Love と呼びたいものの `c` は一つの値に決まらない。`c` の地図（マンデルブロ集合）の全体が取りうる値の場。一つの `c` で描く範囲（1.41）が狭義の私、ありえた `c` の縁を重ねた円の雲（2）が広義の私。

この記録が使う三つの語（`stance.md` 1-4。一つの文の中で行き来しない）：

- **軌跡の渦**：一つの `c` で、一つの出発点から打った `z` の並びが、回りながら一点へ寄って見える形。
- **円の雲**：いろいろな `c` の縁（ジュリア集合）の点を重ねたもの。一つの `c` の図には現れない。
- **五段階の渦**：創造の五段階の渦。エネルギーの出入りのあいだに保たれる形（散逸構造・蝋燭の炎）。

「縁」は一つの `c` のジュリア集合 `J_c`、「縁が囲む内側」は充填ジュリア集合 `K_c`。計算はすべて Claude（node で書いた手元の計算。§6）。

## 要点

- **広義の私（円の雲）は、半径 2 の円を埋めていない**（§2-2）。マンデルブロ集合の `c` の縁を全部重ねても、雲の外の輪郭は、実軸の向きで 2（`c = −2` の両端だけ）、45° の向きで 1.33〜1.37、虚軸の向きで 1.15〜1.20 しかない。横に長い楕円のような形で、半径 2 の円には ±2 の二点でしか触れない。マンデルブロ集合の外の `c`（`|c| ≤ 2`）を足しても、輪郭はほとんど広がらない。いまの読み物の「いろいろな `c` の縁の点が、半径 2 の円の範囲を雲のように形作る」「半径 2 の円の中を雲のように埋め」は、形としては言い過ぎになっている。半径 2 は、雲が出られない線（`|c| ≤ 2` なら 2 を超えたら戻らない）で、雲の形そのものではない。
- **狭義の私（一つの `c` の縁が届く範囲）は、`c` ごとに 1 から 2 まで違う**（§2-1）。仮説 A では 1.41 は黄金角の `c` の一つの値にすぎない。マンデルブロ集合から `c` を一様に取ると、真ん中の値は 1.32、八割が 1.14〜1.60 に入る。最小は `c = 0` の 1、最大は `c = −2` の 2。
- **「つながった縁」を保てる `c` は、ちょうどマンデルブロ集合**（§2-3。ファトゥとジュリアの二択・Milnor 定理 17.3）。外では縁は粉のようにばらばらになり、0 から打った道も散る。中でも、骨組みの「内側の一点」がそのまま成り立つのは主カーディオイド（面積で 78%）だけ。13% は内側が二点を交互に回り（周期 2）、残りは三点以上を回る。マンデルブロ集合の縁の上の `c`（`c = i` など）では、内側が無く、縁だけが在る。
- **`c` が一歩ごとに動いても、`c` に合わせて動く縁なら、点は散らず縮まず保たれる**（§2-4）。一つの `c` の縁の点 2000 は、`c` を半径 0.002 で動かすと 25 歩で 1296 が散る（前の計算と同じ）。一方、動く `c` の並びに合わせて遡って取った縁の点は、0 が散り、0 が一点へ縮み、原点からの平均の距離 1.04 を保つ（半径 0.1 まで動かしても同じ）。数学では、`c` の並び `(c_n)` に対して縁（ジュリア集合 `J(c_n)`）が定義され、くり返しで縁は縁へ写る（Brück 2001, pp.347–348）。「`c` が少しでも動くと縁の点は保たれない」（前の計算）は、縁を一つの `c` に固定したときの話になる。
- **三つの記録の抱えた問いを、式で確かめられることと、仮に当てることに分けた**（§3）。式で答えが出たのは、物とエネルギーの出入りが縁に無いこと（式の事実）、見る側を式に置く場所が無いこと（図の平面の外）、`c` が動いても縁は保てること。仮に当てることとして残るのは、いろいろな `c` を何と読むか（人・時・自己）・恒常性の語・自己の置き場の逆さま・見る側を置くかどうか。
- **推論の梯子を一段ずつ並べた**（§1）。いちばん大きな飛躍は、「`z` を脳内の自己と置く」段と、「縁の点の集まりを私と読む」段の二つ。どちらも式からは出ず、pjdhiro の直感から置いている。数学の側で詰められたのは、その二段の前後の形（縁は保たれる・半径 2 は線引き・雲の形）。

## 1. 推論の梯子：骨組みから円の雲の「私」まで

第五部の骨組みを、出発から円の雲の「私」まで一段ずつ並べる。列「数学の事実」は式と原典で言えること、列「当てはめ（仮）」は直感への当てはめ、列「飛躍」は、前の段からその段へ、式だけでは渡れない所。

| 段 | 数学の事実 | 当てはめ（仮） | 飛躍 |
|---|---|---|---|
| 1. 式 `z → z² + c` を起業家の歩みのたとえにする | 二次式のくり返し | 起業家の漸化式（第一部） | 大きい。たとえの選択そのもの。pjdhiro は「当てはめようとしていること自体がねらい」（stance 1-4・2026-11-20） |
| 2. `z` は脳内の自己 | `z` は平面の一点 | 脳内の自己たち。エネルギーの粒・可能性 | 大きい。二乗を自己と自己の掛け算と読むために置いた（stance 1-4・2026-11-22） |
| 3. 一歩は前へ、死に向かって | 一方向のくり返し | 時間・寿命のような逃れられない一方向 | 中。式は遡りもできるが、前だけを当てる |
| 4. `c` は一つの値に決まらない（仮説 A） | 一歩ごとに同じ `c` を足すのが式。`c` を変えると別の式 | Love と呼びたいもの。一定なのは一歩の働き方 | 中。仮説 A の読みで、式の外（どの `c` を取るか）に Love を置く |
| 5. 円を超えたものは散る | `|c| ≤ 2` なら `|z| > 2` は戻らない（§2-2） | 発散・残らないエネルギー・淘汰 | 小 |
| 6. 内側の点は一点へ寄る | 主カーディオイドの `c` でだけ一点。ほかは二点以上を回る・内側が無い（§2-3） | 届かないけど惹かれる Love・他者 | 中。骨組みは黄金角の `c`（主カーディオイド）の形を一般に置いている |
| 7. 縁の点は入れ替わり、形が保たれる | `J_c` は完全に不変（Milnor 補題 3.1）。`c` が動くときも、動く縁は縁へ写る（Brück 2001） | 入れ替えながらギリギリ保たれる「私」 | 小〜中。「点が入れ替わる」は式の事実、「それが私」は当てはめ |
| 8. 狭義の私は一つの `c` の縁が届く範囲 | `R(c) = max |z|`（`z ∈ J_c`）は 1〜2（§2-1） | 狭義の私 | 中。範囲（半径）を私の輪郭と読む |
| 9. 広義の私は、ありえた `c` の縁の重なり | 重なりは横長の楕円のような形で、半径 2 に触れるのは ±2 だけ（§2-2） | 広義の私・確率・可能性 | 大きい。いろいろな `c` を何と読むか（人・時・自己）が決まっていない。読みによって「重ねる」意味が変わる |

二つの大きな飛躍（段 2 と段 9）は、どちらも pjdhiro の直感から置いた所で、式からは出ない。式の側で詰められるのは、その前後の形の確かさ（段 5・6・7・8・9 の右の列）で、§2 がそれをした。

## 2. 数と図で確かめる

### 2-1. 狭義の私：一つの `c` の縁が届く範囲は、`c` ごとに違う

マンデルブロ集合から `c` を一様に（同じ広さに同じ数）3000 取り、それぞれの縁（ジュリア集合）の点を 3000 ずつ遡りで取って、原点からいちばん遠い距離 `R(c)` を測った。

| | `R(c)` |
|---|---|
| いちばん小さい（`c = 0`） | 1.000（縁は半径 1 の円） |
| 下から 10% | 1.141 |
| 下から 25% | 1.219 |
| 真ん中 | 1.321 |
| 上から 25% | 1.437 |
| 上から 10% | 1.600 |
| いちばん大きい（`c = −2`） | 2（縁は −2 から 2 までの線分） |
| 黄金角の `c`（約 −0.378 + 0.562i） | 1.409 |
| `c = −1` | 1.618（黄金比） |
| `c = i` | 1.508 |

仮説 A で読むと、「1.41 が狭義の私」は黄金角の `c` での値で、狭義の私の輪郭は `c` によって 1 から 2 まで変わる。`c = −1` で 1.618（黄金比 `(1 + √5)/2`。`z = −φ` が `z² − 1 = φ` に、`φ` が `φ` に写る）が出るのは、数の上の偶然でなく式から出る（`φ² − 1 = φ`）。

### 2-2. 広義の私：円の雲は、半径 2 の円を埋めていない

マンデルブロ集合の `c` を 6000 取り、それぞれの縁の点を 400 ずつ重ねて描いた（手元の画像。§6）。雲は真ん中が薄く、原点から 0.75〜1.25 で濃い（読み物の見取り図と同じ）。外の輪郭は横に長い。

向きごとの外の輪郭（原点からの距離）を、二つのやり方で測った。一つは縁の点の重ね（2 万の `c`）、もう一つは、向きごとに半径を 2 から 0.01 ずつ下げ、その点を縁が囲む内側に含む `c` があるかを、マンデルブロ集合の中の 9 万 4550 の `c`（0.004 の格子）で探したもの。

| 向き（実軸から） | 縁の重ね | 格子での探し |
|---|---|---|
| 0°（実軸） | 1.93（`c = −2` に近い `c` の取り方の限り。`c = −2` でちょうど 2） | 1.92（同じ） |
| 15° | ― | 1.47 |
| 30° | 1.53 | 1.42 |
| 45° | 1.38 | 1.33 |
| 60° | 1.26 | 1.25 |
| 75° | ― | 1.14 |
| 90°（虚軸） | 1.20 | 1.15 |

二つのやり方の差は 0.05 ほどで、形は同じ。マンデルブロ集合の外の `c`（`|c| ≤ 2`。縁は粉のようにばらばら）を足しても、45° で 1.32、90° で 1.14 と、輪郭は広がらない。

確かなこと：

- 円の雲は、半径 2 の円の中に収まる（`|c| ≤ 2` で `|z| > 2` なら `|z² + c| ≥ |z|(|z| − 1) > |z|`。第五部の畳みの見積もり）。
- 半径 2 の円に触れるのは、±2 の二点だけ（`|z| = 2` で `|z² + c| ≥ 4 − |c| ≥ 2`。等しくなるのは `|c| = 2` で `c = −z²` の向きのときだけで、マンデルブロ集合で `|c| = 2` なのは `c = −2` だけ）。
- 雲は円を埋めていない。虚軸の向きでは 1.2 ほどで終わる。

だから、半径 2 は、雲が出られない線であって、雲の形そのものではない。読み物の「いろいろな `c` の縁の点が、半径 2 の円の範囲を雲のように形作る」「半径 2 の円の中を雲のように埋め」は、形としては言い過ぎになっている（§5 の案）。pjdhiro の言葉「私は点線の半径２の円が、「私かもしれない円の雲」」（2026-11-23）は、雲の外の線を円で引いた読みとして残る。どちらで読むか（円の線が私か、線の内の形が私か）は、§5 で聞く。

仮に当てると（Claude の読み。言い切らない）：この repo では、実軸に認知できるもの、虚軸に認知し得ないものを置いている（stance 1-4・2026-11-20）。それで読むと、広義の私は、認知できる向きには 2 まで伸び、認知し得ない向きには 1.2 ほどまでしか届かない形をしている、と読めるのかもしれない。ただ、横に長いのは、マンデルブロ集合の `c` が実軸の向きに長く（−2 から 0.25）、虚軸の向きに短い（±1.12 ほど）ことから来ている。式の作り（`z` と `−z` が同じ所へ行く・`c` の地図の形）から出る形で、当てはめの重さは pjdhiro が決める。

### 2-3. つながった縁を保てる `c` の幅：マンデルブロ集合と、その中の分かれ

確かなこと（Milnor 定理 17.3・p.17-2。ファトゥとジュリアによる）：二次式では、0（ただ一つの臨界点）から打った道が散らなければ、縁が囲む内側 `K_c` も縁 `J_c` もつながっている。散れば、どちらも数えきれないほどのかけらに分かれる。0 から打った道が散らない `c` の集まりがマンデルブロ集合なので、**つながった縁を保てる `c` の幅は、ちょうどマンデルブロ集合**。

マンデルブロ集合の中を、骨組みの行「内側の一点」が成り立つかで分けた（`c` を一様に 2 万取り、0 から打った道の行き着く周期を数えた。面積は約 1.50 で、知られている値 1.506 に近い）。

| 内側で起きること | 面積の割合 | 骨組みとの関係 |
|---|---|---|
| 一点へ寄る（主カーディオイド） | 78.1%（式で出す値 `3π/8 ÷ 1.506 = 78.2%`） | 骨組みの「内側の一点」がそのまま成り立つ |
| 二点を交互に回りながら寄る（周期 2 の円板） | 12.7% | 届かない他者が二つ、交互に現れる |
| 三点を回る | 3.7% | |
| 四点〜六十四点を回る | 4.6% | |
| 周期を見つけられなかった（マンデルブロ集合の縁の近く） | 0.9% | 縁の上の `c` では、内側が無く（`K_c = J_c`）、縁だけが在る |

仮説 A で読むと、Love と呼びたいものの取りうる値の場（マンデルブロ集合）の八割では、「私」（縁）は一つの届かない他者を囲み、残りの二割では、いくつかの他者を順に回って囲む、と読めるのかもしれない。マンデルブロ集合の縁の上の `c` では、他者が無く、縁だけが在る。外の `c` では、縁がばらばらになり、0 から打った道も散る。「つながった私が在る」ことと「Love の値がマンデルブロ集合の中にある」ことが、式の上では同じ条件になっている。

### 2-4. `c` が一歩ごとに動くとき：縁を `c` に合わせて動かせば、点は保たれる

前の計算（`decisions.md` の 2026-11-25 の行）：黄金角の `c` の縁の点 2000 を、`c` を半径 0.002 の中で一歩ごとに動かして打つと、25 歩で 1298 が散る。`c` を固定すれば 0。

今回、`c` の並び `c_1, c_2, …, c_25`（黄金角の `c` の周りに、半径 `r` の中で一歩ごとに取り直す）を決め、二つの点の集まりを同じ並びで打った。

| `c` の動く半径 `r` | 一つの `c` の縁の点 2000：散る | 一点へ縮む | 動く縁の点 2000：散る | 一点へ縮む | 残った点の原点からの平均 |
|---|---|---|---|---|---|
| 0.002 | 1296 | 10 | 0 | 0 | 1.04 |
| 0.02 | 1453 | 10 | 0 | 0 | 1.04 |
| 0.1 | 1495 | 18 | 0 | 0 | 1.04 |

動く縁の点は、25 歩目の縁の点から、同じ並びを逆にたどって（`±√(z − c_k)` を `k = 25, …, 1` の順に）遡って取った。`c` が動いても、それに合わせて動く縁にいた点は、散らず縮まず残る。

確かなこと（Brück 2001）：`c` の並び `(c_n)` に対して、くり返し `F_n = f_{c_n} ∘ … ∘ f_{c_1}` が遠くへ行かない点の集まり `K(c_n)` と、その縁 `J(c_n)` が定義され、`J(c_n) = ∂K(c_n)`（p.347）。縁は `F_k⁻¹(F_k(J(c_n))) = J(c_n)` の意味で不変（p.348）。どの `c_n` も `|c_n| ≤ 1/4` なら `J(c_n)` はつながっている（p.351。Brück・Büger・Reitz 1999 の結果として引かれている。黄金角の `c` は `|c| = 0.68` で、この条件の外）。

仮説 A の「一定なのは一歩の働き方で、`c` は一つの値に決まらない」を、「`c` が時とともに動く」と読むなら（これは §3 の「いろいろな `c` を何と読むか」の一つで、決めていない）、縁の点が保たれるのは、縁も `c` に合わせて動くときだけ、となる。「私」は、固定した形を保つのでなく、動く `c` に合わせて形を変えながら、散らず縮まずにいる、と読めるのかもしれない。

## 3. 抱えたままの問いの仕分け

三つの記録（#198・#199・#200）の「抱えたままの問い」と、第五部の決めに残った問いを、式で確かめられることと、仮に当てることに分けた。

| 問い（出どころ） | 式で確かめられること（結果） | 仮に当てること（pjdhiro が決める） |
|---|---|---|

## 4. プロジェクトの駆動源に返すもの（仮）

- 仮説 A で、Love と呼びたいものの取りうる値の場をマンデルブロ集合と置くと、「つながった私が在る」ことと「Love の値がその場の中にある」ことが、式の上で同じ条件になる（§2-3）。駆動源（Love）は、私を動かす力というより、私がひとつながりで在れるかを決める条件として働いているのかもしれない。#200 の pjdhiro の言葉「生命の駆動源というより、生命になってしまう制約」と同じ向き。
- `c` が動いても、縁が `c` に合わせて動けば私は保たれる（§2-4）。プロジェクトの駆動源が時とともに変わっても、駆られる側の「私」は、駆動源に合わせて形を変えながら在り続けられる、と読めるのかもしれない。逆に、形を固定したまま駆動源だけが動くと、私は散るか、届かない一点へ縮む。
- 広義の私は、認知できる向き（実軸）に長く、認知し得ない向き（虚軸）に短い形をしている（§2-2）。駆られていると私が感じる広がりは、認知できる側に伸びて見えやすい、と読めるのかもしれない。ただし、これは `c` の地図の形から来ているので、当てはめの重さは低く見ている。
