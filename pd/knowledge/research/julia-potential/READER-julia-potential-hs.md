# 起業家の進み方と、ジュリア集合の式

<div class="reader-lead glow-card" id="jh-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>起業家は、試して外れたら戻り、見つけたら条件を変えてまた試す、をくり返して進むように見えます。その一歩が、ジュリア集合を描く式 <code>z → z² + c</code> に似ているのではないか、と pjdhiro は見立てました。</p>
<p>式をくり返すと、点は散るもの・一点へ寄るもの・縁に残るものに分かれます。縁に残る点の重なりを「私」、<code>c</code> を Love と呼びたいものと見ると、神・愛・美のポテンシャルも、その縁にあるのかもしれません。</p>
<p>読み物「<a href="julia-potential.html">起業家の漸化式と、ジュリア集合</a>」の筋を、図を一つ動かしながら、数学の言葉をできるだけ使わずに追います。</p>
</div>

## 起業家は、どう進んでいるように見えるか

<!--OPEN-->

<a id="jh-dfs"></a>新しいことを始める人は、はじめから地図を持っているわけではありません。手もとのものでやってみて、外れたら戻り、別の道を試します。部活で新しい練習法を試すときも、似た進み方をしているかもしれません。

プログラミングでは、分かれ道が枝のように広がる形を「木」と呼びます。一つの枝を行けるところまで進み、外れたら一つ前の分かれ目に戻って次の枝を試すたどり方を、深さ優先探索（DFS）と言います。では、一本の木をたどって何かを見つけたら、そのあとはどうなるのか。pjdhiro は、こう見ています。

<strong>pjdhiro の見方：</strong>DFS（深さ優先探索）の先で見つけたら、そこから、条件やパラメータを変えて、次の探索が違うツリーに対して始まるんじゃないかな。DFS に DFS が入れ子になっている、ということです。DFS を一回やって人生が終わり、ではないよね。

<strong>見つけた所から、条件を変えた次の木で、また探索が始まります。</strong>探索の中に、次の探索が入っている形です。外れたことも経験として抱えたまま進み、戻るときに、それまでの経験を一つにまとめます。

やめずに続ける姿について、pjdhiro は「商いは、飽きない」という言葉を思い出しています。「商い」も「飽きない」も「あきない」と読める、かけ言葉です。

## 一歩の結果が、次の一歩の出発になる

<!--OPEN-->

<a id="jh-rec"></a>前の結果に決まりを当てて次を出すくり返しを、数学では漸化式と言います。たとえば「前の数を 2 倍する」なら、1, 2, 4, 8, … と進みます。

起業家の一歩を、いちばん簡単に書くと、次のくり返しになります。pjdhiro が書いた、計算機の言葉に似せた手順（疑似コード）です。

```
今の自分 = はじめの自分
while 続ける:
  会って変化した部分 = 人に会う(今の自分)
  今の自分 = 今の自分 ＋ 会って変化した部分
```

<strong>今の自分に、人に会って変化した部分を足したものが、次の自分になります。</strong>前の値から次の値を決めるので、漸化式の形です。

## Love と呼びたいものは、重力のようにずらす

<!--OPEN-->

<a id="jh-drift"></a>この手順を見て、pjdhiro は、こう見立てました。

<strong>pjdhiro の見方：</strong>漸化式は、起業家のよう。Love と呼びたいものは、重力のようにドリフトする。それは、ジュリア集合の漸化式のようだ。

ドリフトは、流れに押されて、少しずつ漂うようにずれていくことです。重力が物の通り道を少しずつ曲げるように、<strong>Love と呼びたいものが、一歩ごとに、起業家を同じ向きへ同じだけずらしているのではないか、という見立てです。</strong>

## ジュリア集合を描く式に、当ててみる

<!--OPEN-->

<a id="jh-julia"></a>足し算の前に「今の自分を、今の自分で掛ける」一手を入れ、足すものを、一歩ごとに同じだけ引き寄せるもの（Love と呼びたいもの）に替えてみます。

```
今の自分 = はじめの自分
while 続ける:
  今の自分 = 今の自分 × 今の自分 ＋ 引き寄せ
```

記号で書くと `z → z² + c` です。いまの `z` を二乗して `c` を足し、それを次の `z` にします。`z` と `c` は、平面の上の一点で表せる数（複素数）です。二乗すると、点は、原点から見た角度が二倍になり、原点からの距離が二乗になります。

<strong>この式をくり返したとき、遠くへ散っていく点と、散らない点の境目にできる込み入った形が、ジュリア集合です。</strong>このページでは、この境目を縁（ふち）と呼びます。

## 式の文字に、意味を仮に当てる

<!--OPEN-->

<a id="jh-assign"></a>式の文字に、次の意味を仮に当てます。

<div class="tablefit">

| 式の文字 | 仮に当てる意味 |
|---|---|
| `z` | 起業家の脳内の自己。気づくことも、決めることも、その自己の働きに入る |
| `z²` | 脳内で起きる、自己と自己の掛け算 |
| `+ c` | Love と呼びたいものが、重力のように、一歩ごとに同じ向きへ同じだけ引き寄せる力 |

</div>

<strong>`z` を脳内の自己と置くのは、二乗の所から決めたことです。</strong>自分を自分で掛けるには、掛け合わさる自己が、起業家の中にいくつも要るからです。

## 自己は、一つではないのかもしれない

<!--OPEN-->

<a id="jh-self"></a>自己が一つでない、という見方には、脳の研究の足場があります。神経科学者のスキッパーらは、自己について調べた 912 本の脳画像の研究を集め直しました。すると、自己には共通の中心が無く、脳のあちこちに散らばった仕組みが、その時々に組み合わさったものでした（2026 年。専門家の審査を受ける前の論文です）。これを読んで、pjdhiro は、二乗をこう見ました。

<strong>pjdhiro の見方：</strong>自己は単一では無い。とするなら、二乗するように、自己と自己が創造的に協働するイメージです。

<strong>二つの自己が掛け合わさる分は、どちらか一つの自己からは出てきません。</strong>自己と自己が協働して、一つでは出ないものを、次の一歩に生むのかもしれません。

## 前へ進めると渦、遡ると縁

<!--OPEN-->

前へ進めた点は、外へ飛び出さずに、渦を巻いて一か所へ寄っていきます。その一点から式を逆にたどると、一段ごとに、一つ前の候補が二つに分かれます。二乗を戻す平方根には、プラスとマイナスの二つがあるからです。<strong>何段もたどると、実際に通ってきた一本のほかは、縁に散らばります。</strong>

## ありえた道は、縁に並んでいるのかもしれない

<!--OPEN-->

<a id="jh-paths"></a>同じ式なのに、前へ進めるか、逆にたどるかで、まるで違う形になります。この図を見て、pjdhiro は次の問いを立てました。

<strong>pjdhiro の問い：</strong>この渦の軌跡と、ジュリア集合の関係が何を意味するのか。それを直感で読み取りたいのです。

起業家に当てると、前へ進めた点は、脳内の自己が一歩ごとに移っていった跡で、実際に通ってきた一本の道と読めます。pjdhiro は、起業家は渦を巻くように進み、違うルートで来ていたら、その渦はジュリア集合のような軌跡だったかもしれない、と見ています。<strong>通ってきた道は一本でも、遡ると、ありえた別の道が無数に分かれ、それらは縁に並んでいるのかもしれません。</strong>

## ジュリア集合のような何かが、神・愛・美の場ではないか

<!--OPEN-->

<a id="jh-q"></a>起業家が実際に歩む一本の道の向こうに、ありえた道の並ぶ縁がある。この見立てから、pjdhiro は次の問いを立てました。

<strong>pjdhiro の問い：</strong>ジュリア集合のような何かが、神・愛・美のポテンシャルなのではないか。

ポテンシャルは、pjdhiro の言葉では「場と呼びたいような、可能性」です。まだ形になっていないけれど、そこから何かが生まれうるもの、という意味です。<strong>起業家を駆るものが出てくる場は、縁のような形をしているのではないか、という問いです。</strong>

## 美は、起業家のエネルギーに近いのではないか

<!--OPEN-->

<a id="jh-beauty"></a>この問いに、美の定義から近寄ります。お寺や教会、美術品などを前にして、美しいのに畏れを感じることがあります。美の側から近寄ると決めたとき、pjdhiro は、行き先も一緒に見ていました。

<strong>pjdhiro の見方：</strong>美とは、起業家のエネルギーと近いのかもしれない。

美は、美しさと恐ろしさの入り乱れたところから出るのではないか。その出てくる場は、神や愛の出てくる場と同じで、心を惹きつけるという点で同じなのではないか。<strong>もしもそうなら、起業家が何かに惹きつけられて動き出すときのものと、美しいものに心を惹かれるときのものは、同じなのかもしれません。</strong>

## 当初の直感は、たくさんの点を前へ打つ絵だった

<!--OPEN-->

<a id="jh-cloud"></a>ここまでは、0 という一つの出発点から打った一本の道を見てきました。図を描く前、pjdhiro は、別の形を思い描いていました。

<strong>pjdhiro の見方：</strong>私は当初、発散して飛び散ったエネルギー以外の収束、という感じのものになるんだろうと思っていました。淘汰やサバイブのようなものです。

<strong>この直感は、たくさんの点をいっせいに前へ打つと、ほとんどは外へ散って残らず、残ったものが一点へ寄っていく、という絵に見えます。</strong>図の「③ たくさんの点を放つ」をクリックすると、半径 2 の円いっぱいに点を放って、いっせいに前へ進めます。

## 散るもの、寄るもの、縁に残るもの

<!--OPEN-->

<a id="jh-three"></a>円を超えた点は、外へ散って戻りません。内側に落ちた点は、渦を巻きながら一点へ寄っていきますが、何歩打っても、その一点に届くことはありません。<strong>散りもせず、寄りもせずに残るのは、縁の上にあった点だけです。</strong>縁の点は一歩ごとに入れ替わりながら、縁という形だけが保たれます。

## いろいろな c の縁を重ねた雲を、「私」と読む

<!--OPEN-->

<a id="jh-me"></a>放った点が散って残る図を見て、pjdhiro は、こう当ててみました。

<strong>pjdhiro の見方：</strong>寄っていく一点は、Love の引き寄せと感じるかもしれない。ジュリア集合の境が、場や揺らぎや縁と感じて、神や美を感じるかもしれない。一点のことではなく、複数の点の総合としての半径で描かれた範囲の円が、私なのかもしれない。

一つの `c` の図で残り続けられるのは、縁の上の点だけです。ここで、`c` の値は一つに決まらず、一定なのは一歩ごとに同じだけ足す働き方だ、と置きます。<strong>ありえたいろいろな `c` の縁を重ねると、半径 2 の円の内に、横に長い雲のような形ができます。この円の雲を「私」と読みます。</strong>

## Love の、二つの面

<!--OPEN-->

<a id="jh-love"></a>pjdhiro は、Love と呼びたいものを、式の中の二つの所に分けて見ています。<strong>一歩ごとに同じだけ足す `c` は、重力のように一定の Love で、内側の点が寄っていく一点は、届かないけれど惹かれる Love です。</strong>寄っていく一点の位置は `c` だけで決まるので、一定の Love が、届かない一点を作り出している、という関係になっていそうです。

## 三つの星を、星座のように結ぶ

<!--OPEN-->

<a id="jh-stars"></a>一本の道と、たくさんの点。二つの見方を通して見えていたものを、pjdhiro は、星座にたとえています。

<strong>pjdhiro の見方：</strong>私の投影、私の世界の解釈、私が私とは感じていない無意識と呼ばれるものが何を感じているのか、Love と呼びたい駆動源がどのような構造なのかを、星座を作るように眺めたのかもしれない。C という一定の力、一ヶ所に収束しようと渦のような軌跡、その軌跡を惹きつけるかのようなとある一点、この 3 つに重ねながら、半径の円という全体・宇宙を感じていたかのような。

三つの星は、どれも式の中に在ります。一歩ごとに同じだけ足される `c`、0 から打って回りながら一点へ寄る軌跡、`c` だけで決まり、寄るものが届かない一点です。<strong>星はそこに在り、星座の線は見る人が引きます。</strong>線の引き方には、見る人の思いや、本人も気づいていない心の動きが出ます。

## 「私」は、あいだにギリギリ保たれる

<!--OPEN-->

<a id="jh-between"></a>その全体と三つの星のあいだに、「私」はどう在るのか。pjdhiro は、こう見ています。

<strong>pjdhiro の見方：</strong>雲は私、半径の外が宇宙や全体。私という雲は、「私以外である外側の宇宙」以外とも言える。私は、宇宙という大気圧のようなもので形作られているかのよう。私は、発散するエネルギーと収束するエネルギーとの間に存在するかのよう。私は、発散したものによってそれ以外になり、収束したものによってそれ以外になり、私は私以外のものの間にギリギリ保っている瞬間のようなもの。

<strong>外へ散ったものでも、一点へ寄ったものでもなく、そのあいだの縁に保たれる点の重なりが「私」なのかもしれません。</strong>

## 最初の問いに戻る

<!--OPEN-->

<a id="jh-back"></a>ジュリア集合のような何かが、神・愛・美のポテンシャルなのではないか。この問いから進んできました。<strong>起業家を駆るものは、一定の力（`c`）と、それが作る届かない一点という、Love の二つの面なのかもしれません。</strong>ジュリア集合は、その軌跡を眺めるために付けた星座の名のようなもので、神・愛・美のポテンシャルは、その縁に感じられる所なのかもしれません。

<p>図の <code>c</code> で <code>z → z² + c</code> をくり返すと、0 から前へ打った点は一点へ寄り、そこから逆にたどった点は縁に散ること、円いっぱいに放った点が、散るもの・寄るもの・縁に残るものに分かれること、いろいろな <code>c</code> の縁を重ねると半径 2 の内に横に長い雲ができることは、数学の事実です。<code>z</code> を脳内の自己、<code>z²</code> を自己と自己の掛け算、<code>c</code> を Love と呼びたいものと置くこと、縁を神・愛・美のポテンシャルと見ること、美を起業家のエネルギーに近いと見ること、円の雲を「私」と読むことは、pjdhiro の見立てから立てた仮説です。こじつけに見えるかもしれませんが、pjdhiro は、当てはめてみることで考えを広げる足場にしたい、と見ています。</p>
