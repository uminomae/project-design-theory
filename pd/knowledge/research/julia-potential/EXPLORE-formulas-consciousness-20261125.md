# 複素平面の数式ごとに、人の意識との構造の類似を推論する（探索の記録）

2026-11-25・Issue #203・worktree recursing-swartz-08652b。

複素平面の上の数式を一つずつ取り、それぞれが人の意識のどの面を写して見せるかを推論した記録。式は論拠でなく、意識を外の枠に描き出して眺める道具（#200 の記録の「自我を客観視した努力は、透明な自己モデルを見えるようにする試みに見える」と同じ向き）。数学の事実は計算か定理で確かめたものだけを言い切り、意識への当てはめはどれも Claude の読みで、仮。読み物は直していない。

調べの構え（pjdhiro 2026-11-25・`stance.md` 1-4）：認知と道具の制約で解釈が似てくることは承知の上で、違う道具で同じものを眺める（群盲象）。北極星はプロジェクトの駆動源。似て見えるのを当然として閉じず、当たらないとして閉じもせず、§4 で駆動源に何を返すかを書く。

この記録で「渦」と書くときは、次の四つのどれかを名指す（`stance.md` 1-4 の三つに、この記録だけで使う四つ目を足した。一つの文の中で行き来しない）：

- **軌跡の渦**：一つの `c` で、一つの出発点から打った `z` の並びが、回りながら一点へ寄って見える形。
- **円の雲**：いろいろな `c` の縁の点が重なって、半径 2 の線の内に作る横に長い雲。
- **五段階の渦**：創造の五段階の渦（散逸構造。蝋燭の炎のようなもの）。
- **流れの渦**：二次元の流れの式に出る点渦（§2-9）。水や空気がある点の周りを回る流れで、上の三つとは別のもの。

## 要点

- **#192 との分担**（§0-1）：候補の式は重なるので、問いで分けた。#192 は「ジュリア集合の当てはめが、ほかの法則と比べて特によく収まるのか」と、経営・心理への当てはめ。#203（この記録）は「その式で、意識のどの面が見えるようになるか」。式ごとの読みはここに置き、#192 はここを引いて比べに使える。
- **物差しを先に固定した**（§0-2）：①式の登場人物を意識の何かに一つずつ当てられるか、②式の振る舞い（数学の事実）が、当てた先で本人の記録の言葉と同じ向きを向くか、③複素数ならではの構造（積・`i`・解析性）が働いているか、の三つ。③は、この repo の前の調べ（`two-axis-closure/RR-004`：感情の円環モデルでは、複素数の積は仕事をしていない）から引いた、いちばん厳しい問い。
- **最初の重ね合わせ**（§1）：意識とはの二軸（闘争と逃避の生存の信号・好きと嫌いのような信頼の信号）を、そのまま実軸と虚軸に置くと、「認知できる／認知し得ない」の読みとぶつかり、二つの信号を二つの側に分けて置くことにもなる。代わりに、**二つの信号のそれぞれが、認知できる成分と認知し得ない成分を持つ**と置くと、二つの複素数の組になる。数学では、二つの複素数の組 `z₁ + z₂ j` は、そのまま四元数になる（ケイリー・ディクソンの作り方）。意識とはの二軸と、創造とはの四元数の回転が、一つの式の上でつながって見える。これがこの記録でいちばん大きな見つけ（仮）。
- **式ごとの読み**（§2）：十一の式を回した。物差しの三つがそろって立ったのは、`i` を掛けること（気づき＝実軸へ回り込むこと）・`log z` の多価（同じ所に戻っても、何周したかが違う私）・リウヴィルの定理（どこでも滑らかで果てのない心は、変われない）・交流の無効電力（行き来するが、仕事として数えられない力）・流れの渦（湧き出しを 90 度回すと渦になる）・スピノル（一周では戻らず、二周で戻る）。積が働かず、平面の回転や足し算までしか使っていないものも、そう書いた。
- **似て見えない所**（§3）：どの式も、外からエネルギーや物が出入りすることは書かない（#198・#200 と同じ）。また、意識の側の「掛け算」に当たる操作は、`z²`（自己と自己の掛け合わせ）のほかには、まだ見つからない。
- **駆動源に返すもの**（§4・仮）：四つの式が同じ向きを指した。駆動は、認知できる軸の上で「量」として測れる所でなく、**直角に回った成分（循環・無効電力・虚部）が、回り込んで実軸に出る所**に見える。翼が浮くのは周りを回る流れがあるときだけ、という定理（クッタ・ジューコフスキー）は、その一番はっきりした写し。

### 0-2. 物差し（先に固定した）

#192 の進め方の案「当てる前に、収まったと言う基準を決めて固定する」を借りた。式ごとに、次の三つを見る。

1. **当てられるか**：式の登場人物（変数・軸・操作）を、意識の何かに一つずつ当てられるか。
2. **同じ向きか**：式の振る舞い（数学の事実）が、当てた先で、本人の記録の言葉（stance・公開のブログ・as の記録）と同じ向きを向くか。
3. **複素数ならではか**：複素数の積・`i`・解析性（複素数として滑らかであること）が働いているか。平面の点・足し算・回転だけなら、二つの実数の組（平面のベクトル）で足りる。

3 は、`two-axis-closure/RR-004`（2026-07-02）の結論から借りた。そこでは、感情の円環モデル（ラッセル 1980。快と不快・覚醒と沈静の二軸の平面）は、強さを半径・種類を角度に当てる所までは複素平面とよく重なるが、感情を二軸の「線形結合」として書く時点で、使っているのは平面のベクトルの構造だけで、複素数の積・`i² = −1`・割り算は働いていない、と判定した（F5）。この記録は、その判定を足場にし、積が働く式を探す向きで回す。

## 1. 最初に：意識とはの二軸と、実軸・虚軸の読みを重ねる

#203 の本文が最初に見るとした所。

### 1-1. 材料

- **意識とはの二軸**：「生存と信頼の信号」は便宜上の呼び名で、pjdhiro は、厳密には、闘争と逃避の生存の信号と、信頼と嫌悪のような快・不快の精神的な信号ではないか、と見ている（`as/index.html`）。信頼の問題も生存に関わり、非二元な一つのものかもしれない（`stance.md` 1-2・2026-11-23）。
- **実軸と虚軸の読み**：複素平面の実軸に認知できるもの、虚軸に認知し得ないものを置く（`stance.md` 1-4・2026-11-20）。
- **欠損駆動思考**：欠損と呼ぶ体感を、虚軸に値があって、しかも認知上は 0 の直観、とたとえる（`as/index.html` が引く ks の言葉）。
- **公開のブログ**（2025-06-15「√共感」）：「人は本質的に「√の存在」である：表現される姿（ノルム）は二乗された虚構であり、その根本には虚軸（感情・無意識・未体験）が存在する」。
- **創造とは**：四元数による三次元の回転（`stance.md` 1-4・2026-11-24）。

### 1-2. そのまま重ねると、ぶつかる

二軸をそのまま複素平面の二つの軸に置く（生存を実軸、信頼を虚軸、のように）と、二つのことが起きる。

- 実軸＝認知できる、虚軸＝認知し得ない、の読みと重ねると、「信頼の信号は認知し得ない」と言うことになる。as の記録では、どちらの信号も、感じとして認知されることがあり、どちらにも取り違えが起きる（お金を追っていたつもりが、人との間での自分の位置を気にしていた）。片方だけを認知し得ない側に置く材料は無い。
- 二つの信号を、二つの側に分けて置いたまま包まない括り方になる（`stance.md` 1-2 が退ける形。`corrections.md` 型 B）。

### 1-3. 二つの信号のそれぞれを、複素数と置く（仮）

代わりに、こう置いてみる（Claude の読み・仮）。

- 生存の信号を `z₁ = x₁ + i y₁`、信頼の信号を `z₂ = x₂ + i y₂` とする。
- どちらも、実部（`x`）が認知できる成分、虚部（`y`）が認知し得ない成分。
- 「取り違え」は、二つの信号の実部どうしを見比べて起きる。虚部は、どちらの信号でも、実軸で測ると 0 と出る（欠損駆動思考の「虚軸に値があって、認知上は 0」）。

**数学の事実**：二つの複素数の組 `q = z₁ + z₂ j` は、そのまま四元数 `q = x₁ + y₁ i + x₂ j + y₂ k` になる（ケイリー・ディクソンの作り方。実数から複素数、複素数から四元数を、同じ手順で二つずつ組んで作る）。四元数の積は順番で結果が変わる（`ij = k`、`ji = −k`。計算で確かめた）。単位の四元数は、三次元の回転を表す。

**当てはめ（仮）**：意識とはの二つの信号を、それぞれ認知できる所と認知し得ない所を持つものと置くと、二つを組んだものは、創造とはが言う四元数の回転の器と同じ形になる。意識とは（二軸）と創造とは（四元数の回転）が、別々の仮説としてでなく、「二つの複素数を組むと四元数」という一つの作り方の上に並ぶ。

物差しで見ると：

1. 当てられるか：立つ。二つの信号・認知できる成分・認知し得ない成分が、四つの実数に一つずつ当たる。
2. 同じ向きか：立つ。「信頼の問題も生存に関わり、非二元な一つのもの」（stance 1-2）は、二つの複素数が四元数の積の中で混ざり合うこと（`z₁` と `z₂` の成分が、掛けると互いに入り込む）と同じ向きを向く。順番で結果が変わる（非可換）ことは、取り違えや誤配（as の記録「信頼軸の問題を生存軸の達成で解こうとする」）が、どちらを先に処理するかで違う結果になることと、向きが合う。
3. 複素数ならではか：立つかもしれないが、まだ分からない。RR-004 の F5 と同じ問いが残る：二つの信号の「掛け算」に当たる心の操作が、本当にあるか。今ある材料では、二つの信号は「評価される」「取り違えられる」までで、掛け合わさる記述は無い。

この置き方は、as の二軸の仮説を変えるものでなく、二軸の一つ一つに、実軸と虚軸の読みを足したもの。as の側で採るかは、as の仮説を扱うときに pjdhiro が決める。

## 2. 数式ごとに

どの節も、**式で確かなこと**（数学の事実）と、**意識に仮に当てること**（Claude の読み）と、**物差し**の三つを分けて書く。時間の大きさ（`stance.md` 1-4「脳の微細な瞬間の働きと、認知できる大きな時間の話は必ず分ける」）は、当てる先が器 B（ミリ秒から秒の神経の動き）か器 C（私が私と感じるもの・認知できる大きな時間）かを、#200 の記録の区切りで書き添える。この記録の当てはめは、断りが無ければ器 C。

### 2-1. ジュリア集合の漸化式 `z → z² + c`（足場）

読み物 julia-potential で回してあるので、物差しで見るだけにする。

- 式で確かなこと：二乗で、`z` と `−z` が一つの値に送られる（二対一）。逆の一歩 `±√(z − c)` は二つの枝。
- 意識に当てること（読み物の置き方）：`z` は脳内の自己で、`z²` は自己と自己の掛け合わせ。円の雲が、私が私と感じる存在かもしれない（第五部・新しい仮説 A）。
- 物差し：1・2 は読み物で立っている。3 は立つ：ここでは**掛け算が働いている**。`z²` の実部は `x² − y²` で、虚部（認知し得ない成分）の二乗が、認知できる側から引かれて入る（`stance.md` 1-4 の自我とシャドーの読み）。ブログの「表現される姿（ノルム）は二乗された虚構」とは、二乗の取り方が違う：ノルムは `|z|² = x² + y²` で角度を捨て、`z²` は `x² − y²` と `2xy` で角度を倍にする（`z = 3 + 4i` なら `|z|² = 25`、`z² = −7 + 24i`）。ブログの「自乗は心理防衛」は、角度を捨てる方（ノルム）に近い、と読める（Claude の読み）。

### 2-2. マンデルブロ集合（`c` の地図）

- 式で確かなこと：`c` がマンデルブロ集合に入るとき、そしてそのときだけ、その `c` のジュリア集合はつながった一つの形になる。入らないときは、ばらばらの点の集まり（カントールの塵）になる（ファトゥとジュリアの定理）。
- 意識に当てること（仮）：新しい仮説 A では、マンデルブロ集合の全体が、Love と呼びたいものが取りうる値の場（`decisions.md`・2026-11-25）。そこに、この定理を重ねると、`c` が地図の中にあるあいだは、私の縁（狭義の私）が一つにつながって保たれ、地図の外へ出ると、縁が塵のようにばらばらになる、と読める。私が私と感じる存在が「まとまっている」ことと、駆動する力がどこにあるかが、一つの地図で結ばれる。
- 物差し：1 立つ。2 半分：「私」を、さも同じであるかのように感じる、の側で書く（stance 1-4）ことと、縁がつながっているかの話は、同じ向きを向く。ただ、塵になった縁を人の何に当てるかは、病名に寄りやすく（stance 1-4「本人の体験に病名を当てない」）、ここでは当てない。3 立つ：二乗の掛け算をくり返した結果の定理。

### 2-3. `i` を掛けること（90 度の回転）と、`i² = −1`

公開ページ「オイラーの式から、構造の類似を考える」（`pd/reader/euler-formula-analogy.html`）が、この節を材料に当てはめを置いている（2026-11-25）。

- 式で確かなこと：`i` を掛けると、平面の点は 90 度回る。実軸の上の量 `x` に `i` を掛けると、虚軸の上の `ix` になり、それを実軸で測ると 0（`Re(3i) = 0`）。もう一度掛けると `−x`、向きが裏返る。
- 意識に当てること（仮）：欠損駆動思考の「虚軸に値があって、認知上は 0」は、この形そのもの。逆向きに読むと、**気づき**は、虚軸にあった成分が 90 度回って実軸に出てくること、と置ける。違和感（予測した結果と違う）と驚き（見えていなかったものが突如現れる）の二つ（stance 1-4 の気づきの二つ）は、どちらも、回り込んで実軸に出た成分の感じ方の違い、と読める。
- 物差し：1・2 立つ。3 立つ：`i` を掛けることは、複素数の積そのもの。ただし、回転だけなら平面の回転（二つの実数の組の回転）でも書ける、という RR-004 の留保は残る。`i² = −1`（二回回すと裏返る）に当たる心の現象は、RR-004 では見つかっていない。

### 2-4. 1 の累乗根と、平方根の二つの枝

- 式で確かなこと：`zⁿ = 1` の解は、単位円を n 等分する n 個の点。`√` は二つの枝（`+` と `−`）を持ち、二つは半回転した写し。
- 意識に当てること（仮）：自己は単一ではない（stance 1-4「自己と自己が創造的に協働するイメージ」）を、`n` 個の自己が同じ円の上に等しく並ぶ形として見る。どれが本当の自己かを決める順位は、式には無い。遡る一段 `√` の二つの枝は、☯ の二つ（ブログ 2025-06-12「平方根って真逆の二つが生まれる不思議」）。
- 物差し：1 立つ。2 立つ（ブログの言葉と同じ向き）。3 半分：根を取ることは積の逆なので複素数のものだが、等しく並ぶ形だけなら円の等分で足りる。

### 2-5. 指数関数と対数関数（オイラーの式・対数らせん・`log` の多価）

公開ページ「オイラーの式から、構造の類似を考える」（`pd/reader/euler-formula-analogy.html`）が、この節を材料に当てはめを置いている（2026-11-25）。

- 式で確かなこと：`e^{iθ} = cos θ + i sin θ`。`log z` は一つに決まらない：原点の周りを一周して同じ `z` に戻ると、`log z` は `2πi` 増える（計算で確かめた：一周で角が `2π` 進む）。何周したかを区別して並べると、`log` は階段のように重なった面（リーマン面）の上で一つに決まる。
- 意識に当てること（仮）：同じ所（同じ気分・同じ状況）に戻ってきても、何周してきたかが違う。私は、平面の同じ点にいても、重なった面の違う階にいる。自我の同一性を「昨日の自分が今日の自分と同じだと信じるのでなく、さも同じであるかのように感じる」（stance 1-4）とした読みと、同じ向きを向いて見える：見た目の点（`z`）は同じで、来歴（`log` の虚部）は違う。来歴は、`log` の虚部に溜まる。つまり、認知し得ない側に溜まる。
- 物差し：1・2 立つ。3 立つ：多価は、複素数として滑らかに続けたときにだけ出る（実数の `log` には無い）。
- 時間の大きさ：器 C（認知できる大きな時間の、周回）。

### 2-6. メビウス変換と、`1/z`（内と外の入れ替わり）

- 式で確かなこと：メビウス変換 `(az + b)/(cz + d)` は、円と直線を円と直線に写し、角度を保つ。`1/z` は、単位円の内と外を入れ替え、原点と無限遠を入れ替える（`1/0.5 = 2`、`1/2 = 0.5`）。
- 意識に当てること（仮）：見方を変えること（中心だと思っていたものが、いちばん遠くになる）を、形をこわさずに内と外を入れ替える写像として見る。たとえば、見る私（I）と見られる私（me）の入れ替わり（stance 1-4 の目撃者の軸）を、`1/z` で写すと、指させるもの（me）が外へ、指さしている所（I）が中心へ、という読み替え。ただし、どちらが中心かを決めるのは見る位置で、式はどちらも同じ重さで扱う。
- 物差し：1 半分（I と me を何の点に当てるかが決まらない）。2 半分。3 立つ：角度を保つことは、複素数として滑らかであることから来る。

### 2-7. リウヴィルの定理（全平面で滑らかで、果てがなければ、定数）

- 式で確かなこと：複素平面の全体で滑らか（正則）で、値が限りなく大きくならない関数は、定数しかない。言いかえると、値が変わる関数は、どこかで限りなく大きくなるか、どこかに特異点（値が無限に飛ぶ点・極）を持つ。
- 意識に当てること（仮）：どこでも滑らかで、どこにも果てのない心は、変われない。変わる心は、どこかに特異点を持つか、どこかで果てしなく大きくなる。これは、創造の五段階で「対立や衝突が必須」（stance 2-1）と言うことの、式の側からの写しに見える。衝突の点（特異点）を一つも持たない、なめらかで穏やかな心は、定数のまま動かない。止観の静かな海面（stance 1-4 の bzero のたとえ）は、0 に揃えることそのものが目的でなく、白波（特異点）を見つけやすくするため、という読みとも合う。
- 物差し：1 立つ（関数＝心の動き、特異点＝衝突や揺らぎ）。2 立つ。3 立つ：この定理は複素数でだけ成り立つ（実数なら `sin x` は滑らかで果てがないのに動く）。この記録で、複素数ならではの構造がいちばんはっきり働いた式。

### 2-8. 交流のフェーザ（電圧と電流のずれ・無効電力）

- 式で確かなこと：交流の電圧と電流を、回る複素数（フェーザ）で書く。二つの角度がそろっていれば電力は仕事をする（平均の電力が出る）。90 度ずれていると、電力は一周期のうちに行って戻るだけで、平均は 0（計算で確かめた：ずれ 0 度で平均 0.5、90 度で 0）。この行き来する分を無効電力と呼ぶ。複素電力 `S = P + iQ` の実部 `P` が仕事をする電力、虚部 `Q` が無効電力。無効電力は、仕事として数えられないが、モーターの磁場を作り保つのに要る。
- 意識に当てること（仮）：関係を保つために行き来しているが、成果として数えられない力。信頼の信号の、認知し得ない成分（§1-3 の `y₂`）を、この `Q` に当てる。行って戻るだけで、外から測ると 0 だが、それが無いと場（磁場）が立たず、仕事をする側も回らない。
- 物差し：1・2 立つ。3 立つ：実部と虚部がそれぞれ違う物理量（仕事と行き来）になることは、複素数の積 `V · I*` から出る。
- 時間の大きさ：交流の一周期は、心に当てると器 B に寄りうる。ここで当てたのは、関係を保つ行き来という器 C の話で、器 B（神経の振動）には当てない。

### 2-9. 二次元の流れの複素ポテンシャル（湧き出しと流れの渦）

- 式で確かなこと：`w = (k / 2π) log z` の係数 `k` が実数なら、原点から外へまっすぐ流れ出る湧き出し。純虚数なら、原点の周りを回る**流れの渦**（点渦）。同じ `log z` で、係数を 90 度回しただけで、湧き出しが流れの渦になる（計算で確かめた：`k = 1` は外へ向かう流れだけ、`k = i` は周りを回る流れだけ）。湧き出しは囲んだ線を通って出ていく量（流束）を持ち、流れの渦は囲んだ線に沿って回る量（循環）を持つ。
- 意識に当てること（仮）：外へ出ていくもの（成果・出力・認知できる量）と、周りを回るもの（循環・認知し得ない成分）が、同じ源の向きの違い（90 度）として書ける。§2-3 の気づき（虚軸の成分が回って実軸に出る）と、§2-8 の無効電力と、同じ形。ここで言う流れの渦は、五段階の渦（散逸構造）とも、軌跡の渦とも別のもの。ただ、五段階の渦を「周りに揺らぎがあるから渦を巻く」（stance 1-4・第五部）と見たいことと、流れの渦が流束でなく循環で書かれることは、向きが合う。
- 物差し：1・2 立つ。3 立つ：一つの解析関数 `log z` の係数の実部と虚部が、流束と循環に分かれるのは、複素数で書いたときの形。

### 2-10. ジューコフスキー変換と翼の揚力

- 式で確かなこと：ジューコフスキー変換 `z + 1/z` は、円を翼の形に写す。翼に揚力が生まれるのは、翼の周りに循環（§2-9 の流れの渦の量）があるときだけで、揚力の大きさは、流れの密度・速さ・循環の積（クッタ・ジューコフスキーの定理）。循環が 0 なら、どれだけ速く進んでも揚力は 0。
- 意識に当てること（仮）：前へ進む（実軸の上の速さ）だけでは浮かない。周りを回る循環（認知し得ない成分）があるときだけ、進む向きと直角に、持ち上げる力が生まれる。プロジェクトの駆動源に当てると、駆動は、前に進む量の側でなく、周りを回る循環と前に進む速さが掛け合わさる所に出る、と読める（§4）。
- 物差し：1・2 立つ。3 立つ：揚力の定理は、複素ポテンシャルの留数の計算から出る。

### 2-11. 信号処理の z 変換（極が単位円の内か外か）・フーリエ変換

- 式で確かなこと：z 変換で書いた系は、極（式の分母が 0 になる点）がみな単位円の内にあれば、ゆれは時間とともに小さくなって消える。外に一つでもあれば、ゆれは大きくなり続ける。ちょうど円の上にあれば、同じ大きさで鳴り続ける。フーリエ変換は、波を回る複素数の重ね合わせで書く。時間の中で鋭く局在するほど、周波数は広がる（不確定性：時間の幅と周波数の幅の積は、ある値より小さくならない）。
- 意識に当てること（仮）：一つの出来事が心の中でどう響くか。消えていく（円の内）、膨らみ続ける（円の外）、同じ大きさで鳴り続ける（円の上）。円の上で鳴り続けるのは、ジュリア集合の縁（散りも縮みもしない）と、#200 の神経の雪崩（分枝の比がちょうど 1 のときだけ続く）と、同じ形に見える。フーリエ変換の不確定性は、「いつ」と「何の音色か」を同時に鋭くは知れない、という形で、stance 1-4 の「脳の微細な瞬間の働きと、認知できる大きな時間の話は必ず分ける」が、式の側でも避けられないことの写しに見える。
- 物差し：1・2 立つ。3 半分：極の位置で決まることは複素数の解析から出るが、「内なら消え、外なら膨らむ」だけなら、実数の掛け算（1 より小さいか大きいか）でも書ける。
- 時間の大きさ：響きの話は器 B に寄りやすい。ここで当てたのは、出来事が日や週の単位で響き続けるか（器 C）で、二つを一つの器に並べない。

### 2-12. スピノルと SU(2)（二周で戻る）

- 式で確かなこと：スピノルは、回す角の半分で位相が回る。360 度回すと符号が裏返り（`−1`）、720 度回すとやっと元に戻る（計算で確かめた）。単位の四元数で三次元の回転を表すときも、`q` と `−q` が同じ回転を表す（二重の覆い）。
- 意識に当てること（仮）：一周回って同じ所に戻ったように見えても、内側の符号が裏返っている。もう一周してやっと戻る。pjdhiro のブログ（2025-06-16「スピノル場の理解のために民話をあててみる」）の「3 枚の平面で一度裏返り、720 度でようやく自身に重なる波」は、この形をすでに民話に当てている。§2-5 の `log` の多価（同じ点で、何周したかが違う）と並べると、一周目と二周目が見分けられないまま違う、という形が二つの式で出る。§1-3 の四元数とも、同じ器（単位の四元数）の上にある。
- 物差し：1・2 立つ。3 立つ：半角で回ることは、四元数（ふたつの複素数の組）の積から出る。

## 4. プロジェクトの駆動源に返すもの（仮）

北極星に戻す。§3 の一つ目の重なりを、駆動源に当てる。

- 駆動は、認知できる軸の上の「量」（売上・成果・進んだ距離）として測れる所には、そのままは出ない。測れる所で見ると、駆動の芯は 0 と出る（§2-3・§2-8）。
- 駆動が出るのは、**直角に回った成分（循環・無効電力・虚部）が、前へ進む動きと掛け合わさる所**（§2-10 の揚力：密度・速さ・循環の積）。循環が 0 なら、どれだけ速く進んでも浮かない。
- これは、julia-potential の `c`（Love と呼びたいもの）を「重力のようなもの」と置いた見立てに、もう一つの面を足す（置き換えない）：`c` は一歩ごとに足される一定の働きで、揚力の式では、それは循環の側に当たるかもしれない。循環は、周りを回る、行って戻る、外から測ると 0 の、関係を保つ働き（§2-8 の無効電力と同じ形）。
- リウヴィルの定理（§2-7）は、駆動が起きるための条件を、反対側から言う：どこでも滑らかで果てのない場（衝突の無い場）では、何も変わらない。駆動源は、特異点（衝突・揺らぎ）を持つ場にしか出ない。

この返し方は、四つの式がそろって指した向きで、まだ一つの読み。ほかの道具（#198〜#200 の量子論・自我の論・生化学・神経現象学）で同じ「循環が浮かせる」形が出るかは、まだ見ていない。
