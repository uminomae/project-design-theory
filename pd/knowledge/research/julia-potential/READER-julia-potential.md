式に書くと `z → z² + c` です。`z` は起業家の思考・心理・行動（気づきや決定も含む）、`z²` は自分で自分を回す一歩、`c` は Love と呼びたいものの重力です。これは、ジュリア集合を描く式です。値を前へ打つと、一か所に寄る渦になります。遡ると、ジュリア集合の込み入った境目になります（[図で見る](#jp-vortex)）。

<details><summary>詳しく — ジュリア集合とは</summary>

ジュリア集合は、`z → z² + c` のような簡単な式をくり返すと現れる形です。名は、フランスの数学者ガストン・ジュリアにちなみます。

- `z` も `c` も、平面の上の一点で表せる数（複素数）です。`c` を一つ決め、出発点の `z` を一つ選んで、二乗して `c` を足す、をくり返します。
- 二乗すると、点は、原点から見た角度が二倍になり、原点からの距離が二乗になります。`c` を足すと、毎回、同じ向きに同じだけずれます。
- 出発点によって、くり返すうちに限りなく遠くへ行く点と、いつまでも遠くへ行かない点に分かれます。遠くへ行かない点の集まりの縁（境目）が、ジュリア集合です。
- 境目は、どれほど拡大しても込み入った模様が続きます。形は `c` ごとに違います。
- `c` を平面のどこに置くと境目がひとつながりになるかを塗った地図が、マンデルブロ集合です。このページの図の「c を選ぶ」の黒い形がそれです。
- 一歩を逆に戻すと、平方根が二つあるので、点は二つに分かれます。遡った点は、境目に集まっていきます。このページは、この遡る向きから見ます（第三部）。

</details>

## 漸化式を、起業家のたとえにする

<!--OPEN-->

<a id="jp-recurrence"></a>見立ての一つ目は、漸化式は起業家のよう、です。まず、漸化式とは何かから見ます。

漸化式は、数の並びの各項を、それより前の項から決める式です。`z → z² + c` なら、いまの値 `z` を二乗して `c` を足したものが、次の値になります。出てきた値に、また同じことをします。同じ決まりを、自分が出した結果にくり返し当てていくので、反復とも、再帰的とも言われます。

<details><summary>詳しく — 漸化式・反復・再帰という言葉</summary>

三つの言葉は、同じくり返しを、違う所から見て呼んだものです。

- 漸化式：数学の事典 MathWorld は、漸化式を、第 n 項を、それより前の項の組み合わせで表す関係、と書きます。`z → z² + c` は、一つ前の項だけから次の項を決める漸化式です。
- 反復：数学者ミルナーの講義録は、写像 `f` を n 回重ねたもの（n 回の反復）を `f∘n` と書き、ジュリア集合を、この反復のふるまいで定めます。
- 再帰：計算機科学の教科書 SICP は、二つを分けて書きます。手続きが再帰的だというのは、定義が自分自身を参照するという書き方の話です。過程が再帰的か反復的かは、計算がどう進むかの話で、決まった数の状態と、それを更新する決まりで表せる過程を、反復的な過程と呼びます。`z → z² + c` をくり返す計算は、状態が `z` 一つで、更新の決まりが式そのものです。SICP の言い方に当てると、反復的な過程です。自分を呼ぶ関数で書けば、再帰的な手続きにもなります。

pjdhiro の言う「再帰的な行動原理」を、いまの一歩の結果を次の一歩の出発にする、という意味で読めば、どの言葉で呼んでも同じくり返しを指します。

<p id="jp-pseudo"><b>疑似コードで書くと</b></p>

pjdhiro の言う「再帰は、構造を繰り返す」は、一歩の形（構造）を、自分が出した結果にもう一度当てていくことです。エフェクチュエーションの一歩、決定ツリー（pjdhiro がリアルオプションの話題で挙げたもの）、このページの式は、どれも、その形で書けます。疑似コードは Claude が書いたものです。

```
function 進む(手段):                         # エフェクチュエーション
    if 終える(手段): return 手段
    できること = 何ができるか(手段)
    相手      = 人に会う(できること)
    約束      = 気づいて、決める(相手)        # 一歩の中の判断
    return 進む(手段 + 約束で増えた手段)      # 同じ形を、もう一度

function 価値(節):                           # 決定ツリー
    if 節が葉: return 結果
    return 一番よいもの([期待値(価値(子)) for 子 in 選べる道(節)])   # やめる・待つ・進む

function 歩く(z, c, n):                      # z → z² + c
    if n == 0 or |z| > 2: return z
    return 歩く(z*z + c, c, n - 1)           # z*z が自分で自分を回す一歩、c が毎回同じだけ引き寄せる
```

書いてみると、違いも一つ見えます。決定ツリーでは、どの節にも選べる道が複数あり、そのうち一本を通ります。式の `歩く` は、前へは一本道で、二つに分かれるのは遡る `±√(z − c)` のほうです。分かれ道が、決定ツリーでは前に、式では後ろに出ます。これが食い違いなのか、同じものを逆の向きから見ているのかは、まだ読めていません。

<p><b>原文</b></p>

- MathWorld："A recurrence relation is a mathematical relationship expressing f_n as some combination of f_i with i<n."
- ミルナー p.3-1："let f∘n : S → S be its n-fold iterate."
- SICP 1.2.1："we must be careful not to confuse the notion of a recursive process with the notion of a recursive procedure"。反復的な過程は "one whose state can be summarized by a fixed number of state variables"。

訳は Claude。

<strong>pjdhiro の体験：</strong>リアルオプションの視点について話題になったとき、再帰と反復の関数の違いを「再帰は、構造を繰り返すんです。起業家みたいに」と思いつきで言ったことがある。その時、「商いとは飽きない」という言葉を思い出した

<strong>pjdhiro の見方：</strong>それにloveという重力のようなcを加えて、非二元を考慮すると、ジュリア集合の漸化式に似てた

ここでの再帰は、一歩の形（構造）を、自分が出した結果にくり返し当てることです。一歩の結果が、次の一歩の出発になります。pjdhiro は、式の中で決まっていることと、漸化式が何に当たるかを、こう言っています。

<strong>pjdhiro の見方：</strong>決まっているのは、c=Loveと呼びたい一定の力、√が存在すること。漸化式は、エフェクチュエーションのようなシンプルな再帰的な行動原理。たとえば、（人に会い、気づきを得る）を繰り返すような。

## z は、起業家の思考・心理・行動

<!--OPEN-->

<a id="jp-z"></a>では、くり返されている `z` は何か。pjdhiro は、`z` を次のように置きました。

<strong>pjdhiro の見方：</strong>私はzは二乗もできるし、ルートもあるという意味で、思想やDNAのようなものがいいのかなと思っています。しかも虚軸を持つ複素平面に馴染むもの。認知可能なものと認知できないものという軸。

<strong>pjdhiro の見方：</strong>思想やDNAというものが何でもいいけど、実軸や認知できるものだけを切り取った概念じゃないか？波間の渦のように、渦以外の波の存在が抜けてるのではないか？というのが認知し得ない面

`z` は、起業家の思考・心理・行動です。気づくことも、決めることも、ここに入ります。`z` は平面の上の一点で、横の軸（実軸）と縦の軸（虚軸）の二つの成分を持ちます。横の軸に認知できるもの、縦の軸に認知し得ないものを置きます。思想や DNA のような呼び名は、そのうち横の軸だけを切り取った言葉です。渦に名前を付けると周りの波が抜けるように、認知し得ない面が抜けている、という見方です（渦と波は、「[創造とは](../cs/)」が創造の五つの段〔場・波・縁・渦・束〕に置く語）。

式の側から見ると、`z = x + iy`（`x` が認知できる成分、`y` が認知し得ない成分）を二乗すると、`z² = (x² − y²) + 2ixy` になります。次の一歩の認知できる成分に、認知し得ない成分の二乗 `y²` が、引かれて入ってきます。認知し得ないものは、見えないまま、次に見えるものを変える、と読めます。

初めの値は、起業家ごと、状況ごと、時代ごとにばらばらです。

<details><summary>詳しく — z の置き方が、起業家の思考・心理・行動に決まるまで</summary>

対話では、はじめ、`z` を物事の中心にある主体と置いていました。そのあと、pjdhiro は、`z` は主体そのものでなく、主体の心理や行動ではないか、と見直しました。

<strong>pjdhiro の見方：</strong>z が主体ではなく、zは主体の心理や行動じゃないかな？

そこから `z` の中身を詰めていき、一度は「起業家自身」と置きました。けれども、その言い方は誤解が多いので、心理や行動に思考を合わせ、気づきや決定も含めた、起業家の思考・心理・行動を、認知できる面と認知し得ない面を持つ一つの数として置く、上の置き方に直しました。

</details>

## z の二乗は、自分で自分を回す一歩

<!--OPEN-->

<a id="jp-square"></a>式の二乗の所は、起業家の何に当たるのか。pjdhiro は、こう問いました。

<strong>pjdhiro の問い：</strong>zの二乗に当てはまる現実世界の起業家の行動が見つかるといいんだよね。心理面でも良いので。

二乗には、式の上で二つのはたらきがあります。一つは、平面の上の点を、原点から見た角度を二倍にし、原点からの距離を二乗にすることです。距離が 1 より小さい値はさらに小さく、1 より大きい値はさらに大きくなります。もう一つは、向きが逆の二つの値 `z` と `−z` を、同じ一つの値に送ることです（二対一）。二乗したあとの値からは、二つのどちらから来たのかが分かりません。

pjdhiro は、二乗を、自分自身で自分自身を回すように進むこととして見ています。

<strong>pjdhiro の見方：</strong>自分自身と自分自身を回転させるように進む、という視点はどうだろうか？

`z` に `z` を掛けると、`z` は自分の角度だけ回り、自分の大きさの分だけ伸び縮みします。自分で自分を回す、という見方は、二乗のこの性質と言葉のとおりに重なります。その回転を、pjdhiro は、時間や寿命のように、逃れられない一方向のものと見ています。

<strong>pjdhiro の見方：</strong>ちょっと雑すぎるけど、回転は時間や寿命のような逃れられない一方向、Cも重力のような。

ただし、この回転は、外からはそう見えません。

<strong>pjdhiro の見方：</strong>起業家自身を回転させる、とは、周囲から見ると、人に会って決める、と繰り返す、のようなシンプルな繰り返しに見える。でもそれは認知できるものとしてそうで、実際は認知し得ないものも含まれるし、その存在は言語化できずに認知されるものだけが切り取られる。

周りに見えるのは、回転のうち認知できる側だけです。その側に、二乗の一面に似て見える行動や心理（のめり込み・思いがけないこと）があります。二対一の候補として、pjdhiro は相補性を挙げています。どれも、二乗そのものに当たるとは確かめられていません。

<details><summary>詳しく — 周りに見える行動や心理で、二乗に似て見えるもの（のめり込み・思いがけないこと・相補性）</summary>

認知できる側に現れる起業家の行動と心理の中で、二乗の二つのはたらきに形が近く見えるものを、Claude が原典で探しました。どれも Claude の読みで、二乗そのものに当たると確かめたものではありません。

- 大きさが二乗になることに近いもの：のめり込み。スタウは、自分が責任を負う決定が悪い結果になったとき、人は前に選んだ道に、いちばん多くの資源を注いだ、と報告しました（1976）。結果が次の行動を強め、それがまた次の結果になる形は、1 より大きい値を二乗がさらに大きくする形に近く見えます。
- 二対一に近いもの：思いがけないこと。サラスバシーは、時とともに思いがけず起きたことを生かすには、エフェクチュエーションのほうが向く、と書きました（2001）。良い思いがけなさも悪い思いがけなさも、次の一歩の材料になる、と読めば、逆向きの二つが同じ一つに送られる形に近く見えます。ただし、原典は、思いがけないことを良し悪しに分けて書いてはいません。

自分で自分を回す、という見方が重なるのは、角度と大きさのはたらきのほうです。

二対一のはたらきの候補として、pjdhiro は相補性を挙げています。

<strong>pjdhiro の見方：</strong>相補性というのはどうだろうか？ボーア、ユングなど

相補性は、物理学者のボーアが、量子のふるまいについて出した考えです。電子は、検出器には一粒ずつ届くのに、たくさん集めると、波が重なったときのような縞を描きます。ボーアは 1928 年の論文で、粒の絵と波の絵は、矛盾する絵ではなく相補的な絵で、二つが一緒にあって初めて記述になる、と書きました。どちらの穴を通ったかを確かめる見方と、縞を見る見方は、一度の実験では両立しません（読み物「[不二（非二元）とは](nondual.html#nd-electron)」で見ています）。

二乗では、向きが逆の二つ `z` と `−z` が同じ一つの値になり、出てきた値からは、どちらから来たのかが分かりません。遡ると、一つの値が `+√` と `−√` の二つに開きます。逆向きに見える二つが、一つの結果の中で見分けられないまま両方とも在る、という形は、二つの絵が一度には見えないまま、一緒にあって一つの記述になる、という相補性の言い方に近く見えます。ただし、ボーアの相補性は、観測と記述の話です。二つを一つの値に送る式の話ではありません。二対一が、自分で自分を回す一歩の何に当たるかは、まだ空いています（[空いたままの所](#jp-gaps)）。

</details>

<details><summary>詳しく — スタウの「のめり込み」は、どんな論か</summary>

組織行動の研究者バリー・スタウは、1976 年の論文で、うまくいっていない道に、人がかえって多くを注ぎ込んでいく現象を、実験で確かめました。題のとおり、選んだ道へのコミットメントが深まっていくこと（エスカレーション）を扱った論文です。

実験では、イリノイ大学の商学の学生 240 人が、架空の会社 Adams & Smith の財務の副社長を演じました。会社は利益が落ちています。一回目の決定では、研究開発の追加の 1,000 万ドルを、二つの事業部（消費者向けと産業向け）のどちらか一つに全部入れます。そのあと、五年後の売上と利益の数字を見せ、二回目の決定で、2,000 万ドルを二つの事業部に好きなように分けます。数字は、選んだ事業部が持ち直した場合と、さらに落ち込み、選ばなかった事業部が良くなった場合とに、くじで割り当てました。もう一つの組の学生は、一回目の決定を「別の財務の役員がした」と聞かされ、二回目だけを決めました。

前に選ばれた事業部に、いちばん多く注いだのは、自分で選んだ事業部が落ち込んだ組で、平均 1,307 万ドルでした。ほかの三つの組との差だけが、意味のある差でした。他人が選んだ場合は、結果が悪くても、注ぐ額ははっきりとは増えませんでした。

スタウは、これを自己正当化で説明します。人は、自分の前の行動が理にかなっていた、という見かけを保とうとし、悪い結果の責任が自分にあるときほど、前に選んだ道に注ぎ込みます。注ぎ込みを増やすと、さらに悪い結果になり、それがまた注ぎ込みを増やす、という循環になりうる、とも書いています。論文の冒頭では、その例として、インドシナへの米国の政府の深入り（ペンタゴン・ペーパーズにある 1965 年の覚え書き）を引いています。

上の畳みの「結果が次の行動を強め、それがまた次の結果になる」は、この循環の言い方によっています。二乗が 1 より大きい値をさらに大きくする形に近く見える、というのは Claude の読みで、スタウは式を使っていません。

<p><b>原文</b></p>

- p.27："persons committed the greatest amount of resources to a previously chosen course of action when they were personally responsible for negative consequences."
- p.29："committing additional resources to a losing decisional alternative can also turn into a negative cyclical process."／"this higher level of commitment may, in turn, lead to further negative consequences."
- p.37：自分で選んだ事業部が落ち込んだ組は、二回目の決定で平均 "13.07 million dollars" を同じ事業部に注いだ。
- p.41：結果は "a self-justification notion that individuals actively seek to maintain or restore the appearance of rationality to a previously chosen course of action" と合う。

## c は、一歩ごとに同じだけ引き寄せる

<!--OPEN-->

<a id="jp-drift"></a>見立ての二つ目は、Love と呼びたいものは重力のようにドリフトする、です。式では `c` に当たります。

「[Love駆動開発と呼びたいもの](love-driven-dev.html)」は、人やプロジェクトを動かしているもの（駆動源）を、Love と呼びたいものと置く読み物です。pjdhiro は、その Love と呼びたいものを、漸化式の `c` に置きました。`c` は人ごとに違い、一人の中では一定です。

この置き方の土台には、Love と重力の構造の似かたを問う見方があります（読み物「[愛は、重力に似ていないか](gravity-love.html)」）。

<strong>pjdhiro の見方：</strong>愛は重力と似ていないか？それはCと似てないか？という感じですね。一つは。基礎にある視点。なので汎用的に色々使えそう。まずは創造。それ以外にも。

思考・心理・行動が自分で自分を回すだけなら、式の値は、原点の周りで回り、原点からの距離が変わるだけです。そこに `c` を足すと、値は毎回、同じ向きに同じだけずれます。一歩ごとのずれは小さくても、くり返すうちに、値がどこへ行き着くかを大きく変えます。外へ限りなく遠ざかる値もあれば、外へ出ずに残る値もあります。どちらになるかは、`c` と初めの値で決まり、残るものは一部です。物を同じように引き寄せ、通り道を少しずつ曲げていく重力のようなもの、とたとえられます。pjdhiro は、`c` を、重力のように、符号が一つしかないものと見ています。

<strong>pjdhiro の見方：</strong>＋の符号しかない物理の概念って、今のところそれが一番有名では？確認されていることの中では。

電気の力には、引き合う向きと退け合う向きがあります。重力は、知られている限り引き寄せるだけで、押し返す重力（負の質量）は確かめられていません。式でも、`c` は毎回、同じ向きに同じだけ足されます。

ドリフトは、流れに押されて、少しずつ漂うようにずれていくことです。Love駆動開発で、pjdhiro は、同じ駆動が、成果と呼ばれる向きにも、お金や名誉や権力の向きにも、知識や子孫のようなお金にならないものの向きにもドリフトする、と見ています。どの向きも、善悪でなく、同等の現れです（「[Love駆動開発と呼びたいもの](love-driven-dev.html#ldd-drift)」で引いた見方）。式でも、`c` の値に、良い値と悪い値はありません。違う `c` は、違う形を残すだけです。

式の数学そのものは、Love駆動開発の章「[数学の視点で見る](love-driven-dev.html#ldd-math)」で見ています。この置き方を意思決定に当てた仮の案は、「[意思決定とは](decision-making.html#dm-circle)」の巻末にあります。

## ジュリア集合を、逆にたどる

<!--OPEN-->

<a id="jp-origin"></a>この式を、pjdhiro は 2025 年に、遡る向きから見ていました。

ジュリア集合は、`z → z² + c` のような簡単な式をくり返したときに、限りなく遠くへ行く点と行かない点の境目にできる形です。境目は、どれほど拡大しても込み入っています。pjdhiro は 2025 年 5 月、この形を、点がどこから来たかをさかのぼる向き（逆写像）から動かして見ていました。一歩を逆に戻すには、`c` の分を引いてから平方根を取ります。平方根は、プラスとマイナスの二つあります。

pjdhiro は、記事に次のように書いています。

<strong>pjdhiro の見方：</strong>☯️陰陽マークのように見える。円の分割(平方根による角度が半分になる)と反転コピー（マイナスの平方根）の箇所が。

<strong>pjdhiro の見方：</strong>発散しそうでしない境界で複雑な模様になる。「境界が曖昧な地点」＝「創造が生まれる土壌」という直感にまた一つ。

（pjdhiro の公開文「[陰陽なJulia集合を逆にたどる](https://uminomae.github.io/pjdhiro/20250531julia/)」から）

平方根で角度は半分になり、マイナスの平方根は、もう一方を半回転させた写しになります。pjdhiro は、この二つの枝の並びを ☯ に見ました。境目に込み入った模様が出ることは、創造が生まれる所についての直感と重なっていました。

記事が参考にしていたのは、Steven Wittens の「[How to Fold a Julia Fractal](https://acko.net/blog/how-to-fold-a-julia-fractal/)」（2013）です。そこでは、点が収まる円を、遡る向きに一段ずつ畳んでいくと、ジュリア集合の形になる様子を、動く図で見せています。下の図は、その見せ方に倣って、このページで新しく描いたものです。大きさ 2 の円の上の点を、`±√(w − c)` で一段ずつ遡ります。一段を「− c」「√」「−√」の三歩に分けて、一歩ずつ進めたり戻したりできます。

## 値を前へ打つと渦になり、遡るとジュリア集合の形になる

<!--OPEN-->

<a id="jp-vortex"></a>同じ一つの式を、前へ進めると渦になり、後ろへ遡るとジュリア集合の形になります。

よく見るジュリア集合の絵は、平面のすべての点を出発点にして式をくり返し、遠くへ行く点と行かない点を塗り分けて描きます（章の終わりの畳みの図）。この章でするのは、それとは別のことです。出発点を 0 の一つだけにして、出てきた値 `z₀, z₁, z₂…` そのものを順に平面に打ちます（赤）。そして、赤の一点から、同じ式を逆に `±√(z − c)` で一段ずつ遡ります。遡る一段では、`+√` と `−√` の両方をたどるので、一段ごとに点が二倍に分かれます。その枝を全部打ちます。

<details><summary>詳しく — よくある塗り分けと、この章の打ち方の違い（計算式とプロット）</summary>

<a id="jp-gaps"></a>問いに近寄っても、埋まらない所が残りました。どの論も触れていなかった所です。

<b>自分で自分を回す一歩は、周りからは何に見えているのか。</b>`z²` は、起業家の思考・心理・行動が自分で自分を回す一歩と仮に置きました（[z の二乗は、自分で自分を回す一歩](#jp-square)）。周りに見えるのめり込みや思いがけないことは、二乗の一面に似て見えるだけでした。認知できる側に切り取られた行動や心理のうち、角度と大きさを変えるはたらきと、二対一のはたらきを、両方とも持つものは、まだ見つかっていません。

<b>`√` を取ることは、何を意味するか。</b>式の側では、遡る一段は、大きさが一つに決まり、向きが二つに分かれます。それがたとえの側で何に当たるかは、当てはまる概念が見つかっていません。

<strong>pjdhiro の見方：</strong>このルートは違和感だけで、当てはまる概念がない。数式だけがある

<b>`z` と `−z` を一つに送る二対一を、どう読むか。</b>前へ進む一歩は、見分けられる二つを、同じ一つへ送ります。逆向きの二つが同じ一つに行く、という形で書いた論は、読めた中にはありませんでした。pjdhiro が挙げた相補性（ボーア）は、二つの絵が一緒にあって一つの記述になる、という言い方が近い候補ですが、観測と記述の話です（[z の二乗は、自分で自分を回す一歩](#jp-square)）。

<strong>pjdhiro の見方：</strong>ここをどう解釈するかです。これが最後のピースで、いつまで経っても埋まらない。

<b>自然によく見られる形と、美しさの関係。</b>四段の一つ目と二つ目のあいだの飛躍です。作る側から触れたアレグザンダーも、なぜそうなるかは言っていません。

<b>美・神・愛は、同じものを指しているか。</b>三つ目の仮説の「もしも」の所です。古典には三つを神の名として重ねる論（偽ディオニュシオス）があり、測る研究には美と崇高を分ける結果があります。どちらも、この「もしも」を確かめたものではありません。

前へ打った渦と、遡った境目の形との関係が何を意味するかも、まだ読めていません。境目の上の点から遡った点が境目のどこにでも近づくことは数学で確かめられていて、渦の上の点から遡った枝が境目に寄ることは Claude の計算で確かめました。その意味を読んだ論は見つかりませんでした。pjdhiro は、起業家・組織・社会はフラクタルで、どこかの大きさで `√` がなじむものが見つかれば、ほかの大きさにも当てて読める、という強い仮説を持っています。その最初のとっかかりは、まだ見つかっていません。
