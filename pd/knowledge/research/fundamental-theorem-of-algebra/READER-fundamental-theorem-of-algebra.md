# 代数学の基本定理

<div class="reader-lead glow-card" id="ft-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p><code>x² + 1 = 0</code> には、数直線の上に答えがありません。2 乗した数は 0 より小さくならないので、1 を足すと 0 に届かないからです。数を平面まで広げると、0 の真上の <code>i</code> と、真下の <code>−i</code> の二つが答えになります。</p>

<p class="reader-summary__title">概要</p>

複素平面の数式を人の意識に照らしていた対話の中で、pjdhiro はこう言いました。

<strong>pjdhiro の見方：</strong>一次元の数直線的な思考を止めたい。

代数学の基本定理は、数直線だけで考えると答えが足りなくなることを、いちばん素朴な形で見せる数学です。方程式の答えを数直線の上だけで探すと、答えが無いことも、次数より少ないこともあります。x を n 回掛け合わせた項までを持つ方程式（n 次方程式）は、複素数の平面まで広げると、重なりも数えて、ちょうど n 個の答えを持ちます。これを代数学の基本定理と呼びます。答えを探すのに、平面より外の数は要りません。<code>zⁿ = 1</code> では、答えが円の上を同じ角度ずつ回った所に並びます。

## x² + 1 = 0 は、数直線の上と下に答えを持つ

<!--OPEN-->

<a id="ft-two"></a>数直線の上の数は、2 乗すると 0 以上になります。3 × 3 = 9、(−3) × (−3) = 9 で、0 × 0 = 0 です。だから、x が数直線のどこにあっても、x² + 1 は 1 以上で、0 になりません。数直線の上だけで探すと、x² + 1 = 0 には答えがありません。

数を平面まで広げると、2 回掛けると −1 になる数 i があります。i を掛けることは、0 を中心に 90 度回すことです。i を 2 回掛けると 180 度回るので、−1 を掛けたのと同じになります。−i を掛けると、逆向きに 90 度回ります。−i も、2 回掛けると 180 度回って、−1 になります。

だから、x = i と x = −i で、x² + 1 = 0 になります。二つの答えは、数直線の 0 の真上と真下に、一つずつ並びます。i を掛けると 90 度回ることは、読み物「[回転の掛け算](rotation-multiplication.html)」で、数直線から一歩ずつ説明しています。

## 答えの数は、次数と同じ

<!--OPEN-->

<a id="ft-count"></a>方程式の中で、x がいちばん多く掛け合わされている回数を、その方程式の次数と呼びます。x² + 1 = 0 は 2 次、x³ − 1 = 0 は 3 次です。代数学の基本定理は、n 次方程式が、複素数の中に、ちょうど n 個の答えを持つ、と言います。

答えの数を数えるときは、重なった答えも数えます。たとえば、x² − 2x + 1 = 0 は (x − 1) × (x − 1) = 0 と書けるので、答えは 1 だけです。この 1 は、同じ答えが二つ重なったものとして、2 個と数えます。

<div class="tablefit">

| 方程式 | 次数 | 数直線の上の答え | 平面まで広げた答え |
|---|---|---|---|
| x² − 1 = 0 | 2 | 1 と −1 | 1 と −1（二つとも数直線の上） |
| x² + 1 = 0 | 2 | なし | i と −i |
| x² − 2x + 1 = 0 | 2 | 1 | 1 が二つ重なる |
| x³ − 1 = 0 | 3 | 1 | 1 と、1 から 120 度・240 度回った二つの点 |
| x⁴ − 1 = 0 | 4 | 1 と −1 | 1、i、−1、−i |

</div>

数直線の上だけで探すと、答えは次数より少なくなることがあります。平面まで広げると、答えが足りなくなることはありません。

平面で足りる、というところも、この定理の言っていることです。x² + 1 = 0 は、数直線の外の数を求めました。けれども、方程式の数（係数）に i の付いた数を使っても、平面の外の数を求める方程式はありません。数直線から平面へは一度広げる必要がありますが、平面から先へ広げる必要はありません。

<details><summary>詳しく — どうして必ず答えがあるのか（考え方だけ）</summary>

ここでは、答えが少なくとも一つあることの考え方だけを置きます。方程式の左辺を、x に数を入れると値が出る式として見ます。左辺は x = 0 のとき 0 でないとします（0 なら、0 がもう答えです）。

x を、0 を中心にした大きな円の上で一周させます。円が十分に大きいと、左辺の値は、x を n 回掛けた項でほぼ決まります。x を n 回掛けると、回る角度は n 倍になります。だから、x が円を一周する間に、左辺の値は 0 のまわりを n 周する輪を描きます。

次に、円をだんだん小さくして、0 の一点まで縮めます。値の描く輪も形を変え、最後は一点（x = 0 のときの左辺の値）に縮みます。0 のまわりを n 周していた輪が、0 を囲まない一点になるには、縮む途中のどこかで、輪が 0 の上を通らなければなりません。そこで左辺が 0 になり、答えが一つ見つかります。

答えが一つ見つかれば、左辺を (x − その答え) で割って、次数を一つ下げられます。同じことを n 回くり返すと、n 個の答えがそろいます。

厳密に言うには、円を縮める途中で、値の輪が切れずに続くこと（連続であること）を確かめる道具が要ります。このページでは、その道具は使いません。この定理は答えがあることを言いますが、答えの求め方は言いません。

</details>

## zⁿ = 1 の答えは、円を n 等分する

<!--OPEN-->

<a id="ft-circle"></a>x² + 1 = 0 では、二つの答えが、数直線の上と下に分かれました。z を n 回掛けると 1 になる数、つまり zⁿ = 1 の答えを見ると、分かれた答えの並び方が、もっとはっきり見えます。ここでは、平面の数を z と書きます。

複素数の掛け算は、伸ばして、回すことです。0 からの距離が 1 より大きい数は、掛けるたびに伸びていきます。1 より小さい数は、縮んでいきます。だから、n 回掛けて 1 に戻る数は、0 からの距離がちょうど 1 の数で、掛けても伸び縮みせず、回るだけです。

回るだけの数を n 回掛けて 1 に戻るには、回った角度の合わせた量が、ちょうど何周か（360 度の何倍か）になればよいことになります。だから答えは、半径 1 の円の上で、1 から 360 ÷ n 度ずつ回った n 個の点です。この n 個の点は、円を n 等分します。

n = 2 なら、答えは 1 と −1 で、どちらも数直線の上にあります。n が 3 以上になると、数直線の上に残るのは 1 だけ（n が偶数なら、1 と −1）で、ほかの答えは数直線の外に出ます。
