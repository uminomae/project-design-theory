# 一年の軌跡を、追体験できるストーリーの別ページにする — 骨格の案

読み物からのつなぎ方（`love-history` が第四部でしたのと同じ形）：

- 巻末の畳み「一年の軌跡」の中身（日付の表と 🚧）を、二、三文のまとめと別ページへのリンクに置き換える。題辞（「私にとっての AI 協働のこの一年は……」）は別ページの冒頭へ移す。
- 巻末の畳み「私というアプリ」の終わりに、別ページへのリンクを一つ足す。
- 冒頭の概要の「背景」の段（テンプレートの `reader-lead`）は今のまま。巻末へのリンクがあるので、そこから辿れる。
- 巻末の 🚧 のリンクは、#88 から #109 に向け直す（ページを出すときに一緒に）。

## 3. 骨格の案

題（案）：**私というアプリを、読めるようにした一年**（題は問 1 で聞く）

## 4. 書く前に確かめること

- 起点の言葉は、元の記録と一字ずつ照らす（`corrections.md` 型 H）。章 8 の逐語の出所を探す。
- 各章の出来事（日付・何が起きたか）は、公開の投稿・pjdhiro の repo の commit・この repo の公開ファイルで確かめたものだけを書く。今までの repo の誕生日（ks 2/10・cs 2/19・as 3/17・pd 3/25）は、今は非公開のアーカイブにしか無いので、日付として書かず、公開の投稿に出ている時期で書く。
- 「詳しく」のリンクは、GitHub のファイルでなく公開ページ（pjdhiro のブログ・このサイト）を先に置く（`writing.md` 6-4）。対話録は GitHub の公開ファイルしか無い。
