# Love駆動開発：新しい第四部の趣旨と流れの案（#115）

今の第三部「人は、世界をどう解釈するか」を二つに分けたときの、新しい第四部の案です。#115 の本文とコメント 8 本にある pjdhiro の言葉を筋にして、今の章と repo にある材料を当てました。章の題はどれも仮で、組んでから決めます。

## 1. 第四部の趣旨（決めること 1）

pjdhiro の言葉を、言った順に並べると、筋はこうなります。

1. 「人の心理は自分が思っているようにはできていない。」信頼や愛の感じにも、本人に見えない発生源がある（転移・対象関係・元型・防衛・発達の段階と状態）。
2. だから、信頼と信仰と期待は、本人にも分けにくい（「信頼と信仰と期待を分けられるか？　のような感情メタ認知の程度の話」）。
3. それを先に示さないと、信頼が解説できない（「群盲象を評すようにしか定義できないから」）。信頼は一つに定義せず、何でないかを、わかりやすい問い（〜と信頼は、どう違うのか）と論拠で並べる。
4. 「感情の分類としては、狭い意味でのポジティブなLoveの定義に最も近いのは信頼という感情」。ここで第五部の Love へ渡す。

第四部が見るもの：非物質的なこと（心理・感情・発達・防衛）。第五部へ渡すもの：信頼は一つに定義できず、似たものとの違いからしか指せないこと、その信頼が狭い意味の Love にいちばん近い感情であること。

## 2. 部の分け目

今の第三部の章を、次のように分けます。

| 今の章 | 行き先 |
|---|---|
| 人は、生存と信頼の信号で世界を切り取る | 第三部（中身は #114 を待つ） |
| 信号は、体の内側から湧く | 第三部 |
| 信号と考えがずれると、欠けを感じる | 第三部 |
| 価値は、受け取る人の意識で生まれる | 第三部に置いたままにし、#114 が済んでから決める（#115 の一つ目のコメント） |
| 先が見えないとき、どの信号が湧くか | 第三部。畳みの「帯ごとに湧く信号の表（仮説）」だけ、第四部の発達の章へ |
| 信頼は、関係の積み重ねの中で育つ | 第四部（愛着と信頼の対比の材料） |
| 期待は先に向き、信頼は積み重ねの上に立つ | 第四部（期待と信頼の対比） |
| 心は、自分を守るしくみを持っている | 第四部（見えない発生源） |
| 発達の段階で、何が脅威に見えるかが変わる | 第四部（見えない発生源と、分けられるかの程度） |

分け目は「先が見えないとき、どの信号が湧くか」と「信頼は、関係の積み重ねの中で育つ」のあいだです。Love とはは第五部、開発の部は第六部になります。

開発の部の「心の言葉は、どこで誤解されるか」（心理的安全性・GRIT・レジリエンス・内発的動機）は移しません。職場で誤解される言葉の話で、後半の部に置くと決めてあります（decisions の「読み物は二つに分かれる」の行・#96）。第四部からは、要るところでリンクします。

## 4. 信頼にどこまで触れるか（決めること 3）

信頼を一つに定義しません。まとまり C の対比ごとに、違いとして見えた面を残していきます（向いている時間・良いことも悪いことも含むか・相手が目の前にいなくても働くか、など）。それらを章 11 の頭で並べ、「信頼とは、こういう面から指せる」とだけ書きます。保留していた「信頼とは」には、この形で触れます（#115 の四つ目のコメント「この形で触れることになるのかもしれない」）。
