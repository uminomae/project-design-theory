## 並べ方と、決めたこと

- 冒頭に pjdhiro の言葉のカードを置かなかった。この調べに当たる本人の言葉は、本人の個性（類推力・構造の類似を見抜く力）の自己分析で、公開ページに写さない（stance 2-8「本人の状態や作り方を既存の型と並べた見方は手元に」）。推論とはの章が残した問いの続き、という入り方にした（writing §5-10 の「記録に問いが無ければ、このページが立てる問いとして書く」）。
- 章の並び：関係を重ねる（構造写像）→ 何を重ねるか（多重の制約・知覚の側）→ 思い出されにくさ（問題解決の実験・図式）→ 力として（発達・成分・構え・人の特徴）→ 仮説を生むところ（マクスウェル・ケプラー・研究室の観察）→ 結び。構造写像・多重の制約・知覚の側の三つを「同じ働きの別の所を照らす」と並べたのは Claude（型 B：論ごとに「〜は言わない」を並べない）。チャルマーズらの批判は、知覚の側に目を向けた論として書き、構造写像を負かす形にしていない。
- 結びの「類推は、知覚から仮説の候補まで続く流れの中に、どこにでも入り込む働きとして研究されてきた」は、このページの仮説として書いた。M2 の「どの推論の形にも入り込む」と同じ様子かもしれない、も仮説の形。
- 共役のベクトルを当てる力（#205 の M8）は、中身を書かず、「重ねて出た推測に、ずれに合った確かめを当てる力」として名前だけ工事中で一文指した（ページが無いのでリンクしない）。
- 人の能力を測ったり比べたりしない。ペンらの人と動物の比べは、論者の仮説として紹介した。
