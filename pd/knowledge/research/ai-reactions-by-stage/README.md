# ai-reactions-by-stage — AI への反応を帯に置いてみる（仮説・初回収集）

Issue: **pd#140** https://github.com/uminomae/project-design-theory/issues/17
作成: 2026-11-03（Claude・初回収集と仮配置）。状態: **仮説のまま**。帯の定義・スクリーナーへの反映はしていない（§8 判断待ち）。

> **段階を人の等級にしない。** ここで置くのは「その文章に出ている見え方の構造」であって、人の値打ちや正しさではない。
> 同じ人でも、相手・場面・時期で出る構造は変わる。
> 帯の上下は、AI について誰が正しいかとも関係しない。4.x の形で強く警告している人の警告が当たることもある。

---

## 1. 目的

2026-11-03 の対話（`knowledge/notes/dialogue/2026-11-03-non-duality-love-gravity-signals.md` §5）で、「先が見えない（不確かさ）」が帯によって違って現れる表を立てた。

| 帯 | 「先が見えない」の現れ方（§5 の表） |
|---|---|
| 4.x | 脅威として急いで埋める・決める |
| 5.0〜5.5 | 対象として観て、埋めずに耐える（ネガティブ・ケイパビリティ）。耐えている私はまだ外にいる |
| 6.0 | 場の揺らぎとして受ける。耐える対象でなく、そこから渦が起きる側 |
| 6.5 | 耐えていた私も、観られる側に入る |
| 6.5〜7 | 先が見えないまま、確かめずに落ち着いている |

pjdhiro の問い：「AI への恐怖や期待は発達段階で分けられるかもしれない。仮説として。さまざまな反応をネット上で探してピックアップし、段階に対して配置していくと、何か見つかるかもしれない」。
AI は「限りがなく、先が見えない」対象の典型なので、この表をそのまま当てられる素材になりうる。本ファイルはその初回の収集と仮配置。

## 2. 方法

1. **収集**（2026-11-03）: WebSearch／WebFetch。英語圏は Claude が直接、日本語の発言と世論調査は調査エージェント（team-researcher）が並行で集めた。型の幅（恐怖・期待・拒絶・道具視・協働・依存・救済・受容）が出るように選び、一人の複数の発言や長い文章を優先した。
2. **出典の確かさ**を列に残した。「確認」＝本文を取得して読んだ／「抜粋」＝本文の一部だけ／「二次」＝報道・要約・検索結果だけで本文は未読。二次だけのものは判定を弱く扱った。
3. **配置**は二段で行った。
   - **A. 不確かさの扱い（§5 の表の行）**: 文章の中で、先の見えなさをどう扱っているか。埋める／保留して並べる／観て耐える（自分の欲も対象）／場として受ける／観る私も入る／主題にならない。
   - **B. 帯（スクリーナーの判定基準）**: `stages-screener/README.md` §8 の判定基準・参照体系で、何を対象にできているか × どこまで包容しているか（[CN-024](../../concepts/CN-024_stage-as-object-and-embrace.md)）。
   - A と B を分けたのは、配置の途中で **A の行が同じでも B の帯が決まらない**ものが多かったため（§6 で詳しく）。
4. 迷うものは **判定不能** に置き、理由を書いた。無理に当てていない。

## 3. 判定規則（この収集で使ったもの）

スクリーナーの規則（§8「帯の判定基準」「判定ルールの参照体系」）を、自己申告の選択肢ではなく他人の文章に当てるために、次のように読み替えた。

1. **語は帯を運ばない**（[CN-023](../../concepts/CN-023_words-do-not-carry-the-band.md)）。「非二元」「意識」「宇宙」「進化」「慈悲」などの語、仏教や形而上の語彙、熱力学や文明史の大きな規模は、それだけでは帯の手がかりにしない。
2. **恐怖か期待か（感情の向き）は帯を運ばない**。向きは内容。帯は、その恐怖や期待を**どう抱えているか**（構造）に出る。
3. **知っていることと生きていることを分ける**（について主義・CG p.13, p.43）。「名前は作られたものだ」を一般論や他人への批判として言っているだけなら、5.0 の条件（自分の意味づけに当てはめている）を満たさない。
4. **状態と段階を分ける**（CG p.87, p.89／O p.22）。一度の会話で動揺した、一度ぞっとした、という記述は、ふだんの見方として扱わない。
5. **段階は対話では隠れる**。経営者の株主向け発言、運動の声明、宣伝・説得のための文章は、相手に合わせて書かれている。そう読める文章には「相手に向けた文章」と注記し、帯を弱く扱った。
6. **複雑さは上の帯の目印ではない**（CG p.78, pp.85–86）。理屈が精巧でも、結論で不確かさを閉じていれば A の行は「埋める」。
7. **6.0・6.5 は非二元性を条件にする**（§8 参照体系 7.）。不確かさと日常の行為が二つのまま並んでいるだけなら 6.0 にしない。目撃する私が外にいて層を眺める形は 6.5 にしない。
8. **抜粋・二次情報だけのものは、帯を言わない**（A の行だけ置く）。

帯の名前は §8 のもの（〜3.5／4.0〜4.5／5.0〜5.5／6.0／6.5）。§5 の表は「4.x」と書くが、「急いで埋める」は 〜3.5 にも出る。本ファイルの「4.x」は **〜4.5 まで**（3.5 以前を含む）を指し、3.5 と 4.x の区別は試みていない。

## 5. 帯ごとの型のまとめ（仮）

個人 56 件の仮配置: **4.x（仮）20 件／5.0〜5.5（仮）3 件／6.0・6.5 0 件／判定不能 33 件**（うち 5.0 候補 2・6.0 候補 1）。

### 4.x — 不確かさを埋める・または並べて保留する

（型の例には、A の行が同じで帯は判定不能に置いたものも含めて挙げる。）

- **確信で閉じる型**: 破滅の確信（#1）と救済の確信（#2・#3・#46・#21）は、**向きが逆で形が同じ**。どちらも先の見えなさを一つの未来に決め、反対側を「パニック」「楽観の愚かさ」と名づけて外に置く。
- **定義・信念で閉じる型**: 「AI は意識を持たない」「芸術は作らない」「魂がある」（#14・#20・#39・#40・#42）。問いを定義や信念で先に閉じる。この型は宗教・非二元の語彙でも起きる（#23）。
- **道具・協働に変換する型**: 棋士・研究者・実務家（#17・#37・#38・#44）。不確かさを、検証や手順で扱える問題に変換する。3.5〜4.5 の仕事の見方。
- **並べて保留する型**: 「脅威と期待の両方」「いまの段階では」（#33・#35・#48・#54・#56）。**保留は 4.0 にすでに出る**（CG の 4/5「両方とも」「場合による」）。ここが §5 の表とずれた所（§6）。

### 5.0〜5.5 — 埋めたい自分を対象にして、耐える

- 3 件（#6・#7・#29）はすべて英語圏の長い文章で、共通するのは **「確信したい・制御したい・前に戻りたい」という自分の欲と、それを支える自分の物語を対象にしている**こと。恐怖も期待も持ったまま、どちらにも決めない。
- そして三つとも、耐える努力が書かれている（「戻りたい日がある」「処理の時間をとる」「穏やかさを探る」）。§5 の表の「耐えている私はまだ外にいる」とそのまま合う。
- 恐怖の向きは三つとも「恐怖あり」。期待側の 5.x の文章は今回見つからなかった。

### 6.0・6.5 — 置けたものはない

- 候補は 1 件（#24・仏教学者のエッセイ）。分からなさと日常の行為（食べる・働く・気づかう）が切り離されていない形があり、観る私も不確かさの内側にいる。ただし教えの解説として書かれていて、書き手のふだんの見え方なのか、教えの説明なのかを分けられない。
- #23（非二元の教師）は語の上では最も上に見えるが、問いを教えの前提で閉じる形で、6.0 の条件（非二元性が見え方の構造に出る）を文章からは確かめられない。CN-023 の実例。
- 6.5 の形（耐えていた私も観られる側に入る）は、一件も見つからなかった。

### 判定不能 — 多かった理由

- 短い・二次情報・抜粋（規則8）が最も多い。
- 一度の体験（#11・#32）は状態。
- 組織・集団・株主向け（#26・#46・#47）は、相手に合わせた文章。
- **依存・救済・素朴な受容（#19・#52・#53）は、§5 の軸がそもそも当たらない**。AI が「先の見えない未来」としてではなく、目の前の関係の相手として現れているため。

## 6. 見えたこと（仮説として）

1. **恐怖か期待かでは、段階は分かれない**。pjdhiro の問い「AI への恐怖や期待は発達段階で分けられるか」に対して、今回の材料での答えは「向きでは分かれない。抱え方で分かれる」。破滅の確信と救済の確信は同じ形（埋める）で、5.x の 3 件はどれも恐怖を抱えたまま。感情の向きは CN-023 の「語」と同じく内容で、帯を運ばない。
2. **§5 の表の「4.x＝埋める」は狭すぎる**。4.0〜4.5 では、複数の見通しを並べて決めない「保留」がすでに出る。5.x と 4.x を分けるのは「保留しているか」ではなく、**保留している自分の、埋めたい欲とその物語を対象にしているか**。§5 の表の 5.0〜5.5 の包容の段（「不確かさと、答えたい欲とを並べて抱える」）がまさにこれで、表の 4.x の行にだけ「並べて保留する」を足すと、材料と合う（§8 判断待ち）。
3. **上の帯の語彙は、上の帯の見え方を運ばない**。宇宙・熱力学・進化（#21）、非二元・意識（#23）、仏教（#24・#25）、どれも語の上では上に見え、構造では決まらなかった。検索も語でしかできないので、**語で探す方法では 6.x の文章を見つけにくい**（方法の限界・§7）。
4. **5.x の文章は「自分の反応の記録」の形をとる**。英語圏の 3 件も、日本語の 5.0 候補（#51・補足の体験記）も、AI について論じる文章ではなく、AI に向かう自分の見え方がどう動いたかの記録だった。AI 論の主張を集めると 4.x が多く出るのは、主張という形式が「埋める」側に寄るためかもしれない。
5. **依存・救済の型は別の軸が要る**。AI を関係の相手として受け取る文章では、不確かさの軸が当たらない。関係・愛着の側から読む軸（Love 駆動開発の「引力」の側）が要るかもしれない。
6. **世論調査の「両方」は保留の証拠ではない**。日本は「両方」が多く（S3）、「分かっている」が低い（S4）。「両方」は抱えている両方なのか、まだ決めていない・関心が薄いのかを、集計から分けられない。

## 7. 揃わなかった所・保持論点

- **6.0・6.5 の実例がない**。母集団でも 6 は 0.5%（CG）で、そのうえ後の帯の人は相手に合わせて書く。AI について公に書くとき、手前の帯の語り方に合わせている可能性がある。いないのか、見えないのかは分けられない。
- **移り目の記述をどこに置くか**。枠組みが崩れていく体験（#10）や「見え方が冬の間に変わった」（#8）は、帯でなく移り目かもしれない。スクリーナーは移行期の判定をやめた（§1）が、反応の配置では移り目が一つの型として目立つ。
- **素朴な受容と、後の帯の素朴さを外から分けられない**（#53）。CG p.90 は 6 の回答がとても素朴でありうると書く。
- **不確かさを受ける形と、それを結論の論拠に使う形**（#22）。§5 の対話でいう「確かめずに済む」と「確かめたいのを堪える」に加えて、「確かめないことを理由に進める」がある。外から似て、内側で違う三つ目。
- **判定者が一人**（Claude）。同じ材料を別の判定者が置いたら、どれだけ一致するかは確かめていない。
- **日本語の長文が少ない**。日本の公人の発言は取材や抜粋が多く、長い自己記述は一般の note に偏った。
- **数字の確認が残る**。S3 の日本の列の割り当て、S4 の設問と数字の対応、S6 の比較国（中国か英国か）は原文で確かめていない。
- **期待側の 5.x がない**。5.x の 3 件はすべて恐怖を抱えた文章。期待を抱えたまま自分の欲を観る文章がないのか、探し方の偏りかは分からない。

## 8. 判断待ち（pjdhiro）

1. **§5 の表の 4.x の行に「並べて保留する」を足すか**。材料では、保留は 4.0 で出て、5.x を分けるのは「埋めたい自分を対象にしているか」だった（§6 の 2）。表の変更は帯の読み方の変更にあたるので、Claude はしていない。
2. **問いの言い換え**。「恐怖や期待で分かれるか」→「恐怖や期待をどう抱えているかで分かれるか」にするか（§6 の 1）。
3. **スクリーナーへの反映**。「分からないことに向き合うとき」の分野を足すか。足すなら、4.x を「並べて保留する」、5.x を「保留している自分の欲が見えている」、6.0 を「分からなさと日常の行為が分かれていない」で書き分けられそう。既存 16 問にこの分野があるかは未確認。
4. **依存・救済の型を別の軸で読むか**（§6 の 5）。読むなら as（信号の正本）や Love 駆動開発の側に預けるか。
5. **収集を続けるか、ここで止めるか**。続けるなら §9 の方針で。
