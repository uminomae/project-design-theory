# 要約で残ってほしい要点（採点の基準）

Issue #191。要約を頼む前に書いて固定した（2026-11-24）。要約を見たあとに足したり直したりしない。直したくなったら、この文書の終わりの「固定のあとに気づいたこと」に書き、採点には使わない。

要点は、各ページの冒頭（ざっくりいうと・概要の問い・今の答え・要点の表・構成）と、本文の中心の章から取った。Claude が選んだもので、pjdhiro の確かめは入っていない。

## 種類

| 記号 | 種類 | 中身 |
|---|---|---|
| 芯 | 中心の主張 | 問いと、今の答え（仮説） |
| 二 | 二面性 | 同じものが逆の向きにも働く・良い側だけでない・二つを分けずに言う |
| 条 | 効く条件 | どこで効き、どこで効かないか・「〜の限りで」 |
| 名 | 名乗り | 仮説・素朴体験論・推論に過ぎない・論証ではない |
| 帰 | 帰属 | 誰の言葉・誰の整理か（pjdhiro・Claude・原典の著者） |

採点：要約に、要点の趣旨が読み取れれば「残」、一部だけなら「半」、無いか逆の趣旨なら「落」。逆の趣旨（言い切り・帰属の取り違え）は「誤」として別に数える。

| L2 | 芯 | 今の答え（仮説）：駆動源は「Love と呼びたいもの」。人はその場の一部で、それとのずれを欠け（ギャップ）として感じて動き出すのかもしれない |

| L4 | 二 | 開発は、意図して進めるものと、意図しないまま育つもの・変わっていくものの両方。なってしまう受け身と、なろうとする能動を分けずに言う |
| L5 | 条 | 経営学の考え方は、何を駆動源と見るかで分けると、どれも「〜を問わない限りでの正解」で、合う場面ではよく効く（群盲象。どれも一面） |
| L6 | 名 | 素朴体験論：論拠は pjdhiro 一人の体験で、統計ではない。研究は証明でなく伝える材料。答えは「〜かもしれない」の仮説 |
| L7 | 帰 | Claude が執筆し、問いを出してしっくり来るかを判定するのは pjdhiro。表の分け方などは Claude の整理 |
| L8 | 芯 | Love駆動開発は手順書ではなく、現象の分析と対処の両方（全てをコントロールできるわけではないところで、何もしないわけでもなく対処する） |

## 2. 心理的安全性とは

URL：https://uminomae.github.io/project-design-theory/reader/psychological-safety.html

| ID | 種類 | 要点 |
|---|---|---|
| P1 | 芯 | 問い：この言葉は恥や不安と関係しているか。答え：関係している |
| P2 | 帰 | 心理的安全性が無い状態を不安の防衛と見て、恥不安をその中の一つに置き、成熟した防衛の状態を「心理的安全性が高い」と呼ぶ、のは pjdhiro の見方（研究の定義ではない） |
| P3 | 帰 | エドモンドソン（1999）の定義：対人関係のリスクを取っても安全だ、という集団で共有された信念。中身に、恥をかかされない・拒まれない・罰されないが入る。身の安全ではない |
| P4 | 二 | 同じ「心理的安全性を高めよう」が、受け取る人の発達段階で違う守りの求めとして届く（段階ごとの主な不安はクック＝グロイター、聞こえ方の列は Claude の整理） |
| P5 | 条 | 効く条件：不確かさがあり、創造や協働が要る仕事で重みが大きくなる（エドモンドソンとレイ 2014）。「高いほど良く、どこでも要る」は誤解の一つ |
| P6 | 二 | 保身のための安心も、同じ名で求められうる（「自分の安心・安全のこと」という受け取り方） |
| P7 | 芯 | よくある誤解：身の安全・罰されない仕組み・仲の良さや厳しさの無さ・宣言すれば作れる |
| P8 | 帰 | 「心理的安全」の語は、療法・集団の訓練・組織の変化・チームの研究と、違う場で違う中身で使われ、一つの定義を受け継がずに広がった（来歴） |

## 4. 起業家の漸化式と、ジュリア集合

URL：https://uminomae.github.io/project-design-theory/reader/julia-potential.html

| ID | 種類 | 要点 |
|---|---|---|
| J1 | 名 | ページの全部が仮説で、論証ではない。こじつけに見えることを否定せず、発散思考の足場として当てはめている |
| J2 | 芯 | 起業家の一歩を `z → z² + c` に当てる：`z` は起業家の脳内の自己、`z²` は自己と自己の掛け算、`c` は Love と呼びたいものの重力（一歩ごとに同じだけ引き寄せる） |
| J3 | 帰 | 出発点は pjdhiro の見立て「漸化式は起業家のよう。Love と呼びたいものは重力のようにドリフトする」。数学の事実（Milnor などで照合）と、式への当てはめ（仮）は別 |
| J4 | 芯 | 問い：ジュリア集合のような何かが、神・愛・美のポテンシャル（場と呼びたいような可能性）ではないか |
| J5 | 二 | 美は、美醜・恐ろしさの入り乱れたところから出る。ジュリア集合の形は美しさと畏怖の両方を感じさせる |
| J6 | 芯 | 第五部：たくさんの点を前へ打つと、円を超えたものは散り、内側は一点へ縮み、縁にあったものだけが残る。いろいろな `c` の縁が重なって半径 2 の線の内に横に長い雲を作り、その円の雲が「私」かもしれない（2026-11-25・#202 の答えに合わせて直した） |
| J7 | 芯 | 起業家の行動は、入れ子の深さ優先探索のよう（見つけたら条件を変えて次の木へ）。ほかの意思決定の論（決定ツリーなど）は同じ木を別の位置から見たもの |
| J8 | 二 | 結び：一定の力 `c`・一点へ寄る渦のような軌跡・届かない一点の三つを星座のように結ぶ。「私」は外へ散るものでも一点へ寄るものでもない点で、ギリギリ保たれる |

## 固定のあとに気づいたこと

（要約を見たあとに書く。採点には使わない）

- L5 は「〜を問わない限りでの正解」の言い方まで要点に入れたが、残った要約はどれも「合う場面では効く」に丸めた。趣旨は残ったと見て「残」にした。言い方まで残すかは、別に問える。
- 「名乗りが落ちる」だけでなく「名乗りが広がりすぎる」（数学の事実まで仮説と読む）向きがあった（J3）。種類の表には無い向きで、採点では「誤」に入れた。
