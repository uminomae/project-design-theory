# 交流回路のフェーザ

<div class="reader-lead glow-card" id="ph-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>家のコンセントの電気は、一秒に 50 回か 60 回、行って戻ります。行って戻る電圧と電流は、どちらも波の形をしています。この波は、円の上を回る点の影として書けます。だから電圧と電流は、同じ速さで回る二本の針で書けます。この針をフェーザと呼びます。</p>
<p>電気が一瞬ごとにする仕事の勢い（電力）は、電圧と電流の掛け算です。二本の針の向きがそろっていれば、電力はいつも 0 以上で、電気は熱や明かりや回転として仕事をします。針が 90 度ずれていると、電力は 0 より上と下を同じだけ行き来し、平均すると 0 になります。この行って戻るだけの電力を、無効電力と呼びます。無効電力は仕事として数えられませんが、モーターの中の磁場を作り、保つのに要ります。</p>
<p>このページで働いているもの：回ること。回る針の影が、波になること。二本の針がずれること。電力が、仕事をする分と、行って戻るだけの分の二つに分かれること。</p>

## コンセントの電気は、一秒に 50 回か 60 回、行って戻る

<!--OPEN-->

<a id="ph-outlet"></a>乾電池の電気は、いつも同じ向きに流れます。家のコンセントの電気は、流れる向きが行ったり来たりします。向きが行ったり来たりする電気を交流と呼び、乾電池のように向きの変わらない電気を直流と呼びます。

日本の家のコンセントでは、電気は一秒に 50 回か 60 回、行って戻ります。東日本ではおよそ 50 回、西日本ではおよそ 60 回です。行って戻る一回の中で、向きは二回入れ替わります。だから向きが入れ替わるのは、一秒に 100 回か 120 回です。

コンセントの二つの穴のあいだの電圧は、0 から一方の向きに大きくなり、0 に戻り、反対の向きに大きくなって、また 0 に戻ります。時間を横にとって電圧を並べると、波の形になります。電気製品を差し込むと流れる電流も、同じ速さで行き来する波になります。

この波は、円の上を同じ速さで回る点の影の長さと、同じ形をしています。回る点の影が波になることは、独立ページ「オイラーの式」の章「[回る点の影は、波になる](euler-formula.html#eu-wave)」で、図で見られます。

<details><summary>詳しく — 100 ボルトと、波の山の高さ</summary>

家のコンセントの電圧は 100 ボルトと言われます。けれども、波の山の高さは、およそ 141 ボルトです。100 ボルトは、同じ電気ストーブにつないだとき、同じだけ熱を出す直流の電圧に直した値で、実効値と呼びます。波の山の高さは、実効値のおよそ 1.41 倍（√2 倍）です。

このページの図では、数を見やすくするために、電圧の山の高さも電流の山の高さも 1 にして描きます。

</details>

## 電圧と電流を、同じ速さで回る二本の針で書く

<!--OPEN-->

<a id="ph-needle"></a>電圧の波を、円の上を回る針の影として書きます。針の長さは波の山の高さで、針が一周すると、波は一回行って戻ります。50 回の地域では、針は一秒に 50 周します。電流の波も、もう一本の針の影として書けます。電圧と電流は同じ速さで行き来するので、二本の針は同じ速さで回ります。

二本の針は同じ速さで回るので、針と針のあいだの角度は、回っても変わりません。このあいだの角度が、二つの波のずれです。たとえば、電流の針が電圧の針より 30 度後ろにあれば、電流の波の山は、電圧の波の山より、針が 30 度回る時間だけ遅れて来ます。

どの針も同じ速さで回るので、回り続けていることは、いったん脇に置けます。ある瞬間で止めて、二本の針の長さと、あいだの角度だけを描きます。この止めて描いた針を、フェーザと呼びます。フェーザを見れば、波を時間に沿って描かなくても、二つの波の大きさとずれが一目で分かります。

ずれの大きさは、何をつなぐかで決まります。電気ストーブやトースターの熱を出す線（電熱線）では、電流の針は電圧の針とそろいます。電線を何回も巻いたもの（コイル）では、電流の針は電圧の針より 90 度遅れます。二枚の金属の板を向かい合わせたもの（コンデンサ）では、電流の針は電圧の針より 90 度進みます。モーターの中にはコイルがあるので、モーターの電流は電圧より遅れます。

<details><summary>詳しく — コイルでは、なぜちょうど 90 度遅れるのか</summary>

コイルには、流れる電流が変わると、その変化をさまたげる向きに電圧が生まれる性質があります。だからコイルの両端の電圧は、電流の大きさではなく、電流が変わる速さに比例します。

回る針の影で、変わる速さを考えます。円の上を回る点は、いつも円の接線の向きに進みます。円の接線は、その点を通る半径に直角です（中学で学ぶ円の性質）。だから点が進む向きは、針を 90 度先へ回した向きです。影の長さが変わる速さは、この進む向きを表す矢印の影で決まります。つまり、回る針の影が変わる速さは、針を 90 度先へ回したもう一本の針の影になります。その針の長さは、回る速さに比例します。

コイルの電圧は電流が変わる速さに比例するので、電圧の針は、電流の針を 90 度先へ回した向きを向きます。言い換えると、電流の針は電圧の針より 90 度遅れます。コンデンサでは逆に、電流が、電圧の変わる速さに比例します。だから電流の針が、電圧の針より 90 度先を向きます。

針を 90 度先へ回すことは、複素数では i を掛けることです（読み物「[回転の掛け算](rotation-multiplication.html)」）。同じ速さで回り続けている波に限れば、変わる速さを考えることを、i を掛けることで書けます。だから交流の回路は、微積分の代わりに、複素数の掛け算で計算できます。

</details>

## 針がそろうと仕事をし、90 度ずれると行って戻るだけ

<!--OPEN-->

<a id="ph-power"></a>電気が一瞬ごとにする仕事の勢いを、電力と呼びます。中学の理科で学ぶとおり、電力は電圧と電流の掛け算です。交流では、電圧も電流も一瞬ごとに変わるので、電力も一瞬ごとに変わります。

二本の針の向きがそろっているときを考えます。電圧が正のときは、電流も正で、掛けると正です。電圧が負のときは、電流も負です。負の数どうしを掛けると正になるので、電力はやはり正です。だから電力は、いつも 0 以上です。平均すると、電圧の山の高さと電流の山の高さを掛けた値の、ちょうど半分になります。電気ストーブは、この平均の電力で熱を出します。

二本の針が 90 度ずれているときは、事情が変わります。電圧の波が山から 0 へ下りるあいだに、電流の波は 0 から山へ上ります。針が四分の一周回るごとに、電圧と電流の符号が同じ所と、違う所が入れ替わります。符号が同じ所では電力は正で、違う所では電力は負です。電力が負のときは、電気製品の側から、コンセントの向こうへ電気が戻っています。正の所と負の所は同じ大きさなので、平均すると、電力は 0 になります。電気は、行って戻るだけです。

ずれが 0 度と 90 度のあいだなら、平均の電力は、0 と半分のあいだのどこかになります。

<details><summary>詳しく — 平均が、ちょうど半分になるわけ</summary>

山の高さが 1 で、向きのそろった二つの波を掛けると、電力は、回る針の縦の影の長さを 2 回掛けたもの（2 乗）になります。針の横の影の長さの 2 乗も、同じ形の波で、90 度ぶんずれているだけです。だから二つの平均は同じです。

一方、独立ページ「オイラーの式」の章「[回る点の影は、波になる](euler-formula.html#eu-wave)」にあるとおり、横の影の 2 乗と縦の影の 2 乗を足すと、いつも 1 です（三平方の定理）。同じ平均を持つ二つを足していつも 1 なので、どちらの平均も 1 の半分です。

90 度ずれているときの電力は、縦の影と横の影を掛けたもの（の符号を変えたもの）です。針が一周するあいだに、二つの影の符号が同じになる四分の一周と、違う四分の一周が、二回ずつ同じ形で来ます。だから平均は 0 です。

</details>

## 電流の針を、そろった分と直角な分に分ける

<!--OPEN-->

<a id="ph-split"></a>ずれが 0 度と 90 度のあいだのとき、平均の電力がどう決まるかは、電流の針を二つに分けると見えます。電流の針の先へ行くには、根元から電圧の針の向きにいくらか進み、そこで直角に曲がって進めばよいはずです。こうして電流の針を、電圧の針にそろった針と、電圧の針に直角な針の、二本に分けます。そろった針の長さは、電流の針の、電圧の向きへの影の長さです。たとえば、電流の針の長さが 1 で、ずれが 60 度なら、そろった針の長さは 0.5、直角な針の長さはおよそ 0.87 です。

一本の針の影の波は、その針を二本に分けたそれぞれの影の波を、足したものです。だから電力も、電圧とそろった分の電力と、電圧と直角な分の電力を足したものになります。そろった分の電力は、前の章の「向きがそろっているとき」と同じで、いつも 0 以上です。直角な分の電力は、前の章の「90 度ずれているとき」と同じで、行って戻るだけで、平均は 0 です。平均の電力を決めるのは、そろった分だけです。

二つの分には名前が付いています。そろった分がする仕事の平均を、有効電力と呼びます。直角な分が行って戻る電力の大きさ（電力の波の山の高さ）を、無効電力と呼びます。有効電力の単位はワット、無効電力の単位はバールです。そろった針の長さが、電流の針の長さの何倍かを、力率と呼びます。電熱線だけなら力率は 1 で、コイルだけなら 0 です。

## 行って戻るだけの電力が、モーターの磁場を保つ

<!--OPEN-->

<a id="ph-motor"></a>無効電力は、平均すると 0 なので、何の役にも立っていないように見えます。けれども、多くのモーターは、無効電力が無いと回りません。

多くのモーターは、コイルに流れる電流で磁場を作り、その磁場の力で回ります。交流では電流が行き来するので、磁場も、強まったり弱まったりをくり返します。磁場が強まる四分の一周のあいだは、コンセントの向こうからコイルへ電気が入り、磁場にたくわえられます。磁場が弱まる四分の一周のあいだは、たくわえた電気がコンセントの向こうへ戻ります。この行って戻る電気が、無効電力です。行き来が無ければ磁場が立たず、モーターは回りません。

おおまかには、モーターの電流は、仕事をする分（電圧にそろった分）と、磁場を作って保つ分（電圧より 90 度遅れた分）を合わせたものです。だからモーターの電流の針は、電圧の針より、0 度と 90 度のあいだのどこかだけ遅れます。

家の電気の料金は、電気がした仕事の量で数えます。行って戻るだけの分は、そこに入りません。それでも、行って戻る電流は電線を流れるので、電線を温め、電線が流せる電流の余裕を使います。だから大きな工場では、モーターの近くにコンデンサを置くことがあります。コンデンサの電流は電圧より 90 度進むので、コイルの 90 度遅れた電流と打ち消し合います。行って戻る電気は、遠くの発電所とのあいだでなく、近くのコイルとコンデンサのあいだを行き来するようになります。

## 電力を、一つの複素数で書く

<!--OPEN-->

<a id="ph-complex"></a>フェーザは平面の上の針なので、複素数で書けます。電圧の針を、数直線の 1 の向きに置きます。電流の針が 30 度遅れていれば、電流の針は、角度が −30 度の数です。i を掛けると 90 度回るので、コイルで電流が 90 度遅れることは、電流の針に i を掛けると電圧の針の向きになる、と書けます。

有効電力と無効電力も、一つの掛け算で一度に出せます。まず、電流の針を、数直線（横の軸）で折り返します。折り返すと角度の符号が逆になり、−30 度の針は 30 度の針になります。次に、電圧の針に、折り返した電流の針を掛けて、半分にします。複素数の掛け算では角度が足されるので、できた数の角度は、二本の針のずれと同じです。できた数の横の成分が有効電力で、縦の成分が無効電力です。この数を、複素電力と呼びます。たとえば、二本の針の長さが 1 で、ずれが 60 度なら、複素電力はおよそ 0.25 + 0.43i です。

折り返すわけは、回っている二本の針で考えると分かります。電圧の針も電流の針も、同じ速さで回っています。電流の針を折り返すと、折り返した針は、逆向きに同じ速さで回ります。掛け算では角度が足されるので、電圧の針が回る分と、折り返した針が逆に回る分が打ち消し合います。だから、できた数は回らずに止まっています。止まっている数なので、平均の電力のような、時間に沿って変わらない量を書けます。

電圧と電流の、その瞬間の値（数直線の上の数）を掛けて平均すると、出てくるのは有効電力だけです。無効電力は、平均すると 0 なので、平均の中には現れません。平面の上で掛けると、縦の成分として、行って戻る電力の大きさが残ります。

## このあとに読むもの

<!--OPEN-->

<a id="ph-more"></a>交流の電圧と電流のずれと、無効電力を、人の意識に照らして推論した探索は、記録「[複素平面の数式ごとに、人の意識との構造の類似を推論する](https://github.com/uminomae/project-design-theory/blob/main/pd/knowledge/research/julia-potential/EXPLORE-formulas-consciousness-20261125.md)」の節「交流のフェーザ（電圧と電流のずれ・無効電力）」にあります。

フェーザという書き方が何をたたんでいるか（波を作る逆回りのもう一本の針・回り続けること・始まりの揺れ・二倍の速さで揺れる電力・√2）を、時間に沿った書き方と並べて開くページは、「[交流回路のフェーザが、たたんだもの](ac-phasor-unfolded.html)」（工事中）にあります。

いろいろな速さで回る針を重ねて、どんな波も書くこと（フーリエ変換）と、回りながら伸び縮みする針で、揺れが消えるか膨らむかを読むこと（ラプラス変換と z 変換）は、この針の見方の続きにあたります。どちらも、目次「[複素平面で考える](complex-plane.html)」に並べています。
