# 交流回路のフェーザが、たたんだもの

<div class="reader-lead glow-card" id="pu-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>フェーザは、行って戻る電圧や電流の波を、止めた一本の針で書く書き方です。止めて書くあいだに、いくつかのものが見えない所へたたまれます。波を作るもう一本の、逆に回る針。回り続けていること。スイッチを入れた直後の揺れ。二倍の速さで揺れる電力。そして、山の高さを 100 ボルトに直す √ です。</p>
<p>開いてみると、行って戻るだけに見える交流の電気は、発電所で回るものの影として生まれ、モーターの中でもう一度本物の回転に戻っています。このページは、そこから、√ と 0 と ∞ がたたむ記号に見えること、平均すると 0 だが無いと回らない量、回ることが先にあるかもしれないこと、までをざっと見渡します。</p>
</div>

## 一本の波は、逆に回る二本の針を足したもの

<!--OPEN-->

<a id="pu-pair"></a>フェーザは、電圧の波を一本の針で書きます。けれども、一本の針の横の影を取ることは、もう一本の針を足すことと同じです。

針を、横の軸（実の軸）で折り返した針を考えます。折り返した針は、もとの針と同じ長さで、逆の向きに同じ速さで回ります。二本を足すと、縦の成分は打ち消し合い、横の成分は 2 倍になります。だから、二本を足して半分にしたものは、もとの針の横の影と、いつも同じです。

式で書くと、針を V e<sup>iωt</sup>、折り返した針を V̄ e<sup>−iωt</sup> として、次のようになります（V̄ は V を横の軸で折り返した数で、共役と呼びます）。

<p>v(t) = ½ (V e<sup>iωt</sup> + V̄ e<sup>−iωt</sup>)</p>

行って戻るだけの一本の波は、逆向きに回る二本の針の和です。フェーザの書き方は、そのうちの一本だけを書き、もう一本は「実の部分を取る」という約束の中にたたんでいます。このページでは、長さ 1.3・角度 0.4 の針で、二つの書き方が同じ波になることを計算で確かめました。

## 回り続けることと、始まりの揺れを外して止める

<!--OPEN-->

<a id="pu-stop"></a>残った一本の針も、まだ回っています。フェーザは、その回る部分 e<sup>iωt</sup> を外して、ある瞬間で止めた針 V だけを書きます。外せるのは、一つの回路の中の電圧と電流が、どれも同じ速さ ω で回るからです。回り続けていることと時間は、全部の針に共通なので、書かずに済みます。

止めると、針の角度の起点も決めなければなりません。ふつうは、電圧の針を 0 度に置きます。意味を持つのは、針と針のあいだの角度だけです。

時間に沿って変わる速さを追う計算は、止めた針では、iω を掛けることになります。そのわけは、「交流回路のフェーザ」の畳み「[コイルでは、なぜちょうど 90 度遅れるのか](ac-phasor.html#ph-needle)」にあります。

止めた針がたたむものが、もう一つあります。スイッチを入れた直後の揺れです。たとえば、コイルと抵抗をつないだ回路（50 回の地域で、コイルの電流の遅れが 45 度になるもの）に、電圧が山の所でスイッチを入れます。電流は 0 から始まりますが、止めた針が示す波は、その瞬間に 0.5 の所にいます（電圧の山の高さと抵抗を 1 とした値）。その差は、時間とともに一定の割合で小さくなる揺れとして足され、およそ 3 ミリ秒ごとに 0.37 倍ずつ消えていきます。16 ミリ秒ほどたつと、差は 0.0034 で、1% より小さくなります。フェーザが書くのは、この揺れが消えたあとの、そろった波だけです。

<details><summary>詳しく — 始まりの揺れの計算</summary>

抵抗 R とコイル L をつないだ回路で、ωL = R にすると、電流の針は、電圧の針より 45 度遅れ、長さは電圧の針の 1/√2（およそ 0.71）倍になります（電圧の山の高さを 1、R = 1 とした場合）。時刻 0 の電流の針の横の影は、0.71 × cos 45° = 0.5 です。

実際の電流は 0 から始まるので、そろった波との差は −0.5 です。この差は、e<sup>−t/τ</sup> の形で小さくなります。τ = L/R で、50 回の地域では τ はおよそ 3.18 ミリ秒です。5τ（およそ 16 ミリ秒）のときの差は 0.5 × e<sup>−5</sup> ≈ 0.0034 です。このページでは、回路の式を細かい時間の刻みで追って、この値になることを確かめました。

</details>

## 電力を出すとき、逆に回る針が戻ってくる

<!--OPEN-->

<a id="pu-power"></a>電力は、電圧と電流の掛け算です。電圧も電流も、逆に回る二本の針の和なので、掛けると四つの組ができます。

二本の針を掛けると、回る角度は足し算になります。同じ向きに回る針どうしを掛けた二つの組は、二倍の速さ 2ω で回ります。逆に回る針どうしを掛けた二つの組は、回る分が打ち消し合い、止まります。だから、電力は、止まった部分と、二倍の速さで回る部分の和になります。

<p>p(t) = ½ Re[V Ī] ＋ ½ Re[V I e<sup>2iωt</sup>]</p>

前の半分が止まった部分で、その値が平均の電力（有効電力）です。複素電力 S = ½ V Ī は、この止まった部分を一つの複素数で書いたものです。「交流回路のフェーザ」の章「[電力を、一つの複素数で書く](ac-phasor.html#ph-complex)」で、電流の針を横の軸で折り返して掛けたのは、ここで逆に回る針を選ぶためです。実の部分を取る約束の中にたたまれていた相棒が、電力を出すときに戻ってきます。

後ろの半分の、二倍の速さで回る部分は、複素電力には書かれません。けれども、一瞬ごとの電力は、そこで揺れています。電圧と電流の山の高さを 1 にして、ずれを 0 度・30 度・60 度・90 度と変えて計算すると、一瞬ごとの電力は、どれも有効電力を中心に、上下に 0.5 ずつ揺れました。0.5 は、複素電力の長さ |S| と同じです。複素電力の横の成分が揺れの中心で、長さが揺れの幅です。ずれが 90 度のときは、中心が 0 で、幅だけが 0.5 残ります。

<details><summary>詳しく — 二倍の速さの部分を、有効電力と無効電力で書く</summary>

電圧の針を 1、電流の針を長さ 1・ずれ φ（遅れ）とすると、S = ½ × 1 × e<sup>iφ</sup> なので、P = ½ cos φ、Q = ½ sin φ です。一瞬ごとの電力は、次のように書けます。

<p>p(t) = P ＋ P cos 2ωt ＋ Q sin 2ωt</p>

P ＋ P cos 2ωt は、電圧にそろった分の電力で、0 と 2P のあいだを行き来します。Q sin 2ωt は、電圧に直角な分の電力が、平均 0 で行って戻る部分で、Q はその山の高さです。「交流回路のフェーザ」の章「[電流の針を、そろった分と直角な分に分ける](ac-phasor.html#ph-split)」の無効電力が、ここに出てきます。このページでは、四つのずれのどれでも、この式が一瞬ごとの電圧と電流の掛け算と一致することを確かめました。

</details>

掛け算で回る速さが二倍になるのは、2 乗が角度を 2 倍にするのと同じ働きです（「[オイラーの等式が、たたんだもの](euler-unfolded.html#eo-fold)」）。電力は、電圧と電流という二つの波の積で、波の 2 乗に近い量です。

## 時間に沿った書き方と、フェーザを並べる

<!--OPEN-->

<a id="pu-table"></a>ここまでを、同じ項目で両側に並べます。左は、時間に沿って、たたまずに書いた形です。右は、フェーザで書いた形です。

<div class="tablefit">

| 項目 | 時間に沿って書く | フェーザで書く |
|---|---|---|
| 電圧 | v(t) = V<sub>m</sub> cos(ωt + α) | V = V<sub>m</sub> e<sup>iα</sup>（止めた針一本） |
| 波と針 | ½ (V e<sup>iωt</sup> + V̄ e<sup>−iωt</sup>)：逆に回る二本の針の和 | 「実の部分を取る」と約束し、逆に回る針は書かない |
| 回ること | e<sup>iωt</sup> が、毎瞬、角度 ωt だけ進む | 外す。どの針も同じ速さなので、角度の差だけを残す |
| 角度の起点 | 時刻 0 をどこに置くかで決まる | 電圧の針を 0 度に置くことが多い |
| 変わる速さ | 波の傾きを、時間に沿って追う | iω を掛ける |
| スイッチを入れた直後 | 消えていく揺れ（e<sup>−t/τ</sup>）を含む | 書かない。揺れが消えたあとの波だけ |
| 電力 | P を中心に、二倍の速さで幅 \|S\| だけ揺れる | S = ½ V Ī = P + iQ（止まった部分だけ） |
| 大きさ | 山の高さ V<sub>m</sub> | 実効値 V<sub>m</sub>/√2 で書くことが多い。そのときは S = V Ī |

</div>

このページで並べてみると、フェーザの書き方がたたんでいるものは、少なくとも次の五つに見えます。

1. **逆に回る相棒**：一本の波を作る二本の針のうち、一本は「実の部分を取る」約束の中にいます。
2. **回り続けることと時間**：共通の e<sup>iωt</sup> を外し、角度の差だけを残します。
3. **始まりの揺れ**：スイッチを入れた直後の、消えていく揺れを書きません。
4. **二倍の速さの電力**：一瞬ごとの電力の揺れを、止まった部分 S だけで書きます。
5. **√2**：山の高さを、実効値に直して書きます。そのわけは、あとの章「[100 ボルトは、√ でたたんだ数](#pu-root)」で見ます。

## 開くと、回る針がモーターの中で本物の回転になる

<!--OPEN-->

<a id="pu-motor"></a>フェーザの針は、計算のために描いた絵のように見えます。けれども、たたんだものを開くと、回る針は、モーターの中で本物の回転として出てきます。

工場の大きなモーターの多くは、三相の交流で回ります。三相は、山の来る時刻が一周の 3 分の 1（120 度）ずつずれた、三本の波を使う送り方です。長さのそろった三本のフェーザを足すと 0 になります。三本の針が円を 3 等分しているからです（独立ページ「[代数学の基本定理](fundamental-theorem-of-algebra.html#ft-circle)」の章「zⁿ = 1 の答えは、円を n 等分する」）。

三相のモーターでは、三つのコイルを、円のまわりに 120 度ずつ向きを変えて置きます。一つ一つのコイルの磁場は、行って戻るだけです。ところが、三つの磁場を足すと、大きさの変わらない磁場が、ちょうど ω の速さで回ります。このページでは、三つの行って戻る磁場の和が、どの瞬間も、長さ 1.5 の針が回る形と一致することを計算で確かめました。フェーザの針が回る角度 ωt は、ここでは磁場が本当に回る角度です。

三相では、もう一つのことが起きます。三本の電力を足すと、二倍の速さの揺れが打ち消し合い、一瞬ごとの電力の合計が一定になります。ずれ 30 度で計算すると、合計はいつも、有効電力の 3 倍の 1.30 でした。それでも、それぞれの線には、行って戻るだけの電流が流れていて、モーターの磁場を保っています。

家庭のコンセントのような一本の波（単相）の交流で、一つのコイルに流すと、磁場は行って戻るだけです。その磁場は、最初の章で見たとおり、逆向きに回る半分の強さの二つの磁場の和として書けます。このため、単相の交流で回る誘導モーターは、そのままでは自分で回り始めません。止まっているとき、二つの回る磁場に引かれる力がつり合うからです。そのため、回り始めるための仕組み（向きをずらした二つ目のコイルなど）を持ちます。一度回り始めると、その向きに回る磁場に引かれて回り続けます。たたまれていた逆回りの相棒は、ここでは本物の磁場として、モーターの回り始めを止めています。

## 100 ボルトは、√ でたたんだ数

<!--OPEN-->

<a id="pu-root"></a>家のコンセントの電圧は 100 ボルトと言われますが、波の山の高さはおよそ 141 ボルトです（「交流回路のフェーザ」の畳み「[100 ボルトと、波の山の高さ](ac-phasor.html#ph-outlet)」）。この 100 ボルトは、次の三つの手順でできています。

1. 波を 2 乗します。電熱線が出す熱の勢いは、電圧の 2 乗に比例するからです。
2. 2 乗した波を、一周のあいだで平均します。山の高さが 1 の波なら、平均は 1/2 です。
3. 平均の √ を取ります。√(1/2) ≈ 0.707 なので、山の高さ 141 ボルトは、およそ 100 ボルトになります。

この数を実効値と呼びます。2 乗で波を一つの向きにそろえ、平均で時間に沿った変化を一つの数にし、√ で 2 乗を元の大きさに戻します。実効値でフェーザを書くと、複素電力の ½ も消えて、S = V Ī になります。電気の本の多くは、こちらで書きます。

オイラーの等式の登場人物を眺めていたとき、pjdhiro は、√・π・e を、次のような道具と見ていました。

<strong>pjdhiro の見方：</strong>2 乗されてるのが普通の世界で、それを数学にする際に、√ するように π や e を使ってるような道具のイメージです。二次元を一次元にするものとする、という宣言のようなものとしてます。

交流の電気には、この見方とよく似た手順があります。電力は、電圧と電流の積で、2 乗に近い量です。実効値は、その 2 乗を平均して √ を取り、100 ボルトという数直線の上の一つの数にしたものです。

このページは、ここから一つの仮説を置きます。フェーザの書き方に出てくる「実の部分を取る」「e<sup>iωt</sup> を外す」「√2 で割る」は、どれも、平面の上で回っているものを、数直線の上の数で扱えるようにたたむ記号ではないか、という仮説です。オイラーの等式で e・π・√ が、そう見えてきたのと同じ向きです。

## コイルとコンデンサは、0 と ∞ を入れ替える鏡の両側にいる

<!--OPEN-->

<a id="pu-zero"></a>コイルとコンデンサの、電流の流れにくさ（インピーダンス）は、止めた針では、次のように書けます。コイルは iωL、コンデンサは 1/(iωC) です。コイルは速さ ω に比例し、コンデンサは ω に反比例します。

速さ ω を 0 に近づけると（向きの変わらない直流に近づけると）、コイルは 0、つまりただの電線になり、コンデンサは ∞、つまり切れた線になります。ω を大きくしていくと、逆に、コイルが ∞、コンデンサが 0 に近づきます。

二つが同じ大きさになる速さを ω<sub>0</sub> とすると、ω<sub>0</sub> = 1/√(LC) です。ω を ω<sub>0</sub> の何倍かで測り、その倍率を x と置くと、コイルの大きさは x に、コンデンサの大きさは 1/x に比例します。このページでは、x を 0.01・0.5・1・2・100 と変えて、コイルとコンデンサの大きさがちょうど逆数どうしになることを確かめました。

x を 1/x に送る写し方は、0 と ∞ を入れ替え、1 だけを動かしません。「オイラーの等式が、たたんだもの」の章「[0 の反対は、∞ かもしれない](euler-unfolded.html#eo-zero)」で見た、0 と ∞ を入れ替えて半径 1 の円を動かさない鏡と、同じ形です。コイルとコンデンサは、その鏡の両側にいて、x = 1 の所で出会います。

x = 1 のとき、コイルは +i の向き、コンデンサは −i の向きに同じ大きさを持ち、足すと 0 になります。この状態を共振と呼びます。共振のとき、コイルの磁場とコンデンサの電場のあいだで、電気が行って戻ります。外から見ると、行って戻るだけの電力は 0 に見えますが、中では行き来が続いています。抵抗の無い回路なら、行き来は止まりません。「交流回路のフェーザ」の章「[行って戻るだけの電力が、モーターの磁場を保つ](ac-phasor.html#ph-motor)」で、工場のコンデンサが、コイルの遅れた電流を近くで打ち消していたのも、この行き来です。

オイラーの等式の球の上で、0 と ∞ のあいだに 1 の輪があることを見ていたとき、pjdhiro はこう言っています。

<strong>pjdhiro の見方：</strong>ゼロと無限大の波間に、渦としての 1 が立つのかもしれませんね。これも創造の構造に見える。

ここでの渦は、創造の五段階の渦（波間に立つ渦）のたとえです。交流の回路でも、0 と ∞ の両側に分かれたコイルとコンデンサが、x = 1 の所で出会い、外からは 0 に見える行き来を続けます。共振を、0 と ∞ の波間に立つ 1 の一つの例として見ることもできそうです。これは、このページの仮説です。1 を決める ω<sub>0</sub> に √ が入っていることも、前の章の √ と同じ向きに読めるかもしれません。

## 回ることが先にあるのかもしれない

<!--OPEN-->

<a id="pu-turn"></a>目次「[複素平面で考える](complex-plane.html)」は、交流回路のフェーザの欄に、「平均すると 0 だが、無いと回らない量」という見方を置いています。無効電力のことです。開いてみると、この量の見え方は、どこで見るかで変わります。

一本の線の上で、一瞬ごとの電圧と電流を掛けて平均すると、無効電力は 0 として消えます。三相の三本を足すと、一瞬ごとの揺れまで消えます。それでも、線には行って戻る電流が流れ、モーターの磁場は保たれ、モーターは回ります。平面の上で掛けると、無効電力は、複素電力の縦の成分として残ります。

もう一つ、開いて見えたことがあります。交流の電気は、発電所の発電機が回ることで生まれます。磁石とコイルの一方が回り、その回る角度が、電圧の波の角度 ωt になります。たとえば、磁石の N と S を一組だけ持つ発電機は、50 回の地域では、一分間に 3000 回転します。電線の中を送られるのは、行って戻るだけの波です。それが三相のモーターの中で、もう一度、回る磁場に戻ります。回る、影になって行き来する、また回る、という順です。フェーザの止めた針は、そのあいだの、影しか見えない所に置かれた書き方だと言えそうです。

回転が多いことについて、pjdhiro はオイラーの等式の対話で、こう話しています。

<strong>pjdhiro の見方：</strong>世界には回転の性質を持つものが多いのか、世界を回転という性質で認知するからなのか、道具が回転を扱うからなのか、どれなんでしょうね。いずれにせよ、回転は溢れてそうですね。

交流の電気は、三つのどれとも読めそうです。発電機とモーターは、本当に回っています。行って戻る波を回る針の影と見るのは、人の見方です。フェーザは、回転を扱う道具です。

このページが置く仮説は、次のとおりです。行って戻るだけに見えるもの、平均すると 0 に見えるものの陰で、回ることが先に起きているのかもしれない。数直線の上で見ると 0 になる量が、平面の上では縦の成分として残るのは、その回転の、たたまれた側を見ているからかもしれない。「オイラーの等式が、たたんだもの」の補足「[回ることが先にあるのかもしれない](euler-unfolded.html#eo-turn)」と同じ向きの問いを、毎日使う電気の中で置いておきます。
