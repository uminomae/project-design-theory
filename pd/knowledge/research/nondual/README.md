## 追記の決まり

1. **どこに足すか。** 今の分野の章に当たれば、その章に `###` の例を足す。どの章にも当たらない材料が三つ以上たまったら、新しい分野の章を立てる。分野ごとの並びがなじまないと分かったら、並べ方そのものを変える（pjdhiro 2026-11-18「その都度変える試行錯誤で良い」）。変えたら、冒頭の構成と今の答えを同じ作業で直す。
2. **例の形。** 誰でも知っている場面で、二つが見分けられることを先に言う。次に原典が何と書いたかを、帰属を付けて書く。そのあと、どう切り離せないかを一、二文。例ごとに「出典」の畳み（原文の鍵の文・頁・写しへのリンク）。物理は、教科書の事実・研究の主張・たとえを分けて書く。
3. **表。** 例を足したら、巻末の縁と渦の表に一行足し、冒頭の例の数をそろえる。表は Claude の整理と書いたまま保つ。
4. **なじまない例。** 照らしてみて形と食い違った例は、捨てずに畳みに置き、pjdhiro に見せる。ルビンの盃とクザーヌスは、はじめなじまない例と置いたが、pjdhiro の見方で、非二元を認識する難しさの例と、非二元そのものを言う例に置き直した（Claude の「食い違う」の読みが狭かった）。
5. **照合の状態。** 載せるのは本文照合済だけ（`docs/rules/sources.md` §3-3）。上の表に一行足す。読めなかったものは「載せなかった候補」に置く。
6. **pjdhiro の言葉。** 新しい発言は、上の「pjdhiro の発言」に原文で足し、何への答えかを添える。本文では、カードの前に、何を読んでの言葉かを書き、カードのあとに答えの段を置く。
7. 足した日と例を、下の「更新の記録」に一行足す。
