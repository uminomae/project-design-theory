## 禅の句は、円をどう語っているか

<!--OPEN-->

<a id="zh-zen"></a>禅の書物には、円の言葉が出てきます。たとえば『信心銘』（伝・僧璨）には、「圓同太虛　無欠無餘」という句があります。円か（まどか）なることは大きな空と同じで、欠けも余りも無い、という意味です。ここの「円」は描いた図形ではなく、道（いちばん大切なもの）が欠けなく満ちている様子を言う言葉です。

同じ『信心銘』は、続けて「極小同大」「極大同小」とも言います。いちばん小さいものは大きいものと同じ、いちばん大きいものは小さいものと同じ、という意味です。その句は「不見邊表」（果てが見えない）と続きます。すぐ前の句は、ひとときと万年、ここと四方の果てを分けずに語っていて、この句も、広がりの大小と果てについて言っています。

『碧巌録』第 33 則には、資福という僧が、訪ねてきた陳操を見るなり一つの円を描く話があります。陳操は、来ただけでもう外れているのに、そのうえ円まで描くとは、と退けます。円は、言葉の代わりに何かを示すしぐさとして描かれますが、それで伝わるとは限らない、という話です。

## 円の上を歩くと、一周で始めに戻る

<!--OPEN-->

<a id="zh-walk"></a>半径 1 の円（単位円）の上を、点 (1, 0) から左回りに歩くことにします。歩いた道のりを θ と書くと、着く点は (cos θ, sin θ) です。これは数学 II で習う一般角と弧度法の言い方そのものです。弧度法では、角度を、半径 1 の円の上を歩いた道のりで測ります。一周は 2π で、360 度にあたります。

一周歩くと、始めの点 (1, 0) に戻ります。θ = 0 と θ = 2π は同じ点で、二周（4π）でも三周でも同じです。円には、はしがありません。歩いた道のりはいくらでも大きくできるのに、着く点は円から出ません。

ここで、角度を「何周回ったか」で数えてみます。一周を 1 と数えると、0 周・1 周・2 周……は、どれも同じ点 (1, 0) に来ます。一周は、回った量としての 1（100%）です。この見方は、あとの章で使います。

## e<sup>iθ</sup> は、単位円の上をちょうど速さ 1 で進む

<!--OPEN-->

<a id="zh-e"></a>複素数で書くと、点 (cos θ, sin θ) は cos θ + i sin θ です。数学 III で習う数 e（約 2.718）を使うと、これを e<sup>iθ</sup> と書けます（オイラーの式）。θ = π を入れると e<sup>iπ</sup> = −1 で、半周した点です。θ = 2π を入れると e<sup>2πi</sup> = 1 で、一周して戻った点です。

e は、(1 + 1/n)<sup>n</sup> の n をどこまでも大きくした先の数です。100% の伸びを限りなく細かく刻んで、限りなく何度も掛け合わせたもの、と言えます。同じ作り方で、1/n の代わりに iθ/n を使うと、(1 + iθ/n)<sup>n</sup> は e<sup>iθ</sup> に近づきます。伸びる向きを直角に替えると、大きさは増えずに、回るようになります。

<details><summary>詳しく — (1 + iθ/n)<sup>n</sup> を計算してみる</summary>

θ = 2π として、n を大きくしていくと、次のようになります（電卓やプログラムで確かめられます）。

- n = 10：およそ 4.13 − 3.29i（まだ円から外れている）
- n = 1000：およそ 1.020 − 0.0001i
- n = 1000000：およそ 1.00002

n を大きくするほど 1 に近づき、近づいた先の e<sup>2πi</sup> がちょうど 1 です。

</details>

e<sup>iθ</sup> は、単位円の上を左回りに、ちょうど速さ 1 で進みます。だから θ が、そのまま歩いた道のりになります。底を e でなく別の正の数 c にすると、c<sup>iθ</sup> も単位円の上を回りますが、速さは |log<sub>e</sub> c| になります。たとえば c = 2 なら、速さはおよそ 0.69 です。左回りに速さがちょうど 1 になるのは、底が e のときだけです（1/e なら、速さは 1 でも逆回りになります）。単位円の上で道のりと角度がぴったり重なるところに、e が選ばれている理由の一つがあります。

写してみると、次のことが分かります。

- 平面の 0 は、南極に来ます。
- 単位円は、赤道に来ます。1 と −1 も赤道の上です。
- 単位円の内側の点は南の半球へ、外側の点は北の半球へ行きます。
- 平面のどこまでも遠い所は、北極の一点に集まります。この点を ∞（無限大）と呼びます。

数直線も、球に写すと一つの円になります。数直線の上では、右へどこまで進んでも ∞ には着きません。球の上では、0 から右へ進むと、半周で北極の ∞ に着きます。そこを越えると、左の果てから戻ってきて、また 0 に着きます。右の果てと左の果ては、北極の一点で重なっています。この円の上で、0 と ∞ は向かい合う二点です。

単位円は、0 と ∞ のちょうど真ん中の赤道です。e<sup>a + iθ</sup> の大きさは e<sup>a</sup> なので、a = 0 のとき、ちょうど単位円の上にいます。a を限りなく小さくすると e<sup>a + iθ</sup> は 0（南極）へ、限りなく大きくすると ∞（北極）へ近づきます。

## 「極小同大」を、二つの読み方で読む

<!--OPEN-->

<a id="zh-read"></a>ここまでの二つの形（一周で始めに戻る円・0 と ∞ が両極に来る球）を、禅の句「極小同大」「極大同小」に重ねてみます。重ね方は一つではありません。どれも、このページの仮説です。

一つ目の読み方は、点として読むものです。球の上では、0 と ∞ は南極と北極で、点 z を 1/z に写すと、二つがちょうど入れ替わります。入れ替えても形が変わらない、対等な二つの極です。たとえば、平面の半径 100 の円の外側（とても大きい所）は、球の上では北極のまわりの小さな帽子になり、半径 1/100 の円の内側（とても小さい所）が南極のまわりに作る帽子と、同じ大きさです。いちばん小さい所といちばん大きい所が対等に並ぶ形が、句と似ています。ただし、この読み方では、0 と ∞ は向かい合う二点で、同じ点ではありません。

二つ目の読み方は、回った量として読むものです。pjdhiro は、この句について、こう読んでいます。

<strong>pjdhiro の見方：</strong>もう一つの解釈は、2πr の開始点と終着点が同じで、0 と無限大ってことじゃないのかな？

<strong>pjdhiro の見方：</strong>出発点から進むと、0 度と 360 度で同じ位置。それが 0 と無限大のようなものが同じ、という感性は、0 とネイピア数が指し示す何かが同じ位置ではないか、という直観です。無限大のような極大さを感じる概念を、ネイピア数が指しているはずです。

ここでの 0 と無限大は、着く点ではなく、回った量として読めます。0 周、1 周、2 周……は、どれも同じ点に来ます。回った量はいくらでも大きくできるのに、位置は円から出ません。数学で言えるのは、ちょうど何周かで止まるたびに出発点に戻る、までです。止まらずに回り続けた先は、一つの点には決まりません。e<sup>0</sup> と e<sup>2πi</sup> が同じ点 1 になるのも、肩が 0 の所と 2πi の所が同じ点に来る、という意味で、e そのものや ∞ が 1 の位置に来るわけではありません。

二つの読み方は、球の上でつながっています。球の経線（北極と南極を通る大きな円）を一周すると、数直線を、0 から ∞ を越えて 0 まで通り抜けることになります。一周すると始めの点に戻ること、いくら回っても終わりが来ないこと、どこまでも遠い所が北極の一点に閉じて果てが無くなること、の三つは、同じ一周の別の面です。句そのものは、広がりの果てについて言っています。どれに重ねるかは、読む人の読みです。
