## 立体の回転は、数で挟んで書く

<!--OPEN-->

<a id="eo-quat"></a>平面の回転は、複素数を一回掛ければ書けます。i を掛けると 90 度、e<sup>iθ</sup> を掛けると角度 θ だけ回ります（独立ページ「[オイラーの式](euler-formula.html)」）。立体の回転を書くには、四元数という数を使います。

四元数は、w + xi + yj + zk の形の数です。w が実の部分で、i・j・k は三つの虚の向きです。三つとも、2 回掛けると −1 になります。i と j を掛けると k になりますが、順番を入れ替えて j と i を掛けると −k になります。掛ける順番で答えが変わることを、非可換と言います。

四元数が四つ目の向きを持つ数としてどう見えるかは、動画で見ると掴みやすいかもしれません。

ただし、実の部分の数（ふつうの実数）は、どの四元数と掛けても、順番で答えが変わりません。順番で答えが変わるのは、向きの違う虚の向きどうしを掛けたときだけです。

立体の中の点 v を、軸 u のまわりに角度 θ だけ回すには、点を xi + yj + zk の形に置き、q = e<sup>uθ/2</sup> という数で前と後ろから挟みます。

<p>v' = q v q<sup>−1</sup></p>

q<sup>−1</sup> は q の逆数です。挟むと、軸の向きの成分はそのまま残り、軸と直角な成分だけが角度 θ だけ回ります。q は、e の肩（指数）に、軸 u と、回したい角度の半分 θ/2 を乗せた数です。前から q を掛けて半分、後ろから q<sup>−1</sup> を掛けてもう半分回り、合わせて θ になります。

物理では、同じ回転を、パウリ行列という三つの 2 行 2 列の行列で書きます。電子の向き（スピン）を回すときの書き方です。四元数の i・j・k を、パウリ行列 σ<sub>x</sub>・σ<sub>y</sub>・σ<sub>z</sub> にそれぞれ −i を掛けたものに置き換えると、掛け算の決まりがそっくり同じになります。だから、物理の U v U<sup>†</sup>（U<sup>†</sup> は U の逆にあたる行列）は、四元数の q v q<sup>−1</sup> と同じ形をしています。

<details><summary>詳しく — 四元数の掛け算の決まりと、パウリ行列との対応</summary>

四元数の掛け算の決まりは、次のとおりです。i² = j² = k² = −1、ij = k、jk = i、ki = j、ji = −k、kj = −i、ik = −j。

パウリ行列は、σ<sub>x</sub> = [[0, 1], [1, 0]]、σ<sub>y</sub> = [[0, −i], [i, 0]]、σ<sub>z</sub> = [[1, 0], [0, −1]] です（[a, b] は行列の一つの行）。四元数の 1 を 2 行 2 列の単位行列 I に、i・j・k を −iσ<sub>x</sub>・−iσ<sub>y</sub>・−iσ<sub>z</sub> に置き換えて計算すると、上の決まりがすべて成り立ちます。このページでは、置き換えたものどうしを掛けて、全部の組で確かめました。

軸 k のまわりを角度 θ 回す q = e<sup>kθ/2</sup> は、行列では U = [[e<sup>−iθ/2</sup>, 0], [0, e<sup>iθ/2</sup>]] になります。点 σ<sub>x</sub>（四元数の i にあたる）を U σ<sub>x</sub> U<sup>†</sup> と挟むと、cos θ σ<sub>x</sub> + sin θ σ<sub>y</sub> になり、i が j の向きへ角度 θ だけ回ったことになります。

</details>

<details><summary>詳しく — 回す式が、そもそも省いているもの</summary>

v' = q v q<sup>−1</sup> は、点 v の実の部分を 0 と置いて使う式です。実の部分は、q と順番を入れ替えても同じなので、挟むと q と q<sup>−1</sup> が打ち消し合い、動きません。軸の向きの成分も、同じ理由で動きません。

q と −q は、同じ回転を表します。挟むと符号が二回出て、打ち消し合うからです。だから、回す数 q の側は、立体が一周（θ = 2π）しても −1 になるだけで、もとの 1 に戻るのは二周（θ = 4π）したときです。電子の向きが二回転で元に戻ると言われるのは、この性質のことです。

</details>

この書き方には、平面の回転を e<sup>iθ</sup> で書いたときには見えなかった部品が出てきます。回す軸 u、角度を半分ずつ前と後ろに分けること、掛ける順番、それに、二周してやっと元に戻る回す数 q（上の畳み）です。次の章で、四元数の二つの軸をゼロにしてオイラーの等式と並べ、この四つが等式の中ではどこへ行ったのかを見ます。

どの二つをゼロにするかで、残る平面が変わります。挟む式 q v q<sup>−1</sup> は、実の部分を 0 と置いて使う式です。だから、この式でオイラーの等式と並べるには、実の向きを含まない平面を残します。ここでは、実の部分 w と k をゼロにして、i と j の平面を残し、軸を k にします。

両側に同じ項目を並べると、次のようになります。

<div class="tablefit">

| 項目 | オイラーの等式の側（複素平面） | 四元数の側（i と j の平面） |
|---|---|---|
| 平面の点 | x + iy | xi + yj |
| 横の向き | 1 | i |
| 縦の向き | i | j |
| 回す軸 | 式には出てこない（※） | k |
| 回す式 | e<sup>iθ</sup> を片側から掛ける | e<sup>kθ/2</sup> と e<sup>−kθ/2</sup> で前と後ろから挟む |
| 回したあとの点 | (x cos θ − y sin θ) + i (x sin θ + y cos θ) | (x cos θ − y sin θ) i + (x sin θ + y cos θ) j |
| 半周（θ = π） | e<sup>iπ</sup> = −1 を掛ける。1 は −1 に着く | e<sup>kπ/2</sup> = k で挟む。i は −i に着く |

</div>

※ オイラーの側の回す軸は、平面に直交する奥行きの向き（z の向き）です。複素数には、その向きを書く場所がありません。

回したあとの点は、横の向きの名前と縦の向きの名前が違うだけで、同じ数が並びます。たとえば x = 0.3、y = 0.9、θ = 0.7 では、どちらも横が −0.3503、縦が 0.8816 になります。

```
// 四元数 w + xi + yj + zk を [w, x, y, z] の並びで書く
function mul(a, b) {
  const [a0, a1, a2, a3] = a, [b0, b1, b2, b3] = b;
  return [
    a0 * b0 - a1 * b1 - a2 * b2 - a3 * b3,
    a0 * b1 + a1 * b0 + a2 * b3 - a3 * b2,
    a0 * b2 - a1 * b3 + a2 * b0 + a3 * b1,
    a0 * b3 + a1 * b2 - a2 * b1 + a3 * b0,
  ];
}

const x = 0.3, y = 0.9, theta = 0.7;

// オイラーの側：e^{iθ} を x + iy に片側から掛ける
const euler = [
  x * Math.cos(theta) - y * Math.sin(theta),
  x * Math.sin(theta) + y * Math.cos(theta),
];

// 四元数の側：e^{kθ/2} と e^{−kθ/2} で xi + yj を前と後ろから挟む
const q    = [Math.cos(theta / 2), 0, 0,  Math.sin(theta / 2)];
const qInv = [Math.cos(theta / 2), 0, 0, -Math.sin(theta / 2)];
const v = [0, x, y, 0];
const r = mul(mul(q, v), qInv);

console.log("オイラーの側：横", euler[0].toFixed(4), "縦", euler[1].toFixed(4));
console.log("四元数の側　：横", r[1].toFixed(4), "縦", r[2].toFixed(4));
console.log("四元数の側の実の部分と k：", r[0].toFixed(4), r[3].toFixed(4));
```

```
import math

# 四元数 w + xi + yj + zk を (w, x, y, z) の並びで書く
def mul(a, b):
    a0, a1, a2, a3 = a
    b0, b1, b2, b3 = b
    return (
        a0 * b0 - a1 * b1 - a2 * b2 - a3 * b3,
        a0 * b1 + a1 * b0 + a2 * b3 - a3 * b2,
        a0 * b2 - a1 * b3 + a2 * b0 + a3 * b1,
        a0 * b3 + a1 * b2 - a2 * b1 + a3 * b0,
    )

x, y, theta = 0.3, 0.9, 0.7

# オイラーの側：e^{iθ} を x + iy に片側から掛ける
euler = complex(math.cos(theta), math.sin(theta)) * complex(x, y)

# 四元数の側：e^{kθ/2} と e^{−kθ/2} で xi + yj を前と後ろから挟む
q = (math.cos(theta / 2), 0, 0, math.sin(theta / 2))
q_inv = (math.cos(theta / 2), 0, 0, -math.sin(theta / 2))
r = mul(mul(q, (0, x, y, 0)), q_inv)

print("オイラーの側：横", round(euler.real, 4), "縦", round(euler.imag, 4))
print("四元数の側　：横", round(r[1], 4), "縦", round(r[2], 4))
```

</details>

二つの式は同じ点に着きます。それでも、四元数の側には、オイラーの側に書かれていない部品があります。前の章で出てきた四つです。このページで並べてみると、オイラーの等式がたたんでいたものは、少なくとも次の四つに見えます。

1. **回す軸**：平面の回転にも、平面と直角な軸があります。オイラーの側では、軸は数の中に置き場がなく、式に出てきません。
2. **半分ずつ、両側から**：四元数の側では、角度の半分を前に、半分を後ろに掛けます。オイラーの側では、全部を片側から掛けます。
3. **掛ける順番**：四元数の側では、k と i を入れ替えると符号が変わります。オイラーの側では、e<sup>iθ</sup> と点を入れ替えても答えが同じなので、順番が見えません。
4. **二周で戻る回し手**：回す数 e<sup>kθ/2</sup> は、平面が一周しても −1 で、二周してやっと 1 に戻ります。e<sup>iθ</sup> は一周で 1 に戻ります。

四つのうち最後の「二周で戻る回し手」には、√ の形が入っています。回す数 q = e<sup>kθ/2</sup> を 2 回掛けると、q<sup>2</sup> = e<sup>kθ</sup> になります。q は、e<sup>kθ</sup> の二つある √ の一つです。立体の回転は、q を前と後ろから挟んで（q v q<sup>−1</sup>）、半分ずつ受け持って角度 θ 回します。だから、回されるものが一周（θ = 2π）して元に戻ったとき、q 自身は半分の所 e<sup>kπ</sup> = −1 にいます。二周してやっと 1 に戻ります。

pjdhiro は、この形について、こう話しています。

<strong>pjdhiro の見方：</strong>一周まわると半分回る、というルートの感じは、おそらく本質を指してると思うので、抱持したいね。電子のスピンも関係するんでしょ？

電子のスピンにも、同じ形の数学が出てきます。物理では、電子のスピンの状態に掛かる回転の行列が、この形をしています。一つ目の章の畳みにある U = [[e<sup>−iθ/2</sup>, 0], [0, e<sup>iθ/2</sup>]] は、θ = 2π で −I になります。スピンの向きは一周で元に戻りますが、状態には −1 が掛かり、4π でやっと I に戻ります。それでも、U と −U は、挟んで回したときに同じ回転になります。立体の回転一つに、回す行列が二つずつ対応しているので、数学では、回す行列の集まり（SU(2)）が、立体の回転（SO(3)）を二重に覆う、と言います。行列の計算は、確かめられる数学の事実です。電子のスピンの回転がこの行列で書けることは、量子力学の教科書の事実です。

一周で半分しか回らない、という形が、何の本質を指しているのかは、このページでは問いとして置きます。

<details><summary>詳しく — 実の向きを含む平面で並べると</summary>

オイラーの等式と同じ平面（w + iy の平面。j と k をゼロ）を四元数の中に残すこともできます。この平面は実の向きを含むので、挟む式 q v q<sup>−1</sup> では動きません。q = e<sup>iθ/2</sup> で挟むと、点 0.3 + 0.9i は 0.3 + 0.9i のまま残ります。

この平面を回すには、q<sup>−1</sup> でなく、同じ q で両側から挟みます。e<sup>iθ/2</sup> z e<sup>iθ/2</sup> = e<sup>iθ</sup> z で、オイラーの側と同じ点に着きます（0.3 + 0.9i は、θ = 0.7 で −0.3503 + 0.8816i）。

逆に、同じ q で両側から挟む式は、j と k の平面を動かしません。q で前と後ろから挟む二つの式は、同じ q を使いながら、別々の平面を回しています。

</details>

<details><summary>詳しく — 片側から一回掛けると、もう一枚の平面も回る</summary>

オイラーの側の「e<sup>iθ</sup> を片側から掛ける」ことを、四元数の全体に当ててみます。すると、1 と i の平面が角度 θ 回るのと同時に、j と k の平面も同じ角度 θ だけ回ります。たとえば、j に e<sup>iθ</sup> を前から掛けると、cos θ j + sin θ k になります。j と k をゼロにした平面の上では、この二枚目の平面の回転は見えません。

片側から一回掛けるという一番素朴な書き方が、四元数の中では、二枚の平面を同時に回す働きになっています。オイラーの等式は、その二枚目を見えない所に置いた形だ、と読むこともできそうです。

</details>

<details><summary>詳しく — 行列で書くと、オイラーの等式は −I になる</summary>

二つの側を、同じ 2 行 2 列の行列の言葉で書くと、一本につながります。

平面全体に i を掛けることは、点 (x, y) を 90 度回す行列 J = [[0, −1], [1, 0]] を掛けることと同じです。J を 2 回掛けると −I になります。I は、何も変えない単位行列です。i² = −1 は、行列では J² = −I です。

e<sup>iθ</sup> を掛けることは、角度 θ だけ回す行列 cos θ I + sin θ J を掛けることです。θ = π を入れると、cos π = −1、sin π = 0 なので、行列は −I になります。平面のすべての点を、0 をはさんで反対側へ送る行列です。

だから、e<sup>iπ</sup> + 1 = 0 は、行列では −I + I = O と書けます。O は、どの点も 0 に送る行列です。等式の 1 は「何も変えない」行列 I、0 は「すべてを 0 に送る」行列 O、e<sup>iπ</sup> は「半周回す」行列 −I にあたります。

四元数の側も、パウリ行列で 2 行 2 列の行列にすると、同じ所に着きます。e<sup>kπ</sup> も −I になります。i と j の平面の点 xi + yj は、行列では −i [[0, x − iy], [x + iy, 0]] になり、左下の角にオイラーの側の点 x + iy がそのまま入っています。これを U で挟むと、左下の角が e<sup>iθ/2</sup> (x + iy) e<sup>iθ/2</sup> = e<sup>iθ</sup>(x + iy) に変わります。

U = [[e<sup>−iθ/2</sup>, 0], [0, e<sup>iθ/2</sup>]] で [[0, a*], [a, 0]] を挟む（a* は a と虚の部分の符号だけ違う数）と、左下の角は e<sup>iθ/2</sup> × a × e<sup>iθ/2</sup> になります。複素数どうしは順番を入れ替えても同じなので、これは e<sup>iθ</sup> a です。右上の角は e<sup>−iθ</sup> a* です。

挟む式 q v q<sup>−1</sup> を行列にすると、その中で、オイラーの掛け算が、同じ数を両側から半分ずつ掛ける形で行われています。上の「実の向きを含む平面で並べると」の畳みで見た、同じ q で両側から挟む式が、ここに入っています。

</details>

## 0 と 1 も、次元をたたむ記号かもしれない

<!--OPEN-->

<a id="eo-fold"></a>四つを開いてみると、たたむ働きをしているのは、e<sup>iθ</sup> を掛ける一つの式だけではないように見えてきます。オイラーの等式の登場人物も、それぞれが何かを一つにたたむ働きをしているように見えます。pjdhiro は、等式の登場人物を眺めていた対話の初めに、0 と 1 について、こう言っています。

<details><summary>寄り道 — 次元という言葉も、一つの意味ではない</summary>

<a id="eo-dim"></a>たたむ記号の話をしていると、そもそも「次元」とは何かが揺れてきます。このページの構成を考えていたとき、pjdhiro はこう言っています。

<strong>pjdhiro の問い：</strong>そもそも次元という概念も、だいぶ誤解されてる可能性あるよね。ジュリア集合の次元数とか、違いそうだもんね。

次元という言葉には、少なくとも二つの使われ方があります。一つは、場所を言うのに数がいくつ要るか、です。数直線は 1 つ、平面は 2 つ、立体は 3 つです。もう一つは、細かく見ていったとき、形がどれだけ増えるか、です。線を半分の大きさの升目で数え直すと、升目の数は 2 倍に、面なら 4 倍になります。何倍になるかを 2 の何乗かで書くと、その指数が次元です。

二つの使われ方は、いつも同じ数になるわけではありません。たとえば、線分を三等分して真ん中を山形に折る操作を、限りなくくり返した曲線（コッホ曲線）は、大きさを 1/3 にすると同じ形が 4 つ並びます。4 = 3<sup>d</sup> から、d はおよそ 1.26 です。線より込み入っていて、面より薄い形です。

ジュリア集合の縁も、同じように測れます。c = 0 のときの縁は、半径 1 の円で、次元は 1 です。c = −1 のときの縁を、このページで細かい升目で数えて見積もると、およそ 1.2 になりました。c = −0.8 + 0.156i と c = −0.123 + 0.745i でも、1.1 から 1.2 ほどで、どれも整数になりませんでした。

数の個数で数えた次元も、一つの決まりではありません。複素平面に一点 ∞ を足すと、球の表面になります。四元数は四つの数で書きますが、大きさ 1 の四元数を集めると、四つの向きの中の、三次元の球の表面になり、それが立体の回転を書きます。何次元の世界の話をしているのかは、何を数えたかで変わります。

<b>ジュリア集合の縁を、升目で数えたやり方</b>

c = −1 のジュリア集合の縁の点を、逆向きのくり返し（z から ±√(z − c) を選ぶことをくり返す）で 60 万個ほど集めました。平面を、一辺が 4/2<sup>k</sup> の升目に分け、点が入る升目を数えます。k を 6 から 9 まで細かくしていったとき、升目の数がどれだけ増えるかの傾きを取ると、およそ 1.23 でした。同じやり方で c = 0 を数えると 1.01 で、円の 1 に合います。

この数え方は見積もりで、点の集まり方の偏りで少し低めに出ることがあります。

</details>

## 回ることが先にあるのかもしれない

<!--OPEN-->

<a id="eo-turn"></a>ここまでを並べると、一つの見方が浮かびます。平面の回転が先にあり、それを数直線に折りたたむために、0 と ∞、√・π・e のような記号が便宜上使われているのではないか、という見方です。

pjdhiro は、回転が溢れていることについて、こう話しています。

<strong>pjdhiro の見方：</strong>世界には回転の性質を持つものが多いのか、世界を回転という性質で認知するからなのか、道具が回転を扱うからなのか、どれなんでしょうね。いずれにせよ、回転は溢れてそうですね。

自然対数（底が e の対数）についても、同じ向きの見方があります。対数は、歴史の上では、大きな数の掛け算を足し算に替えて楽に計算するための道具として作られました（ネイピア）。e は、利息を細かく分けて付けると元の何倍になるかを考えたときに出てきた数です（ヤコブ・ベルヌーイ）。どちらも、円の話から始まったものではありません。

ところが、複素数の対数を考えると、円が出てきます。log z の虚の部分は、z が 0 のまわりで回った角度です。その角度を、半径 1 の円の上の道のりでちょうど測れるのは、底が e のときだけです（独立ページ「[オイラーの式](euler-formula.html)」の畳み「e と、「1 + x/n を n 回掛ける」こと」）。pjdhiro は、ここから逆向きに考えています。

<strong>pjdhiro の見方：</strong>e は単位円のためのツールではない、というのが一般的ですよね？そこが逆だと思うのです。我々が自然対数と呼ぶものが特別なのは、単位円が特別だからで、その上の次元にステレオ投影前のものがあって、それが大切だから、と逆算しています。

歴史の順番は、計算の道具と利息が先でした。このページが置くのは、歴史の言い直しではなく、自然対数が「自然」に見える理由が、円の側にもあるのかもしれない、という揺さぶりです。0 と ∞ が、まだ誤解されているかもしれないのと同じ向きの問いです。

<strong>pjdhiro の見方：</strong>ゼロはまだ誤解されてるかもしれませんね。無限大も。

## 禅の円と、円の雲

<!--OPEN-->

<a id="eo-circle"></a>回転と円の話から、少し寄り道をします。この章を高校の数学の言葉だけで読む解説は、「[禅の円を、高校の数学で読む](zen-circle-hs.html)」にあります。禅には、円を描いて答える話や、「円か（まどか）」という言葉で、欠けの無いものを語る句があります。pjdhiro は、禅の円についてこう話しています。

<strong>pjdhiro の見方：</strong>禅は単位円のようなものを表してると、勝手に思ってた。

たとえば、『信心銘』（伝・僧璨）には「圓同太虛　無欠無餘」（円かなることは大きな空と同じで、欠けも余りも無い）という句があります。同じ銘は、いちばん小さいものといちばん大きいものが同じだ、とも言います（「極小同大」「極大同小」）。『碧巌録』第 33 則では、資福が、訪ねてきた陳操を見るなり、一つの円を描きます。円は、言葉の代わりに何かを示すしぐさとして描かれます（この則では、陳操はそれを、来ただけでもう外れているのに、そのうえ円まで描くとは、と退けます）。

いちばん小さいものと、いちばん大きいものが同じ所にある、という言い方は、球の上で 0 と ∞ が、入れ替えても形が変わらない、対等な二つの極になることと、形が似ています。これは、このページの読みです。

この句には、もう一つの読み方があります。pjdhiro は、こう読んでいます。

<strong>pjdhiro の見方：</strong>もう一つの解釈は、2πr の開始点と終着点が同じで、0 と無限大ってことじゃないのかな？

円の上を歩くと、歩いた道のりが 0 の所と、2πr 歩いた所は、同じ点に重なります。何周歩いても同じで、e<sup>iθ</sup> でも、θ = 0 と θ = 2π は同じ点 1 を指します。円には、はしがありません。ここで 0 と重なっているのは、点ではなく、歩いた量です。

この読みの元にあった直観を、pjdhiro はこう言い直しています。

<strong>pjdhiro の見方：</strong>出発点から進むと、0 度と 360 度で同じ位置。それが 0 と無限大のようなものが同じ、という感性は、0 とネイピア数が指し示す何かが同じ位置ではないか、という直観です。無限大のような極大さを感じる概念を、ネイピア数が指しているはずです。

ここでの 0 と 1 と無限大は、着く点ではなく、回った量として読めます。周の数で数えると、0 周、1 周（100% の 1）、2 周……は、どれも同じ点に来ます。回った量はいくらでも大きくできるのに、位置は円から出ません。数学で言えるのは、ちょうど何周かで止まるたびに出発点に戻る、までです。止まらずに回り続けた先（無限の周）は、一つの点には決まりません。

e は、100% の伸びで、一単位の時間育ち続けた量です（(1 + 1/n)<sup>n</sup> の n をどこまでも大きくした先、2.718…）。同じ育ち方のまま、伸びの向きを直角に替えると、量は大きくならずに、円の上を回り始めます。e<sup>iθ</sup> は、半径 1 の円の上を左回りに速さ 1 で進み、θ がそのまま歩いた道のりになります。底を正の数 c にすると、c<sup>iθ</sup> の速さは |ln c| になり、左回りに速さがちょうど 1 になるのは、底が e のときだけです（1/e なら、速さは 1 でも逆回り）。e が単位円で大活躍するというのは、数学ではこのことです。

数学では当たり前のことですが、この言い方について、pjdhiro はこう話しています。

<strong>pjdhiro の見方：</strong>e が単位円で大活躍する。当たり前のことを言ってるんだけど、数式では当然の、e と π が一つのものであるかのような感動を、素朴な感覚として経験してもらえそうなコピーなのかもね。

一つの式にまとめると、e<sup>x + iθ</sup> の大きさは e<sup>x</sup>、向きは θ です。x は伸びた量、θ は回った量です。伸びた量 x が 0 の所が、ちょうど単位円です。x を限りなく縮めると 0（南極）へ、限りなく伸ばすと ∞（北極）へ近づきます。球の上で、単位円は 0 と ∞ のちょうど真ん中の赤道です。回った量 θ のほうは、いくら増やしても、赤道を回り続けます。

pjdhiro の言う「無限大のような極大さ」に、数学で近いものは二つあります。伸びた量 x を限りなく大きくした先の ∞ と、回った量 θ をいくら増やしても同じ輪にとどまることです。e そのものは限りのある数で、e が 0 や ∞ と同じ位置に来るわけではありません。

点として見ると、このページの重ね方では、次のようになります。数直線を球に写すと、似たことが見えます。数直線の上では、右へどこまで進んでも ∞ には着きません。球に写すと、数直線は一つの円になり、右の果てと左の果ては北極の一点 ∞ で重なります。0 から右へ進むと半周で ∞ に着き、そこを越えると左の果てから戻ってきて、また 0 に着きます。この円の上では、0 と ∞ は向かい合う二点で、同じ点に重なるのは、右の果てと左の果てです。

「極大同小」の句は「不見邊表」（果てが見えない）と続きます。数学の側では、少なくとも三つの形に重ねられます。平面のどこまでも遠い所が、球の北極の一点に閉じて端が無くなること。円をいくら回っても終わりが来ないこと。一周すると始めの点に戻ること。三つは別々ではありません。球の経線を一周すると、数直線を 0 から ∞ を越えて 0 まで通り抜けることになるからです。ただし、点として見れば、この一周の上で 0 と ∞ は向かい合う二点です。回った量として読む pjdhiro の 0 と ∞ とは、別の見方です。句そのものは、前の句が時の長短と十方の広さを打ち消すのを受けて、広がりの果てについて言っています。どれに重ねるかは、このページの読みです。

<strong>pjdhiro の見方：</strong>こうやってみるとオイラーの等式は、クリーンすぎてリーダブルさがないよね。オイラーはその一行だけを示したわけではないだろうけど、後世の人がそこだけ切り取ってしまった。関数の宣言のように、入出力の型だけがあって、内部が分かってないし、使い所も分かってない。

<strong>pjdhiro の見方：</strong>ライブラリに一行、関数名と引数と戻り値の型だけあってもね。何に使うのか help が欲しい。

プログラムの関数には、何を受け取り何を返すかの宣言と、使い方を書いた説明書（help）が付いています。オイラーの等式は、exp という関数に iπ を入れると −1 が返る、という一行にあたります。

数学のライブラリにも、e<sup>z</sup> を計算する関数 exp があり、説明書（help）が付いています。中身の厚さはライブラリでまちまちです。Python の cmath.exp は一行だけです。NumPy の exp には、複素数を大きさと位相に分ける説明と、図の例があります。Wolfram Language の Exp には、周期・応用・よくある落とし穴まで並んでいます。見た範囲では、厚い説明書にも、回す軸や掛ける順番は書かれていません。

下は、そうした厚めの説明書によく書かれている中身を、このページの言葉でまとめたものです。<span class="help-add">色の付いた行</span>が、このページで開いたものを書き足した所です。

<pre class="help-doc"><b>exp(z)</b>
  複素数 z を受け取り、e の z 乗を返す。

  定義
    e ≈ 2.71828。実数 x では、e^x は (1 + x/n)^n の n をどこまでも大きくした先の値。

  複素数のとき
    z = a + ib なら、e^z = e^a (cos b + i sin b)。
    e^a が大きさ、cos b + i sin b が大きさ 1 の向き（位相）。
<span class="help-add">    何をしているか：平面の全体に掛けて、大きさを e^a 倍し、平面ごと角度 b だけ回す。</span>
<span class="help-add">    a = 0 なら、伸ばさずに回すだけ（単位円の上を進む）。</span>

<span class="help-add">  なぜ底が e か</span>
<span class="help-add">    底を正の数 c にすると、c^(iθ) = e^(iθ ln c) は、単位円の上を速さ |ln c| で進む（c < 1 なら逆回り）。</span>
<span class="help-add">    左回りに速さがちょうど 1 になり、θ がそのまま円の上の道のりになるのは、底が e のときだけ。</span>

<span class="help-add">  前提（省略されている既定値。等式がたたんでいた四つ）</span>
<span class="help-add">    回す軸：平面に直交する奥行きの向き。複素数には置き場がなく、式に出てこない。</span>
<span class="help-add">    半分ずつ、両側から：平面では全部を片側から掛ける。立体では、軸 u の e^(uθ/2) で前と後ろから挟む（q v q⁻¹）。</span>
<span class="help-add">    掛ける順番：平面では順番が結果を変えないので、式に出てこない。立体では、入れ替えると符号が変わる。</span>
<span class="help-add">    二周で戻る回し手：回転そのものは一周で戻るが、立体の回す数 q は一周で −1、二周でやっと 1 に戻る。</span>

  周期
    e^(z + 2πi) = e^z。2πi ごとに同じ値に戻る。
<span class="help-add">    回った量で読むと：0 周、1 周、2 周……は、どれも同じ点に来る。</span>
<span class="help-add">    逆の log は、何周したかの分だけ値が開き、一つに決まらない。</span>

  例
    exp(0) = 1　　exp(iπ) = −1　　exp(2πi) = 1
<span class="help-add">    オイラーの等式 e^(iπ) + 1 = 0 は、exp(iπ) = −1（半周）の −1 を移して、0 と 1 も式に入れた形。</span>

<span class="help-add">  球の上で（章「0 と 1 も、次元をたたむ記号かもしれない」のステレオ投影）</span>
<span class="help-add">    このページの置き方（半径 1 の球を、赤道の高さの平面に写す）で 0 を南極、∞ を北極に置くと、</span>
<span class="help-add">    a = 0 の単位円は、二つのちょうど真ん中の赤道になる。a を限りなく小さくすると e^z は 0 へ、</span>
<span class="help-add">    限りなく大きくすると ∞ へ近づく。</span>

  応用
    微分方程式、確率と統計 など。
<span class="help-add">    立体の回転（四元数）。</span>

  関連
    log（逆の関数）、sin、cos<span class="help-add">、四元数の回転 q v q⁻¹</span></pre>

書き足した行の多くは、平面の上だけで使う限り、書かなくても困らないものです。書かなくても困らないからか、説明書には書かれにくいようです。オイラーの等式の一行にも、たたまれています。立体へ持っていくと、たたまれていたものが、四元数の式の中に出てきます。軸は引数として、順番と二周は式の形として出てきます。色の無い行だけでも exp は使えますが、なぜそうなるか、平面の外でどう使うかは、色の付いた行に書かれています。

<details><summary>出典</summary>

- Python 3 の `cmath.exp` の説明（docstring）は「Return the exponential value e\*\*z.」の一行（手元の Python で確かめた）。
- NumPy の `exp` の説明は、ソースの [ufunc_docstrings.py](https://github.com/numpy/numpy/blob/main/numpy/_core/code_generators/ufunc_docstrings.py) にある。Notes の欄で、複素数の入力を e^a と e^{ib} に分け、e^{ib} = cos b + i sin b を大きさ 1 で周期的な位相と書き、複素平面の上の大きさと位相を描く例を載せている。
- Wolfram Language の [Exp](https://reference.wolfram.com/language/ref/Exp.html) は、オイラーの公式への書き換え、2πi の周期、応用（微分方程式・確率と統計 ほか）、よくある落とし穴の欄を持つ。
- 上の説明書は、これらを写したものではなく、よく書かれる中身をこのページがまとめ直したもの。

</details>
