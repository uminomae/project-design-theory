# オイラーの等式が、たたんだもの

<div class="reader-lead glow-card" id="eo-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>禅の円と、単位円は似ていないか。このページは、この問いから始まります。オイラーの等式 e<sup>iπ</sup> + 1 = 0 は、半径 1 の円（単位円）の上で半周回る掛け算を書いた式です。円の式なのに、そこには育ち方の数 e が出てきます。肩に乗せた数 θ が、そのまま円の上を左回りに回った道のり（弧度で測った角度）になるのは、底が e のときだけです。</p>
<p>なぜ e は、単位円でこれほど大活躍するのか。このページは、平面が基本なのではなく、立体を回す数（四元数）の側が基本だ、という pjdhiro の見方で並べ直して探します。同じ写し方（ステレオ投影）で、四元数の球は立体へ、球は平面へ、円は直線へ写せます。一番下の段では、円を一点から写すと直線になります。このページの球の上では、単位円は赤道で、数直線は、北極を通る経線の円を写したものです。二つの輪は 1 と −1 で交わります。そう並べると、0 と ∞ は数直線のはしではなく球の両極に、e・π・√ は円の世界を数直線の側で扱うための記号に見えてきます。オイラーの等式は、二つの輪が重なる一点です。最後に、禅の円に戻り、e がその円で何をしているのかを、六つの問いで確かめます。</p>
</div>

<p class="reader-summary__title">概要</p>

このページは、pjdhiro の問いと見方に、Claude が数学で確かめて答える形で作っています。始まりは、禅の円とオイラーの等式が似て見える、という pjdhiro の感じです。その円に e が出てくることに驚いたところから、なぜ e が単位円の世界でこれほど働くのかを探していきます。探す足場は、四元数の側を基本に置き、平面と数直線をその下の段と見る、という pjdhiro の見方です。

題の「たたんだもの」は、オイラーの等式の一行が書かずに済ませているもの（このページでは「省かれているもの」と言います）を指します。本文では「たたむ」という語を使わず、数学の働きごとに一つの語を当てます。北極から光を当てて、丸い形を平らな所へ移すことを「写す」、写した先に ∞ を一点足して丸い形に戻すことを「閉じる」、北極と中心を通るように切って、一つ下の段の形を取り出すことを「切り口を取る」、四元数の四つの向きのうち二つを使わないことを「二つの向きを 0 に置く」、e<sup>iθ</sup> がまっすぐな座標を円に何周も巻くことを「巻きつける」、log がそれを戻すことを「ほどく」と言います。2 乗と √ は、「角度を 2 倍にする」「角度を半分にする」とそのまま書きます。pjdhiro の言葉の中の「たたむ」「次元を落とす」は、そのまま残し、前後で、どの働きのことかを言い直します。

どの章も、見方（pjdhiro の仮説と、このページの置き方）を先に、数学ではどうなるかを後に書きます。段の頭に、<span class="step-mark">見方</span>と<span class="step-mark step-mark--math">数学では</span>の印を付けます。畳みの「詳しく」は、数学の段です。

説明は、高校の数学で読める言葉で書きます。計算の細かい所と、本筋から外れる話は、畳みと巻末の補足に置きます。三角比・三角関数・弧度法・複素数を、回転を扱うための角度としておさらいしておくには、「[三角関数から複素平面まで、回転を扱うための角度の話だった](angle-rotation.html)」があります。結びの禅の円の章を、高校の数学の言葉だけで、絵と言葉で追う解説は、「[禅の円を、高校の数学で読む](zen-circle-hs.html)」にあります。

## 禅の円と、オイラーの等式は似ていないか

<!--OPEN-->

<a id="eo-zen"></a><span class="step-mark">見方</span>禅には、円を描いて答える話や、「円か（まどか）」という言葉で、欠けの無いものを語る句があります。たとえば『信心銘』（伝・僧璨）には「圓同太虛　無欠無餘」（円かなることは大きな空と同じで、欠けも余りも無い）という句があります。pjdhiro は、禅の円について、こう話しています。

<strong>pjdhiro の見方：</strong>禅は単位円のようなものを表してると、勝手に思ってた。

<span class="step-mark">見方</span>どこが似て見えるのかは、このページを通して探していきます。一つ目の手がかりとして、このページは、どちらも、はしの無い一つの輪だ、と見ます。

<span class="step-mark step-mark--math">数学では</span>等式は、その輪の上で 1 を半周させて −1 に着かせ、そこに 1 を足して 0 にします。0・1・i・π・e の五つが、輪の上の一つの動きに収まっています。五つの数の一つずつの説明は、独立ページ「[オイラーの式](euler-formula.html)」にあります。

<details><summary>詳しく — 行列で書くと、オイラーの等式は −I + I = O になる</summary>

平面全体に i を掛けることは、点 (x, y) を 90 度回す行列 J = [[0, −1], [1, 0]] を掛けることと同じです（[a, b] は行列の一つの行）。J を 2 回掛けると −I になります。I は、何も変えない単位行列です。i² = −1 は、行列では J² = −I です。

e<sup>iθ</sup> を掛けることは、角度 θ だけ回す行列 cos θ I + sin θ J を掛けることです。θ = π を入れると、cos π = −1、sin π = 0 なので、行列は −I になります。平面のすべての点を、0 をはさんで反対側へ送る行列です。

だから、e<sup>iπ</sup> + 1 = 0 は、行列では −I + I = O と書けます。O は、どの点も 0 に送る行列です。等式の 1 は「何も変えない」行列 I、0 は「すべてを 0 に送る」行列 O、e<sup>iπ</sup> は「半周回す」行列 −I にあたります。

</details>

## その円に、e が出てくる

<!--OPEN-->

<a id="eo-e"></a><span class="step-mark">見方</span>等式を単位円の上で見ると、不思議な所が一つあります。円の式なのに、出てくる数が e です。

e と聞いて思い浮かぶのは、2.718… という数、自然対数の底、指数や対数の計算を足し算で扱えるようにしてくれる便利な数、くらいではないでしょうか。指数の曲がった線を、まっすぐな線にして扱うときに出てくる数、という覚え方もあります。教科書では、利息の計算から出てくる数として習います（下の寄り道）。

けれども、その覚え方からは、e が 2 や 10 より特別な理由は見えてきません。

<span class="step-mark step-mark--math">数学では</span>対数を使えば、底が 2 でも 10 でも、掛け算は足し算になり、指数の曲線は、目盛りを対数にしたグラフでまっすぐな線になります。この働きだけなら、底は e でなくてもかまいません。

単位円の上では、この同じ働きが、回転を重ねることを、角度を足すことに替える形で出てきます。e<sup>iα</sup> と e<sup>iβ</sup> を掛けると、e<sup>i(α+β)</sup> です。e<sup>iθ</sup> は、半径 1 の円の上を、1 から左回りに速さ 1 で進みます。θ がそのまま、円の上を歩いた道のりになります。底をほかの正の数 c に替えても、c<sup>iθ</sup> は同じ円の上を進みます。ただし、速さは |ln c| になります。2 ならおよそ 0.69、4 ならおよそ 1.39 です。肩の θ と、円の上を左回りに進んだ道のりがぴったり同じになるのは、底が e のときだけです（1/e なら、速さは 1 でも逆回りです）。足し算になるのはどの底でも同じで、足す角度が、そのまま歩いた道のりになるのは e だけ、ということです。

<span class="step-mark">見方</span>e が 2 や 10 より特別に見えない理由と、単位円で e が大活躍する理由は、ちょうど裏表になっています。底を選ばないのは、掛け算を足し算にする働きで、e だけが持っているのは、その足し算を、円の上の道のりにそろえる働きです。ここに、驚きがあります。

## 四元数から平面へ：二つの向きを 0 に置くと、複素数を掛ける回転と同じ回転が出てくる

<!--OPEN-->

<a id="eo-fold4"></a><span class="step-mark">見方</span>一番上の段から、平面の段へ移ります。今度は形を切るのでなく、回す点と回し手の、四つの向きのうち二つを 0 に置きます。

<span class="step-mark step-mark--math">数学では</span>四元数は、w + xi + yj + zk の形の数です。w が実の部分で、i・j・k は三つの虚の向きです。三つとも、2 回掛けると −1 になります。i と j を掛けると k になりますが、順番を入れ替えて j と i を掛けると −k になります。立体の中の点は、大きさ 1 の四元数 q で前と後ろから挟んで（q v q<sup>−1</sup>）回します。

回す点は、実の部分 w がもともと 0 です。残りの k も 0 に置くと、点は i と j の平面に乗ります。その平面を、k を軸に角度 θ 回すと、i を 1 に、j を i に重ねて見たとき、オイラーの側で e<sup>iθ</sup> を掛けたのと同じ点に着きます。回し手 e<sup>kθ/2</sup> のほうは、ちょうど 0 に置いた w と k の向きの部分だけでできています。

同じ形の式 e<sup>kπ</sup> = −1 も出てきますが、それは平面の半周ではなく、一周にあたります。平面を半周回す回し手は e<sup>kπ/2</sup> = k です。

同じ点に着くのに、四元数の側には、オイラーの側に書かれていない部品が四つあります。等式の一行で省かれているものです。

1. **回す軸**：平面を立体の中に置くと、平面の回転は、平面と直角な軸のまわりの回転として見えます。オイラーの側では、軸は数の中に置き場がなく、式に出てきません。
2. **半分ずつ、両側から**：四元数の側では、前に e<sup>kθ/2</sup>、後ろにその逆の e<sup>−kθ/2</sup> を掛けて、半分ずつ回します。オイラーの側では、全部を片側から掛けます。
3. **掛ける順番**：四元数の側では、k と i を入れ替えると符号が変わります。オイラーの側では、e<sup>iθ</sup> と点を入れ替えても答えが同じなので、順番が見えません。
4. **二周で戻る回し手**：回す数 e<sup>kθ/2</sup> は、平面が一周しても −1 で、二周してやっと 1 に戻ります。e<sup>iθ</sup> は一周で 1 に戻ります。

<span class="step-mark">見方</span>平面の上だけで回している限り、どれも書かなくても困らないので、等式の一行では省かれている、と読めます。四つ目の回し手は、回転 e<sup>kθ</sup> の平方根（角度が半分）の形をしていて、電子のスピンにも同じ形の数学が出てきます。対比の表、その場で動かせる計算、行列での書き方、スピンの段は、補足「[立体の回転と並べると](#eo-quat)」にあります。

## 0 と ∞ を、球の両極に置く

<!--OPEN-->

<a id="eo-zero"></a><span class="step-mark">見方</span>次は、平面から直線の段へ移ります。このページは、平面を閉じた球の上で見ると、まず 0 と 1 の置き方が変わる、と見ます。数直線の上では、0 と 1 は左右に並びます。pjdhiro は、等式の登場人物を眺めていた対話の初めに、0 と 1 について、こう言っています。

<strong>pjdhiro の見方：</strong>非二元から発想しようと思ってます。0 と 1 は、数直線のような左右に配置されるものではない。e と π は、数直線に次元を落とす、ステレオ投影のような際に必要になるもの、と逆に発想しようとしてます。つまり e の理解は不要。ルートのような記号になりつつある。

カードの「数直線に次元を落とす」は、このページの語では、写す・巻きつける・ほどく、の組にあたります。e と π がそこで何をするかは、章「[e・π・√ も、0 と ∞ も、円の世界を数直線の側で扱うための記号かもしれない](#eo-fold)」で見ます。

<details><summary>寄り道 — リーマン予想の平面も、この球に写せる</summary>

<span class="step-mark step-mark--math">数学では</span>リーマン予想は、ゼータ関数という関数についての、まだ解かれていない予想です。ゼータ関数は 1 + 1/2<sup>s</sup> + 1/3<sup>s</sup> + … の和から始まり、和のままでは意味を持たない所まで、式を広げて決めた関数です。その値が 0 になる点（零点）には、−2・−4・−6… と決まって並ぶもの（自明な零点）と、それ以外があります。予想は、それ以外の零点が、すべて実部（横の座標）が 1/2 の縦の直線の上にある、と言います。この直線を臨界線と呼びます。予想が素数について何を言い当てようとしているかは、読み物「[起業家の漸化式と、ジュリア集合](julia-potential.html#jp-riemann)」の第六部にあります。

この章の球の絵から、pjdhiro はリーマン予想の平面の図を思い出しています。

<strong>pjdhiro の見方：</strong>三次元を二次元にステレオ投影する際、−1 を通る球面状の円が投影された直線を考えてください。それは 1 と 1/2 のリーマン予想の平面図と似てる。

<span class="step-mark step-mark--math">数学では</span>臨界線が赤道に、0 と 1 が両極に来るように写し方を選ぶと、二つの図は重なります。ゼータ関数の平面の点を s と書き、w = s/(s − 1) の w に送ります。すると、次のように移ります。

- 臨界線は、半径 1 の円、つまりこの章の球の赤道に移ります。臨界線は、0 からの距離と 1 からの距離が等しい点の集まり（|s| = |s − 1|）で、これは |w| = 1 と同じ条件だからです。
- 1/2 は、赤道の上の −1 に移ります。
- 0 は 0（南極）に、1 は ∞（北極）に移ります。1 は、ゼータ関数の値が限りなく大きくなる点です。

この章の写し方では、北極を通る円だけが直線に写ります。s の平面の臨界線は、北極を通る円を写した直線です。w = s/(s − 1) は、球を回すのではなく、円を円のまま保って球の上の点を動かす写し方です。s = 1 を北極へ運び、それまで北極にいた s の ∞ を、赤道の上の 1 へ運びます。臨界線は s = 1 を通らないので、北極を通らない円、つまり赤道になります。直線に見えるか円に見えるかは、北極を通るかどうかで決まります。

pjdhiro は、続けてこう問いました。

<strong>pjdhiro の問い：</strong>ゼータ関数は球のようなものを扱ってるよね？

<span class="step-mark step-mark--math">数学では</span>ゼータ関数に、π<sup>−s/2</sup> と、階乗を整数でない数に広げた関数（ガンマ関数。定義の式に e<sup>−t</sup> が出てくる）を掛けて整えた関数は、s と 1 − s を入れ替えても値が変わりません（関数等式）。ゼータ関数そのものの値は変わります。w の側では、1 − s は 1/w に移ります。これは、次の章の「詳しく」にある、1 と −1 を通る軸のまわりの半回転です。さらに、s を横の軸で上下に折り返した点（s̄）では、値も元の値を上下に折り返したものになります。二つを合わせると w → 1/w̄ で、この章の鏡（0 と ∞ を入れ替え、単位円の上の点だけを動かさない）になります。鏡の上にない零点があれば、鏡をはさんだ向かいにも必ず零点があります。鏡の上の零点は、自分自身が向かいです。この対称性は、自明でない零点だけのものです。自明な零点 −2・−4… は w の側では 2/3・4/5… に来ますが、向かいの 3/2・5/4… は零点ではありません。リーマン予想は、球の上では、自明でない零点が対に分かれず、すべて鏡の上（赤道）に乗っている、と言い換えられます。

<span class="step-mark">見方</span>この写し方では、ゼータ関数の平面の 0 と 1 が球の両極に来て、二つの真ん中の 1/2 が赤道の上に来ます。すぐ上のカードの「ゼロの逆は無限大で、1 は 1/2 かのような」と、形が重なる所です。整えるのに、π と、e の入った式で作る関数が要ることも、章「[e・π・√ も、0 と ∞ も、円の世界を数直線の側で扱うための記号かもしれない](#eo-fold)」の仮説と並べて見ることができそうです。

<span class="step-mark step-mark--math">数学では</span>数学で言えるのは、写し方を替えると二つの図が重なる、までです。写し方を替えただけなので、これで予想が解けるわけではありません。ゼータ関数そのものは、s の ∞ に近づくとき、近づく道によって行き先がばらばらです。1 に近づく道も、果てしなく大きくなる道も、0 に何度も戻る道もあります。そのため、∞ にも値を置いて、球の全体の上の関数にすることはできません。w の側では、この点は赤道の上の 1 で、臨界線の上の零点は、ここへ向かって詰まっていきます。球の形をしているのは、関数等式の対称性のほうです。

- (1 + iπ/n)<sup>n</sup> は、n = 4 でおよそ −2.32 + 1.20i、n = 16 でおよそ −1.35 + 0.05i、n = 64 でおよそ −1.08、n = 1000 でおよそ −1.005 と、−1 に近づく。一歩で掛ける数の大きさは √(1 + π²/n²) で、1 より少し大きいので、一歩ごとに円の外へはみ出す。
- 一般に、(1 + iθ/n)<sup>n</sup> は e<sup>iθ</sup> に近づく。e = lim (1 + 1/n)<sup>n</sup> と同じ形の極限。
- 底を正の数 c にすると、c<sup>iθ</sup> = e<sup>iθ ln c</sup> で、単位円の上を速さ |ln c| で進む（c < 1 なら逆回り、c = 1 なら動かない）。
- 複素数の対数 log z の虚の部分は、z が 0 のまわりで回った角度。その角度（単位円の上の道のり）がそのまま虚の部分になるのは、底が e のときだけ（底 c なら θ/ln c。独立ページ「[オイラーの式](euler-formula.html)」の畳み「e と、「1 + x/n を n 回掛ける」こと」）。

</details>

<strong>pjdhiro の見方：</strong>次元をたたむ接点にあるものだ、が一番かな。今のところ。

e<sup>iπ</sup> = −1 は、赤道の上を 1 から半周回った所です。そこで、回る輪は、数直線の輪にふたたび重なります。回る世界の動きが、数直線の上の一つの数 −1 として読める所です。その −1 に 1 を足すと、数直線の真ん中の 0 になります。

<span class="step-mark">見方</span>等式 e<sup>iπ</sup> + 1 = 0 は、回る世界と数直線の世界の、二つの輪が重なる一点を名指している、と見ることができそうです。

題の「たたんだもの」、つまり等式の一行で省かれているものは、ここまでで二つ見えてきました。一つは、この一点の後ろにある球と、写す・巻きつけるというつながりです。

もう一つは、章「[四元数から平面へ：二つの向きを 0 に置くと、複素数を掛ける回転と同じ回転が出てくる](#eo-fold4)」で見た四つの部品です。同じ半周を一つ上の段で書くと別々に見える部品が、平面の段の等式の一行では省かれています。

<details><summary>寄り道 — 美しいと感じる所は、赤道なのか</summary>

オイラーの等式は、数学者たちが美しいと呼んできた式です（読み物「[美とは](beauty.html#bt-euler)」の章「数学者が、いちばん美しいと呼んできた式」）。球の上で見ると、等式に出てくる 1 と −1 は、どちらも赤道の上にあります。pjdhiro は、美しさの基準について、こう問いを立てています。

<strong>pjdhiro の問い：</strong>オイラーの等式は、我々の現実と数学が重なるポイントですね。ステレオ投影で言える。それは美の基準かもしれない。いつも通りの感じというしっくり感かもしれないし、フツーの世界がフツーに赤道に出てるという安心感かもしれない。美の基準が数学的なのか、我々の日常に近いのか、ということは分かってないんじゃ？

<span class="step-mark">見方</span>美しいと感じる所が、二つの世界が重なる輪にあるのかは、このページでは確かめられません。仮説として置きます。

</details>

<details><summary>詳しく — 角度を曲げないこと</summary>

- ステレオ投影は、球の上の二本の曲線が交わる角度を、平面の上でも同じ角度に写す（等角写像）。円は円か直線に写る。
- e<sup>z</sup> は、どの点でも微分が 0 にならない複素関数なので、交わる角度を保つ。
- だから、まっすぐな座標 → 平面 → 球のつながりも、角度を保つ。航海の地図（メルカトル図法）が等角なのは、このつながりの逆向きにあたる。

</details>

## 禅の円に戻る

<!--OPEN-->

<a id="eo-circle"></a><span class="step-mark">見方</span>円と、0 と ∞ の絵がそろったところで、始まりの禅の円に戻ります。ここまで、e と単位円の話をしてきましたが、出発点は、禅の円が単位円に似て見える、という pjdhiro の感じでした。この章を高校の数学の言葉だけで読む解説は、「[禅の円を、高校の数学で読む](zen-circle-hs.html)」にあります。

**0 と ∞ は、対等な二つの極**

<span class="step-mark">見方</span>『信心銘』は、「圓同太虛」の句のあとで、極めて小さいものは大きいものと同じで、極めて大きいものは小さいものと同じだ、とも言います（「極小同大」「極大同小」）。そのあとに「不見邊表」（果てが見えない）と続きます。このページは、この句を、ここまでの球の絵で読みます。

<span class="step-mark step-mark--math">数学では</span>数直線の両はしは、北極の一点で結ばれて閉じ、0 と ∞ は、球の南極と北極に来ます。0 と ∞ を入れ替える変換 z → 1/z は、球を 1 と −1 を通る軸のまわりに半回転させるだけで、球の形を変えません。0 と ∞ は、入れ替えても形の変わらない、対等な二つの極です。二つは向かい合う別の点で、同じ場所ではありません。

<span class="step-mark">見方</span>極めて小さいものと極めて大きいものが同じだ、という句は、この、入れ替えても形の変わらない二つの極と、形が似ています。句の「果てが見えない」を、両はしを北極で結んで閉じた、はしの無い輪に重ねて読むこともできそうです。句そのものは、前の句が時の長短と十方の広さを打ち消すのを受けて、広がりの果てについて言っています。

∞ の極は、ただの遠い所でもありません。章「[数直線を、北極から写した経線の円として見る](#eo-pole)」で見たとおり、北極は光を当てて写している所で、pjdhiro はそこを「私の位置。私からは見えない」と読みました。いちばん大きい極には写している私が、いちばん小さい極には、写した地図の真ん中の 0 があります。

**二つの極のあいだに立つ e**

<span class="step-mark">見方</span>では、その二つの極のあいだで、e は何をしているのでしょうか。章「[回ることが先にあるのかもしれない](#eo-turn)」では、円をまっすぐな一歩で歩き、刻みを限りなく細かくした先に e<sup>iπ</sup> が出てきました。その刻みの中に、0 と ∞ が入っています。pjdhiro は、この一歩を、こう言い表しています。

<strong>pjdhiro の見方：</strong>素朴な言い方では、無限の逆数のようなものをやってるんだよね。もちろん逆数ではないんだけど、逆数っぽいものを使いたい時のやつ。それが無限大とリンクしてる直感なんだと思う。

<span class="step-mark step-mark--math">数学では</span>一歩を小さくするほど、歩数は増えます。歩数が北極（∞）へ向かうとき、一歩は南極（0）へ向かいます。二つを球に置くと、いつも赤道をはさんで、同じだけ北と南に離れて向かい合います。一歩は歩数の逆数なので、北と南を入れ替えた所に来るのです。それでも、一歩と歩数を掛けると、いつも 1（100%）で、1 は赤道の上にあります。その 100% を、育ちながら限りなく細かく重ねた先に出てくるのが e です。e は 2.718… という、限りのある一つの数で、北極にも南極にもいません。

<span class="step-mark">見方</span>だから、e と無限大は、一見すると、逆数どうしのような関係に見えてきます。e は、無限大の逆数のようなもの（限りなく小さい一歩）を、無限大の回数だけ、向かい合わせたまま重ねて作る数だからです。逆数になっているのは歩数と一歩で、e そのものは ∞ の逆数ではありません。

<span class="step-mark step-mark--math">数学では</span>同じ刻み方で、一歩ごとに、今いる点から見て直角の向き（円の接線の向き）に進むと、歩数を限りなく増やした先で、ちょうど単位円の上を歩きます。北極の ∞ と南極の 0 が向かい合う、その真ん中の赤道を、e<sup>iθ</sup> は一周します。

<details><summary>詳しく — 数学の言葉で言うと</summary>

- 歩数 n と一歩 1/n を掛けると、いつも 1。e = lim (1 + 1/n)<sup>n</sup> は、この 1 を n 回に分けて、育ちながら重ねた先の値。
- 平面の正の数 x を球の上に戻すと（写すの逆）、高さ（赤道が 0、北極が 1、南極が −1）は (x² − 1)/(x² + 1) になる。x を 1/x に替えると、高さの符号だけが変わる。だから n と 1/n は、赤道をはさんで向かい合う。n = 2 なら高さ ±0.6、n = 10 なら ±0.98。x = 1 は高さ 0（赤道）。
- 1/z は、球の上では 1 と −1 を通る軸のまわりの半回転で、0 と ∞ を入れ替える。
- 数の表と、絵で追う説明は、「禅の円を、高校の数学で読む」の章「[無限に刻むことは、北極と南極へ同時に向かうこと](zen-circle-hs.html#zh-aha)」にある。

</details>

<a id="eo-role"></a>**e はどんな役割か**

<span class="step-mark">見方</span>ここまでを集めて、このページの読みで、e の役割を六つの問いに当ててみます。右の列の印で、その行が数学で言えることか、見方かを分けます。

<div class="tablefit">

| 問い | 答え | 段 |
|---|---|---|
| 何を | まっすぐな座標（大きさの対数と回った角度）を、円の世界に巻きつける。log は、それをほどく。単位円の上では、肩の数を、そのまま左回りに歩いた道のりにする（底が e のときだけ） | <span class="step-mark step-mark--math">数学では</span> |
| どこで | 船の地図と平面のあいだ。球の上では、南極（0）にも北極（∞）にも着かず、そのあいだの全部で働く | <span class="step-mark step-mark--math">数学では</span> |
| いつ | 歩数が ∞ へ、一歩が 0 へ、赤道をはさんで向かい合ったまま同時に向かった先で出てくる | <span class="step-mark step-mark--math">数学では</span> |
| どうやって | 今の自分を元にした少しを、今の自分に足すことを、限りなく細かくくり返す。足す向きを直角にすると、大きさを変えずに円の上を回る | <span class="step-mark step-mark--math">数学では</span> |
| 誰と誰のあいだで | 写す元の円の世界と、写した先の数直線の側にいる私（北極から写している私）とのあいだの通訳 | <span class="step-mark">見方</span>このページの読み |
| なぜ大切か | 単位円が宇宙の真理かもしれない円だとするなら、e は、その円の上をそのまま歩ける数だから | <span class="step-mark">見方</span>pjdhiro |

</div>

**ただの円ではない円**

<span class="step-mark">見方</span>pjdhiro は、ここで、e が「自然対数の底」と呼ばれることに目を向けています。禅で真理のように説かれてきた円が単位円だとするなら、その円にそのまま触れる e に「自然」の名が付いているのは、素朴なイメージにぴったりかもしれない、という見方です。

ここまで来ると、このページが e の話をしながら、ずっと禅の円を読んでいたことが見えてきます。禅が円で言っていたのが、いちばん小さいものといちばん大きいものを、対等な二つの極として抱える世界の形だとするなら、単位円は、ただの円ではないのかもしれません。単位円を、ただの円だと思っていませんか。pjdhiro は、それが宇宙の真理かもしれない、と見ています。正解として言える話ではなく、開いたままの問いです。

最後に、円を描く話を見ます。『碧巌録』第 33 則では、資福が、訪ねてきた陳操を見るなり、一つの円を描きます。陳操はそれを、来ただけでもう外れているのに、そのうえ円まで描くとは、と退けます。資福は、方丈の戸を閉めます。円を描いて示すことと、その円を退けることが、一つの則の中に並んでいます。このページが球と数直線で重ねてきた読みも、円に重ねた言葉の一つです。

最初の問いに戻ります。禅の円と単位円が似ているのは、どちらも、いちばん小さいものといちばん大きいものを、入れ替えても形の変わらない対等な二つの極として、はしの無い一つの輪に抱える形だから、というのがこのページの見立てです。碧巌録第 33 則は、その輪に言葉を重ねること自体を、もう一度問い直させます。

そして、問いが一つ残ります。e が「自然対数の底」と呼ばれるようになった由来は、何だったのでしょうか。円の側から e を見てきたあとでは、その名前にも、ちょっと問いが立ちます。

自然対数は、歴史の上では、円ではなく双曲線（y = 1/x の曲線）の下の面積から見つかった、と言われます。そう聞いて、pjdhiro はこう問いました。

<strong>pjdhiro の問い：</strong>それは、最初から、平面を扱う道具だったんじゃ。円の平面と直交する軸を扱うための。虚軸のような。

双曲線から「自然」と呼ばれた数が、なぜ円の上でこれほど働くのでしょうか。その数は、はじめから、円の平面と、それに直交する軸を扱う道具だったのでしょうか。この問いも、開いたまま置きます。

<details><summary>詳しく — 円と双曲線</summary>

- 1 から a までの、双曲線 y = 1/x の下の面積は ln a（底が e の対数）になる。
- 円 x² + y² = 1 と双曲線 x² − y² = 1 は、y を iy に替えると、互いに移り合う。
- 双曲線の側の cosh と sinh は、肩に iθ を入れると円の側に移る：cosh(iθ) = cos θ、sinh(iθ) = i sin θ。

</details>

<details><summary>出典</summary>

- 『信心銘』（伝・僧璨）。大正蔵 T48 no.2010。「極小同大　妄絕境界　極大同小　不見邊表」は [0377a05〜a06](https://cbetaonline.dila.edu.tw/zh/T48n2010_p0377a05)（CBETA の本文で照合。「妄絕境界」の「妄」は大正蔵の字で、校注の甲本は「忘」。日本で広く読まれる本文は「忘絶境界」）。すぐ前の句は「一念萬年」「十方目前」で、時の長さと十方の広さを分けずに語る。
- 『碧巌録』第 33 則「陳操尚書看資福」。大正蔵 T48 no.2003 巻 4、[0172a17〜a20](https://cbetaonline.dila.edu.tw/zh/T48n2003_p0172a17)（CBETA の本文で照合）。資福が円を描き、陳操がそれを退け、資福は方丈の戸を閉める。

</details>

## exp の説明書に、省かれていたものを書き足す

<!--OPEN-->

<a id="eo-help"></a><span class="step-mark">見方</span>ここまで見てきたものを、プログラムの説明書の形にまとめ直します。等式を一つずつ見ていったあとで、pjdhiro はオイラーの等式をこう見ています。

<strong>pjdhiro の見方：</strong>こうやってみるとオイラーの等式は、クリーンすぎてリーダブルさがないよね。オイラーはその一行だけを示したわけではないだろうけど、後世の人がそこだけ切り取ってしまった。関数の宣言のように、入出力の型だけがあって、内部が分かってないし、使い所も分かってない。

<strong>pjdhiro の見方：</strong>ライブラリに一行、関数名と引数と戻り値の型だけあってもね。何に使うのか help が欲しい。

<span class="step-mark">見方</span>プログラムの関数には、何を受け取り何を返すかの宣言と、使い方を書いた説明書（help）が付いています。オイラーの等式は、exp という関数に iπ を入れると −1 が返る、という一行にあたります。

<span class="step-mark step-mark--math">数学では</span>数学のライブラリにも、e<sup>z</sup> を計算する関数 exp があり、説明書（help）が付いています。中身の厚さはライブラリでまちまちです。Python の cmath.exp は一行だけです。NumPy の exp には、複素数を大きさと位相に分ける説明と、図の例があります。Wolfram Language の Exp には、周期・応用・よくある落とし穴まで並んでいます。見た範囲では、厚い説明書にも、回す軸や掛ける順番は書かれていません。

そうした厚めの説明書によく書かれている中身に、このページで見えるようにしたものを書き足した exp の説明書は、「[人類の man](man.html#man-exp)」に置いています。<span class="help-add">色の付いた行</span>が、このページで見えるようにしたもの（回す軸・掛ける順番・二周で戻る回し手・球の上で・地図で読むと ほか）を書き足した所です。

<p class="man-import-wrap"><a class="man-import" href="man.html#man-exp" data-import="man.html#man-exp-doc" data-import-title="exp(z) の説明書（人類の man）">exp の説明書を開く</a></p>

<span class="step-mark">見方</span>書き足した行の多くは、平面の上だけで使う限り、書かなくても困らないものです。書かなくても困らないからか、説明書には書かれにくいようです。オイラーの等式の一行でも、省かれています。立体へ持っていくと、省かれていたものが、四元数の式の中に出てきます。軸は引数として、順番と二周は式の形として出てきます。色の無い行だけでも exp は使えますが、なぜそうなるか、平面の外でどう使うかは、色の付いた行に書かれています。

<details><summary>出典</summary>

- Python 3 の `cmath.exp` の説明（docstring）は「Return the exponential value e\*\*z.」の一行（手元の Python で確かめた）。
- NumPy の `exp` の説明は、ソースの [ufunc_docstrings.py](https://github.com/numpy/numpy/blob/main/numpy/_core/code_generators/ufunc_docstrings.py) にある。Notes の欄で、複素数の入力を e^a と e^{ib} に分け、e^{ib} = cos b + i sin b を大きさ 1 で周期的な位相と書き、複素平面の上の大きさと位相を描く例を載せている。

- 「人類の man」の exp の説明書は、これらを書き写したものではなく、よく書かれる中身をまとめ直したもの。

## 補足：地球儀・平面・船の地図の、三つの世界

<a id="eo-fold3"></a><span class="step-mark step-mark--math">数学では</span>章「[e・π・√ も、0 と ∞ も、円の世界を数直線の側で扱うための記号かもしれない](#eo-axes)」で描いた e の巻きつけ方は、地球儀の上の経度と緯度でも描けます。

平面の点 z = re<sup>iθ</sup> を log でほどくと、log z = log r + iθ になります。地球儀の上の点で言えば、経度 θ がそのまま横の座標に、緯度が縦の座標 log tan(π/4 + 緯度/2) になります。これは、航海の地図で使われてきたメルカトル図法の縦の座標と同じ式です。このページでは、この地図を船の地図と呼びます。船の地図では、大きさの対数 log r を縦に、回った角度 θ を横に描きます。ふつうの複素平面の描き方（実の部分が横、虚の部分が縦）とは、縦と横が入れ替わっています。こうして、同じ点が三つの世界に置かれます。

## 補足：立体の回転と並べると

<a id="eo-quat"></a><span class="step-mark step-mark--math">数学では</span>章「[四元数から平面へ：二つの向きを 0 に置くと、複素数を掛ける回転と同じ回転が出てくる](#eo-fold4)」の続きです。四元数で回す式と、二つの向きを 0 に置いて並べた対比の表、その場で動かせる計算、二周で戻る回し手とスピン、行列での書き方を置きます。

**立体の回転は、数で挟んで書く**

四元数の掛け算は、順番を入れ替えると答えが変わることがあります（i と j を掛けると k、j と i を掛けると −k）。ただし、実の部分の数（ふつうの実数）は、どの四元数と掛けても、順番で答えが変わりません。順番で答えが変わるのは、向きの違う虚の向きどうしを掛けたときだけです。

立体の中の点 v を、軸 u のまわりに角度 θ だけ回すには、点を xi + yj + zk の形に置き、q = e<sup>uθ/2</sup> という数で前と後ろから挟みます。

<p>v' = q v q<sup>−1</sup></p>

q<sup>−1</sup> は q の逆数です。挟むと、軸の向きの成分はそのまま残り、軸と直角な成分だけが角度 θ だけ回ります。q は、e の肩（指数）に、軸 u と、回したい角度の半分 θ/2 を乗せた数です。軸と直角な成分は、前から q を掛けて半分、後ろから q<sup>−1</sup> を掛けてもう半分回り、合わせて θ になります。

物理では、同じ回転を、パウリ行列という三つの 2 行 2 列の行列で書きます。電子のスピンの向きを回すときの書き方です。四元数の i・j・k を、パウリ行列 σ<sub>x</sub>・σ<sub>y</sub>・σ<sub>z</sub> にそれぞれ −i を掛けたものに置き換えると、掛け算の決まりがそっくり同じになります。だから、物理の U v U<sup>†</sup>（U<sup>†</sup> は U の逆にあたる行列）は、四元数の q v q<sup>−1</sup> と同じ形をしています。

<details><summary>詳しく — 四元数の掛け算の決まりと、パウリ行列との対応</summary>

四元数の掛け算の決まりは、次のとおりです。i² = j² = k² = −1、ij = k、jk = i、ki = j、ji = −k、kj = −i、ik = −j。

パウリ行列は、σ<sub>x</sub> = [[0, 1], [1, 0]]、σ<sub>y</sub> = [[0, −i], [i, 0]]、σ<sub>z</sub> = [[1, 0], [0, −1]] です（[a, b] は行列の一つの行）。四元数の 1 を 2 行 2 列の単位行列 I に、i・j・k を −iσ<sub>x</sub>・−iσ<sub>y</sub>・−iσ<sub>z</sub> に置き換えて計算すると、上の決まりがすべて成り立ちます。このページでは、置き換えたものどうしを掛けて、全部の組で確かめました。

軸 k のまわりを角度 θ 回す q = e<sup>kθ/2</sup> は、行列では U = [[e<sup>−iθ/2</sup>, 0], [0, e<sup>iθ/2</sup>]] になります。点 σ<sub>x</sub>（四元数の i にあたる）を U σ<sub>x</sub> U<sup>†</sup> と挟むと、cos θ σ<sub>x</sub> + sin θ σ<sub>y</sub> になり、i が j の向きへ角度 θ だけ回ったことになります。

</details>

<details><summary>詳しく — 回す式の前提（実の部分を 0 と置くこと、q と −q）</summary>

v' = q v q<sup>−1</sup> は、点 v の実の部分を 0 と置いて使う式です。実の部分は、q と順番を入れ替えても同じなので、挟むと q と q<sup>−1</sup> が打ち消し合い、動きません。軸の向きの成分も、同じ理由で動きません。

q と −q は、同じ回転を表します。挟むと符号が二回出て、打ち消し合うからです。だから、回す数 q の側は、立体が一周（θ = 2π）しても −1 になるだけで、もとの 1 に戻るのは二周（θ = 4π）したときです。電子のスピンの状態が、二回転（4π）でやっと元の符号に戻ると言われるのは、この性質のことです。向きそのものは一周で戻ります。

</details>

この書き方には、平面の回転を e<sup>iθ</sup> で書いたときには見えなかった部品が出てきます。回す軸 u、角度を半分ずつ前と後ろに分けること、掛ける順番、それに、二周してやっと元に戻る回す数 q（上の畳み）です。続けて、四元数の二つの向きを 0 に置いてオイラーの側と並べ、この四つが等式の中ではどこへ行ったのかを見ます。

<a id="eo-pair"></a>**二つの向きを 0 に置いて、オイラーの側と並べる**

四元数の w・i・j・k の四つの向きのうち、二つを 0 に置くと、平面が一枚残ります。そこでは、e<sup>iθ</sup> を掛けるのと同じ回転が書けます。


どの二つを 0 に置くかで、残る平面が変わります。挟む式 q v q<sup>−1</sup> は、実の部分を 0 と置いて使う式です。だから、この式でオイラーの等式と並べるには、実の向きを含まない平面を残します。ここでは、実の部分 w と k を 0 に置いて、i と j の平面を残し、軸を k にします。

両側に同じ項目を並べると、次のようになります。

<div class="tablefit">

| 項目 | オイラーの等式の側（複素平面） | 四元数の側（i と j の平面） |
|---|---|---|
| 平面の点 | x + iy | xi + yj |
| 横の向き | 1 | i |
| 縦の向き | i | j |
| 回す軸 | 式には出てこない（※） | k |
| 回す式 | e<sup>iθ</sup> を片側から掛ける | e<sup>kθ/2</sup> と e<sup>−kθ/2</sup> で前と後ろから挟む |
| 回したあとの点 | (x cos θ − y sin θ) + i (x sin θ + y cos θ) | (x cos θ − y sin θ) i + (x sin θ + y cos θ) j |
| 半周（θ = π） | e<sup>iπ</sup> = −1 を掛ける。1 は −1 に着く | e<sup>kπ/2</sup> = k で挟む。i は −i に着く |

</div>

※ オイラーの側の回す軸は、平面に直交する奥行きの向き（z の向き）です。複素数には、その向きを書く場所がありません。

回したあとの点は、横の向きの名前と縦の向きの名前が違うだけで、同じ数が並びます。たとえば x = 0.3、y = 0.9、θ = 0.7 では、どちらも横が −0.3503、縦が 0.8816 になります。

function mul(a, b) {
  const [a0, a1, a2, a3] = a, [b0, b1, b2, b3] = b;
  return [
    a0 * b0 - a1 * b1 - a2 * b2 - a3 * b3,
    a0 * b1 + a1 * b0 + a2 * b3 - a3 * b2,
    a0 * b2 - a1 * b3 + a2 * b0 + a3 * b1,
    a0 * b3 + a1 * b2 - a2 * b1 + a3 * b0,

}

const x = 0.3, y = 0.9, theta = 0.7;

// オイラーの側：e^{iθ} を x + iy に片側から掛ける

<a id="eo-parts"></a>二つの式は同じ点に着きます。本文の章で挙げた四つの部品のうち、最後の「二周で戻る回し手」を、もう少し見ます。

四つのうち最後の「二周で戻る回し手」は、角度を半分にした形をしています。回す数 q = e<sup>kθ/2</sup> を 2 回掛けると、q<sup>2</sup> = e<sup>kθ</sup> になります。q は、2 回掛けると e<sup>kθ</sup> になる二つの数（もう一つは −q）の一つで、e<sup>kθ</sup> の角度を半分にした数です。立体の回転は、q を前と後ろから挟んで（q v q<sup>−1</sup>）、半分ずつ受け持って角度 θ 回します。だから、回されるものが一周（θ = 2π）して元に戻ったとき、q 自身は半分の所 e<sup>kπ</sup> = −1 にいます。二周してやっと 1 に戻ります。

pjdhiro は、この形について、こう話しています。

<strong>pjdhiro の見方：</strong>一周まわると半分回る、というルートの感じは、おそらく本質を指してると思うので、抱持したいね。電子のスピンも関係するんでしょ？

<span class="step-mark step-mark--math">数学では</span>電子のスピンにも、同じ形の数学が出てきます。物理では、電子のスピンの状態に掛かる回転の行列が、この形をしています。上の畳み「四元数の掛け算の決まりと、パウリ行列との対応」にある U = [[e<sup>−iθ/2</sup>, 0], [0, e<sup>iθ/2</sup>]] は、θ = 2π で −I になります。スピンの向きは一周で元に戻りますが、状態には −1 が掛かり、4π でやっと I に戻ります。それでも、U と −U は、挟んで回したときに同じ回転になります。立体の回転一つに、回す行列が二つずつ対応しているので、数学では、回す行列の集まり（SU(2)）が、立体の回転（SO(3)）を二重に覆う、と言います。行列の計算は、確かめられる数学の事実です。電子のスピンの回転がこの行列で書けることは、量子力学の教科書の事実です。

<span class="step-mark">見方</span>一周で半分しか回らない、という形が、何の本質を指しているのかは、このページでは問いとして置きます。

<details><summary>詳しく — 実の向きを含む平面で並べると</summary>

オイラーの等式と同じ平面（w + iy の平面。j と k を 0 に置く）を四元数の中に残すこともできます。この平面は実の向きを含むので、挟む式 q v q<sup>−1</sup> では動きません。q = e<sup>iθ/2</sup> で挟むと、点 0.3 + 0.9i は 0.3 + 0.9i のまま残ります。

この平面を回すには、q<sup>−1</sup> でなく、同じ q で両側から挟みます。e<sup>iθ/2</sup> z e<sup>iθ/2</sup> = e<sup>iθ</sup> z で、オイラーの側と同じ点に着きます（0.3 + 0.9i は、θ = 0.7 で −0.3503 + 0.8816i）。

逆に、同じ q で両側から挟む式は、j と k の平面を動かしません。q で前と後ろから挟む二つの式は、同じ q を使いながら、別々の平面を回しています。

</details>

<details><summary>詳しく — 片側から一回掛けると、もう一枚の平面も回る</summary>

オイラーの側の「e<sup>iθ</sup> を片側から掛ける」ことを、四元数の全体に当ててみます。すると、1 と i の平面が角度 θ 回るのと同時に、j と k の平面も同じ角度 θ だけ回ります。たとえば、j に e<sup>iθ</sup> を前から掛けると、cos θ j + sin θ k になります。j と k を 0 に置いた平面の上では、この二枚目の平面の回転は見えません。

片側から一回掛けるという一番素朴な書き方が、四元数の中では、二枚の平面を同時に回す働きになっています。<span class="step-mark">見方</span>オイラーの等式は、その二枚目を見えない所に置いた形だ、と読むこともできそうです。

</details>

<details><summary>詳しく — 四元数の側も、行列で書くと −I に着く</summary>

章「[禅の円と、オイラーの等式は似ていないか](#eo-read)」の畳みで、e<sup>iπ</sup> + 1 = 0 は、行列では −I + I = O でした。

四元数の側も、パウリ行列で 2 行 2 列の行列にすると、同じ所に着きます。e<sup>kπ</sup> も −I になります。i と j の平面の点 xi + yj は、行列では −i [[0, x − iy], [x + iy, 0]] になり、左下の角にオイラーの側の点 x + iy がそのまま入っています。これを U で挟むと、左下の角が e<sup>iθ/2</sup> (x + iy) e<sup>iθ/2</sup> = e<sup>iθ</sup>(x + iy) に変わります。

U = [[e<sup>−iθ/2</sup>, 0], [0, e<sup>iθ/2</sup>]] で [[0, a*], [a, 0]] を挟む（a* は a と虚の部分の符号だけ違う数）と、左下の角は e<sup>iθ/2</sup> × a × e<sup>iθ/2</sup> になります。複素数どうしは順番を入れ替えても同じなので、これは e<sup>iθ</sup> a です。右上の角は e<sup>−iθ</sup> a* です。

挟む式 q v q<sup>−1</sup> を行列にすると、その中で、オイラーの掛け算が、同じ数を両側から半分ずつ掛ける形で行われています。上の「実の向きを含む平面で並べると」の畳みで見た、同じ q で両側から挟む式が、ここに入っています。

</details>

## 補足：次元という言葉も、一つの意味ではない

<a id="eo-dim"></a><span class="step-mark">見方</span>円の世界を数直線の側で扱う記号の話をしていると、そもそも「次元」とは何かが揺れてきます。このページの構成を考えていたとき、pjdhiro はこう言っています。

<strong>pjdhiro の問い：</strong>そもそも次元という概念も、だいぶ誤解されてる可能性あるよね。ジュリア集合の次元数とか、違いそうだもんね。

<span class="step-mark step-mark--math">数学では</span>次元という言葉には、少なくとも二つの使われ方があります。一つは、場所を言うのに数がいくつ要るか、です。数直線は 1 つ、平面は 2 つ、立体は 3 つです。もう一つは、細かく見ていったとき、形がどれだけ増えるか、です。線を半分の大きさの升目で数え直すと、升目の数は 2 倍に、面なら 4 倍になります。何倍になるかを 2 の何乗かで書くと、その指数が次元です。

二つの使われ方は、いつも同じ数になるわけではありません。たとえば、線分を三等分して真ん中を山形に折る操作を、限りなくくり返した曲線（コッホ曲線）は、大きさを 1/3 にすると同じ形が 4 つ並びます。4 = 3<sup>d</sup> から、d はおよそ 1.26 です。線より込み入っていて、面より薄い形です。

ジュリア集合の縁も、同じように測れます。c = 0 のときの縁は、半径 1 の円で、次元は 1 です。c = −1 のときの縁を、このページで細かい升目で数えて見積もると、およそ 1.23 になりました。c = −0.123 + 0.745i でも、1.1 から 1.2 ほどで、どちらも整数になりませんでした。知られている値は、c = −1 でおよそ 1.268、c ≈ −0.1226 + 0.7449i（ドゥアディのウサギと呼ばれる形）でおよそ 1.393 です。升目の見積もりは、整数でないことを見るためのもので、次元の値としては読めません（下のやり方）。

数の個数で数えた次元も、一つの決まりではありません。複素平面に一点 ∞ を足すと、球の表面になります。四元数は四つの数で書きますが、大きさ 1 の四元数を集めると、四つの向きの中の、三次元の球の表面になり、それが立体の回転を書きます。何次元の世界の話をしているのかは、何を数えたかで変わります。

<b>ジュリア集合の縁を、升目で数えたやり方</b>

c = −1 のジュリア集合の縁の点を、逆向きのくり返し（z から ±√(z − c) を選ぶことをくり返す）で 60 万個ほど集めました。平面を、一辺が 4/2<sup>k</sup> の升目に分け、点が入る升目を数えます。k を 6 から 9 まで細かくしていったとき、升目の数がどれだけ増えるかの傾きを取ると、およそ 1.23 でした。同じやり方で c = 0 を数えると 1.01 で、円の 1 に合います。

この数え方では、逆向きのくり返しで集めた点が縁の一部に偏るので、次元ははっきり低く出ます。ウサギでは、知られた値より 0.2 以上低く出ました。

<details><summary>出典</summary>

## このあとに読むもの

<a id="eo-more"></a>e<sup>iθ</sup> が円の上を回る点であること、e<sup>iπ</sup> + 1 = 0 の五つの数は、独立ページ「[オイラーの式](euler-formula.html)」にあります。−1 から i へ、回る掛け算を数直線から一歩ずつ見る説明は、読み物「[回転の掛け算](rotation-multiplication.html)」にあります。禅の円の章を、高校の数学の言葉で、絵と言葉で追う解説は、「[禅の円を、高校の数学で読む](zen-circle-hs.html)」にあります。

円が真理のように扱われる話は、ジュリア集合の読み物の円の雲（いろいろな c のジュリア集合の縁の点が重なって、半径 2 の線の内に作る雲）にもつながります。円の雲と、起業家の漸化式は、読み物「[起業家の漸化式と、ジュリア集合](julia-potential.html#jp-cloud)」にあります。

複素数が関わるほかの数学は、目次「[複素平面で考える](complex-plane.html)」に並べています。
