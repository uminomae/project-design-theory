# 直交する軸を扱っている道具たち

<div class="reader-lead glow-card" id="oa-gist"><span class="reader-lead__label">ざっくりいうと</span>
<p>数学や物理には、まっすぐな数の線（数直線）だけでなく、それと直角に交わるもう一本の軸を扱う道具がいくつもあります。複素数の虚軸、四元数の三つの虚の軸、時間と空間の平面、交流の回る矢印、位置と運動量の平面などです。このページは、そうした道具を、素朴な言葉の一行と、数学の一行の二段で並べます。</p>
<p>始まりは、e が「自然対数の底」と呼ばれる由来を聞いた pjdhiro の問いです。自然対数と e は、はじめから、円の平面と直交する軸を扱う道具だったのではないか。原典で照らすと、「自然の」という名は双曲線の面積から付き、円や虚数と結ばれたのは、名が付いたあとでした。数学では、直角の向きを生むのは i で、e は、その向きへ回る速さをちょうど 1 にする底です。問いは開いたまま置きます。</p>
</div>

<p class="reader-summary__title">概要</p>

このページは、pjdhiro の問いに、Claude が原典と数学で確かめて答える形で作っています。段の頭に、<span class="step-mark">見方</span>（pjdhiro の問いと、このページの読み）、<span class="step-mark step-mark--math">数学では</span>、<span class="step-mark step-mark--math">歴史では</span>の印を付けて書き分けます。道具の一覧の「素朴な言葉」の行は、数直線から入らない人のために Claude が書いた言い直しで、数学の言い切りではありません。原典の訳は Claude です。

「直交」には、道具ごとに違う意味があります。ふつうの直角（ユークリッドの直交）のほかに、時間と空間の直交（ミンコフスキーの直交）、位置と運動量の対（シンプレクティックの対）、関数どうしの直交があります。一覧では、どの意味の直交かも書きます。

i を掛けると 90 度回ること、−1 を掛けると 180 度回ることのおさらいは、読み物「[回転の掛け算](rotation-multiplication.html)」と「[三角関数から複素平面まで、回転を扱うための角度の話だった](angle-rotation.html)」にあります。

## 問いの始まり：「自然」の名を聞いて

<!--OPEN-->

<a id="oa-start"></a>読み物「[オイラーの等式が、たたんだもの](euler-unfolded.html)」の結びには、e が「自然対数の底」と呼ばれるようになった由来は何だったのか、という問いが残っています。その由来を Claude が調べ、自然対数は双曲線 y = 1/x の下の面積から見つかった、と答えたところで、pjdhiro はこう問いました。

<strong>pjdhiro の問い：</strong>それは、最初から、平面を扱う道具だったんじゃ。円の平面と直交する軸を扱うための。虚軸のような。

続けて、pjdhiro は、この問いをどういう区分で見ていくかを話しています。

<strong>pjdhiro の見方：</strong>直交する軸を扱ってる道具たち、という区分で見ていくのはとても大事なんです。数直線的世界観が馴染まない人たちのためにも。

このページは、この区分で道具を並べます。あわせて、問いの足場になる事実を、歴史と数学の二つの側から並べます。歴史の側では、名を付けた人たちが、円や直交する軸のことを書いていたかを見ます。数学の側では、e と i が、それぞれ何をしているかを見ます。

## 「自然の」対数は、双曲線の面積から名が付いた

<!--OPEN-->

<a id="oa-name"></a><span class="step-mark step-mark--math">歴史では</span>原典で照らせた順に並べます。

- 最初の対数は、ネイピア（1614）が、円の正弦に付けた数でした。定義は「各正弦の対数とは…の数である」で、表は正弦と対数を並べた列でできています。虚数は出てきません。
- そのあと、双曲線の下の面積が、対数の働きをすることが見つかります。サン＝ヴァンサン（1647）は、漸近線の上の区切りが等比なら、双曲線の切片の面積は等しくなる、と示しました。ド・サラサ（1649）は、その面積が「対数の代わりになりうる」と書きました。
- 「自然の」対数という呼び名は、メルカトル（1668）の補足に、「自然の対数を表の対数に直す小表」として出てきます。「自然の」は、10 を底とする「表の」対数と対にした語でした。同じ年に、コリンズはグレゴリーの本を紹介する文で「双曲線の対数」と書いています。
- オイラーは、e を「双曲線対数が 1 になる数」と書きました（1731 年の手紙と『力学』1736）。『無限解析序説』（1748）の §122 では、この底の対数は、双曲線の求積を表せるので「自然の、すなわち双曲線の対数」と呼ばれる、と書いています。

<span class="step-mark step-mark--math">歴史では</span>名を付けた人たちの本文の、照らした箇所には、円や虚数への言及は見当たりません。円と自然対数を虚数で結ぶ文は、名が付いたあとに出てきます。

- ヨハン・ベルヌーイ（1702 年の手紙）は、「虚の対数は、実の円の扇形と取るべきだ」と書きました。
- コーツ（1714）は、円の弧を、虚の比の「測り」に √−1 を掛けたもので表しました。その直前に「説明のつかない仕方で」と添えています。今の式で書けば、ix = ln(cos x + i sin x)（主値で）にあたります。
- オイラーは、『無限解析序説』の §138 で、e<sup>+v√−1</sup> = cos v + √−1 sin v と書きました。§122 で置いた自然の対数の底 e を、同じ本の中で、円の正弦と余弦に結んだことになります。

<span class="step-mark">見方</span>pjdhiro の問いの「最初から」は、二通りに読めます。一つは、名を付けた人が、そう意図していたか。もう一つは、道具そのものが、もともとそういう性質を持っていたか。前の読みには、上の順のとおり、照らした範囲で出典が見当たりません。後の読みには、次の二つの章の数学があります。どちらの読みで問いを抱えるかは、開いたままにします。

## 円と双曲線は、y を iy に替えると移り合う

<!--OPEN-->

<a id="oa-hyper"></a><span class="step-mark">見方</span>自然対数が双曲線の面積から見つかったのなら、それは、はじめから平面の図形を扱う道具だったのかもしれません。円と双曲線を、同じ項目で並べてみます。

<span class="step-mark step-mark--math">数学では</span>円の式 x² + y² = 1 の y を iy に置き換えると、双曲線の式 x² − y² = 1 になります。二つは、次のように同じ形で並びます。

<div class="tablefit">

| 項目 | 円 | 双曲線 |
|---|---|---|
| 式 | x² + y² = 1 | x² − y² = 1 |
| 曲線の上の点 | (cos θ, sin θ) | (cosh u, sinh u) |
| 原点と結んだ扇形の面積 | θ/2 | u/2 |
| θ と u の呼び名 | 円の角 | 双曲線の角 |
| 互いへの移り方 | cos(iu) = cosh u、sin(iu) = i sinh u | cosh(iθ) = cos θ、sinh(iθ) = i sin θ |

</div>

双曲線 y = 1/x の下の、1 から t までの面積は ln t です（t > 1。0 < t < 1 では、向きを付けた面積として負の値になります）。この面積とそのまま一致するのは、底を e に取った対数だけです。底が b なら、log<sub>b</sub> t = ln t / ln b で、面積の 1/ln b 倍になります。

y = 1/x を、直線 y = x で折り返してから時計回りに 45 度回し、長さを 1/√2 倍にすると、x² − y² = 1 の双曲線になります。そのとき、y = 1/x の上の点 (t, 1/t) は、(cosh(ln t), sinh(ln t)) に移ります。つまり、y = 1/x の下の面積 ln t が、そのまま双曲線の角 u になります。円で、扇形の面積の二倍が角 θ になるのと、同じ形です。

円の側でも、同じ自然対数が、ln(cos θ + i sin θ) = iθ（主値、−π < θ ≤ π）として、円の角を測ります。自然対数は、双曲線の角と円の角を、どちらも余分な定数なしに測る対数です。

<span class="step-mark step-mark--math">歴史では</span>この二つ（双曲線の角と円の角を、同じ対数が測ること）が一つの式で結ばれたのは、前の章で見たとおり、名が付いたあとでした。

<details><summary>詳しく — y = 1/x を回して、x² − y² = 1 にする</summary>

- xy = 1 では、原点と (1, 1)・(t, 1/t) を結んだ扇形の面積は、曲線の下の面積 ln t に等しい（両端の三角形の面積はどちらも 1/2 で、打ち消し合う）。
- xy = 1 を時計回りに 45 度回すと X² − Y² = 2 になる。さらに長さを 1/√2 倍に縮めると x² − y² = 1 になる（面積は 1/2 倍）。回すだけだと、点 (t, 1/t) は (cosh(ln t), −sinh(ln t)) に来る。先に直線 y = x で折り返しておくと、(cosh(ln t), sinh(ln t)) に来る。折り返しで変わるのは角の向き（符号）だけで、面積の大きさは変わらない。
- 折り返して回して縮めると、点 (t, 1/t) は x = (t + 1/t)/2、y = (t − 1/t)/2 に移る。これは cosh(ln t)、sinh(ln t) そのもの。
- 縮めたので面積は 1/2 倍になり、扇形の面積は (ln t)/2 になる。双曲線の扇形の面積は u/2 なので、u = ln t。
- 円の側の ln(cos θ + i sin θ) = iθ は、主値（−π < θ ≤ π）で取ったとき。θ に 2π を足しても同じ点なので、複素数の対数は 2πi ごとに値が並ぶ。

</details>

<details><summary>詳しく — この計算を、その場で動かして確かめる</summary>

面積を細かい台形で足して ln t と比べ、点 (t, 1/t) を折り返して回して縮めた先が cosh(ln t)・sinh(ln t) と同じになるかを見ます。

<div class="code-run">

```
// 1 から t までの、y = 1/x の下の面積を、細かい台形で足す
const area = (t, n = 100000) => {
  let s = 0;
  const h = (t - 1) / n;
  for (let k = 0; k < n; k++) {
    const x0 = 1 + k * h, x1 = x0 + h;
    s += ((1 / x0 + 1 / x1) / 2) * h;
  }
  return s;
};
for (const t of [2, 5, 10]) {
  // 点 (t, 1/t) を、直線 y = x で折り返し、時計回りに 45 度回し、1/√2 倍に縮めた先
  const x = (t + 1 / t) / 2, y = (t - 1 / t) / 2;
  console.log("t =", t,
    "| 面積", area(t).toFixed(6), "ln t", Math.log(t).toFixed(6),
    "log2 t", Math.log2(t).toFixed(6),
    "| x² − y²", (x * x - y * y).toFixed(6),
    "| x", x.toFixed(6), "cosh(ln t)", Math.cosh(Math.log(t)).toFixed(6),
    "| y", y.toFixed(6), "sinh(ln t)", Math.sinh(Math.log(t)).toFixed(6));
}
```

</div>

</details>

## 直角を生むのは i で、e は回る速さを 1 にする

<!--OPEN-->

<a id="oa-role"></a>円にも双曲線にも e が出てくるなら、直交する軸を立てているのは e なのでしょうか。e と i が、それぞれ何をしているかを分けて見ます。

<span class="step-mark step-mark--math">数学では</span>e<sup>iθ</sup> を θ で微分すると、i e<sup>iθ</sup> になります。動く向きは、今の位置に i を掛けた向き、つまり位置から 90 度回した向きで、速さは 1 です。e<sup>iθ</sup> は、単位円の上を速さ 1 で回ります。

底を b（b > 0、b ≠ 1）に替えると、b<sup>iθ</sup> = e<sup>iθ ln b</sup> になります（主値で取ったとき）。これも単位円の上を回りますが、速さは |ln b| です。左回りに速さ 1 で回る底は、e だけです（1/e は、逆回りに速さ 1 で回ります）。

e<sup>x + iy</sup> = e<sup>x</sup> · e<sup>iy</sup> と分けると、実の向き x は大きさの伸び縮みに、虚の向き y は回転になります。二つは、直交する二本の軸の上で、別々に働きます。ただし、大きさと回転にこう分かれることは、どの底 c > 0（c ≠ 1）でも起きます。c<sup>x + iy</sup> = c<sup>x</sup> · c<sup>iy</sup> と分かれ、回る角が y ln c になるだけです。

対数は掛け算を足し算に替える、片対数のグラフで指数の曲線が直線になる、という一般によく知られた働きも、底が 2 でも 10 でも成り立ちます。底の違いは、定数倍だけです。e だけに起きるのは、目盛がちょうど 1 にそろうことです（eˣ の傾きが x = 0 でちょうど 1）。円の上を回る速さが 1 になることも、双曲線の角が u = ln t になることも、同じ「目盛が 1 にそろう」ことの表れです。

まとめると、直角の向きを生むのは、e ではなく i です。e の指数関数は、i を掛けることを、なめらかな流れに変えます。e は、その流れの速さがちょうど 1 になる底です。

<span class="step-mark">見方</span>この分担を pjdhiro の問いに当てると、問いは次のように読み直せるかもしれません。これは、このページの読みです。

- 直交する軸を立てたのは i で、e は、その直交する向きへの動きを「1 の速さ」で測る目盛として、i の隣に呼ばれ続けた道具なのではないか。
- 双曲線の面積でも、円の回転でも、e は同じ役（角を、余分な定数なしに測る目盛）をしている。名が付いたのは双曲線の側からだったが、その役は、平面の二つの角（円の角と双曲線の角）を、同じ目盛で測ることだったのではないか。

どちらの読みも、名を付けた人がそう意図していた、とは言えません。意図と、あとからの読みは、分けて置きます。

<details><summary>詳しく — 底を替えたときの回る速さを、その場で確かめる</summary>

b<sup>iθ</sup> = cos(θ ln b) + i sin(θ ln b) として、θ を少し進めたときに単位円の上を進む道のりを、θ の増えで割ります。

<div class="code-run">

```
// 底 b の b^{iθ}（主値）が、単位円の上を回る速さと向き
for (const b of [2, Math.E, 10, 1 / Math.E]) {
  const p = (th) => [Math.cos(th * Math.log(b)), Math.sin(th * Math.log(b))];
  const d = 1e-6;
  const [x1, y1] = p(0), [x2, y2] = p(d);
  console.log("b =", b.toFixed(4),
    "| 速さ", (Math.hypot(x2 - x1, y2 - y1) / d).toFixed(4),
    "| |ln b|", Math.abs(Math.log(b)).toFixed(4),
    "|", y2 > 0 ? "左回り" : "右回り");
}
```

</div>

- 主値でない枝を取ると、b<sup>iθ</sup> には e<sup>−2πnθ</sup>（n は整数）が掛かり、単位円から外れる。
- log z = ln|z| + i arg z（z ≠ 0）。arg は 2π ごとに値が並ぶ（多価）。

</details>

## 縦の単位の性質で、回る・ずれる・引き伸ばされるに分かれる

<!--OPEN-->

<a id="oa-three"></a>前の章で、直角を生むのは i だと見ました。では、i の代わりに、性質の違う縦の単位を置くと、e の何乗かを掛けることの意味はどう変わるのでしょうか。

<span class="step-mark step-mark--math">数学では</span>数 a + b·k の k を一つ決めると、平面の上の掛け算が一つ決まります。k を二乗した数が −1・0・+1 の三通りで、e<sup>kθ</sup> を掛けることの意味が分かれます（三つとも 2 行 2 列の行列にして、数値で確かめました）。

<div class="tablefit">

| k² | 名前 | e<sup>kθ</sup> | 掛けると | 保たれる量 | 「直交」の意味 |
|---|---|---|---|---|---|
| −1 | 複素数（i） | cos θ + i sin θ | 円の回転 | a² + b² | ふつう（ユークリッド）の直交 |
| 0 | 双対数（ε） | 1 + εθ | ずらし（シア）：(a + bε)(1 + εθ) = a + (b + aθ)ε | a² | 直交は無い |
| +1 | 分解型複素数（j） | cosh θ + j sinh θ | 双曲線の回転（相対論のローレンツ変換） | a² − b² | ミンコフスキーの意味の直交（ユークリッドの直交ではない） |

</div>

<b>素朴な言葉：</b>同じ「e の何乗かを掛ける」でも、横に対して縦をどう扱うかで、回る・ずれる・引き伸ばされる、の三つに分かれます。三つ目の「引き伸ばされる」は、斜めの一方へ伸び、もう一方へ同じ割合で縮む動きで、面積は変わりません。どれになるかを決めているのは e ではなく、縦の単位 k の性質です。

<span class="step-mark step-mark--math">歴史では</span>二乗して 0 になる単位を入れたのは、クリフォード（1873）です。クリフォードは、その単位 ω を、回転を「その軸に平行な並進」に変えるものとして書いています。直交ではなく、平行の話でした。

<details><summary>詳しく — 三つを 2 行 2 列の行列で書く</summary>

- a + b·k を、縦に並べた (a, b) と見る。k を掛けることは、k² = −1 なら [[0, −1], [1, 0]]、k² = 0 なら [[0, 0], [1, 0]]、k² = +1 なら [[0, 1], [1, 0]] を掛けることにあたる。
- e<sup>kθ</sup> は、それぞれ [[cos θ, −sin θ], [sin θ, cos θ]]（回転）、[[1, 0], [θ, 1]]（ずらし）、[[cosh θ, sinh θ], [sinh θ, cosh θ]]（双曲線の回転）になる。
- 行列式はどれも 1。保たれる量は、順に a² + b²・a²・a² − b²。

</details>

<details><summary>出典</summary>

- クリフォード「双四元数の素描」（1873）。1882 年の『数学論文集』の再録（p. 181 から）で照らした（[Internet Archive の写し](https://archive.org/details/mathematicalpap00clifgoog)）。

</details>

## 直交する軸を扱っている道具たち

<!--OPEN-->

<a id="oa-tools"></a>pjdhiro の区分で、道具を並べます。どの道具も、素朴な言葉の一行と、数学の一行の二段で書きます。「直交」の意味が道具ごとに違うので、数学の行の終わりに、どの意味の直交かを添えます。作った人が何を書いていたかは、次の章にまとめます。

**1. 複素数と e<sup>iθ</sup>（実軸と虚軸）**

<b>素朴な言葉：</b>まっすぐな数の線に、直角な線をもう一本足します。i を掛けると、向きが 90 度変わります。二回掛けると 180 度で、−1 になります。

<span class="step-mark step-mark--math">数学では</span>i² = −1。e<sup>iθ</sup> = cos θ + i sin θ を掛けると、平面が θ だけ回ります。直交は、ふつう（ユークリッド）の直交です。

**2. 双曲線関数とローレンツ変換（時間と空間）**

<b>素朴な言葉：</b>時間と空間を二本の軸にした平面では、速さを変えることが、円の回転ではなく、双曲線に沿った「引き伸ばしの回転」になります。

<span class="step-mark step-mark--math">数学では</span>光の速さを 1 にとると、t' = t cosh φ − x sinh φ、x' = −t sinh φ + x cosh φ。t² − x² が保たれ、速さは v = tanh φ です。同じ向きの速さの変更を重ねると、φ（ラピディティ）が足し算になります。直交は、ミンコフスキーの意味の直交です。

**3. 四元数と SU(2)（三つの虚の軸）**

<b>素朴な言葉：</b>直角な線を一本でなく三本、互いに直角に立てます。三本どうしの掛け算で、立体の中の回転が書けます。

<span class="step-mark step-mark--math">数学では</span>i² = j² = k² = ijk = −1。単位四元数 q = cos(θ/2) + n sin(θ/2)（n は長さ 1 の純虚の四元数）で、v ↦ q v q⁻¹（v は純虚の四元数）が、軸 n のまわりの θ の回転になります。q と −q は同じ回転を与えます（SU(2) から立体の回転へは、二つが一つに対応します）。q は e<sup>nθ/2</sup> とも書けます。直交は、ふつうの直交です。

**4. フェーザ（交流）**

<b>素朴な言葉：</b>波を、回る矢印の影として見ます。微分は、矢印を 90 度先へ回し、長さを ω 倍にすることです。コイルでは電圧が電流より四分の一周先に、コンデンサでは四分の一周あとになります。

<span class="step-mark step-mark--math">数学では</span>v(t) = Re(V e<sup>iωt</sup>)。時間で微分することは、iω を掛けることです（ω > 0）。理想的なコイルとコンデンサで、ずれは ±90 度になります。インピーダンスは Z = R + iX です（工学では i の代わりに j と書きます）。直交は、ふつうの直交です。

**5. フーリエ変換（時間と周波数）**

<b>素朴な言葉：</b>時間の軸と周波数の軸を直角に置いた平面で、フーリエ変換は、その平面を四分の一回すことにあたります。四回回すと元に戻ります。

<span class="step-mark step-mark--math">数学では</span>ユニタリに規格化すると F⁴ は恒等で、F² は f(t) ↦ f(−t) です。固有値は 1・−i・−1・i です。90 度の回転というのは、ウィグナー分布の上で W<sub>Ff</sub>(t, ω) = W<sub>f</sub>(−ω, t) となる意味で（e<sup>−iωt</sup>/√(2π) の取り方で）、t と ω の目盛をそろえる取り方が前提です。直交は、時間と周波数の平面の直角で、関数どうしの直交（e<sup>iωt</sup> どうし）とは別の意味です。

**6. 位相空間（位置と運動量）**

<b>素朴な言葉：</b>「どこにいるか」と「どれだけの勢いで動いているか」を、二本の軸にした平面です。ばねの振動は、この平面の上で回る点になります。

<span class="step-mark step-mark--math">数学では</span>H = (p² + q²)/2（質量と角振動数を 1 にとる）の解は q = cos t、p = −sin t で、(q, p) の平面を時計回りに回ります。ハミルトンの方程式は d/dt (q, p) = J ∇H で、J = [[0, 1], [−1, 0]] は J² = −I を満たし、時計回りの 90 度の回転（z = q + ip に −i を掛けること）として、i の役をします。直交は、内積の直交ではなく、シンプレクティックの対です。

**7. 直交座標と内積（斜めでなく直角の軸を選ぶ理由）**

<b>素朴な言葉：</b>軸が直角なら、横の量と縦の量を、互いに混ぜずに別々に測れます。軸が斜めだと、片方を測ると、もう片方が少し混ざります。

<span class="step-mark step-mark--math">数学では</span>長さ 1 で互いに直交する基底（正規直交基底）なら、成分は v·e₁・v·e₂ で別々に取れ、長さは √(x² + y²) です。軸の間の角が α の斜めの座標（軸の長さ 1）では、長さは √(x² + y² + 2xy cos α) で、v·e₁ = x + y cos α と成分が混ざります。直交は、ふつうの直交です。

**8. ウィック回転（時間を虚の向きへ回す）**

<b>素朴な言葉：</b>時間の軸を、空間と同じ種類の軸へ 90 度回して、計算しやすくします。

<span class="step-mark step-mark--math">数学では</span>t = −iτ と置くと、e<sup>−iHt</sup> が e<sup>−Hτ</sup> に、t² − x² が −(τ² + x²) に移ります。実の変数を置き換えるのではなく、解析接続として扱います。ミンコフスキーの直交を、ふつうの直交に移す操作です。

**9. ラプラス変換の s = σ + iω（伸び縮みの軸と回転の軸）**

<b>素朴な言葉：</b>育つか減るか（横）と、振れるか（縦）を、一つの平面の二本の軸にします。

<span class="step-mark step-mark--math">数学では</span>e<sup>st</sup> = e<sup>σt</sup> e<sup>iωt</sup>。σ < 0 で減り、σ > 0 で増え、ω の向きは振動です。前の章の e<sup>x + iy</sup> = e<sup>x</sup> · e<sup>iy</sup> を、時間の関数にしたものです。直交は、ふつうの直交です。

**10. 電磁波と、リーマン＝ジルベルシュタインのベクトル（電場と磁場）**

<b>素朴な言葉：</b>光の波（平面波）では、電気の振れと磁気の振れが互いに直角で、進む向きにも直角です。この二つを、一つの複素の量にまとめられます。

<span class="step-mark step-mark--math">数学では</span>真空（電荷と電流が無い所）で F = E + icB と置くと、マクスウェルの方程式のうち回転の二つの式は i ∂F/∂t = c ∇×F の一つに、発散の二つの式は ∇·F = 0 にまとまります。ここの i は空間の軸ではなく、二つのベクトルを束ねる印です。平面波では |E| = c|B| で、電場と磁場は互いに、また進む向きとも、ふつうの意味で直交します。

<details><summary>詳しく — 「直交」の意味の注意</summary>

- 時間と空間（2・8）：ミンコフスキーの直交は、t² − x² で測る直交で、ふつうの直角ではない。w = ict と置くと −c²t² + x² = x² + w² になり、ローレンツ変換は (x, w) 平面の、虚の角 iφ の回転に見える。今はあまり使われない、歴史の上の書き方。
- フーリエ変換（5）：前向きの変換に係数を付けない取り方（∫ f e<sup>−iξx</sup> dx）では、F² = 2π × 反転になる。e<sup>+iξx</sup> の取り方では、W<sub>Ff</sub>(t, ω) = W<sub>f</sub>(ω, −t) になる。固有値の並び (−i)ⁿ は、e<sup>−iξx</sup>/√(2π) の取り方のとき。
- 位相空間（6）：位相空間には、もともと内積が無い。「90 度」と言えるのは、H などで目盛を一つ選んだあと。量子の状態の意味では、位置の基底と運動量の基底は直交の反対で、|⟨x|p⟩| が一定の「互いに偏りのない基底」になる。位置の表示と運動量の表示は、フーリエ変換（e<sup>−ipx/ħ</sup>/√(2πħ)）で移り合う。
- 直交座標（7）：直交していても長さが 1 でなければ、成分は v·e₁/|e₁|² になる。
- 四元数（3）：q v q⁻¹ の回す向きは、軸 n の向きに右ねじを進める向き。

</details>

## 開いたままの問い

<!--OPEN-->

<a id="oa-open"></a><span class="step-mark">見方</span>始まりの問いに戻ります。自然対数と e は、はじめから、円の平面と直交する軸を扱う道具だったのでしょうか。

ここまでで言えるのは、次の二つです。歴史では、「自然の」の名は双曲線の面積から付き、円や虚数と結ばれたのは、名が付いたあとでした。数学では、直角の向きを生むのは i で、e は、その向きへの動きを 1 の速さで測る目盛です。そのうえで、e は、双曲線の角と円の角を、同じ目盛で測っています。問いは、この二つのあいだに開いたまま置きます。

<span class="step-mark">見方</span>このページには、ほかにも開いた問いがあります。

- 直交する軸を扱う道具を、数学と物理の外（心の動きや、人と組織のこと）でも、同じ区分で並べられるか。
- 数直線的世界観が馴染まない人に、どの道具から見せると届きやすいか。
- 「直交」の四つの意味（ふつうの直交・ミンコフスキーの直交・シンプレクティックの対・関数の直交）を、素朴な言葉で、どう言い分けるか。

## このあとに読むもの

<!--OPEN-->

<a id="oa-more"></a>e が単位円の上でなぜこれほど働くのかを、禅の円から探す読み物は「[オイラーの等式が、たたんだもの](euler-unfolded.html)」です。この問いは、その結びの章「[禅の円に戻る](euler-unfolded.html#eo-circle)」で立ちました。

e<sup>iθ</sup> が円の上を回る点であることは独立ページ「[オイラーの式](euler-formula.html)」に、−1 と i の回る掛け算は読み物「[回転の掛け算](rotation-multiplication.html)」にあります。複素数が関わるほかの数学は、目次「[複素平面で考える](complex-plane.html)」に並べています。
