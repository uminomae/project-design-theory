## 追記の決まり

このページは、調べが増えるたびに足していく。

1. **どこに足すか。** 今の部の問いに答える材料なら、その部に章を足す。第一部＝美はどこにあるか（物か、見る人か、脳か）、第二部＝美は考えを動かすか、第三部＝言い当てられないものの美（詩・日本の美の言葉・宗教）。どの部の問いにも当たらない材料が三つ以上たまったら、新しい部の問いを立てる。部を足すときは、冒頭の「構成」と「今の答え」の箇条も同じ作業で直す。
2. **章の形。** 章の頭に、その章が何を見るかの一文。次に読者の今の像（たとえば、…、とよく言われます）と、高校生でも分かる例。答えの段。そのあとに「詳しく」の畳み（原文の鍵の文と外れた例）と「出典」の畳み（`.claude/skills/public-page-review/SKILL.md` §3）。
3. **照合の状態。** 公開文に載せるのは本文照合済のものだけ（`docs/rules/sources.md` §3-3）。読んだ原典は、上の表に一行足し、状態を `sources.md` §3 の語で書く。読めなかったものは「載せなかったもの」に置き、読めたら本文に上げる。辞書・事典の引用は、事典が引いたものと分かる文で書く。
4. **Claude の見立て。** 第四部に置く。原典の要約の章には混ぜない。見立ては pjdhiro の採否が済んでいないものとして書き、採否が決まったら `docs/rules/decisions.md` の「美とは（#167）」の行に写す。
5. **pjdhiro の言葉。** 新しい発言は、上の「pjdhiro の発言」に原文で足し、何への答えかを添える。本文には、カードの前に、その発言がなぜ出たかの文を置く。
6. **入口。** 章を足したら、冒頭の今の答え・要点の表・機械向けの要約（テンプレートの頭の案内・description）と、巻末の「原典と、読む順」・保持論点を、同じ作業で今の本文にそろえる。
7. 足した日と章を、下の「更新の記録」に一行足す。
