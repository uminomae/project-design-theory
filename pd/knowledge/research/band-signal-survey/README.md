## 要約

1. 4.x の「不確かさ＝脅威＝生存の信号」は、複数の研究系譜と一致する。ただし不確かさへのストレス反応は**どの帯でも既定**で、安全の知覚がそれを抑えている、という書き方（Brosschot ら 2016・GUTS）が強い。
2. 5.x と 6.x の差を「努力のある段／努力のない段」として捉える三人称の足場は、瞑想の熟練者研究にある（逆 U 字・予期の段の基線の低下）。**ただし研究はすべて練習時間で人を分けていて、自我発達の段階で分けた研究は見つからなかった**。帯と信号をつなぐ実証は現時点で無い。
3. 熟練者は信号が「鳴らない」のでなく、**予期の段で鳴らず、出来事が来ると強く鳴る**（Lutz ら 2013）。
4. 信頼の信号に一番近い実験は、つながり（手を握る）が不確かな脅威への脳の反応を下げるもの（Coan ら 2006）。ただし相手は見えている。6.5〜7 の「見えない先に確かめずにつながる」とは条件が違う。
5. Panksepp の CARE は**養う側**の系で、受け取って落ち着く側（緒の安定）に近いのは**絆による PANIC/GRIEF の鎮静**。ただし静けさは、安定の静けさと離脱の静けさを区別しない。
6. ネガティブ・ケイパビリティの**キーツ原典は「耐える」「努力」を言っていない**。努力を前提にする読みは Bion の規律と、日本語の受容（帚木 2017 の副題）にある。
7. ポリヴェーガル理論は、信頼の信号の生理学的根拠としては使わない（Grossman & Taylor 2007・Grossman 2023）。
