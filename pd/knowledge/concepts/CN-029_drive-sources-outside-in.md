## 1. 七つの駆動源（外から内へ）

| 駆動源 | 代表する考え方 |
|---|---|
| 外部環境（市場、競争、顧客、利害関係者、より広い環境） | 株主価値の最大化、競争戦略、破壊的イノベーション、マーケティング（コトラー）、ステークホルダー理論、環境学派 |
| 内部の資源 | 資源ベース理論（VRIO） |
| 先に決めた到達点（目標、計画、効率） | 目標管理（MBO）、OKR、経営計画、科学的管理法、リーン生産 |
| 行為と学習 | リーン・スタートアップ、リアル・オプション、創発戦略 |
| 集団の共有（規範、文化、存在意義） | 企業倫理、コンプライアンス、CSR、組織文化、知識創造理論（野中）、パーパス経営 |
| 人の内側（共感、意欲、判断） | デザイン思考、動機づけ理論、合理的選択 |
| 起業家の心（ビジョン、欲、本能） | アントレプレナー学派、エフェクチュエーション |

ページの表には三つめの列「効果的な状況」（〜の限りでの正解）がある。正本はページの MD。

## 2. 読み

- 外から内へ下りていくと、最後は起業家の心に行き着く。ビジョンも、欲も、本能も、駆動源として確かに働いている。
- **Love駆動開発が追っているのは、その心のさらに背後で、心を動かしているもの**（pjdhiro）。目標や意欲や構想そのものは、なぜ発生するのか（CN-028 §2b の構想の 5W1H の「なぜ」）。
- 理論を何十年も更新してきたコトラー（製品 → 顧客 → 人の価値観）と野中郁次郎（SECI → 場 → 賢慮 → 共感経営）の歩みも、同じように人の内側へ進んできたように見える（Claude の読み。年と要旨は照合前）。
- 見渡し方は『戦略サファリ』の作法（十の学派・冒頭の群盲象）に倣う。pjdhiro「戦略サファリを紹介したいし、知ってる人には作法を私が知っていることで安心して欲しい」。
- 群盲象は何度でも繰り返す。一部に触れた言葉が全体を言い当てた言葉として広まると、バズワードになる（pjdhiro「ビジネスワードがバズワード化しないよう」）。Love駆動開発という言葉も、象の一部に触れた手の一つ。

## 3. 保持論点（急いで解かない）

- 「外から内へ」は一本の向きとして読めるが、外部環境の中にも人（利害関係者）がいて、起業家の心も環境に動かされる（pjdhiro「非二元的に見ると、それは環境がそうさせた、とも言える」）。外と内の区切りは観測の構えで、実在の分割ではない。
- 心理学との距離感（意志の錯覚・ひらめきの段階など）を表にどう入れるかは未着手（pjdhiro「経営学や心理学との距離感や位置付けは読者にとても有効な視点を与える」）。
- 権力学派（交渉と政治）は駆動源としては別だが、表を絞る方針で入れていない。
