## 体感のたとえ（pjdhiro の言葉）

> 欠損駆動思考とは、違う言い方をすれば、虚軸に値があって、しかも、認知上は 0 の直観です。

> 「考えて決める」だけの行動の軸と直交するように、存在の虚軸があるかもしれない。コサイン 90 度のような、ゼロの点。

## 読み方

- 「考えて決める」（行動・Doing）を一本の軸＝実軸とする。存在（Being）は、それと直角に立つもう一本の軸＝虚軸。
- 直角に立つ二本の軸は互いの上に影を落とさない（cos 90° ＝ 0）。**虚軸に値があっても、行動の軸の上では長さ 0 に測られる。**
- その「0 に測られるのに、値がある」を感じ取る直観が、欠損駆動思考。欠けているのは「何も無い」ことではなく、**測っている軸の上に射影がないこと**。
- 重力の井戸の絵に重ねると、中心の「引く力ゼロ」がその射影の 0。周りの軌道はその軸のまわりにできている（＝動かず、何もなく、自分からは見えないのに、すべてを回す中心）。

## 補強（2026-11-03・Q&A Filing・pjdhiro 承認）: 欠損への気づき＝ゼロの場所で湧く信号を「何？」と問うこと

出典: 対話録 `knowledge/notes/dialogue/2026-11-03-non-duality-love-gravity-signals.md` §3・§4（pd#138）。

> **pjdhiro**: 欠損駆動のコサイン 90 度はまさにその解説がしっくりくる。なぜゼロに虚軸を観れるのか？は、臍の緒の安定感は感じているから、というのは一つだし、全てかもしれない。だから as repo で生存と信頼の信号について追っていた。**その信号がゼロの場所で沸いてしまうとしたら何？と思うことが、欠損への気づき**だと思う。

- **認知は射影、体感は絶対値** [M]: cos 90°＝0 は、虚軸の値を行動の軸（実軸）に射影した長さ。認知は実軸しか読まないので 0 と出る。けれど体は、射影でなく値そのものの大きさ（「臍の緒の安定感」＝先が見えない何かにつながっている落ち着き）を受け取っている。虚軸を見ているのではなく、虚軸の値を受け取っている。だから「認知上は 0」と「安定を感じている」が同時に成り立つ。
- **ゼロの場所で湧く信号が、虚軸の値の証拠**: 実軸で 0 なら信号は湧かないはず。それでも湧くなら、どこかに値がある。見えないものを直接見るのでなく、見えない所から来る信号で、そこに何かあると知る（ブラックホールを周りの光で知るのと同じ検出の仕方・gravity-love 2章）。この問いの立て方が、欠損への気づき。
- **湧く信号の種類で、欠損の扱いが分かれる** [S]: ゼロの場所で湧くのが**生存の信号**なら、見えない先は脅威になり、不安になり、欠損は埋めるべき欠陥として扱われる。湧くのが**信頼の信号**なら、安定になり、欠損は源として観られる。欠損駆動（源として観る）と欠損回避（欠陥として埋める）は、同じゼロの場所でどちらの信号が湧くかの違い。信号の正本は awareness-space（帯×信号の表と神経現象学での検証設計は pd#139・as `evidence/review/2026-11-03-stage-band-x-signal-neurophenomenology.md`）。
- **先が見えないのに安定する理由**（三つの筋・Claude）: ①見えないのは欠けているからでなく、そこに乗っているから（見ている点は視野に現れない）②安定は知ることからでなく、つながっていることから来る（胎児は母を認識していないのに安定している・愛着の安全基地）③先が見えないことが不安になるのは、その先を「他」として見ているとき。切り離されていなければ、見えない先は自分が属している側。
- 正本の予定は変わらない: ks#215 で本論化したら ks を指す参照に縮める。

## 補強（2026-11-04・Q&A Filing・pjdhiro 承認）: 本質の見立て — 同じ法則と思うほど似ている、それでも問うのは構造の類似

出典: pd#144 の対話（Session 20261104-949）。本文の置き場所は `reader/love-driven-dev.html` の節「本質の見立て」。

- **pjdhiro の見立て**: 「抽象的には、そして本質的には、私は　物質を構成する波動と広い意味での愛は、同じ物理法則に従っているのではないか？という見立てです。　たとえるならば、重力や素粒子の波動が人体でも起きているかもしれない、などの。妄想ですが。」「脳神経に伝わる神経伝達物質とその後の信号処理は量子論的なことが起きてるのではないか。という意味です」「それを、心という解釈装置が、愛や感情として認知するように人間の認知と解釈ができている。」
- **問う構えは変わらない**: 「構造が似ているかを問う　というスタンスは変わりません。」「同じ法則なのではないかと思うほど似ていることがある。と思っています。同じ法則であったとしたら、むしろ信じやすいとも思っています。しかし、同じ法則であることを確かめようとしているわけではありません。」
- **研究の扱い**: 「他の研究は大いに参考にします。似ているかどうか？それがどのような現象と論拠かも気にします。でも私がそれらを論拠に演繹することはないです。」「全ての研究は一面であり、群盲象を評すようなことだと思うのが基本スタンスです。」「全ての論は条件付きで真理なのでしょうが、それは直接統合するのは難しいだろうと思います。」
- **このノートとの重なり（形の重なり・演繹ではない）**: 量子力学では状態は複素数の波で書かれ、粒子が見つかる確率は絶対値の二乗で決まる。波全体の位相は観測にかからないが、位相の差は干渉で現れる。重なるのは「位相そのものは、それだけでは数に出ないのに、重なると確かな違いを生む」振る舞いと「虚軸に値があって、認知上は 0」の形。〔2026-11-05 訂正：旧記述「観測で得られるのは絶対値の二乗だけ」「認知は射影、体感は絶対値と同じ形」は、観測＝絶対値が体感の側にあたり対応がねじれていた・位相の差は観測できる。読解テスト R2 の指摘・pd#144〕
- **心という解釈装置**: 体が受け取った大きさを、心が射影して愛や不安として読む。情動研究では構成主義的情動理論（Barrett）が近い（原典未照合）。
- **神経での量子の効果は未決着**: 提案（Hameroff & Penrose の微小管説・Fisher の核スピン説・イオンチャネルのコヒーレンスの計算）と、反対の見積もり（Tegmark の脱コヒーレンス）がある（いずれも原典未照合）。
