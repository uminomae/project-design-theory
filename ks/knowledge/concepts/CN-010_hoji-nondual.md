## 1. 概念の核心

> 同時に見ることでしょうね。抱持や包容は。非二元という意味でもあります。

（pjdhiro・2026-11-02・抱16）

抱持とは、実軸でゼロと測られていることと、虚軸に値があるかもしれないことを、どちらも消さずに見ていること。二軸のまま同時に見る。この意味で非二元。

## 2. なぜこの概念が必要か

- 抱持と非二元性を本人が直接つないだのは抱16 が初めて。それまで正本（`core-definitions.md`）の抱持は「誤差を問いとして保持する機能」で、非二元の語はなかった
- 発達段階の自己観察（techo・2026-10-25）で本人が確定した非二元性の基準（pd スクリーナー §8 参照体系 7）を、抱持の記述に接続する置き場が要る
- 「非二元」の語は誤解されやすい（「一つになる」と取り違えられる）。弁別を置く

非二元性の基準（本人確定・2026-10-24・pd スクリーナー）: 「二つでない」であって「一つになる」ではない。区別は保たれたまま、切り離されていない。6.0 の形＝限りのなさと日常が二つに並ばず行き来／6.5 の形＝目撃するものとされる層の相互浸透／除外＝区別が消えて一つになる。

## 4. 誤解されやすいポイント

| 誤解 | 弁別 |
|------|------|
| 非二元＝一つになる・区別が消える | 「二つでない」であって「一つになる」ではない。実軸と虚軸の区別は消えない。消せば抱持ではない |
| 抱持＝見えてから抱く | 識別できないまま包容することも含まれる（抱17）。見えないまま抱く時間がある |
| 抱持の場合は二つ | 二つの場合があり、それ以外もある（抱18）。二つに限らない |
| 悪い保持＝抱持の弱い形 | 悪い保ち方は執着・信仰のように囚われること（抱19）。問いでなく閉じた結論を保っている。草案 v0.4 の推論では一軸化の出口（抱13 の入口と対） |
| 抱持の反対＝忘れる | 抱持が終わる道は二つ（決める／忘れる。草案 v0.4 の推論）。記憶は保つ力の候補（抱11） |
| 抱持は 6.0 か 6.5 かに当たる | 書かない。段階を評価軸にしない（位16 ④・本人同意）。抱持がどの段階かの本人の言葉はない |
| 非二元を看板にする | 本人は非二元の語を中核の論でほとんど使わない（techo「とらわれない自然体」）。本ノートでも語を掲げず、見え方の構造として書く |

## 8. 保持論点

1. 「同時に見る」と「識別できないまま包容する」の前後と、それ以外の場合（抱18）
2. 悪い保ち方（囚われる）が「安易に正解という二元に陥る」（抱17）と同じ動きか。草案 v0.4 の推論（一軸化の出口）が線引きの内か外か
3. 抱持と発達段階の対応は書かない。S26 のマッチング仮説（同じか二つ離れた段階で保持が成立）との関係も書かない
4. シーヤー（止観する私）の在不在と違和感が湧くタイミング（CN-009 §8-13）
