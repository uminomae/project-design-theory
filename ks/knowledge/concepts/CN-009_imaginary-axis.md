## 1. 概念の核心

> 虚軸に値があって、しかも、認知上は 0 の直観

（pjdhiro・2026-11-01）

定義ではない。定義「棄却される誤差を、問いとして拾う態度」と同じタイミングで起きることの、違う言い方・違う視点（pjdhiro）。

## 2. なぜこの概念が必要か

- 2025-06 の三投稿にあった「虚軸・直交する軸・ゼロの点」の筋には、本論の中に受け皿がなかった（`knowledge/text/foundation/origin-2025-06.md` §0）。「スピノル＝回転の平方根」の筋が M2 五段階の「渦（Spinor）」へ流れたのに対し、こちらは落ちたままだった。
- 定義を変えずに、この表現と、その原体験を置く場所が要る。本ノートがその置き場。
- 定義と表現の関係は、まだ言葉にし得ない（pjdhiro）。関係を言語化前のまま保持する。これは `for-ai/preamble.md` §3（意図的に定義しきらない概念。表現しようとすることを精密に記述しつつ、不可知的側面を保持する）と同じ構え。

## 8. 保持論点

書かずに置くこと。pjdhiro の言葉を待つ。

1. 「垂直と水平」（神と人／罪と恥。06-12）と実軸／虚軸が同じ対とは限らない。
2. 虚軸と信頼軸（情動の構成の生存軸・信頼軸）は別の切り口。同じものと書かない。
3. cos 90° は比喩か本質か決めない。
4. 定義「棄却される誤差を、問いとして拾う態度」と表現「虚軸に値があって、しかも、認知上は 0 の直観」の関係は言語化前。並べて置くだけ。
5. 3D 表現（`docs/CONCEPT.md`。ゼロの中心・直交を視覚にするか）は別 Issue。
6. project-design（pd 5章のリンク替え）・creation-space（M2「渦（Spinor）」の筋）との境界。
7. 二つの論が並ぶとき（生の意味／視点、前反省的／反省的、解消欲求／関心、保つ／探索。`docs/issues/ISS-216-candidate-survey.md` §4）は、どちらかに決めず、同時に起きるとも書かない。「いろんな場合がある」として両方を調べて追い続ける（§5 の 2026-11-02 の言葉、位11）。この態度と定義「棄却される誤差を、問いとして拾う態度」は同じ向きに見えるが、対応づけは書かない。
8. 欠損（予想と現実の誤差）と、Frankl の noö-dynamics のような「現在と為すべきこと（ought）」の差は別（§5 の 2026-11-02 の言葉、抱14）。pjdhiro の語「脳のモデルの予測誤差」と「幼児でも認識可能なレベルの時間軸」のどちらに何が属するかは、本人の言葉を待つ。候補調査の表（`docs/issues/ISS-216-candidate-survey.md` §7-1・§7-2）は層の違いの記録として読む。〔2026-11-10 の追記：pjdhiro は、脳のモデルの予測誤差（意識し得ないレベル・ミリ秒から一秒ほど）と、欠損の話で使う「予想」「誤差」を厳密に分けるよう言った（「予想と誤差は欠損駆動でも使う言葉なので、そこは厳密に分けて」）。欠損の側の誤差は、気づける長さの話で、定義の芯から下ろして補足にした。Frankl の差がどちらに属するかは、まだ本人の言葉を待つ〕
9. 「違和感」の定義は「言語化できない感覚的なもの」（§5 の 2026-11-02 の言葉、位12）。cos 90° の感覚をデザイン思考側の語で言うときの判定基準は、「違和感」という語が文献にあるかではなく、起点に持ち込まれるものが言語化できない直感・感覚・感情かどうか。既存の論（Schön・Dorst・Peirce・Cross・Lawson）をこの基準で読み直すのは #216 の採点後。「違和感＝欠損」とは書かない。
10. 欠損の定義の文（§5 の 2026-11-02 の言葉、定15）と、旧定義「予想と現実の誤差を、意識が「欠け」として捉えた主観的経験」の関係。構図（実軸でゼロ → 虚軸で意味）と体験（違和感や欠けを感じること）は並べて置く。2026-11-03 に正本を仮説的定義に言い直した（旧定義は併記）。神経現象学側（awareness-space#149）の結果で更新する。〔2026-11-10 の追記：pjdhiro は、虚軸のたとえ・定15・定2・ゼロの場所で湧く信号への問い・引き寄せられる方向の五つを並べた問いに、五つとも選んで「どれもあってます。」。正本は五つを面として並べる形にした（`schema/core-definitions.md`）。五つの関係は、並べて置くだけ〕
11. 虚軸は「記号で表現すると最もしっくりくる概念」で、比喩でしかないかもしれず、本質かもしれない（定18・定17）。実在の主張として書かない。定義は仮説的な定義（足場）。
12. 「ゼロですら虚軸の可能性を持つ」（定19）。「どのゼロに値があるか」の基準は立てない。失われるのは「ゼロはゼロ」と短絡的に決めること。「欠損駆動思考は虚軸の欠損」で全てか、見落としがあるか（定16）は開いたまま。
13. シーヤー（本人の語。止観する私）が想起・ぼーっとで居なくなり夢では居る非対称（techo `logs/2026-10-25-ego-development-self-observation.md`）と、違和感が「湧く」タイミングに関係があるか。違和感に気づくのはシーヤーが戻った瞬間か、居ない間にも湧いているか。本人「わからない」（2026-11-02・Session 20261102-198）。言葉で決めず、自己観察の記録で貯める。
14. 抱持の二つの場合（二軸のまま同時に見る／識別できないまま包容する。抱16・抱17）の前後と、それ以外の場合（抱18「それ以外もあるだろう」）。CN-010 §8-1。
15. 悪い保ち方（執着・信仰のように囚われる。抱19）が「安易に正解という二元に陥る」（抱17）と同じ動きか。草案 v0.4 の推論（一軸化の出口）が線引きの内か外か。
16. 「ゼロと測る軸は測る側の構造で決まる」（位16 ①・Claude の読み・本人同意）の置き場。草案 v0.4 では II-1 に推論として置き、仮説の表にも一行。本人の言葉を待つ。
