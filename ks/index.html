欠損駆動思考

Love駆動開発の読み物は、構想の手前で動いているものを、それに動かされているものの側から書いています。欠損駆動思考は、その探究の一つです。

このページの問いは、記号の上では 0 と出るところで、人は何を感じているのか、です。考えや心と、体で湧く信号とが離れるとき、人は何かが欠けていると感じるのかもしれません。その欠けを、すぐに解かずに問いのまま持つ構えを、欠損駆動思考と呼んでいます。

この探究の問い — Love駆動開発の、輪郭を指す指

構想や設計や計画のいちばん最初には、何かが欠けているという感じがあります。このページは、その感じがどこで生まれるのかを見ます。

詳しく — 月を指す指

仏教には、指月のたとえがあります。月を指し示す指は、月そのものではない、というたとえです。Love駆動開発の読み物は、Love と呼びたいものを月にたとえ、そこに並ぶ言葉や仮説を、月を指す指として置いています。欠損駆動思考も、その指の一本です。

Love駆動開発の読み物では、言葉や記号で切り取れるのは、波間に見えた渦のほうだ、と書いています。「意識とは」は、人が何で世界を切り取っているかを見ています。このページは、切り取った渦の輪郭のところを見ます。記号の上では 0 と出るのに、体が何かを受け取っているところです。

欠けは、受け身で感じてしまう — 考えや心と、体で湧く信号とが離れるとき

欠損は、予想と現実の誤差を、意識が「欠け」として捉えた主観的経験です。考えや心と、体で湧く信号とが離れるとき、人は何かが欠けていると感じやすくなる、と pjdhiro は見ています。Love と呼びたいものが駆動しているから、人は受け身でこの欠けを感じてしまうのかもしれません。

詳しく — 信号の見込みと、経験とのずれ

「意識とは」は、人は生き延びられるか（生存）と、つながっていられるか（信頼）の二つの値を見込んで、世界を切り取っているのかもしれない、と置いています。その見込みと経験がずれたときに、ずれが欠けとして感じられるのかもしれません。

予想と現実のずれは、多くの場合「間違い」として片づけられます。まだ見えていないものがあるのではないか、と受け取ったとき、ずれは欠損になります。

切り取った輪郭のところに、まだ何かある — 虚軸に値があって、認知上は 0 の直観

pjdhiro のたとえ：欠損駆動思考と呼んでいる私の体感をたとえるなら、虚軸に値があって、しかも、認知上は 0 の直観です。

直角に立つ軸の値は、もとの軸の上で測ると 0 になります。地図の上から高さを測ると、どれほど高い山でも 0 と出るのと似ています。

pjdhiro のもう一つのたとえ：または、質量で歪んだ方向に吸い寄せられるように感じる信号とのギャップ。

pjdhiro の見方：実存主義的な i や、無意味さは、コサイン 90 度だと思います。実軸では無意味。でも。

詳しく — 虚軸と、0 と出る値

虚軸は、回転の掛け算から来た言葉です。数に −1 を掛けると、向きが反対になります。数直線の上で 180 度回したことになります。2 回掛けると −1 になる数を i と書き、i を 1 回掛けると 90 度回ります。i の付いた数が並ぶ軸は、もとの数直線と直角に立ちます。これが虚軸です。

90 度の向きにある長さを、もとの軸に映すと、長さにコサイン 90 度を掛けた値になります。コサイン 90 度は 0 なので、どれほど長くても 0 と出ます。

pjdhiro は、「考えて決める」行動の軸と直角に、存在の軸が立っているかもしれない、と見ています。言葉や数値の記号は、「考えて決める」軸の上に並ぶものです。

詳しく — 質量で歪んだ方向に、吸い寄せられる

Love駆動開発の読み物は、Love を重力に似たものとして見ています。そこでは、重力を重力場として見ます。重力場は、質量のまわりで歪みます。一般相対性理論では、星も光も、その重力場の中にいて、歪みに沿って進みます。中にいるものには、歪みそのものは目では見えません。

体で湧く信号が、見えない歪みの方へ吸い寄せられるように感じられるとき、考えや心が向いている方とのあいだに、ギャップが生まれる、と読むこともできます。

問いのまま持つ — 抱持

抱持は、反射的に処理せず、誤差を問いとして持ち続けることです。欠損に気づいたとき、すぐに答えを出さず、まだ分からないという状態にとどまります。違和感をすぐに解かずに抱えておくと、一つの面だけに縛られた判断を、しにくくなるのかもしれません。

詳しく — 抱えておくことを支えるもの

抱持には、支えになる環境や関係が要ります。安心できる場、問いを分け合える相手、立ち返れる記録が、その足場になります。

欠けから、構想や設計が始まる — その先は、経営学が扱ってきた範囲

欠けは、やがて解くべき問題になります。pjdhiro は、構想や設計や計画はここから始まり、その先の問題解決は経営学がこれまで扱ってきた範囲だと見ています。欠損駆動思考は、その手前で、欠けを問いとして拾う構えです。

詳しく — デザイン思考やプロジェクトマネジメントの作法と並べると

デザイン思考は、ユーザーへの共感を起点に、課題の定義、アイデアの創出、プロトタイプの検証を繰り返す、問題解決の進め方です。プロジェクトマネジメントは、目的を定め、計画を立て、進み具合を確かめて直していく作法を積み上げてきました。どちらも、解くべき問題がある程度の形をとってから、よく効きます。

欠損駆動思考が見るのは、問題が形をとる前の、欠けの感じです。プロジェクトの場面でいえば、まだ言葉にならない要件や、弱い兆し、説明しにくい停滞がその例です。同じことは、一人の中でも、人の集まりでも、社会でも起きます。

まだ分からないこと — なぜ 0 のところに何かを感じるのか

記号の上では 0 と出るところに、なぜ何かを感じるのかは、まだ分かっていません。

pjdhiro の見方：なぜゼロに虚軸を観れるのか？は、臍の緒の安定感は感じているから、というのは一つだし、全てかもしれない。だから「意識とは」で生存と信頼の信号について追っていた。その信号がゼロの場所で湧いてしまうとしたら何？と思うことが、欠損への気づきだと思う。

詳しく — 臍の緒の安定感

pjdhiro の体験：メタ認知の最終でウロボロスのように見る私と見られる私が生まれる時、そこにしっくり感はなくて、どちらかというと見る私とは別の、頭頂の先の臍の緒のようなケーブルの先に宇宙のような安定感をあたえる何か、存在があるかのような感覚がある。

この安定感と、生存と信頼の信号については、「意識とは」で追っています。
