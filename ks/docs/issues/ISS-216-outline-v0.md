## 4. 機構 — 違和感が立ち、気になり、保つ

定12 の三段と、本人の訂正（抱11）に沿って四つの小節に分ける。各小節は「本人の言葉」＋「照合済みの候補」で、機構を Claude が組み立てない。

### 4-1. 信号が立つ（気づきの部品。定義は as#149）

**本文**
- 「意識にのぼる信号は、予測と誤差がある場合に立つ。認知される。という意味です。それは　気づきの部品だろう、という推測です」（抱11・原文）。**気づきと抱持は別概念**（抱10 追記）。気づきの定義は awareness-space#149 で立てる。ここでは「部品」の推測として置き、定義しない
- 照合済み（統合表 §0-0）: 予測処理の主流は「意識内容＝予測側」で、誤差そのものを意識するとは言わない。precision が注意の向きを決める（Feldman & Friston 2010）。「誤差が意識化を駆動する」側は主流と近く、「誤差が意識の内容になる」側は違う。→ 本文にはこの差を書き、どちらが正しいかは書かない

**仮説**: 欠7「予測誤差を超えたものだけが体験されるのではないか？という仮説。それは神経現象学が証明してくれるだろう」（原文）→ 節 6

**テスト文**: 抱10・抱11

### 4-2. 違和感 → 気になる → 探索したくなる（駆動）

**本文**
- 本人の文は 定12 のみ。「探索したくなる」は解消欲求と関心の両方（§8-1 #3「両方」）。場合分けのまま並べる（位11）
- 照合済みの候補（統合表 §1 定12 表・§2）: 「0 のはずなのに」に近いのは Polanyi（隠れた一貫性への intimation）・Sartre（不在が知覚に「ある」）・Heidegger §16（故障で連関が見える）。「気になって探索」に近いのは Dewey の felt difficulty・Peirce の abduction・Loewenstein の information gap・Berlyne の conceptual conflict・Friston の epistemic value。**両段を一つで言う論は見つかっていない**（§2）
- gap の内容が認識されていないのに感じだけがある状態の最近接は Koriat の noetic feelings（§7-2）。ただし round 3 で、Koriat・Hart・Polanyi・Litman D-type・Frankl のいずれも「欠けがあることは自覚された上での感じ」と確認。「欠けを予測していない状態」を正面から書く候補は未発見（critic r3）
- 実存主義側の「別軸に意味がある」（定11）に直接なのは Tillich（無意味さを受け入れる行為自体が意味ある行為。1952 p.176）と Nagel（視点の二重性）。「別軸」の中身は違う（§0-1）。定11 の「意味」は両方・まだ決めない（§4 の答え）

**仮説**: 創7「創造プロセス自体が何で生み出されているのかは謎…ラブが駆動させているかもしれない。ラブとは謎」（原文）→ 節 6。pd の問い「愛は重力と似てないか」は踏み台として参照のみ

**テスト文**: 定11・定12・位10・位11

### 4-3. 保つ（抱持）— 何が必要か

**本文**
- 「その後に、その信号を抱持するのは忍耐力や興味といった心理エネルギーや頭脳の記憶が必要だろう」（抱11・推測）。「保つために、何が必要なのかわかりません。一般的には脳みそでの記憶力とされると思いますが、心理的な興味関心、性格的なものなど、他にもありそうです」（抱12・原文）。**答えで埋めない**。四方向（記憶／興味・関心／性格／関係）に候補を並べる（統合表 §7-3）。訓練・習慣は「性格」の方向の中（§8-1 #8「含む」）
- 「忍耐力」は耐性全て（§8-1 #5）。候補 4 語（Keats の negative capability／Rosenzweig の frustration tolerance／Schnitker の patience／Duckworth の grit）はどれも「保つ対象」が 抱11 の「信号」と一致しない。最近接は決めない（§0-9）
- 「保つ」の名前つき既存論（§7-1）: Dewey の maintain the state of doubt、Frankl の noö-dynamics、Jaspers の限界状況、Camus の反抗、Tillich の accept、d.school Bootleg の hold the tension（POV 文の作法）。整理軸の動詞は原語。どれが抱持に当たるかは決めない。**保つ担い手と対象が「予測と誤差」の信号と一致する論は round 3 までに無い**（§0-10）
- 「保つ」の語は二方向（critic r2）: 問い・緊張を保つ（抱持側）／閉じた結論を保つ（need for closure の permanence）。後者は抱持ではない

**仮説**: 抱5「一人で待てないのは仮説」／抱6「安定した心理が必要というのは持論。精神分析論や発達心理学からの発想。論理的に演繹したわけではない」→ 節 6

**テスト文**: 抱11・抱12
