## 3. 発言に反しない推論で導かれること（骨子の候補。線引き待ち）

各項は「推論 → 根拠の発言 → 反しないことの確認」。本文にはまだ入れていない（入れたものは明記）。

**推論 1. 構図と体験は、同じ出来事の二つの言い方**
定15（実軸でゼロ → 虚軸で意味があった）は構図の側、定2（違和感や欠けを感じること）は体験の側。定7「定義と表現は同じタイミングで起きること。言い方と視点が違うだけ」はこの二つにも当てはまると読める。→ v0.1 の §2 はこの読みで両方を並べた。反する発言なし。ただし定7 は「関係はまだ言葉にし得ない」とも言うので、「同じ出来事」と断定せず並べるにとどめた。

**推論 2. 欠損は「ゼロと定義する」操作を前提にする**
定15「ゼロだからゼロと定義されて」、定8「客観性の必要からゼロと言わざるを得ないために、見落とされる」、欠8「規格品に合わせるために粗く処理」。→ 欠損は純粋な知覚ではなく、実軸の認知の枠組み（誰かが・何かがゼロと定義すること）との関係で生じる。定14 の三つ（認知しづらかった／記号で表現しづらかった／価値観として受容されなかった）は、実軸が物事を処理する三つの面（認知する／記号で表す／価値づける）の失敗として読める。反する発言なし。本文には入れていない（穴 2）。

**推論 3. 欠損駆動思考の流れと、時制**
定15 の「実は虚軸で意味があった」は事後の言い方。現在時制で与えられるしるしは違和感（定12「ゼロのはずなのに違和感がある」）。→ 流れ: 実軸でゼロと定義される → 違和感（体験側のしるし）→ 抱持（切り捨てない）→ 探索 → 虚軸の意味が見つかる、または見つからない。本文 §2 駆動に「見つかることもあれば、見つからないこともある」と入れた。見つからなかった場合もそれを欠損と呼ぶかは、線引きが無い（穴 1）。

**推論 4. 抱持とは何をしないことか**
定15（ゼロと定義されたまま無意味扱い）と抱13（正解を一つにしたがる／早く結論を出してスッキリしたい）を並べると、保てない側＝違和感を実軸に潰し、ゼロのまま確定させること。→ 抱持＝ゼロと定義されたものを、ゼロのまま確定させない時間を作ること。反する発言なし。正本の定義文「反射的に処理せず、誤差を問いとして抱え保つ」と向きは同じで、対象が「誤差」から「ゼロと定義されたものへの違和感」に広がる（定3）。本文には入れていない（穴 7 と一緒に聞く）。

**推論 5. 出発点の問いと、欠損の定義がつながる**
定15 に「無意味・無価値のように扱われた」が入ったので、問1「無意味さは無意味なのか」は、欠損の定義を問いの形にしたものと読める。定11「cos 90° の 0 ＝無意味さ ＝別軸に意味がある」も同じ向き。ただし本人は問1 について「概念とどう関わっているのかが本人にも意味不明。曖昧」と言っている（問1 メモ）。→ 推論としてだけ置く。本文 §1 は「まだ言葉になっていません」のまま（穴 4）。

**推論 6. 信頼は、虚軸の値の一例かもしれない**
問3〜5 への答え（欠損駆動思考＝信頼という未定義の概念を見つけたり曖昧なまま扱うための思考方法）と、原6（虚軸＝感情・無意識・未体験）、定15（実軸でゼロ扱い → 虚軸で意味）。→ 信頼は実軸では測れずゼロ扱いされやすい、虚軸の値の一例と読める。反する発言なし。本文には入れていない（穴 5）。

**推論 7. 虚軸の中身と、実軸の失敗は対になる**
原6「根本には虚軸（感情・無意識・未体験）がある」と定14 の三つ。→ 感情・無意識・未体験（虚軸側にあるもの）が、認知しづらく・記号で表しづらく・価値として受け容れられない（実軸側の失敗）、と対にできる可能性。推論 2 の続き。原6 は 2025-06 の言葉で、今も虚軸の中身がそれかは未確認（穴 3）。

**推論 8. 気づきの部品と欠損の範囲は違う**
抱11「意識にのぼる信号は、予測と誤差がある場合に立つ。それは気づきの部品だろう」、定2「誤差は違和感の一つ」、定15（ゼロと定義されたもの＝予測すらされていないものを含む）。→ 予測誤差の信号は欠損の体験側の一部にすぎず、欠損は誤差の無い場面（ゼロと定義されたまま、予測されていない）にもありうる。これが 3-2 の「欠けの自覚なしの違和感」であり、先行研究が見つからない部分。awareness-space（気づき＝予測誤差側）と kesson-space（欠損＝ゼロと定義されたものへの違和感）の分担の根拠にもなる。反する発言なし。本文 3-2 に「ゼロだからゼロと定義されたものに、欠けの自覚なしに違和感だけがある状態」として入れた。

**推論 9. 虚軸は記号であって、存在の主張ではない**
定18「記号で表現すると虚軸の概念を使うのが最もしっくりくる。ただの比喩でしかないかもしれない」。→ 本論は虚軸を「もっともしっくりくる記号」として使い、実在を主張しない。したがって 4-1 の比較（Tillich の信仰／Nagel の視点）は、記号の選び方の比較であって、存在論の比較ではない。本文 4-1 に「この文章の『別の軸』は、虚軸という記号で書いています」と入れた。

**推論 10. 定義の身分と、正本の改訂の順序**
定18「神経現象学の知見を借りて仮説的に定義して足場としていくしかない」。→ 本論の定義文はすべて仮説のタグを持つ。正本 `core-definitions.md` の改訂は、この足場の上で、神経現象学側（as#149）の結果とともに行う。先に正本を書き換えない。反する発言なし。
