## II. 見えないものをゼロとする認知と、抱持（軸 ②。v0 4-3・4-4 を含む）

軸 ② の章。「ゼロとする認知」の側（誰が・何がゼロと定義するか）と、「抱持」の側（ゼロのまま確定させない）を一つの章に置く。順序は、ゼロとする認知 → 抱持 → 保てない側 → 保つために何が必要か。

### II-1. ゼロとする認知は、測る側の構造で決まる

**本文（Claude の読み・本人同意の印つき。置き場は本人の答え待ち＝議論ノート問い 4）**

### II-2. 抱持 — 二軸のまま同時に見る。識別できないまま包容する

**本文**
- 抱16（原文）「同時に見ることでしょうね。抱持や包容は。非二元という意味でもあります」。抱持・包容＝二軸のまま同時に見る＝非二元。本人が抱持と非二元性を直接つないだ唯一の文
- 抱17（原文）「非二元的なものを、曖昧なまま、識別できないまま、それでも包容することも含まれます。忍耐力やわからなさへの迷いの時間など（安易に正解という二元に陥らない）などを表します」。見えてから抱くのではなく、見えないまま抱く時間も抱持の中にある
- 抱18（原文）「二つの場合がある。それ以外もあるだろう」。「識別できないまま包容する」と「同時に見る」は二つの場合として並べてよいが、二つに限らない。相の前後は言っていない
- 非二元性の基準（pd スクリーナー §8 参照体系 7・本人確定 2026-10-24）を**定義でなく参照**として置く：非二元性は「二つでない」であって「一つになる」ではない。区別は保たれたまま、切り離されていない。→ 抱持は区別（実軸・虚軸）を消さない。「一つになる」と書かない
- 「複雑さ＝包容されていない微細さ」（techo・本人）は、包容の対象が微細なものであることの本人の言葉。本文に入れるかは採点後

**仮説**: なし

**テスト文**: 抱16・抱17・抱18・定3（対象は違和感）

**書かないこと**: 抱持が 6.0 か 6.5 か。抱持と STAGES の包摂の列（受け取る → 選ぶ → 両方を見る → 入り込み合う）の対応。どちらも本人の言葉がない
