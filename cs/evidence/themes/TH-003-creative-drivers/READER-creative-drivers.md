# 創造の駆動源は何？

「[創造とは](../)」は、創造を、場 → 波 → 縁 → 渦 → 束 の五つの段階で書いています。五段階は、物事が生まれるときに、どんな形と過程をたどるかを書いたものです。

このページは、その次の問いとして、何が創造を動かすのか（創造の駆動源）を見ます。

- **問い**：創造は、何に動かされて起きるのか。
- **今の見方**：今は、駆動源のうち、心理・思考・感覚という、人の内面の非物質的な面だけを見ています。三つは、陰陽のように分けづらい一組として見ています。
- **今のところ**：思考の面では、新しい考えを何が動かすかが、論ごとに違う面で書かれてきました。疑い・困りごと・驚き・目的の無い遊び・美の感覚・考えへの引き寄せです。感覚の面は、欠損駆動思考が、違和感から見ています。心理の面には、伝えたい要求と見つけられたくない要求の同居を書いた、ウィニコットの論文と、同じ二つの動機を自分を見つけたい思いの中に置いた、エニアグラムの型の記述を置いています。

## 一　問いと、今の見方

<a id="cd-question"></a>この章では、なぜ駆動源を問うのかと、今どこまでを見ているのかを置きます。

### 形の次に、駆動源を問う

五段階は、創造の形を書いています。けれど、形が分かっても、何がその形を動かしているのかは分かりません。創造とはの次に何を探るのかについて、pjdhiro はこう話しています。

> <strong>pjdhiro の見方：</strong>創造とはの次の探索は駆動源です。それはLoveかもしれません。なぜなら、Love駆動開発は人生や自己刷新など、創造のプロジェクト全般に適用できる汎用的なものを射程に入れているからです。

「[Love駆動開発と呼びたいもの](https://uminomae.github.io/project-design-theory/reader/love-driven-dev.html)」の読み物は、人やプロジェクトを動かしているもの（駆動源）が何かを探しています。プロジェクトは、創造の過程の一つの形とも言えます。ただ、ふつうは別のものとして扱われています。そこで、このページは、創造の駆動源を創造とはの側で追い、Love駆動開発の読み物とは、あとでつなぎます。駆動源は Love と呼びたいものかもしれない、という見立ては、そのときまで見立てとして持っておきます。

### 今は、人の内面の面だけを見る

駆動源は、人の内面だけにあるとは限りません。物理・化学・生物で、何が新しいものを生む向きに働くか、という物質の側の問いもあります。このページは、今はそちらを見ていません。見ているのは、心理・思考・感覚という、人の内面の非物質的な面だけです。

このページは、三つを面に分けて書きます。分けて書くことについて、pjdhiro はこう見ています。

> <strong>pjdhiro の見方：</strong>感覚と心理と思考はセットで☯️だと思うから、分けづらい。

分けて書くのは、読みやすくするためです。三つの面は、一つの動きを違う側から見たものとして並べます。たとえば、困りごとは、そのどれにも入ります。パースは、疑いを、落ち着かない、満たされない状態だと書き、その苛立ちが探究を起こす、と書きました。デューイは、考えの一続きの最初の段を、感じられた困りごと（a felt difficulty）と書いています。そう読むと、一つの困りごとが、感じられ、心を落ち着かなくさせ、考えを起こします。この読みは Claude のもので、二人がそう書いているわけではありません。

## 二　心理・思考・感覚の面

<a id="cd-aspects"></a>この章では、三つの面を順に見ます。三つは、上の章で見たように、分けづらい一組です。面ごとの節の違いは、同じ動きを、どの側から見ているかの違いです。

### 心理の面：伝えたいのと、見つけられたくないのが同居する

<a id="cd-psychology"></a>創る人を、何が創ることへ向かわせるのか。この面には、動機・性格・無意識・遊びから創造を見る論を置きます。今は、ウィニコットの論文と、エニアグラムの型の記述を置いています。ほかの論は工事中です。

精神分析家の D・W・ウィニコットは、論文「交流することと交流しないこと」（1962〜63 年に講演で読み、1965 年の論文集に収めた）で、芸術家についてこう書いています。どんな種類の芸術家にも、二つの傾きが同居することから来るジレンマが見て取れる。一つは、伝えたいという切迫した要求です。もう一つは、それよりさらに切迫した、見つけられたくない要求です。だから、芸術家が全身で取り組む仕事を終えることは考えられない、とも続けています。

この論文のもとには、ウィニコット自身の体験があります。稿を準備するうちに、思いがけず「交流しない権利」を言い張るところに来た、と書いています。それは、限りなく搾取されるという空想への、自分の芯からの抗議だった、と。

この同居を読んで、pjdhiro は、創造とはの五段階の縁にあたるのではないか、と問いました。

> <strong>pjdhiro の問い：</strong>「コミュニケーション」と「自己隠蔽」が縁じゃないか？

縁は、異質なものが出会い、ぶつかる境目です。ウィニコットの論文と縁の構造を並べると、似ているところと、似ていないところがあります。

似ているところは三つです。一つめに、二つの要求は、向きが違うまま一人の中にあり、ぶつかったまま仕事を続けさせます。二つめに、ウィニコットは、はっきり伝える交流と黙った交流の両端のあいだに、遊びから文化の体験へつながる中間の領域がある、と書いています。線でなく、幅のある領域です。三つめに、両端はどちらも居場所を持ったまま残る、と書いています。ここは、縁とほとんど同時に起きる渦（二つが見分けられるのに、一つであるかのよう）にも似ています。

似ていないところもあります。論文の中心は、誰とも交流しない芯を守ることです。ウィニコットは、健康な人にも決して交流しない芯があると書き、その芯に届いて変えてしまう交流を「自己に対する罪」と呼びました。縁は、嫌なことも外に置かずに含んで進みます。芯を衝突の外に置くところは、縁と向きが違います。また、交流は、衝突を通らずに、沈黙から自然に生まれることもある、とも書いています。

言葉にも違いがあります。原文で「隠す」（hiding）は、芯が脅かされたときの防衛として出てきます。健康な側は「見つけられない」「交流しない」と書かれています。「自己隠蔽」がどちらを指すかで、縁との似方は変わります。

この並べ方は Claude の見立てで、ウィニコットが五段階について書いているわけではありません。

<a id="cd-self-search"></a>エニアグラムの型の記述にも、同じ二つの動機が出てきます。リソとハドソンは、1996 年の本で、芸術や美に向かって生きる型（タイプ 4）の章の頭に、この芸術家のジレンマを、ウィニコットの言葉として引いています。そのうえで、自分を伝えることと隠すことは、誰もが持ちうる創る動機の二つだが、この型に特に当てはまる、と書きます。この型の人は自分が誰かを探していて、芸術や美に向かう生き方の中で、自分が誰で、自分の何が大事かを見つけたいと望む、という書き方です。

この記述を読んで、pjdhiro は次のように見ています。

> <strong>pjdhiro の見方：</strong>この対立が渦を生むという意味で大切なポイント

リソとハドソンは、同じ型に、向きの違う二つの要求の張り合いを、ほかにも書いています。自分を見つけるために自分に気づいていたい要求と、自意識に閉じ込められないために気づきを越えたい要求は、いつも張り合い、その張り合いは創造で解けうる、と書きます。霊感の瞬間には、逆説的に、いちばん自分であり、いちばん自分から自由である、とも書きます。感じたことを全部表せば恥をさらすおそれがあり、表さなければ終わりのない自己への没入に捕まる、という張り合いもあります。

渦は、二つが見分けられるのに、一つであるかのようにまとまることです。いちばん自分であり、いちばん自分から自由である、という霊感の瞬間の書き方は、二つが見分けられたまま一つであるかのようにまとまる、渦の形に似て見えます。同じ本は、張り合いから退いて内にこもると、創造は想像の中だけで起こるようになる、とも書いています。対立を外さずに抱えたまま、作る行いへ出ることが、渦が巻く条件にあたるのかもしれません。この並べ方は Claude の見立てで、リソとハドソンが五段階について書いているわけではありません。

### 思考の面：考えを、何が動かすか

<a id="cd-thinking"></a>新しい考えは、どこから来るのか。考えることを何が動かすかは、論ごとに違う面で書かれてきました。読み物「[創造的思考とは](https://uminomae.github.io/project-design-theory/reader/creative-thinking.html#ct-drivers)」で読んだ論から、駆動源にあたる記述を並べます。

<div class="tablefit cols-2">

| 疑いの苛立ち | パース 1877：疑いは落ち着かない状態で、その苛立ちが、信念へ至ろうとするもがき（探究）を起こす |
|---|---|
| 困りごと | デューイ 1910：考えることの起こりは、困ること・迷うこと・疑うこと。考えることは、ひとりでに燃え出すものではない |
| 驚き | パース 1908：探究は、不思議な現象の観察から起こる |
| 目的の無い遊び | パース 1908：目的を持たない心の遊び（ミュージング）の中から、探究の第一段階が始まる |
| 美の感覚 | ポアンカレ 1908：無意識が作る組み合わせのうち、美の感覚に触れるものだけが意識に上がる |
| 考えへの引き寄せ | パース 1893：心がその考えを持つ前から、考えそのものが心を引き寄せる。パースは、これを愛による発展と呼んだ |

</div>

並べると違って見えますが、共通するところがあります。どの論も、新しい考えが、意志の力だけで出てくるものではないと書いています。疑いも、困りごとも、驚きも、気づいたときにはもう起きています。ポアンカレの無意識の仕事も、パースの引き寄せも、自分の関与の外で進みます。

表には、思考の面と呼びにくいものも入っています。驚きや美の感覚は、感じるものです。疑いの苛立ちは、心の状態でもあります。考えを動かすものを並べると、感覚と心理が一緒に出てきます。

疑いや困りごとは、何かが欠けているところから押す面に見えます。引き寄せや美の感覚は、まだ持っていない何かが引く面に見えます。同じ一つの動きを、押す側から書いたか、引く側から書いたか、の違いかもしれません。この読みは Claude の見立てで、論者たちがそう書いているわけではありません。

### 感覚の面：違和感と、美の感覚

<a id="cd-sensing"></a>判断の手前で、何かを感じる。その感じが、創ることを動かしているのかもしれません。この面は、このページで書くより先に、ほかのページが見ています。

「[欠損駆動思考](https://uminomae.github.io/project-design-theory/ks/)」は、記号の上では 0 と出るところで、人は何を感じているのかを問います。欠けている感じや違和感を駆動源にする、思考や精神の構えを見る探究です。違和感がどこで立ち、どこで気づかれるのかは、「[違和感は、どこで立ち、どこで気づかれるのか](https://uminomae.github.io/project-design-theory/ks/signal-layers.html)」で見ています。

上の表のポアンカレの美の感覚は、ほかにどう書かれてきたかを、読み物「[美とは](https://uminomae.github.io/project-design-theory/reader/beauty.html#bt-sieve)」にまとめています。

感覚の面を、駆動源の側から並べて書くのは、これからです。

## 三　まだ論じていないこと

<a id="cd-open"></a>この章では、まだ論じていない問いを置きます。

- 心理の面：創る人を創ることへ向かわせる論を、どう並べるか。
- 物質の側：人の内面の外で、何が新しいものを生む向きに働くのか。
- 押す面と引く面：欠けが押す面と、まだ無いものが引く面は、一つの動きの両側なのか。
- Love との関わり：創造の駆動源は、Love駆動開発が Love と呼びたいものと、どこまで重なるのか。二つは、あとでつなぎます。
