## 4. 所見（9 本の原文から）

### 4.1 対照を弾いた理由は「縁」ではなく「創造」の前提
- 対照 4 件の棄却理由は 36 判定ほぼすべてが「新しく生じる過程を扱っていない」（決定論・演繹の順序・固定分類・不生不滅の原子）。段階 3 の定義で弾いた run はない。
- sonnet-r1 の課題 C が最も明示的: 「当てはまらないのは、第3段階の定義のせいではなく、『新しく生じる』という前提を満たさないからである。この判別力は、第3段階そのものではなく、モデル全体の『創造の過程』という前提に由来している」。
- 唯一の陽性（haiku-r3・N1 デモクリトス「部分的 / 4,5」）は「原子＝個（4）」「集まり＝集合（5）」の語の一致で、同じ run の注意欄が「原子は不生不滅で立ち上がらない＝段階 4 と逆向き」と自分で書いている。語の一致を判定に乗せるかどうかの閾値の問題で、haiku で閾値が低い。

### 4.2 縁（3）は「相互作用を含む論」に広く付く
- 9/9 が課題 C-2 で「危険あり」。付いた先は Whitehead（把握）・Connell（促進＝先住種の影響）・Koestler（枠の接触）・Tuckman（norming）で、内容は互いに異質。
- 複数 run が縁を反証可能にする限定を独立に提案した。opus-r1: (a) 段階 2 で生じた差の境界で起きる、(b) 段階 4 より前、(c) そこから新しい関係・法則が生じる。sonnet-r2: 「関係が個に先立って生成の場になる」と限定する。sonnet-r3: (a) 関係がそこで生じる、(b) 2 の後・4 の前に位置する。opus-r2: 「境界・関係・法則」という性格の違う三つが一段階に束ねられていて、一つ合えば対応と言えてしまう。
- 縁を飛ばす事例: Prigogine（P3）は 9/9 とも「2→4 直行」で縁を置かない（haiku-r1 のみ 3 を含む）。sonnet-r3: 「段階3が『必須の中間段階』ではない可能性を示す」。

### 4.3 採用済み anchor の側に出た緊張
- **Bohm（P2）が「個」と「境界」を否定している**: 9/9 が「渦を独立の実体とみなすな」「渦と流れに鋭い区分はない」を引いて、段階 4「個」・段階 3「境界」との食い違いを注意欄に書いた。判定は 9/9「部分的 / 1,4」で、P 群のうち唯一「対応あり」が 0。opus-r3: 「第3段階に対して最もはっきり反対している例」。
- **Simondon（P1）の前個体的実在は「無」ではない**: 5/9（haiku-r2/r3・sonnet-r3・opus-r1/r3）が、段階 1 の構造語「無」と Simondon の「潜在力に満ちた準安定・過飽和」の不一致を指摘。段階 1 の定義表の語「無」が anchor と衝突している。
- **束（5）は anchor から再構成されない**: P3 Prigogine で 5 を含んだ run は 0/9（W4b の留保「束側が再構成されるか」は否定的に決着）。5 が付いたのは Whitehead の客観的不死性（7/9）と Bertalanffy の階層（3/9・弱い）、デモクリトスの集合（語の一致・4/9）。opus-r1: 「第5段階（束）にはっきり対応すると判定した記述は一つもありません。第5段階は第3段階とは逆に、当てはまる論が見つかりにくい段階です」。

### 4.4 似非 2 件
- Tuckman（L1）: 9/9 が「部分的」止まりで、解散が逆向きであることを 8/9 が明言。「5 段階という数の一致が最大の罠」（opus-r2）。4 run（sonnet-r2・opus-r1/r2/r3）が、論文自身の「観察者にモデルの記述を渡して当てはめさせる設計は観察者バイアスに弱い」という批判が**この盲検そのものに当てはまる**と指摘した（§6 限界）。
- Kelvin（L2）: 8/9 が「語の一致」「過程は逆（渦は生成も消滅もしない）」を書いた。haiku-r3 だけが「対応あり / 4・確信度 高」。注意欄では「段階 4 を渦の出現と読むのは誤り」と書いており、判定と注意が矛盾している。

### 4.5 モデル差
- 事前期待からの逸脱 3 件はすべて haiku-r3（L2 対応あり・N1 部分的・N3 弱い）。sonnet・opus は対照 24/24 棄却、L2 は全て弱い〜部分的。
- opus は課題 B で老子（3/3）と Haken（2/3）を挙げ、「比喩語（場・縁）の選び方が東アジアの生成論の系譜」と読んだ。haiku・sonnet は資料内の 3 論（Simondon・Prigogine・Whitehead）に収束。
