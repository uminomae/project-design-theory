## 1. 目的

cs#262 が挙げた三つを、モデル全体について測る。

| 問い | 測り方 |
|---|---|
| **識別力**: 対照（対応しないはずの概念）をきちんと弾けるか | ネガティブコントロール 4 件の棄却率 |

## 2. 盲検の担保

- 回答者に渡すのは `prompt/task-*.md` に `prompt/concepts-*.md` を流し込んだ 1 本のプロンプトだけ。定義表は `knowledge/schema/five-stages.md` の 5 行（段階・名前・構造・プロセス・一行説明）で、**対応概念例は除去**（schema の Stage 4 例に Simondon が既載＝リーク源）。
- 概念記述は一次引用（cs source-note で原典確認済みのもののみ逐語）と史実の要約。「場・波・縁・渦・束」「段階」「創造の5段階」などモデル側の語彙は使わない（Bohm・Kelvin の「渦」は原典自身の語なので残す。W4b と同じ）。
- 回答者は W4b と同じく **Agent ツールのサブエージェント**（Claude のサブスク枠内。API キー経由の `claude -p` や外部モデルは使わない＝pjdhiro ルール 2026-11-02）。プロンプトに「ファイル読み・検索・ツール使用禁止」を明記し、結果報告のツール使用回数が 0 であることを記録する。
- 記述の順序は `build-prompt.py` が seed（モデル名＋試行番号）でシャッフルし「記述 A〜M」と匿名化。区分（P/C/L/N）と ID は回答者に見せない。対応表は `runs/*.map`。

## 4. 採点（事前登録）

各 run の末尾 JSON（judgment / stages / confidence）と本文から次を集計する。基準は実行前に固定した。

| 指標 | 定義 | 合格線 |
|---|---|---|
| **対照棄却率** | N1-N4 で「対応なし」または「弱い対応」の割合（全モデル・全 run） | ≥ 75%。「対応あり」が 1 件でも出たら、その根拠を個別に読む |
| **似非の検出率** | L1 が「終結／方向が逆」に言及、L2 が「表層的／こじつけ」に言及した割合 | ≥ 50% で「cs の判定を独立再現」 |
| **採用済みの再構成率** | P1-P3 が「対応あり／部分的」で、事前期待の段階を含む割合 | 参考値（独立確証ではない） |
| **第 3 段階割付率** | 全判定のうち stages に 3 を含む割合、および概念別 | 対照 N1-N4 のいずれかが 3 を含んだら「当てはまりすぎ」の直接証拠。候補・採用済みだけなら所見に留める |
| **独自性** | 課題 B で挙がった理論名の頻度表。シモンドンが挙がった割合。「違う点」の内容 | 記述でなく分布を報告。シモンドン率が高く「違う点」が薄ければ #263 の優先度を上げる |
| **一致度** | 概念ごとの最頻判定の割合（run 間・モデル間） | < 50% の概念は「記述が曖昧」か「対応が不安定」として個別に読む |

判定ラベルの読み替え: 「対応あり」「部分的に対応」を陽性、「弱い対応」「対応なし」を陰性とする。

## 6. 実行手順

```bash
cd evidence/falsification/blind-test-5stage
# seed = 試行ごとに固定（haiku: 101-103, sonnet: 201-203, opus: 301-303）
python3 -I build-prompt.py prompt/task-ja.md prompt/concepts-ja.md 101 runs/haiku-r1-prompt.md runs/haiku-r1.map
```

Main が `runs/{model}-r{n}-prompt.md` の全文を Agent ツール（該当 model、追加文脈なし）に渡し、返答をそのまま `runs/{model}-r{n}.md` に保存する（先頭にモデル・seed・ツール使用回数を記す）。

確認済み（2026-11-02）: 組み立てスクリプトは 13 記述を A〜M に展開する（≈ 24 KB）。

集計は `python3 -I score.py runs`（判定表・指標・一致度・キーワード抽出）で機械的に出し、似非の検出・課題 B・所見は原文を読んで `RESULTS.md` に起こす（判定表 13 概念 × run、指標 6 つ、所見）。run の原文は `runs/` にそのまま残す。

## 7. 限界（先に書いておく）

- 回答者は LLM であり、「人間の読み手」（cs#262 ②）の代わりにはならない。
- 概念記述を書いたのは対応づけを知っている Main（Claude）であり、記述の選び方・要約の仕方に偏りが入りうる。逐語引用の比率を上げ、要約のみの記述には〔要約〕と明記して区別した。
- 対照 4 件は「対応しないはず」と cs が選んだもので、対照の妥当性自体はモデル外の判断。
- Claude 系 3 モデルは同じ訓練系列であり、独立性は限定的。Claude 以外の回答者は経路未定（§5）。
- 定義表の日本語比喩語（場・波・縁・渦・束）そのものが、語の表面一致を誘う。これは W4b と同じ条件であり、Kelvin（L2）がその検出器になる。
